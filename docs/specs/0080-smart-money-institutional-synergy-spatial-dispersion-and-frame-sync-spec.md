# 需求規格說明書 (PRD #0080)：聰明錢二維空間正交排斥散度、時序影格圖卡即時同步與機構共振決策系統

## Problem Statement (問題陳述)

經由使用者實際操作與專業投資經理人視角檢視，現行「聰明錢觀察儀」存在三項嚴重的介面體驗、時序資料偏誤與金融計算失真問題：

1. **水平死線穿透與大球遮蔽小球 (Horizontal Line Collapse & Small Bubble Occlusion - 照片 1)**：
   - 泡泡 Y 軸坐標在時序軌跡轉換時，因買賣超張數上限計算失真，被全數打平在頂部天花板（$Y = +75$）與底部地板（$Y = -75$），像烤肉串般水平排列在同一條高度線上。
   - 由於缺乏垂直 Y 軸推開空間，排斥演算法只能在單一維度往左右硬擠，導致半徑較大的權值泡泡直接將相鄰的小泡泡完全吞噬覆蓋，使用者無法辨識也無法以滑鼠點擊被遮蔽的小標的，造成嚴重的資訊遺漏。
2. **時序圖卡資訊脫節與未來資料偏誤 (Temporal Tooltip Lookahead Bias - 照片 2)**：
   - 時間軸播放器推進至特定歷史日期（如第 1 天、第 2 天）時，泡泡雖然在位移，但滑鼠懸浮或選中彈出的圖卡（Tooltip）內之價格變動 %、外資/投信/自營商買賣超張數與大白話診斷結論，**完全鎖死在最後一天的最新數據**。
   - 使用者無法理解該股票在特定日期為何會出現在該象限，破壞了時序回放複盤的邏輯一致性。
3. **金融計算失真：絕對張數盲點與土洋對作抹殺 (Financial Model Distortion)**：
   - **絕對張數失真**：台積電買超 1,000 張（佔比極微）與中小型股買超 1,000 張（主力鎖碼 30% 成交量）在舊演算法中權重相同，缺乏成交量參與率（Volume Participation Rate）考量。
   - **土洋對作抹殺**：當外資大賣 10,000 張、本土投信大買 10,000 張時，單純代數相加等於 0，系統誤判為「進出平衡」，抹殺了台股最關鍵的內外資激烈對決與籌碼換手意涵。

## Solution (解決方案)

1. **二維空間正交蜂巢散度演算法 (2D Hexagonal Spatial Dispersion Engine)**：
   - 徹底消除單一水平線：依據法人籌碼深度與成交量參與率，產生具有垂直階梯差異的 Y 軸分佈（自然分佈於 $Y \in [15, 70]$）。
   - 在 `resolveBubbleCollisions` 排斥演算法中加入**正交垂直擾動向量**：當兩顆泡泡半徑重疊且水平相近時，同時在 X 軸與 Y 軸注入上下推開力，使重疊圓形在象限二維空間內自然形成蜂巢狀/晶格狀錯落排列。
   - **半徑適度收斂與小球置頂保護**：泡泡半徑收斂於 `18px ~ 36px`，並在渲染時確保**小泡泡優先置於頂層**，保證滑鼠 100% 能精確拾取與 Hover。
2. **時序影格圖卡即時同步系統 (Real-Time Temporal Tooltip Frame Sync)**：
   - 當滑鼠懸浮或固定選中某標的時，圖卡資訊嚴格與當前播放進度 `currentDateIndex` 即時綁定：
     - **當日漲跌幅**：提取該歷史日期之 `trail[currentDateIndex].changePercent`。
     - **當日法人進出張數**：提取該特定日期的外資、投信與三大法人當日買賣超數值。
     - **當日動態生活化診斷**：依據該股票在該日期的 $(X, Y)$ 象限位置，動態調用 `getBeginnerDiagnosis` 即時更新診斷標題與內文。
   - 播放器播放時，圖卡上的日期標籤、漲跌幅、買賣超張數與多空診斷隨時間軸即時連動跳動，達成 100% 時序複盤邏輯對齊。
3. **專業券商與基金經理人機構共振模型 (Institutional Synergy & Resonance Model)**：
   - 導入機構行為三態判定：
     - 🚀 **土洋合買（法人合力多頭共振）**：外資買超且投信同步買超，多頭動能最強。
     - ⚡ **土洋對作（內外資激烈換手）**：外資與投信方向相反且金額顯著，標記籌碼大換手，不被代數加總抹殺。
     - 💣 **土洋齊砍（法人合力出貨）**：外資與投信同步賣超，破位警示。
   - 將「成交量參與率」（買超張數 / 當日總成交量）納入評分，使中小型鎖碼飆股能獲得合理的機構關注度評分。

## User Stories (使用者故事)

1. 身為投資人，當我在星圖上觀察多檔股票時，我希望泡泡能在象限空間中錯落散開，而不是全部排在同一條死板水平線上，以便於每顆球都能清晰看見且容易用滑鼠點擊。
2. 身為重視微小標的的投資人，我希望小球不會被旁邊的大球遮蔽覆蓋，在滑鼠移入交疊區時能優先選中小球，以便於獲取完整市場情報無遺漏。
3. 身為使用時序播放器複盤的投資人，當時間軸推進時，我希望懸浮的圖卡數值（日期、漲跌幅、法人買賣超）能隨之即時跳動更新，以便於我深刻理解這檔股票在該時間點被歸類在此象限的原因。
4. 身為專業投資者，我希望系統能明確告訴我目前是「土洋合買」還是「土洋對作」，避免因為代數相加為零而錯過內外資籌碼大換手的重大行情。

## Implementation Decisions (實作決策)

1. **正交碰撞排斥迭代改進**：
   - 於 `smartMoneyEngine.ts` 的 `resolveBubbleCollisions` 中：
     若兩圓心 $\Delta y < 0.001$，除了給予 X 軸位移外，強制依據節點 ID 或奇偶性給予垂直正交位移 $\Delta y = (idx \% 2 === 0 ? 1 : -1) \times 12$，使同一條線上的多顆球自動上下錯開形成高低階梯。
2. **圖卡（Tooltip）時序影格計算輔助函數**：
   - 導出純函數 `getTemporalBubbleFrameData(bubble: SmartMoneyBubbleData, dateIndex: number)`：
     提取該特定時序點之 `date`, `changePercent`, `flowScore`, `quadrant`, `foreignNet`, `trustNet`, `dealerNet`，並重新生成對應之 `diagnosisTitle` 與 `diagnosisDetail`。
3. **機構共振標籤擴充**：
   - 於 `SmartMoneyBubbleData` 新增 `institutionalSynergy: 'DUAL_BUY' | 'TUG_OF_WAR' | 'DUAL_SELL' | 'NEUTRAL'`。
   - 在 Tooltip 中以彩色徽章醒目展示（如 `🚀 土洋合買抬轎`、`⚡ 土洋對作激戰`）。

## Testing Decisions (測試決策)

1. **2D 正交空間散度測試**：
   - 給定 5 顆初始坐標完全處於同一水平線（$Y = 70$）的重疊泡泡，排斥後驗證所有泡泡中心間距 $d \ge r_1 + r_2$，且至少有部分泡泡產生顯著的垂直 Y 軸位移（標準差 $\sigma_y > 5$），證明已打破水平單一線。
2. **時序影格資料抽取測試**：
   - 驗證 `getTemporalBubbleFrameData` 在 `dateIndex = 0` 與 `dateIndex = 2` 時，分別返回該日對應的特定漲跌幅、張數與診斷文字，且文字隨象限動態改變。
3. **土洋對作識別測試**：
   - 驗證外資賣超 5,000 張、投信買超 5,000 張時，`institutionalSynergy` 正確判定為 `TUG_OF_WAR`（土洋對作），且診斷文字正確提示籌碼對決換手，不被誤判為進出平衡。

## Out of Scope (範圍界定)

1. **分點券商進出明細 (Broker Branch Level Data)**：本期維持在三大法人整體與美股 CMF 層級，不延伸至特定券商分點（如富邦建國、美林松智）之微觀追蹤。
2. **自動下單交易串接**：本功能專注於籌碼星圖洞察與時序回放，不進行自動委託交易。
