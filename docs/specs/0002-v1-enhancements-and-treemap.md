# 產品需求規格說明書 (PRD): V1.1 增強功能、資產樹狀圖與個人化體驗

## Problem Statement (問題陳述)

在 V1 基礎版本完成後，投資者在實際記帳與檢視投資組合時，遇到以下進階體驗痛點：
1. **多標的視覺化維度單一**：現有的單純長條圖與進度條在持股標的增多（超過 5 檔）時，難以一眼兼顧「資產權重（面積）」與「未實現損益率（顏色）」的二維矩陣關係。
2. **交易錄入操作摩擦**：
   - 每次輸入股票代碼需手動完整鍵入，缺乏台美熱門標的快速選單與歷史標的記憶。
   - 台股手續費在各家券商普遍提供電子下單折扣（如 2.8 折、5 折、6 折），目前需投資人自行手動計算金額後覆寫，不夠直覺。
3. **文化與市場色彩習慣衝突**：亞洲/台股市場習慣「紅漲綠跌」，而美股與國際金融平台習慣「綠漲紅跌」，固定的顏色配置會造成習慣不同市場的投資人認知混亂。
4. **存股與長線指標維度不足**：缺乏「持股成本殖利率 (Yield on Cost, YoC)」計算，使長線存股族難以直觀評估相較於原始投入成本的現金流回報率。

## Solution (解決方案)

1. **原生互動式資產樹狀圖 (Squarified Treemap)**：
   - 以純 TypeScript + React + SVG 實作輕量高效的 Squarified 矩形切割演算法，零額外肥大圖表套件依賴。
   - 矩形面積大小代表個股佔總投資組合市值比例；顏色深淺與色系對應未實現損益率 (Unrealized PnL %)。
   - 支援 Glassmorphism 懸浮 Tooltip 與圖表視圖切換（樹狀圖 / 環形圖 / 配置長條圖）。
2. **智慧交易錄入與券商折數試算**：
   - 內建台美熱門標的字典（台積電、0050、00878、NVDA、AAPL、VOO、QQQ 等）並自動索引使用者歷史輸入標的，提供即時下拉選單建議。
   - 交易彈窗新增「手續費折扣」快捷選擇（不打折、6 折、5 折、2.8 折、自訂折數），自動換算台股手續費（底層 0.1425% × 折扣，支援最低 20 元閥值切換）。
   - 支援「連續記帳」模式，送出後清空數量但保留日期/市場，加速分批紀錄。
3. **漲跌色彩主題自由切換**：
   - 頂部工具列提供「🔴 紅漲 🟢 綠跌（台股習慣）」與「🟢 綠漲 🔴 跌（美股習慣）」切換按鈕。
   - 透過 CSS 變數全域動態連動，並持久化保存於 LocalStorage。
4. **持倉財務指標強化**：
   - 擴充會計計算引擎，針對每檔持股精確計算「累計領息總額」與「持股成本殖利率 (Yield on Cost = 累計股利 / 總買入成本)」。

## User Stories (使用者故事)

- **US-16 (資產樹狀圖視覺化)**：作為投資人，我希望能在儀表板以「資產樹狀圖 (Treemap)」檢視整體持倉，透過面積直觀感知重倉程度，透過色塊明暗一眼看出獲利與虧損分佈。
- **US-17 (圖表視圖彈性切換)**：作為使用者，我希望能自由在「樹狀圖」、「環形配置圖」與「權重長條圖」之間無縫切換。
- **US-18 (券商手續費折數試算)**：作為台股投資人，我希望在錄入買賣交易時能直接選擇或輸入券商折扣（如 2.8 折），系統自動精確算出應扣手續費。
- **US-19 (股票代碼智慧建議 Autosuggest)**：作為使用者，我在輸入股票代碼或名稱時，系統能跳出智慧選單供我快速點選，自動填入市場與代碼。
- **US-20 (漲跌色彩偏好切換)**：作為跨國投資人，我希望能一鍵切換「紅漲綠跌」或「綠漲紅跌」，系統所有損益數字與圖表顏色立即同步更新並在重新整理後維持偏好。
- **US-21 (持股成本殖利率 YoC)**：作為存股投資人，我希望在持倉列表中能看見每檔標的的「累計領息」與「成本殖利率 (Yield on Cost %)」，以評估現金流投報表現。

## Implementation Decisions (實作架構決策)

1. **樹狀圖演算法 (`src/utils/treemap.ts`)**：
   - 採用純數學 Squarified Treemap 演算法，將多檔持股遞迴切割為最接近黃金比例（長寬比接近 1）的矩形集合。
   - 輸出 `{ symbol, name, market, value, weight, pnlPercent, x, y, width, height }` 結構供 SVG 直繪。
2. **色彩主題管理 (`src/types/stock.ts` & `src/index.css`)**：
   - 擴充 CSS 變數 `--profit-color`, `--loss-color`, `--profit-bg`, `--loss-bg`。
   - 提供 `ColorThemeMode: 'taiwan' (紅漲綠跌) | 'international' (綠漲紅跌)`。
3. **計算核心擴充 (`src/engine/calculator.ts`)**：
   - `HoldingPosition` 新增 `totalDividends: number` 與 `yieldOnCostPercent: number`。
   - 新增手續費試算輔助函式 `calculateTaiwanFee(price, shares, discount, minFee)`。
4. **組件升級**：
   - 新增 `TreemapChart.tsx`。
   - 升級 `AllocationChart.tsx` 整合視圖切換器。
   - 升級 `TradeModal.tsx` 加入 Autosuggest 與折扣選擇器。
   - 升級 `HoldingsTable.tsx` 與 `SummaryCards.tsx` 展示 YoC 指標與動態色彩。

## Testing Decisions (測試架構決策)

1. **TDD 測試覆蓋 (`src/engine/calculator.test.ts` & `src/utils/treemap.test.ts`)**：
   - 測試券商折數計算精度（四捨五入與最低手續費 20 元處理）。
   - 測試持股成本殖利率 (YoC) 在多次買進與領息情境下的計算正確性。
   - 測試 Treemap 切割演算法在各邊界條件（單一持股、多持股、零市值、不均勻權重）下座標不超出容器 `[0, 0, 100, 100]`。
2. **驗證方式**：
   - Vitest 全量測試通過。
   - TypeScript 編譯零錯誤。
