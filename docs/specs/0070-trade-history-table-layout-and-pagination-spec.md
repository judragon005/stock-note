# PRD 0070: 歷史交易帳本排版優化與分頁控制系統規格 (Trade History Layout & Pagination Spec)

## 1. 概述 (Overview)
本規格旨在解決歷史交易帳本表格中因欄位寬度分配不均、表頭與內容非預期折行（如日期折行、類別徽章折行、手續費表頭折行）、數值欄位過寬而標的名稱/備註過窄等排版缺陷，並引入緊湊分頁控制機制（每頁 25 / 50 / 100 / 全量），大幅提升多筆歷史交易的瀏覽舒適度與操作體驗。

---

## 2. 核心問題與目標 (Problems & Objectives)

### 2.1 現存問題 (Problems)
1. **非預期折行**：日期（`2026-10-01` 變為兩行）、類別（`現金股利` 徽章折成兩行）、表頭（`手續費` 變 `手續/費`）。
2. **寬度權重分配失衡**：數值欄位右側留白過大，標的名稱與策略備註欄位空間受擠壓。
3. **資訊密度偏低**：單元格 Padding 偏大，導致水平滾動頻繁。
4. **缺乏分頁控制**：600+ 筆交易一次全渲染，長列表滾動尋找成本高。

### 2.2 達成目標 (Objectives)
1. **100% 零折行保證**：所有日期、類別、表頭、數值金額均採用 `whiteSpace: 'nowrap'` 與固定適配寬度。
2. **智慧欄位權重分配**：
   - 交易日期：`96px`
   - 類別：`80px`
   - 標的代碼/名稱：`minWidth: 140px`
   - 異動/成交股數：`90px` (靠右)
   - 單價/比例：`85px` (靠右)
   - 手續費：`60px` (靠右)
   - 稅費：`60px` (靠右)
   - 結算/退款金額：`120px` (靠右)
   - 策略標籤/備註：`minWidth: 160px` (彈性伸展)
   - 操作：`55px` (置中)
3. **現代深色毛玻璃分頁器 (Pagination HUD)**：
   - 支援 `25` / `50` / `100` / `ALL` 筆數切換。
   - 支援第 X 頁 / 共 Y 頁、上一頁、下一頁與快速跳轉。
   - 搜尋或篩選改變時自動安全重置回第 1 頁。

---

## 3. 使用者介面與互動設計 (UI/UX Design)

### 3.1 表格結構 (Table Layout)
- 容器採用 `table-layout: fixed` 或受控欄位寬度，消除瀏覽器自動計算導致的擠壓。
- 單元格 Padding 設為 `8px 8px` / `8px 10px`。

### 3.2 分頁控制器 (Pagination UI)
```
[ 顯示每頁: (25) (50) (100) (全部) ] ---------------- [ < 上一頁 ] [ 第 1 / 25 頁 ] [ 下一頁 > ] (共 605 筆)
```

---

## 4. 驗收標準 (Acceptance Criteria)
1. `2026-10-01`、`現金股利`、`手續費` 等文字在任何螢幕寬度下絕不折行。
2. 數值與金額靠右緊湊排列，代碼與策略標籤擁有充裕水平空間。
3. 分頁功能切換流暢，篩選時分頁狀態自動連動。
4. TypeScript 0 錯誤，單元測試 100% 通過。
