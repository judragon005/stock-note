# 0108. 肌肉書僮核心作戰指令看板與在庫持股限定賣出架構規格書 (Muscle Booker Top 3 Combat Command & Holding-Gated Sell Spec)

## 1. 問題意識與背景需求 (Problem Statement)

使用者在操作肌肉書僮動能雷達時，指出兩項實務交易的核心痛點：
1. **缺乏即刻聚焦的核心作戰指令 (Top 3 Action Directives)**：
   - 在「台股市值 50」等大型標的池中，篩選出的買進或賣出可能有多檔，投資人難以第一時間鎖定最精準、性價比最高的前 3 檔先鋒標的。
2. **未持有標的出現「建議賣出」屬於無效雜訊 (Spurious Sell Signals on Unowned Securities)**：
   - 現貨交易無法無券做空。若投資人庫存中根本沒有持有該檔股票，系統提示「建議賣出·破線停損」屬於無效雜訊。
   - 投資人真正需要的是：**「我有持有的股票中，究竟有沒有哪一檔跌破箱底、必須立即停損撤退？」**。若沒有持有，則不應列為賣出建議；若所有在庫持股均安全，應明確顯示「0 檔 · 持倉安全」。
3. **色彩主題必須支援「紅漲綠跌」與「綠漲紅跌」雙向切換**：
   - 台灣市場習慣「紅漲綠跌」，美股/國際習慣「綠漲紅跌」。若在 UI 中硬編碼綠買紅賣，切換到台灣模式時將造成嚴重視覺錯亂。因此買賣信號必須動態綁定 CSS 語意變數 `var(--gain-color)` 與 `var(--loss-color)`。

---

## 2. 解決方案與核心架構 (Proposed Architecture)

### 2.1 雙欄核心作戰指令看板 (Top 3 Directives Board)
- **位置**：配置於「實戰動作篩選列」與「三色操盤導航儀」之間。
- **左欄：確定建議買進前 3 檔 (Top 3 Confirmed Buy Items)**：
  - 條件：`action === 'BUY'` 且 `riskRewardRatioValue >= 2.0`。
  - 排序：按風益比數值由大到小（降序）排序，取前 3 檔。
  - 主題色：動態綁定 `var(--gain-color)`（台灣模式為紅、國際模式為綠）、`var(--gain-bg)`、`var(--gain-border)`。
  - 內容：排名序號、代碼、名稱、現價、防守價、金色火焰風益比標籤（`🔥 風益比 1:XR`）、突破訊號。
  - 空狀態：顯示「目前無符合風益比 $\ge$ 2.0 之買進標的，切勿追高」。
- **右欄：確定建議賣出前 3 檔 (Top 3 Confirmed Sell Items - Gated by Active Holdings)**：
  - 條件：**必須為在籍持股 (`shares > 0`)** 且技術判定為 `action === 'SELL'`（跌破箱底防守線或 20MA 下殺）。
  - 排序：依照跌破幅度最深者優先排序，取前 3 檔。
  - 主題色：動態綁定 `var(--loss-color)`（台灣模式為綠、國際模式為紅）、`var(--loss-bg)`、`var(--loss-border)`。
  - 內容：排名序號、代碼、名稱、現價、**「在庫持有：X 股」醒目標籤**、原防守線、破線停損原因。
  - 空狀態（持倉安全）：顯示「0 檔 · 🟢 目前在籍持股均在防守線之上，無持股需賣出 (持倉安全)」。

### 2.2 三色實戰導航儀在籍持股警戒標籤聯動
- 導航儀紅色欄位之賣出卡片，若該標的屬於使用者在庫持股，賦予醒目的 `🚨 在庫持股` 標籤，非持有者標註 `池內標的`。

---

## 3. 驗收標準 (Acceptance Criteria)

1. 買進前 3 檔清單完全過濾風益比 $< 2.0$ 之標的，且嚴格依風益比降序排列。
2. 賣出前 3 檔清單僅包含在籍持股（未持有之跌破標的 100% 排除）。
3. 當在庫持股無跌破時，賣出欄顯示 0 檔與安全盾牌健康提示。
4. 全面使用 `var(--gain-color)` 與 `var(--loss-color)`，切換色彩模式時即時聯動。
5. 全量單元測試 100% 通過，`npm run build` 0 型別錯誤。
