# 規格 0147：AI 主力戰情室新手白話決策字典與智能小視窗系統 (Spec 0147)

- **關聯 Issue**：[#117](https://github.com/judragon005/stock-note/issues/117)
- **狀態**：Approved / Ready for Agent

## Problem Statement

目前「AI 主力戰情室」整合了高度專業的量化技術指標、主力籌碼流向、統計路徑預測（Forecast Cone）與風險雷達矩陣等 18 大 Bento-Grid 卡片與頂部行情列。然而，這些面板充斥著專業金融與量化術語（例如：VWAP 主力成本、過手率、沖銷比例、年化漂移、能量多空比、神經網路語意評級等）。

對於非專業或零股票投資經驗的初學者（股市小白）而言：
1. **資訊門檻過高**：面對專業名詞無法直覺理解其本質含義與市場代表性。
2. **缺乏明確買賣行動指引**：即使看懂了數值（例如「主力成本 1,138 元，現價 1,240 元」或「隔日沖比例 35%」），依然不知道「到底現在該買進、觀望、還是該停損賣出」。
3. **無互動式即時提示**：缺乏隨指隨看、抗邊界遮擋、觸控友善的浮動小視窗（Tooltip），導致新手必須離開頁面自行 Google 查閱，嚴重中斷決策流程。

## Solution

建立專為股市初學者設計的**「三段式新手決策字典與智能小視窗系統」**：
1. **領域名詞單一真相字典 (`src/constants/aiForceGlossary.ts`)**：
   - 集中定義頁面中所有名詞的**白話比喻**（日常生活比喻，如批發商進貨、拔河、颱風路徑）、**指標含義**（統計物理本質）、以及**買賣操作指引**（明確區分：多方買訊條件、空方賣訊/逃命條件、觀望警戒條件）。
   - 支援**即時個股數據動態診斷函式**：接收當前股票現價、主力成本、隔日沖比例等數值，輸出專屬該檔個股當下狀態的白話結論（例如：「目前股價高於主力成本 8.9%，主力處於賺錢護盤區，屬偏多支撐狀態！」）。
2. **零外加相依性的輕量無障礙 Tooltip (`src/components/common/TermTooltip.tsx`)**：
   - 滑鼠懸停（Hover）即時浮現，支援行動設備點擊開關。
   - 關鍵字下方具備細微優雅的虛線底紋（`border-bottom: 1px dashed rgba(255,255,255,0.35)`），標題旁支援科技感 `ⓘ` 圖示。
   - **視窗邊界防遮擋保護 (Anti-Overflow & Smart Flip)**：自動計算 Viewport 與卡片邊界，靠右或靠底時自動翻轉，徹底杜絕跑版與被 Bento-Grid 卡片邊緣遮蔽。
   - 符合高對比深色玻璃擬態（Glassmorphism）與無障礙 `aria-describedby` 規範。
3. **全域覆蓋 18 大 Bento-Grid 卡片與頂部行情列**。

## User Stories & Acceptance Criteria

### User Story 1: 初學者白話秒懂
作為一名完全不懂股市的新手，當我將滑鼠懸停在任何專有名詞（如「主力成本」）或標題旁邊的 `ⓘ` 圖示時，我希望能看到用日常生活比喻解釋的白話說明，讓我在 3 秒內理解其背後原理。
- **AC 1.1**：小視窗必須清晰展示【💡 白話比喻】區塊，使用日常生動比喻（如批發進貨價、拔河力道）。
- **AC 1.2**：小視窗必須展示【📊 指標含義】區塊，簡潔說明該指標測量的核心市場行為。

### User Story 2: 一眼掌握買賣方向
作為一名需要做決策的投資人，我不只要知道名詞意思，更想知道看到這項數據時到底該「買」還是「賣」，因此我希望小視窗明確條列出買進與賣出的具體信號。
- **AC 2.1**：小視窗必須包含【🎯 買賣操作指引】區塊，以綠色/紅色/黃色醒目標記明確標示：
  - 🟢 **偏多買訊**：符合何種條件時代表多方強勢，可逢低買進或續抱。
  - 🔴 **偏空賣訊**：符合何種條件時代表風險升高，應果斷停損或減碼賣出。
  - 🟡 **觀望警戒**：何時應保持空手，切勿盲目追價。
- **AC 2.2**：針對具備動態數值的指標（如主力成本、隔日沖比例、多空能量比、評估總分），小視窗底端動態顯示【⚡ 當前個股診斷】，依據當前個股數據給出明確多空狀態結語。

### User Story 3: 完美無抖動與防邊界遮擋互動
作為一名盯盤使用者，在滑鼠移動觸發 Tooltip 時，我不希望畫面發生任何跳動（Layout Shift），也不希望小視窗被螢幕邊緣或卡片邊界切斷。
- **AC 3.1**：Tooltip 必須採用 Portal 或 Fixed/Absolute 浮層定位，觸發時原版面文字位置 100% 保持不動。
- **AC 3.2**：具備螢幕邊界自動偵測；當游標靠近螢幕右側時向左展開，靠近螢幕底端時向上翻轉，確保內容 100% 完整可視。
- **AC 3.3**：在行動裝置或觸控螢幕上，點擊名詞可切換開啟/關閉小視窗，點擊外部區域自動關閉。

## Data Contract & Implementation Architecture

### 1. 字典結構定義 (`src/constants/aiForceGlossary.ts`)

```typescript
export interface GlossaryEntry {
  id: string;
  term: string; // 繁體中文術語名稱
  enTerm?: string; // 英文術語
  metaphor: string; // 💡 白話比喻
  meaning: string; // 📊 指標含義
  buySignal: string; // 🟢 偏多買訊
  sellSignal: string; // 🔴 偏空賣訊
  neutralWarning?: string; // 🟡 觀望警戒
  dynamicVerdict?: (data: any) => string; // ⚡ 動態數值實時診斷
}

export type GlossaryDictionary = Record<string, GlossaryEntry>;
```

### 2. 涵蓋名詞全景索引表

1. **Header 行情指標**：開盤價、最高價、最低價、收盤價、成交量、成交筆數。
2. **01 主 K 線**：MA5/10/20/60 均線、高檔壓力區、主力成本、支撐區、KD 指標、MACD 指標、RSI 指標。
3. **02 AI 決策核心**：趨勢判斷、短線狀態、主力行為、籌碼結構、隔日沖風險、籌碼健康度、支撐區間、壓力區間、基準等級。
4. **03 多維度判讀**：法人、動態/趨勢、籌碼、流動性、波動、動能六維雷達、綜合評分與評級 (A/B/C/D)。
5. **04 AI 籌碼熱區圖**：壓力區、大量成交區、密集成交區、價平區、去撐區。
6. **05 風險雷達圖**：流動性風險、主動風險、隔日沖風險、法人風險、籌碼風險。
7. **06 累積型 AI 預測路徑**：上漲機率、震盪機率、下跌機率、年化漂移、未來預測路徑錐。
8. **07 主力成本結構分布圖**：20日 VWAP、核心成本、倉位成本、成本偏離乖離度。
9. **08 法人行為計量**：外資、投信、自營商、三大法人合計、20日累計買賣超。
10. **09 隔日沖風險分析**：主力賣出異常、籌碼過手率、沖銷比例、隔日回檔風險、日內波動率。
11. **10 AI 多空能量棒**：多方能量、空方能量、多空量能比。
12. **11 健康度綜合評估表**：籌碼健康度、技術結構度、資金動能度、波動風險度、法人支撐度。
13. **12 AI 主力動態信號判斷**：多步買進、主力買賣、追價意圖、波段賣出、紅綠燈號。
14. **13 台股市場情緒儀表板**：散戶情緒、法人情緒、主力情緒、情緒指針。
15. **14 AI 信心維度**：模型準確度、資料完整度、訊號穩定度、策略適用度。
16. **15 籌碼異動摘要**：外資/投信/自營商進出、三大法人微型走勢、短線籌碼結論。
17. **16 買賣力分布圖**：大戶買盤、散戶買盤、散戶賣盤。
18. **17 多空強度分布**：多方強度、空方強度、量能強度、信號等級。
19. **18 主力追蹤總評判 (MLP-AI)**：調節減碼、逢低吸籌、鎖碼推升、洗盤整理。

## Test & Quality Strategy

1. **單元測試 (Unit Tests)**：
   - `aiForceGlossary.test.ts`：驗證詞庫覆蓋所有 18 卡片關鍵詞，所有條目必備 `metaphor`、`meaning`、`buySignal`、`sellSignal` 欄位；驗證動態診斷計算函式之邊界與輸出正確性。
   - `TermTooltip.test.ts`：驗證 hover 觸發渲染、點擊切換、邊界翻轉計算（計算坐標超出 viewport 時 auto-flip）、無障礙 ARIA 標籤。
2. **整合回歸測試**：
   - 確保掛載 Tooltip 後，既有 18 張卡片與 Header 的既有單元測試（如 `KLineChartCard.test.ts` 等 36 份既有測試檔）100% 維持綠燈。
   - 確保 `npm test` 零報錯、`npm run build` TypeScript 0 錯誤。
