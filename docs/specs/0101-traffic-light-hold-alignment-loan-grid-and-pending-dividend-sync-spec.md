# PRD #0101: 三色導航儀動作歸併對齊、借貸卡片雙欄佈局與未到除息日預估股息動態重算規格書

## 1. 執行摘要 (Executive Summary)

本規格書針對使用者實盤操作回饋的三項核心問題，提供精確的工程架構修復與體驗升級：

1. **三色實戰操盤導航儀動作總數對齊**：將達瓦斯箱體常態震盪之 `HOLD`（區間觀望）標的歸併至黃燈（觀望待變／不碰）統計與篩選陣營中，使「建議買進 + 觀望待變 + 建議賣出」之加總與「全部標的」完全一致（解決 $10 + 4 + 1 = 15 \ne 16$ 數量漏洞）。
2. **股票質押與借款卡片雙欄響應式佈局**：重構「台股進行中股票質押與借款」卡片網格，設定最小寬度限制與兩欄約束，寬螢幕下最多並排 2 個卡片，解決 3 欄排列時卡片過窄、數據擠壓的問題。
3. **未到除息日預估股息依最新持股動態重算**：修復尚未到達除息日（`today < exDate`）時，因使用者後續買賣加減碼導致原先補登之預估股息 TradeRecord 與現金流水帳金額錯誤的缺陷，實現在除息日前自動依最新在庫持股動態重新計算預估股息金額與二代健保扣繳。

## 2. 功能規格與驗收條件 (Features & Acceptance Criteria)

### 功能 1：三色導航儀動作統計歸併對齊

- **業務邏輯**：
  - 紅黃綠三色燈號體系下：
    - 🟢 綠燈（`BUY`）：突破箱頂且 20MA 翻揚，或破底翻。
    - ⛔ 黃燈（`AVOID` / `HOLD` 觀望待變）：布林極致壓縮、20MA 壓頂，以及箱內常態震盪（原 HOLD）。
    - 🔴 紅燈（`SELL`）：跌破箱底防守線停損。
- **AC-1.1**：實戰動作篩選按鈕列中：
  - `buyItems.length + avoidItems.length + sellItems.length === scannedItems.length`。
  - 當點擊「⛔ 觀望不碰 / 觀望待變」時，篩選出的標的涵蓋布林壓縮、均線下彎與箱內震盪標的。
- **AC-1.2**：三色實戰操盤導航儀中，黃色區塊的標的數量與篩選按鈕數量完全一致，清單正確顯示該類別標的。

### 功能 2：借貸與股票質押卡片雙欄佈局

- **業務邏輯**：
  - 借貸與質押卡片包含大量即時維持率、應還本利和、設質明細與三個操作按鈕，寬度若低於 420px 會造成資訊緊湊與折行。
- **AC-2.1**：父容器在 1080p 或寬螢幕顯示時，一列最多只顯示 2 個進行中借貸卡片，絕對不排 3 個卡片。
- **AC-2.2**：在小螢幕（手機或窄視窗）下自適應降級為單欄 1 個卡片。

### 功能 3：未到除息日預估股息動態重算引擎

- **業務邏輯**：
  - 除權息的在籍持股嚴格以除息日前一日（`exDate - 1 day`）收盤為準。
  - 若 `today < exDate`（尚未到達除息日），投資人若在除息日前有任何加減碼交易，在籍持股尚未封定，必須依最新持股動態重新計算該除息之 `shares`、`cashAmount` 與法定稅費。
- **AC-3.1**：在 `syncTradesWithCashTransactions` 或交易儲存時，針對 `trade.type === 'DIVIDEND'` 且 `today < (trade.exDate || trade.date)` 之紀錄，動態檢查其 `shares` 是否符合除息日前一日最新累積在庫持股。
- **AC-3.2**：若持股發生改變，自動以最新持股動態重算其應發放金額與二代健保補充保費，現金流水帳本中對應的待交割股息流水金額立即同步更新。
- **AC-3.3**：若該標的在除息日前已全數清倉平倉（最新持股為 0），則該筆待交割股息金額動態調整為 0，避免無持股卻虛增股息現金流。

## 3. 非功能性需求與工程約束

- **TypeScript 0 錯誤**：全型別嚴格校驗，無 `any` 侵蝕。
- **Vitest 100% 綠燈**：現有 57 個測試套件與新增測試全面通過。
- **KISS 與效能**：動態重算僅作用於 `today < exDate` 之未到期股息，已到期歷史股息嚴格維持既有已發放紀錄，零歷史污染。
