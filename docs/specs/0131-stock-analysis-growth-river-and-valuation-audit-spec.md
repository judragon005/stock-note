## Problem Statement

使用者在「個股分析」工作區實盤檢視權值股（如台泥 1101）時，遭遇 5 項嚴重的數值異常與視覺混淆，導致量化模型與決策失真：

1. **成長率基期缺失被誤導為 0% 綠柱**：營收年增率等子分頁在 22Q1~22Q4 因資料庫起始日為 2022 年而缺乏 2021 年同期基期，系統直接輸出 `0%` 且渲染出 8% 高度的綠色柱體，誤導投資人為「零成長或營收持平」。
2. **極端爆發值壓扁正常季度走勢**：23Q2 營業毛利年增率出現 `+5326.2%` 天文數字，使用者無法判斷是否為程式抓錯或髒資料；且因缺乏離群值縮放防禦，導致其餘正常季度（如 +14.5%, +52.1%, -18.2%）全部被壓縮成微不可見的扁平死線。
3. **價值評估所有子頁面呈現虛擬假方塊**：點選「本益比評價」與「本益比河流圖」時，僅呈現 5 條固定 18% 高度之死板 CSS 藍色方塊，缺乏各季真實 TTM EPS 波動、無股價走勢折線、無現價落點標記；而「現金股利殖利率」、「平均現金股息殖利率」與「平均現金股息河流圖」三個子分頁全部導向同一個靜態 4.17% 框架，缺乏真實河流圖與安全邊際估值。
4. **自由現金流報酬率 (FCF Yield) 噴出 9135.81% 天文數字**：因底層計算引擎寫死發行股數為 1,000 萬股，台泥實際流通股數高達 75.3 億股，股數低估 753 倍，使得每股 FCF 被放大了 753 倍。
5. **DCF 現金流折現每股內在價值 28.5 萬元且折價 119 萬趴**：同樣因寫死股數，導致 2 兆元規模之企業自由現金流折現總值除以 1,000 萬股，每股內在價值暴衝至 285,283 元，折價幅度 1,193,554%，完全失去投資決策價值。

## Solution

從第一性原理與事實出發，建立具備自適應極端值防禦、動態股數推導與真實多階河流圖之專業量化估值體系：

1. **數據基期擴充與缺基期平整化**：
   - 擴充 FinMind API 查詢起始日起算至 `2021-01-01`，補齊 2022 年所需之 4 季基期資料。
   - 建立嚴格基期校驗：若無前期同期資料，數據標記為 `-`，柱狀圖高度歸零且以淺灰細線呈現，滑鼠懸停顯示「無前期同期基期資料」。
2. **歷史事實確認與離群值視覺封頂防禦 (Outlier Visual Capping)**：
   - 確認台泥 2023Q2 毛利暴增 `+5326.2%` 係因俄烏戰爭煤炭成本暴跌後之真實歷史回升（2022Q2 毛利 1.1 億回升至 2023Q2 之 59.8 億）。
   - 引入離群值自適應可視縮放：非離群季度以常態上限動態縮放展開，超過 200% 之離群柱體封頂於 100% 高度並標註 `⚡+5326.2%` 與低基期效應說明，兼顧真實數據與正常季度起伏。
3. **全面獨立重構 7 大價值評估子頁面與真實 SVG 河流圖**：
   - 以真實滾動近 4 季 TTM EPS、每股淨值 BVPS、平均現金股息作為基底。
   - 繪製具備 4 階漸層色彩的多邊形 SVG 帶狀河流圖（Area Bands），疊加現價基準線與最新落點光點。
   - 為本益比、淨值比、股息估價提供獨立之五檔階梯卡片、評價位階判定（便宜、合理、昂貴）與數據矩陣表。
4. **全市場動態流通股數推導引擎**：
   - 自資產負債表之股本 (`capitalStock / 10`) 動態推導真實流通股數，並以 `netIncome / eps` 作為次級備援。
   - FCF Yield 改以近 4 季 TTM FCF 計算，台泥收斂至正常之 5%~15% 區間；DCF 每股內在價值收斂至 30~45 元正常區間。

## User Stories

1. 作為價值投資人，我在檢視營收年增率時，希望能明確區分「持平 0%」與「缺乏前期基期」，以便做出客觀的營運成長判斷。
2. 作為量化分析師，我在觀察個股爆發性成長（如毛利年增率數千趴）時，希望能看到顯著的低基期提醒，同時其他正常季度的柱狀圖不要被壓平成一條直線。
3. 作為定存股投資人，我在點擊「本益比河流圖」時，希望能看見隨各季獲利上下波動的真實彩色河流通道與股價落點，以便一眼判斷目前股價處於偏低或昂貴區間。
4. 作為景氣循環股投資人，我在點擊「股價淨值比河流圖」時，希望能依據公司各季真實每股淨值 (BVPS) 檢視股價是否跌破淨值（PB < 1.0x）。
5. 作為存股族，我在點擊「平均現金股息河流圖」與「平均現金股息殖利率估價」時，希望能看見依 7% 便宜價、5% 合理價、3.5% 昂貴價反推之股價通道與安全邊際折溢價。
6. 作為重視現金流的投資者，我在查看「自由現金流報酬率 (FCF Yield)」時，希望能得到基於全市場真實流通股數推導的合理百分比（如 6%~12%），而非數千趴的天文數字。
7. 作為專業估值模型使用者，我在使用「DCF 現金流折現」與動態滑桿時，希望能看到合理的每股內在價值與真實折溢價，支援我的實質建倉決策。

## Implementation Decisions

### 1. 財務管線起算日擴充 (`taiwanFinancialPipeline.ts`)
- 將 `fetchTaiwanQuarterlyFinancials` 內部 `fetchDataset` 之 `start_date` 統一由 `2022-01-01` 擴充至 `2021-01-01`。
- 賦予 2022Q1~2022Q4 充足的前一年同期數據，使四年歷史 YoY 全面具備實質基期。

### 2. 極端值自適應縮放防禦演算法 (`AnalysisMetricView.tsx`)
- 採集所有非無效數據之有效正值集合。
- 提取非離群值門檻（`value < 300%`）計算常態最大值 `normalMax`。
- 視覺縮放天花板 `visualCap` 定義為：若存在 $\ge 300\%$ 離群值，則設為 `Math.max(60, normalMax * 1.35)`，否則為 `Math.max(1, maxVal)`。
- 離群柱體賦予 `⚡` 符號與漸層光澤，高度封頂於 100%；正常季度依 `(value / visualCap) * 100%` 平滑展開。

### 3. SVG 估值河流圖引擎 (`renderValuationRiver`)
- 使用 SVG `<polygon>` 繪製連續多邊形區域色帶：
  - `< mult[0]`：超跌便宜區（翡翠綠漸層）
  - `mult[0] ~ mult[1]`：合理偏低區（湖青藍漸層）
  - `mult[1] ~ mult[2]`：合理偏高區（天藍漸層）
  - `mult[2] ~ mult[3]`：偏高警戒區（橙黃漸層）
  - `> mult[3]`：昂貴區（珊瑚紅漸層）
- 疊加水平現價線與最新一季脈衝圓點與現價標籤。
- 頂部動態生成落點評級徽章（例如：`落點評估：合理偏高 (18x ~ 22x)`）。
- 下方附帶歷季各通道價格數據對照矩陣。

### 4. 全市場動態流通股數推導架構 (`keyMetricsEngine.ts`)
- 建立發行股數推導順序：
  1. 優先取資產負債表之股本：`capitalStock / 10`
  2. 次級備援取損益表：`netIncome / eps`
  3. 保底安全常數：10 億股（杜絕小於等於 0 或 1000 萬股之極端崩潰）
- 支援傳入單季物件或近四季 records 陣列：若為陣列則加總近 4 季 TTM FCF 計算年度報酬率。

## Testing Decisions

1. **外部行為測試原則**：
   - 不測 CSS 具體 style 屬性，只測量化計算結果、邊界防呆、極端值防禦比率與展示標籤。
2. **測試覆蓋範圍 (`src/engine/analysisMetricsAudit.test.ts`)**：
   - 驗證缺乏基期時返回 `displayValue: '-'` 與 `isNoData: true`。
   - 驗證台泥 2023Q2 毛利爆發 `+5326.2%` 之計算真實性與離群縮放正常季度高度保持在 50% 以上。
   - 驗證發行股數動態推算超過 70 億股，且 FCF Yield 處於合理的正常區間。
   - 驗證 DCF 內在價值落在 25~55 元正常區間。
3. **迴歸測試要求**：
   - `npm test` 全站 95 個測試檔案、923 個單元測試 100% 綠燈通過。
   - `npm run build` TypeScript 0 錯誤。
