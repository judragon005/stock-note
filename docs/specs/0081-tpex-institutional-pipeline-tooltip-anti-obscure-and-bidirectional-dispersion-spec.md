- **問題 1 (8299 法人全為 0)**：目前 smartMoneyFetcher.ts 僅向 TWSE 官方開放日報 (und/T86) 抓取上市公司法人數據。8299 (群聯) 屬於 TPEx 櫃買中心上櫃股票，查無記錄，導致外資、投信、自營商全部 fallback 為 0 張，時序播放器每日數據完全鎖死為 0。
- **問題 2 (Tooltip 浮窗自蓋目標泡泡)**：Tooltip 固定於 ottom: 16px; left: 16px。當點選或懸浮於左下象限之標的時，浮窗 100% 蓋在目標泡泡上方，形成視覺盲區。
