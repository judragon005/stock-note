# PRD #0102: 肌肉書僮動能雷達任意代碼即時外部回補診斷與自訂觀察清單規格書

## 1. 執行摘要 (Executive Summary)

本規格書針對使用者在「肌肉書僮·動能雷達」工作區中，渴望分析「不在既有四大標的池（焦點 Top 30、台股在倉、歷史平倉、權值 Top 50）內的任意個股」之需求，提供高整合度、無縫流暢的二合一架構：

1. **任意代碼即搜即算 (Ad-hoc Search & Fetch)**：使用者在搜尋框鍵入任何台股代碼（如 `3017`、`2603`）或美股代碼（如 `NVDA`、`TSLA`）時，若當前池中查無匹配，提供「⚡ 連線外部診斷」按鈕與 Enter 快捷觸發。系統自動發起歷史日 K 回補 (`backfillSymbolOhlcvAndIndicators`)，寫入 IndexedDB 快取並即時運算動能雷達指標。
2. **內嵌式置頂診斷高光卡 (Inline Diagnostic Spotlight Card)**：運算完成後，在三色操盤導航儀正上方即時內嵌渲染診斷卡片，完整展示三色燈號、Darvas 箱子突破狀態、布林極致壓縮帶寬、20MA 扣抵與停損防守價位，並提供「⭐ 釘選至自訂觀察」與「✕ 關閉」按鈕。
3. **常態自訂觀察清單 (Custom Watchlist Pool)**：在標的池切換按鈕中新增「⭐ 自訂觀察 (N)」，儲存於 LocalStorage，使用者可隨時切換至專屬觀察池常態監控、新增或移除自選追蹤標的。

## 2. 功能規格與驗收條件 (Features & Acceptance Criteria)

### 功能 1：任意股票代碼即時搜尋、外部回補與動能雷達運算

- **業務邏輯**：
  - 當搜尋框有輸入（長度 $\ge 1$），且在當前池子過濾結果為空，或使用者按下 Enter / 點擊「連線外部診斷」時：
    - 自動判斷市場類別：純數字代碼預設為台股 `TW`；英文字母為美股 `US`。
    - 啟動 Loading 狀態，調用 `backfillSymbolOhlcvAndIndicators(cleanSymbol, market)`。
    - 取得股票中文名稱 (`resolveOfficialSecurityName`) 與歷史日 K 數列。
    - 調用 `scanMuscleBookerItem` 產出完整 `ScannedStockItem`（包含 actionDecision、darvasBox、bollinger、maDeduction、ATR 停損點位）。
- **AC-1.1**：在搜尋框輸入未在當前池的代碼（例如 `3017`），按下 Enter 或點擊「⚡ 連線診斷」，應正確觸發外部資料回補並在完成後停止 Loading。
- **AC-1.2**：若輸入之代碼查無資料或網路異常，應顯示友善提示訊息（如「查無標的行情或代碼錯誤」），不得造成畫面 Crash 或白屏。
- **AC-1.3**：若該標的先前已存在 IndexedDB 或本地快取，應直接秒開快取日 K，避免重覆發送不必要的外部 HTTP 請求。

### 功能 2：內嵌式置頂診斷高光卡片 (Spotlight Card)

- **業務邏輯**：
  - 完成外部診斷之標的，以高光卡片形式內嵌於三色實戰操盤導航儀上方。
  - 卡片具備明確視覺焦點（深藍漸層邊框、霓虹光暈標章【⚡ 即時外部診斷】）。
  - 卡片呈現核心指標：
    - 股票代碼、中文名稱、最新市價與漲跌幅
    - 肌肉書僮三色燈號徽章（🟢 建議買進 / 🟡 觀望不碰 / 🔴 建議賣出）
    - 箱子戰術狀態（Darvas 箱頂、箱底、突破/破底狀態）
    - 布林帶寬極致壓縮（%）與 20MA 扣抵態勢
    - 建議防守價位與風益比 (R-Multiple)
- **AC-2.1**：高光卡片右上方具備「⭐ 釘選至自訂觀察」按鈕，若該標的已在自訂清單中，按鈕呈現「★ 已在觀察清單」。
- **AC-2.2**：高光卡片右上方具備「✕ 關閉」按鈕，點擊後收合該診斷卡片，恢復預設佈局。
- **AC-2.3**：點擊卡片本體可展開／切換選取該標的，同步連動下方的指標走勢與 K 線圖。

### 功能 3：常態自訂觀察池 (Custom Watchlist Pool)

- **業務邏輯**：
  - 在 [`src/utils/storage.ts`](file:///d:/APP/股票紀錄/src/utils/storage.ts) 建立 `getMuscleBookerWatchlist()` 與 `saveMuscleBookerWatchlist()`，以 LocalStorage 持久化儲存。
  - 標的池切換按鈕新增「⭐ 自訂觀察 (N)」。
  - 切換至「⭐ 自訂觀察」時：
    - 標的來源為自選清單中的所有股票。
    - 支援快速加入新代碼（輸入框 + 新增按鈕）。
    - 標的卡片右上角支援一鍵移除（取消釘選）。
    - 若自訂標的尚無歷史日 K，自動依序或於點擊時完成快取回補。
- **AC-3.1**：在即時診斷卡片點擊「⭐ 釘選至自訂觀察」，該標的代碼立即加入 LocalStorage，頂部「⭐ 自訂觀察 (N)」計數即時 +1。
- **AC-3.2**：切換至「⭐ 自訂觀察」資產池，三色導航儀與四象限篩選僅對自選標的進行歸納。
- **AC-3.3**：在自選池內移除標的後，該標的立即從列表消失，計數即時 -1，資料同步持久化。

## 3. 非功能性需求與工程約束

- **TypeScript 0 錯誤**：維持全專案嚴格型別校驗。
- **Vitest 100% 綠燈**：為 storage 讀寫、搜尋回補觸發與自訂池渲染編寫完整單元測試。
- **KISS 原則**：複用既有 `backfillSymbolOhlcvAndIndicators` 與 `scanMuscleBookerItem`，不重複建立重複輪子。
- **防禦性開發**：輸入代碼自動清理前後空白、強制轉為大寫，妥善處理 404 或空資料邊界情況。
