# PRD 規格書：肌肉書僮風益比硬門檻、帶寬擴張審查與方向實質確立架構

- **版本**：v8.24.0
- **日期**：2026-09-09
- **狀態**：APPROVED
- **關聯 ADR**：[`docs/adr/0105-muscle-booker-risk-reward-bandwidth-direction-gate.md`](docs/adr/0105-muscle-booker-risk-reward-bandwidth-direction-gate.md)
- **核心目標**：杜絕「1599 宏佳騰 (風益比 0.1R)」等向上空間狹窄之雞肋標的誤判為買進，嚴格執行風益比 $\ge 2.0$、布林帶寬審查、方向實質確立、買進優先排序，並阻絕無效代碼（如 3175）加入觀察清單。

---

## 1. 核心業務邏輯與門禁 (Business Rules & Gates)

1. **風益比及格門禁 (Risk-Reward Hard Gate $\ge 2.0$)**：
   - 僅當 $\text{Reward} / \text{Risk} \ge 2.0$ 時，才允許給出 `🟢 建議買進 · 主升發動`。
   - 若型態符合突破或破底翻，但風益比 $< 2.0$（如 1599 僅 0.1R），系統自動將動作判定為 `HOLD / AVOID`，徽章為 `🟡 觀望待變 (空間不足)`，理由標註「已逼近箱頂壓力天花板，風益比不足 2R (期望值過低)，切忌追高」。
2. **帶寬審查與方向實質確立 (Bandwidth Audit & Direction Confirmation)**：
   - **極致壓縮審查**：若布林帶寬 $\le 8.0\%$，視為蓄勢方向未明，一律歸為觀望（`AVOID`）。
   - **過度發散審查**：若布林帶寬 $> 35.0\%$，視為乖離過大過度發散，禁止盲目追高。
   - **方向實質確立**：必須同時滿足（1）收盤價站上 20MA（或收復箱頂），（2）20MA 扣抵望遠鏡預測翻揚向上（`ma20Slope === 'UP'`），代表主力趨勢推升力量確立。
3. **綠燈買進標的優先呈現 (Priority Sorting by R:R)**：
   - 「建議買進 · 主升發動」卡片與綜合監控總表中，買進標的全面按風益比數值由大到小（降序）排序，風益比最高、期望值最強者永遠置頂。
   - 風益比 $\ge 2.0$ 之標的標註亮麗的「🔥 優質風益比」識別。
4. **無效股票代碼防護機制 (Invalid Symbol Guard)**：
   - 使用者在自訂觀察清單輸入代碼（如 3175、無效字串）時，系統先檢核官方字典與非同步遠端存在性驗證。
   - 若查無此股票，嚴格阻擋加入並彈出錯誤提示，且在工作區載入時自動清理既有名單中歷史殘留的無效代碼。

## 2. 驗收標準 (Acceptance Criteria)

- [x] **AC-1 (風益比及格門禁)**：1599 宏佳騰等風益比不足 2.0 的標的，絕不出現在「建議買進」綠燈中，而是自動歸入黃燈觀望待變。
- [x] **AC-2 (綠燈風益比排序)**：綠燈買進標的依據風益比由高至低排列（例如 5.3R ➔ 3.2R ➔ 2.1R），最優標的永遠排在最前面。
- [x] **AC-3 (帶寬與方向確立)**：極致壓縮（$\le 8\%$）或均線下彎者，一律禁止放行買進。
- [x] **AC-4 (無效代碼阻絕)**：輸入 3175 等不存在的股票代碼時，系統明確提示錯誤並禁止加入自訂觀察清單；若名單中已有無效標的，自動清理。
- [x] **AC-5 (全專案單元測試與型別檢查)**：`npm test` 57 套件 100% 綠燈，`npm run build` 0 型別錯誤。
