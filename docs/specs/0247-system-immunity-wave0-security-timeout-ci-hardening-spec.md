# Spec 0247: 系統免疫強化 Wave 0 — 資安邊界止血、全域鎖死鎖根除、CI 全端守門閉環與靜態市場快取徹底退場

## Problem Statement

儘管專案已透過 Spec 0240–0246 建置超過兩千六百項自動化單元測試、7 條架構適應度不變量與 QNAP NAS 24/7 生產伺服器，全量法醫審計揭露系統在「資安邊界、並發可靠性、隱私保護與 CI 免疫守門」四條底層防線上仍存在四類高危結構性破口：

1. **SSRF 安全防線穿透與代理層資源耗盡風險**：開發與生產環境共享之金鑰測活端點（`POST /api/market/probe-key`）未套用主機白名單、私網過濾與禁重導向護欄，可 100% 繞過 NAS 通用代理安全邊界；NAS 代理本身亦缺少請求主體上限與上游逾時中斷控制。
2. **雙軌安全脫敏匯出遺漏歷史快照金鑰，且前端儲存層殘留個人交易硬編碼**：全態封包安全脫敏模式漏洗 `snapshots[*].payload.apiKeys` 副本，導致匯出時仍外洩明文憑證；前端儲存層殘留針對特定個人券商成交股數、金額與股息明細之硬編碼校正邏輯。
3. **全域互斥鎖內存在 8 處無逾時裸抓取與美股取消鏈鍵名錯位**：集保、月營收、除權息、ETF 淨值、董監質押、處置狀態、美股基本面/配息與 SEC 代理皆在全域同步鎖內發起無逾時控制之外部請求，遭遇 TCP 半開將導致排程永久死鎖；美股基本面與配息管線上層與底層鍵名不一致，導致原生 `AbortController` 取消鏈實際斷裂。
4. **CI 免疫系統局部失明且既有架構適應度守門已被實戰繞過**：後端同步目錄下多支獨立測試長期未納入 CI 與本地推送守門（其中包含假 Lambda 自測與未傳目標日直連外網之失修測試）；遠端 CI 缺正式建置與文檔守門；測試執行器啟用靜默忽略未處理例外；既有不變量 3（色票）與不變量 7（靜態快取退場）皆遭實戰繞過，公開目錄仍留存逾 21 MB 過期靜態市場快取，備用部署容器定義檔亦遺漏法定休市日曆複製指令。

---

## Solution

執行「系統免疫強化 Wave 0」，嚴守零新增外部依賴（KISS）與最小爆破半徑原則，一次閉合四道底層物理防線：

1. **Unified SSRF Origin Guard 與 NAS 代理護欄**：抽離統一外部網址安全驗證核心（僅 HTTPS、完整 9 大官方金融供應商白名單、禁憑證嵌入、阻斷本機／私網／Cloud Metadata、強制 `redirect: 'manual'` 並攔截 3xx），同時接上 `POST /api/market/probe-key` 與 NAS `/api/proxy`；NAS 代理補齊 1 MB Body 硬上限（`413`）與 15 秒上游逾時中斷（`504`）。
2. **雙軌安全脫敏全深度清洗與個人財務隱私淨化**：全態匯出與備份脫敏工具全面覆蓋每筆歷史時光機快照內的明文金鑰清洗；徹底剝離前端儲存層硬編碼個人交易對帳函式及其呼叫點。
3. **Deadlock-Free Lock-Scoped Fetch 與美股取消鏈閉合**：於市場同步共用核心提供單一複合逾時抓取原語，遷移全數 8 條鎖內台美採集與 SEC 代理路徑，並統一美股攝取管線之可注入抓取鍵名使上層取消訊號端到端穿透。
4. **Full-Stack CI Immunity Gate 與 10 條架構適應度棘輪**：建立自動探索式後端測試執行器納入專案標準腳本、修正失修與假自測後端測試、移除重複檔；關閉測試執行器未處理例外吞噬開關；遠端 CI 與本地推送守門強制合流後端測試、正式建置與全量文檔守門；拔除引擎層殘留靜態市場快取旁路並物理清除逾 21 MB 過期靜態檔、對齊備用容器休市日曆、收斂戰情室卡片硬編碼色票，最終將架構適應度守門強化並擴充至 10 條不可繞過不變量。

## User Stories

1. 作為在 QNAP NAS 自託管系統的維運者，我希望金鑰測活端點與通用代理共用嚴格的 HTTPS 白名單與禁重導向 SSRF 守衛，以便內網與私網服務不受任何探測與重導向繞過威脅。
2. 作為設定外部金融 API 金鑰的使用者，我希望全部 9 大合法支援供應商在套用 SSRF 護欄後仍能正常完成健康度探測。
3. 作為 NAS 伺服器維運者，我希望反向代理具備 1 MB 請求體硬上限與上游逾時中斷機制，以便防止記憶體耗盡與僵死連線累積。
4. 作為匯出「安全脫敏備份」的投資者，我希望連同歷史時光機快照在內的整個封包 0 處殘留明文 API Key，同時「完整遷移」模式維持向後相容。
5. 作為重視隱私零外洩的維護者，我希望前端程式碼與建置產物不含任何個人券商交易明細硬編碼校正邏輯。
6. 作為依賴 24/7 無人值守湖倉同步的使用者，我希望全域鎖內全部 8 條背景抓取管線強制套用複合逾時控制，且美股按需補齊取消訊號確實穿透至底層網路請求，永不因 TCP 掛起而死鎖。
7. 作為全端品質維護者，我希望所有後端同步測試套件、正式編譯建置與全量文檔守門皆納入遠端 CI，且測試執行器不再靜默忽略未處理非同步例外。
8. 作為戰情室與短線波段使用者，我希望引擎層不再回退抓取逾 21 MB 過期靜態 JSON 快取、雙容器定義檔皆攜帶法定休市日曆，且戰情卡片全面統一遵守 `Directional Palette SSOT`。
9. 作為防止技術債復發的架構師，我希望架構適應度守門升級至 10 條不變量，物理封鎖上述安全、逾時、色票、靜態快取與 CI 盲區復發。

## Implementation Decisions

- **決策 1（Unified SSRF Origin Guard — 延伸修訂 ADR 0243）**：收斂唯一外部網址驗證純函式供通用代理與金鑰測活端點共用，僅放行 HTTPS 與 9 大精確官方金融主機，禁止 `http:`、私網 IPv4/IPv6、Cloud Metadata 與憑證嵌入，並強制 `redirect: 'manual'` 攔截 3xx。
- **決策 2（快照深度脫敏與隱私淨化 — 修補 ADR 0234）**：安全脫敏模式同步清洗每筆歷史快照載荷之 `apiKeys`；移除硬編碼特定個人券商明細之啟動自動對帳函式。
- **決策 3（Deadlock-Free Lock-Scoped Fetch）**：於市場同步共用核心提供支援外部 `AbortSignal` 與預設逾時上限之複合抓取原語，全數遷移台美 8 條鎖內採集管線，並雙向對齊美股攝取管線之 `fetchImpl`/`fetchFn` 參數契約。
- **決策 4（靜態市場快取物理退場與雙容器對齊 — 深化 ADR 0246）**：退役前端快取載入與歷史 K 線回補引擎之靜態 JSON 回退路徑改走 SQLite 湖倉 SSOT，清除公開目錄過期靜態 JSON 並同步備用容器定義檔休市日曆複製指令。
- **決策 5（Full-Stack CI Immunity Gate 與 10 條適應度棘輪）**：建立統一後端測試執行器納管全部後端同步測試（取代假 Lambda 並修復休市測試契約）、移除測試執行器未處理例外靜默吞噬、擴充遠端 CI 與本地推送守門，並於架構適應度守門強化不變量 3/7 與新增不變量 8/9/10。

## Testing Decisions

- **Seam 1（後端 HTTP 邊界與鎖內採集契約）**：透過統一 SSRF 守衛、金鑰測活路由、NAS 代理伺服器與 8 條鎖內採集模組公開介面，離線注入可控掛起／重導向 Mock `fetch` 與 `AbortController`，驗證 100% 阻斷、413/504 防護與逾時釋鎖。
- **Seam 2（全態安全脫敏匯出與隱私淨化契約）**：透過全態匯出快照清洗函式、備份脫敏工具與帳本初始化入口，驗證多筆歷史快照金鑰 0 殘留與零硬編碼竄改。
- **Seam 3（全端 CI 管線與 10 條架構適應度棘輪）**：執行後端統一測試套件、前端全量單元測試（無忽略未處理例外）、型別檢查、正式建置與全量文檔守門全數 0 錯誤。
