# 產品需求規格說明書 (PRD): 美股與台股雙市場交易紀錄與投資分析儀

## Problem Statement (問題陳述)

當代個人投資者通常同時持有台灣股市 (TW) 與美國股市 (US) 的標的資產 (Securities)。然而，跨市場投資面臨以下痛點：
1. **多幣別與匯率干擾**：台股以新台幣 (TWD) 結算，美股以美元 (USD) 結算。許多現有工具強制以單一匯率折算，導致單筆交易的原始投資報酬率受到匯率波動扭曲。
2. **會計與稅費計算複雜**：台股存在整股/零股、0.1425% 手續費與 0.3% (或 ETF 0.1%) 證交稅；美股支援小數點持股且費率結構不同。分批買進後的「移動加權平均成本 (Moving Weighted Average Cost)」與部分賣出時的「已實現損益 (Realized PnL)」難以手動精確維護。
3. **隱私與資料主權**：許多雲端記帳平台要求註冊綁定甚至上傳券商憑證，存在資安與財務數據洩漏風險。

## Solution (解決方案)

建置一個以 **React 18 + TypeScript + Vite** 為核心的現代純前端單頁應用 (SPA)，搭配極致深色 Glassmorphism 儀表板與離線本機儲存 (LocalStorage / JSON / CSV 雙向備份)。  
系統提供「原始幣別獨立記帳 + 統一基準幣匯總」雙軌架構，內建遵循嚴格會計原則的損益計算引擎，自動結算未實現浮動損益、出場已實現損益、現金股息總額，並提供直觀的資產配置分佈圖與即時市價快修機制。

## User Stories (使用者故事)

1. 作為跨市場投資人，我希望能在同一個系統中分別記錄台股 (TWD) 與美股 (USD) 的買進與賣出交易，以便統一管理我的所有投資。
2. 作為長線定時定額投資人，我希望在多次分批買進同一檔股票時，系統能自動依據「移動加權平均法」重新核算平均每股持有成本，以便準確評估目前的持有成本線。
3. 作為波段交易者，我希望在部分賣出持股時，系統能自動扣減對應份額的持倉成本，並精確結算出該筆賣出的已實現損益 (Realized PnL)，以便掌握落袋為安的獲利數字。
4. 作為存股投資人，我希望能夠單獨記錄領取的現金股息 (Dividends)，並在總覽看板中累計呈現，且股息記錄不會錯誤稀釋或干擾現有持股的單位成本基準。
5. 作為注重交易成本的投資人，我希望錄入台股交易時系統能自動估算 0.1425% 手續費與 0.3% 證交稅（ETF 為 0.1%），並允許我手動微調實際扣繳金額。
6. 作為美股投資人，我希望系統支援小數點股數（Fractional Shares）錄入，並自動處理美股賣出時的 SEC 規費。
7. 作為資產管理者，我希望能在頂部隨時切換「全部市場」、「台股 (TWD)」與「美股 (USD)」三種視圖，以便從宏觀總體或個別市場檢視損益。
8. 作為資產管理者，我希望能在儀表板自訂當前 USD/TWD 換算匯率，使美股資產能即時、動態地折算為台幣總市值，方便掌握家庭總資產淨值。
9. 作為投資分析者，我希望能透過持倉分佈進度條與佔比卡片，一眼看出台股與美股的資金配置比例，以及前幾大重倉股的資金佔比。
10. 作為注重隱私的投資者，我希望所有交易數據 100% 儲存在我自己的瀏覽器本機端，無需向任何伺服器註冊帳號或上傳隱私。
11. 作為注重資料安全的投資者，我希望能隨時一鍵將全部交易紀錄匯出為結構化 JSON 備份檔，並能在任何電腦上隨時匯入還原。
12. 作為習慣試算表分析的投資者，我希望能將歷史明細一鍵匯出為包含 UTF-8 BOM 的標準 CSV 檔案，便於在 Excel 中進行進階樞紐分析。
13. 作為即時看盤者，我希望能在持倉列表中直接點擊市價欄位快速修改最新參考價格，系統立即連動重算所有浮動未實現損益與報酬率 %。
14. 作為多策略交易者，我希望能在每筆交易中附加策略標籤（如「核心持股」、「波段動能」、「股息成長」）與交易備註，並能在歷史列表中快速搜尋過濾。
15. 作為講究操作流暢度的使用者，我希望在持倉列表上能一鍵點擊「加碼」或「賣出」，自動開啟預填標的代碼與市場類別的交易彈窗，減少重複輸入。

## Implementation Decisions (實作架構決策)

1. **核心模組劃分**：
   - **會計與計算核心 (`engine/calculator.ts`)**：純函數式設計，接收交易清單 `TradeRecord[]`、現價表 `Record<string, number>` 與匯率 `usdToTwdRate`，輸出不可變之 `CalculationResult`（包含 `holdings` 與 `summary`）。
   - **存儲與資料傳輸模組 (`utils/storage.ts`)**：負責 LocalStorage 的安全讀寫容錯處理，以及 JSON 與 CSV 格式的序列化、BOM 標頭嵌入與檔案下載。
   - **UI 視圖與組件層 (`components/`)**：
     - `Header`：頂部全域切換器、即時匯率調整、新增交易與資料匯出入入口。
     - `SummaryCards`：關鍵財務指標卡片（總市值、未實現損益、已實現損益、股息收益）。
     - `AllocationChart`：資產配置雙市場進度條與個股佔比長條圖。
     - `HoldingsTable`：現有持倉總覽表與行內現價即時編輯器。
     - `TradeHistoryTable`：歷史交易明細表、即時搜尋過濾器與刪除確認。
     - `TradeModal`：交易錄入彈窗，內建台美股自動費率試算邏輯。
2. **資料型別與合約**：
   - 定義於 `types/stock.ts`，嚴格區分 `MarketType ('TW' | 'US')`、`Currency ('TWD' | 'USD')` 與 `TradeType ('BUY' | 'SELL' | 'DIVIDEND')`。
   - 價格、股數與費用一律使用 `number` 精度浮點數計算。
3. **樣式與設計哲學**：
   - 採用純 Vanilla CSS 變數系統與 Glassmorphism 毛玻璃卡片設計，深色主題背景配以 `#10b981` (翡翠綠獲利)、`#f43f5e` (玫瑰紅虧損) 與 `#3b82f6` (科技藍台股) / `#8b5cf6` (美股紫色)。

## Testing Decisions (測試架構決策)

1. **測試縫隙 (Test Seams)**：
   - 將測試縫隙鎖定在最高層級的公開計算介面：`calculateHoldingsAndSummary(trades, currentPrices, usdToTwdRate)`。
   - 不針對內部中間變數進行脆弱測試，僅驗證給定交易序列時輸出的持倉股數、平均成本、已實現損益、未實現損益與多幣別折算總額。
2. **測試套件覆蓋**：
   - 使用 **Vitest** 進行單元測試。
   - 涵蓋案例：單筆/多筆買進移動加權平均、部分賣出已實現損益沖銷、現金股息累積、雙幣別資產總覽折算。

## Out of Scope (第一階段非範疇)

- 自動串接券商 API 進行實時自動下單或同步庫存。
- 期權 (Options)、期貨 (Futures) 等複雜衍生性金融商品之 Greeks 參數計算。
- 自動化台灣國稅局海外所得或綜合所得稅報稅申報書產出。

## Further Notes (後續迭代路線)

- **V2 規劃**：整合免費/輕量金融報價 API（如 Yahoo Finance 或 TWSE Open API）實現一鍵自動更新收盤市價。
- **V3 規劃**：增加月度/年度損益走勢折線圖、股息發放日曆預測與資產再平衡 (Rebalancing) 偏離度模擬試算。
