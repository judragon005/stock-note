# 需求規格說明書 (PRD)：除息公告背景自動同步、雙看板拆分排版、配股配息合併健保扣除與現金帳本 SSOT 連動 (Spec 0064)

## 1. 概述與背景 (Overview & Context)

本規格針對使用者提出的四大關鍵體驗與財務精準度痛點進行系統性升級：

1. **除息公告背景自動同步 (Background Corporate Actions Sync)**：
   - 目前系統僅在使用者手動切換至「股利日誌」分頁且快取為空時，或手動點擊「同步除息公告」時才會發起同步。使用者希望應用程式啟動（持股與交易資料載入）後，背景立即靜默預載同步除息公告，同時保留介面手動同步按鈕。
2. **待入帳與即將除息看板垂直拆分為二 (Dual Kanban Board Separation)**：
   - 原「除權息待入帳行事曆與即將除息公告」看板將「⚡ 除息待入帳（已除息・待入帳）」與「📢 即將除息（尚未除息日程預告）」混合排列。需將其垂直拆分為兩個獨立的高質感看板，且在「無待入帳」或「無即將除息」時仍需占用版面呈現優雅的空狀態占位卡片，維持介面穩定。
3. **配股配息合併計算二代健保與全流程貫穿 (Stock & Cash Dividend Consolidated NHI Tax)**：
   - 依據台灣稅法與券商實務，當上市公司於同次除權息同時配發現金股利與股票股利時（例如 2890 永豐金），股票股利依法按每股面額（NT$ 10）併入單次給付總額計算二代健保補充保費（2.11%，門檻 $\ge \$20,000$），且該健保保費**一律自當期現金股利中直接代扣**。
   - 歷史現金股利明細表目前僅單純以現金股利毛額計算二代健保（如永豐金 31,000 股計算出稅額 719 元、實領 33,381 元），未計入配股 620 股之面額 $6,200 元產生之合併健保 850 元（實領應為 33,250 元）。
4. **現金帳本 (Cash Ledger) 與全域報表 SSOT 自動連動實收入帳**：
   - 現金帳本自動為台股股票股息生成 `DIVIDEND_PAYOUT` 流水時，若交易未手動填寫 `tax`，必須由單一事實來源 (`resolveEffectiveDividendTaxAndNet`) 自動推導配股面額並扣除二代健保，使現金帳本流水金額精準為 **`+NT$ 33,250`**，杜絕出現毛額 34,100 的錯誤數字。

## 2. 核心架構與功能規格 (Core Specifications)

### SPEC-1: 應用程式啟動背景靜默自動同步除息公告
- **啟動觸發**：在 [`src/App.tsx`](file:///d:/APP/股票紀錄/src/App.tsx) 初始化時，當交易資料與持股清單（`holdings.length > 0`）載入完成後，透過 `useRef` + `useEffect` 自動在背景發起 `handleSyncCorporateActions(false)`。
- **操作保留**：保留各分頁的「同步除息公告」手動按鈕，支援使用者手動強制重新整理（`forceRefresh: true`）並顯示旋轉 Loading 狀態。
- **快取保護與節流**：背景預載優先讀取 24H 本地快取與 IndexedDB，並保持 150ms 節流延遲，避免過度消耗 API 額度。

### SPEC-2: 雙看板垂直拆分與空狀態占位排版
- 將原單一綜合看板拆分為兩個獨立的 Glass Card 區塊：
  1. ⚡ **除息待入帳行事曆 (Receivables Kanban)**：
     - 過濾條件：`status === 'PENDING_PAYMENT'`（即 `exDate <= today < payDate` 或已過除息基準日但未過發放日之應收股利）。
     - 標題：「⚡ 除息待入帳行事曆 (Receivable Dividends Pending Payment)」。
     - 統計徽章：顯示「X 筆待入帳」與「預估待入帳合計 +NT$ XXX」。
     - 空狀態：若當前無待入帳項目，顯示半透明專用占位卡片「目前暫無除息待入帳款項，除息基準日過後之應收股利將自動列於此處」，確保版面不坍塌。
  2. 📢 **即將除息公告看板 (Upcoming Ex-Dividends Kanban)**：
     - 過濾條件：`status === 'UPCOMING_EX'`（即 `today < exDate` 之未來即將除息日程）。
     - 標題：「📢 即將除息公告看板 (Upcoming Corporate Actions & Ex-Dividends)」。
     - 統計徽章：顯示「X 筆即將除息」。
     - 空狀態：若當前無即將除息公告，顯示專用占位卡片「目前在倉標的暫無最新除息公告日程」，維持版面結構一致。

### SPEC-3: 台股同次除權息「現金 + 配股」合併健保扣除邏輯
- **法規公式**：
  $$\text{股票股利面額價值} = \text{配股股數} \times 10$$
  $$\text{單次給付申報所得總額} = \text{現金股利毛額} + \text{股票股利面額價值}$$
  $$\text{二代健保補充保費} = \begin{cases} \lfloor \text{單次給付申報所得總額} \times 2.11\% \rfloor, & \text{若總額} \ge 20,000 \\ 0, & \text{若總額} < 20,000 \end{cases}$$
  $$\text{實領現金股利淨額} = \max(0, \text{現金股利毛額} - \text{二代健保補充保費} - \text{匯費})$$
- **扣繳稅額優先級**：
  1. 若該筆交易已手動填寫或由 CSV 匯入明確之 `t.tax > 0` 或 `t.cashAmount > 0`，以手動實收為第一優先。
  2. 若 `t.tax === 0` 或未填，且為台股市場：
     - 系統自動在交易紀錄或官方除權息行事曆中，尋找同標的、同除權息期別（除權基準日與除息基準日相同或相差 $\le 7$ 天）之股票股利（`STOCK_DIVIDEND`）配股股數。
     - 調用 `calculateConsolidatedTwNhiTax` 進行合併計算，將配股健保費用全額自現金股利扣繳，計算出正確的實領金額與稅款。
  3. 若為美股市場，維持 30% 預扣稅與 DOI/JRN 雙筆記帳邏輯。

### SPEC-4: 現金帳本 (Cash Ledger) 與全域報表 SSOT 自動連動
- 在 [`src/engine/cashLedgerEngine.ts`](file:///d:/APP/股票紀錄/src/engine/cashLedgerEngine.ts) 中，由交易自動同步生成台股 `DIVIDEND_PAYOUT` 流水時，直接調用 `resolveEffectiveDividendTaxAndNet`。
- 若交易紀錄未指定 `tax`，現金帳本自動關聯配股面額扣除二代健保，入帳金額精準寫入 **`+NT$ 33,250`**。
- [`src/engine/dividendAggregator.ts`](file:///d:/APP/股票紀錄/src/engine/dividendAggregator.ts) 同步對齊實收金額，確保歷史累積與月度現金流 100% 精準。

## 3. 實例驗證基準 (Benchmark Case: 2890 永豐金)

- **情境條件**：
  - 標的：2890 永豐金（持股 31,000 股）
  - 除息基準日：2026-07-23，每股配息 1.10 TWD，發放日 2026-08-20
  - 除權基準日：2026-07-23，配股率 0.02 (每千股配 20 股)，發放日 2026-08-24
- **計算結果**：
  - 現金股利毛額 = $31,000 \times 1.1 = 34,100$ 元
  - 配股股數 = $31,000 \times 0.02 = 620$ 股
  - 配股面額價值 = $620 \times 10 = 6,200$ 元
  - 合併所得 = $34,100 + 6,200 = 40,300$ 元
  - 二代健保費 = $\lfloor 40,300 \times 0.0211 \rfloor = \lfloor 850.33 \rfloor = 850$ 元
  - **股利明細「扣繳稅款/健保」欄位顯示**：`-NT$ 850`
  - **股利明細「實領淨額」與「折合台幣」欄位顯示**：`33,250 TWD`（折合台幣 `NT$ 33,250`）
  - **現金帳本「DIVIDEND_PAYOUT」流水入帳金額**：`+NT$ 33,250`（非毛額 34,100）
