## 1. Problem Statement (問題陳述)

在現有系統中，美金/台幣（USD/TWD）匯率主要由使用者手動在頂部導航列輸入並儲存在 LocalStorage 中，或由預設值 32.5 兜底。存在以下痛點：
1. **需手動維護匯率**：外匯匯率每日及盤中持續波動，手動輸入無法即時反映美股資產折合台幣的真實市值與損益。
2. **缺乏免費/官方純前端匯率整合**：使用者希望系統能自動由公開免費來源（如 Yahoo Finance `USDTWD=X`）拉取盤中即時/延遲匯率或前一日收盤價，且無須額外架設後端伺服器或購買付費 API Key。
3. **缺乏多層平滑降級與備援機制**：遇到網路斷線、CORS 代理不穩定或 API 異常時，系統若無完善的降級機制（即時價 ➔ 前日收盤價 ➔ 本地快取 ➔ 預設兜底），可能導致美股折算計算出現突兀跳變或 NaN 錯誤。
4. **介面互動與行情機制不同步**：使用者希望匯率能隨全市場即時行情機制（進站載入、開盤輪詢、一鍵重整）同步自動更新，並在 Header 徽章上透明化呈現當前匯率來源狀態與更新時間。

---

## 2. Solution (解決方案)

全面導入**「全自動 USD/TWD 匯率引擎 + 多層平滑備援 + 行情同步輪詢架構」**：

1. **純前端匯率抓取引擎 (`src/engine/priceFetcher.ts`)**：
   - **主要來源 (Yahoo Finance USDTWD=X)**：透過現有健全的 CORS 代理池（含多代理重試與超時熔斷機制），抓取最新即時/延遲匯率。
   - **解析結構 (`ExchangeRateQuote`)**：支援解析當前匯率 (`rate`)、前一日收盤價 (`prevClose`)、漲跌額 (`change`)、漲跌百分比 (`changePercent`) 與狀態標籤 (`sourceType: 'realtime' | 'delayed' | 'prevClose' | 'cached'`)。
2. **多層平滑降級與備援機制 (Fallback Cascade)**：
   - **Level 1**：盤中即時/延遲匯率 (`regularMarketPrice > 0`)。
   - **Level 2**：若即時價格異常，回退至 Yahoo Finance 前一日收盤價 (`chartPreviousClose` 或 `previousClose`)。
   - **Level 3**：若網路/代理請求全數失敗，平滑回退至 LocalStorage 快取的最近一次有效匯率。
   - **Level 4**：若無任何快取，採用預設基準值 (32.5)。
3. **與行情機制完全同步之 Hook 整合 (`src/hooks/usePriceAutoRefresh.ts`)**：
   - **進站自動抓取**：頁面初始載入時自動為持股市價與匯率發起同步抓取。
   - **智慧交易時段輪詢**：台股或美股開盤時段內，每 60 秒背景自動輪詢更新匯率與持股市價。
   - **一鍵手動同步**：點擊頂部「重整行情」按鈕時同步強制刷新匯率。
4. **純自動化 Header 徽章展示 (`src/components/Header.tsx`)**：
   - 移除原手動輸入編輯框，全面改為純自動化徽章。
   - 徽章顯示 `USD/TWD: 32.45`，於背景刷新時展示轉動微動畫。
   - 滑鼠懸停 (Tooltip) 顯示匯率來源狀態（如「盤中即時」、「前日收盤 (32.40)」或「快取備援」）及最後更新時間。

## 3. User Stories (使用者故事)

1. **US-63 (進站自動同步匯率)**：作為美股投資人，當我開啟系統時，系統自動抓取最新 USD/TWD 匯率並換算持股市值，無需我手動查詢並填寫匯率。
2. **US-64 (開盤智慧定時同步)**：作為活躍交易者，在開盤時段內，匯率隨同持股報價每 60 秒自動背景輪詢更新。
3. **US-65 (網路異常平滑降級)**：作為使用者，當網路斷線或公共代理不穩定時，系統自動回退至前日收盤價或本地歷史快取，美股折合台幣之市值計算保持平滑不崩潰。
4. **US-66 (純自動優雅 UI 呈現)**：作為使用者，我在頂部導航列能清楚看到當前匯率數值，滑鼠懸停可檢視匯率狀態與時間，介面乾淨簡潔。

- [ ] Header 匯率徽章改為自動化顯示，含 Tooltip 與刷新旋轉動畫。
- [ ] LocalStorage 持久化快取正常運作，離線時能平滑讀取最近有效匯率。
- [ ] 單元測試 100% 通過（包含解析、降級、快取等情境）。
