# 需求規格說明書 (PRD #0047)：嘉信理財對帳單像素級對齊、利息智能正規化與美股股息毛額雙筆記帳架構

## 1. 執行摘要 (Executive Summary)

本規格書針對美股券商（嘉信理財 Charles Schwab）對帳單與本專案現金流水帳本之間的記帳口徑、利息聚合與微小零頭差額進行深度統一。
透過將美股股息流水統一規範為「稅前毛額（Gross）入帳」，精確對齊嘉信理財官方 **DOI（毛股息入帳）+ JRN（預扣稅扣繳）** 雙筆金流機制；同時升級利息備註智能正規化引擎，支援中文全形逗號、破折號與日期截斷；並建立冪等式實績自動校正模組，達成全量 25 筆美股流水、總 NAV、被動收益與手頭現金水位（$224.79 USD）的 100% 像素級對齊。

---

## 2. 背景與痛點 (Background & Problem Statements)

1. **痛點一：美股股息入帳淨額與預扣稅重複扣抵**
   * 既有系統在自動連動美股股息時，預設將流水記為「扣稅後淨額」（如 $31.56 與 $18.33），但流水帳中又包含一筆獨立的「預扣稅費 -$13.53」與「-$7.85」。
   * 這導致使用者在對帳時發現股息金額與嘉信 DOI 毛額（$45.09 與 $26.18）不符，且現金餘額面臨重複扣稅風險。
2. **痛點二：利息膠囊因全形逗號與破折號未能合併**
   * 真實券商備註包含全形逗號 `，`（例如 `Schwab 嘉信理財-現金利息，利息 0.27 - 預扣 0.08`）或 En-dash `–`（如 `10/30–11/25`），既有邏輯僅以中點 `·` 分割，導致利息被拆散為 3 個獨立膠囊。
3. **痛點三：歷史手動登錄微小零頭差額與除息日落差**
   * SGOV 買進與賣出存在 $1.78 與 $0.02 之手動登錄零頭差，VT 兩筆股息分別存在 $0.02 與 $0.03 差額，累計差額達 -$1.79，導致系統先前需額外登錄一筆手動出金校正流水。

### 3.1 美股股息毛額雙筆記帳架構
* 在 `src/engine/cashLedgerEngine.ts` 中：
  * 當 `trade.type === 'DIVIDEND'` 且 `trade.market === 'US'` 或 `currency === 'USD'` 時，生成的 `CashTransaction` 金額一律為 `gross = trade.shares * trade.price`（稅前毛額）。
  * 與獨立登錄之 `TAX`（預扣稅費）流水自然相減，完美還原嘉信理財 DOI / JRN 雙筆記帳模型。

### 3.2 智能利息名稱正規化 (Smart Note Normalization)
* 升級 `normalizeInterestName` 函式：
  1. 支援正則過濾 `\([^)]*\d+[/~–—-]\d+[^)]*\)`（消除各類日期區間與不同編碼破折號）。
  2. 支援 `[\u00b7,，:：]\s*(?:利息|預扣|本金|\+|\$|\d)` 分割截斷。
  3. 保證 `Schwab 嘉信理財-現金利息` 100% 聚合為單一膠囊。

### 3.3 實績自動對齊模組 (Auto-Reconciliation Engine)
* 在 `src/utils/storage.ts` 中實現 `autoReconcileSchwabRecords`：
  * 冪等檢查並校正 SGOV 買入 ($8,933.82)、SGOV 賣出 ($8,956.07)、VT 2026-03-24 股息 ($26.18, 稅 $7.85) 與 VT 2026-06-23 股息 ($45.09, 稅 $13.53)。
  * 自動清除多餘的手動校正出金流水 (-$1.79)。

## 4. 驗收標準 (Acceptance Criteria)

1. **美股股息流水金額驗收**：
   * `2026-06-23` 股息入帳金額必須為 **`+$45.09`**。
   * `2026-03-24` 股息入帳金額必須為 **`+$26.18`**。
   * `2025-12-23` 股息入帳金額必須為 **`+$11.15`**。
   * `2025-09-23` 股息入帳金額必須為 **`+$4.78`**。
2. **被動收益卡片利息膠囊合併驗收**：
   * 所有跨月份嘉信利息記錄必須合併為 **單一一筆 `💵 Schwab 嘉信理財-現金利息 +$1.00 USD`**。
   * 底部「利息預扣」膠囊必須精確顯示 **`-$0.29 USD`**。
3. **現金水位與交易明細對齊驗收**：
   * 嘉信理財交割戶可用現金餘額必須自然等於 **`$224.79 USD`**，無任何人工出金校正流水。
   * 全專案 304 項單元測試 100% 通過，TypeScript 0 錯誤。
