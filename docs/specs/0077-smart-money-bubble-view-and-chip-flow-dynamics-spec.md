# 需求規格說明書 (PRD #0077)：籌碼移動與聰明錢動態觀察儀（零基礎小白友善版、量價動能四象限泡泡圖與時序播放軌跡系統）

## Problem Statement

在股票投資與資產管理中，投資人面臨「籌碼面資訊盲區」與「量化數據艱澀難懂」的雙重困境：
1. **籌碼資訊盲區**：既有系統具備交易記帳、資產淨值 (NAV) 折線圖、資產樹狀圖與股息行事曆，但投資人無法察覺自己持有的股票目前是否有大型外資、投信或主力機構正在加碼進駐（幫忙抬轎）或是拉高倒貨（即將割韭菜）。
2. **新手門檻過高**：傳統籌碼分析軟體充斥著「投外本比」、「買賣家數差」、「融資融券資券比」、「CMF 散度」等冰冷量化專有名詞，對於零基礎的初學者來說門檻極高，無法在幾秒鐘內理解數字代表的實質多空意涵。
3. **靜態切片缺乏動態時序感知**：傳統報表僅提供當日單點靜態數據，投資人無法直觀看到「資金是連續多天持續流入」還是「一日誘多行情」，缺乏如時間軸動態回放的位移路徑。
4. **台美雙市場籌碼結構差異未對齊**：台股由證交所每日強制公告三大法人明細，而美股依 SEC 法規並無每日法人買賣超，跨市場投資人在統一視圖中缺乏標準化的比對基準。

---

## Solution

建立一個專為「零基礎投資人」打造的視覺化翻譯機——**「籌碼與聰明錢動態觀察儀 (Smart Money Flow Bubble View)」**：
1. **大白話四象限座標系統**：
   - 橫軸（X 軸）為「價格漲跌幅動能 (%)」，縱軸（Y 軸）為「大機構聰明錢進出強度」。
   - 四個象限分別賦予完全口語化、生活化的情境定義：
     - **🔥 主力抬轎飆股區 (右上)**：大機構砸錢買進、股價同步強推，動能最強。
     - **🛡️ 逢低撿便宜區 (左上)**：股價雖然震盪回檔，但大機構卻在悄悄大買吃貨，常為潛在低階起漲點。
     - **⚠️ 割韭菜警戒區 (右下)**：股價看似在漲，但大機構卻在趁高倒貨出逃，散戶極易成為高檔接盤俠。
     - **❄️ 冷凍提款區 (左下)**：股價大跌且大機構也在大賣逃跑，人走茶涼，碰不得。
2. **3 秒看懂的視覺語法**：
   - **大小 (Size)**：在庫市值愈大（或成交量愈大），泡泡愈大，代表影響力愈大。
   - **顏色 (Color)**：連動全專案色彩主題，外資投信合買亮多頭光暈、雙主力倒貨亮空頭警示。
   - **移動軌跡 (Motion Trails)**：泡泡拖帶半透明彗星尾巴，清楚呈現近 5 日、10 日、20 日的位移方向。
3. **時間軸動態播放器 (Timeline Player)**：
   - 提供「播放 / 暫停 / 拖曳」歷史日期滑桿，像動態動畫一樣重播過去一個月聰明錢如何在各股票間換手與轉移。
4. **跨市場官方一手數據標準化**：
   - **台股 (TW)**：直連台灣證券交易所 (TWSE) 官方開放端點（`fund/T86`）與 TPEx 官方數據，每日盤後單次請求獲取全市場三大法人淨買賣超。
   - **美股 (US)**：採用華爾街標準之 Chaikin Money Flow (CMF 佳慶資金流向) 演算法，將 Yahoo Finance 官方日 K 量價時序換算為資金吸籌與派發強度。
   - **跨市場統一標度**：在雙市場全覽視圖中，將流向強度標準化為 $-100\% \sim +100\%$，實現台美同台無縫對比。
5. **人類大白話懸浮診斷 (Tooltip)**：
   - 滑鼠懸浮泡泡時，頂部第一眼呈現一句直接的人類白話結論（如「🟢 主力強烈做多中！外資投信過去 5 天聯手加碼 3.2 萬張」），底下才展開詳細數據。

## User Stories

1. 身為完全沒有籌碼基礎的投資新手，我希望在泡泡圖頂部看到折疊式的「3 秒新手速讀指南」，以便於我不需要查詢任何金融名詞就能立刻看懂圖表。
2. 身為投資組合持有者，我希望進入「籌碼與動態星圖」分頁時，能預設看到我個人在庫持股的動態泡泡分佈，以便於我一眼看出自己的持股哪幾檔有大機構在撐腰。
3. 身為重視主力方向的交易者，我希望當某檔持股落在「🔥 主力抬轎區」時，泡泡以顯眼的強勢光暈呈現，以便於我抱牢強勢多頭部位。
4. 身為想要避開主力倒貨陷阱的投資人，我希望當某檔股票「價漲但法人大賣」落在「⚠️ 割韭菜警戒區」時，系統能發出警示提示，以便於我及時提高警覺。
5. 身為逢低布局型的投資人，我希望看見哪些持股正落在「🛡️ 逢低撿便宜區」，以便於我發掘大機構悄悄逆勢吸籌的潛力標的。
6. 身為注重資金趨勢的長線投資人，我希望點擊時間軸播放器的「▶ 播放」按鈕，觀測過去 20 個交易日內泡泡的連續移動軌跡，以便於分辨該股票是長期穩定流入還是短期一日行情。
7. 身為持有多檔美股的投資人，我希望在切換至「美股市場」時，系統能自動以 CMF 資金流向指標呈現聰明錢意向，並以淺顯文字向我解釋美股指標的由來。
8. 身為台美雙市場配置的投資人，我希望在切換為「雙市場 (ALL)」模式時，美股與台股能以統一的標準化百分比呈現在同一張四象限圖中，以便於我橫向比較不同市場主力對標的的青睞程度。
9. 身為滑鼠移至特定泡泡的使用者，我希望浮窗第一行顯示親切的大白話診斷結論，隨後才呈現買賣超張數與成交金額，以便於我能以最快速度獲取關鍵情報。
10. 身為使用不同視覺習慣的投資人，我希望泡泡的多空顏色嚴格遵循系統已設定的「慣用紅綠主題」（台股紅漲綠跌 / 國際綠漲紅跌），以便於視覺體驗保持高度一致。
11. 身為希望發掘市場新焦點的使用者，我希望在頂部切換「全市場法人焦點 Top 30」，以便於探索除現有持倉之外市場資金最集中追捧的前 30 大標的。
12. 身為離線或弱網環境下的使用者，我希望歷史籌碼資料能保存在瀏覽器 IndexedDB 中，以便於在無網路連線時依然能秒開檢視上一次的籌碼動態。

## Implementation Decisions

1. **工作台分頁載體擴充**：
   - 於頂部 `WorkspaceTabs` 新增 `chips` 分頁（標籤：「籌碼與聰明錢」，圖示：Activity / Zap，徽章動態標註當前持倉多空比或標的數）。
2. **純函數領域計算引擎 (`smartMoneyEngine.ts`)**：
   - **台股三大法人買賣超解析**：解析 TWSE `T86` 格式，計算外資、投信、自營商買賣超張數與金額，並換算為佔股本比例或市場權重。
   - **美股 Chaikin Money Flow (CMF) 演算法**：基於歷史日 K 線之 High, Low, Close, Volume 計算 20 日 CMF 值，範圍介於 $[-1.0, +1.0]$。
   - **四象限座標標準化映射**：
     - $X$ 坐標（動能）：將週期漲跌幅百分比映射至畫布橫軸 $[-100, +100]$，以 0% 為中心中軸。
     - $Y$ 坐標（聰明錢強度）：台股依買賣超金額標準化，美股依 CMF 指標標準化，收斂至縱軸 $[-100, +100]$，以 0 軸為基準線。
   - **白話診斷生成器**：依據象限歸屬與主力動作，動態回傳易懂的人類語言評語（`status`: `ACCUMULATION` | `BREAKOUT` | `DISTRIBUTION` | `LIQUIDATION`）。
3. **資料型別形狀 (Type Contract Prototype)**：
```typescript
export interface SmartMoneyBubbleData {
  symbol: string;
  name: string;
  market: 'TW' | 'US';
  x: number; // 漲跌幅動能 (-100 ~ +100)
  y: number; // 聰明錢流向強度 (-100 ~ +100)
  radius: number; // 泡泡半徑 (基於市值或成交量，12px ~ 48px)
  changePercent: number; // 實質漲跌幅
  netFlowAmount: number; // 實質流向金額 (TWD/USD)
  flowDescription: string; // 繁體中文白話描述 (如: "外資與投信合買 1.2 億")
  quadrant: 'BREAKOUT' | 'ACCUMULATION' | 'DISTRIBUTION' | 'LIQUIDATION';
  quadrantLabel: string; // 白話標籤 (如: "🔥 主力抬轎區")
  diagnosisTitle: string; // 人類診斷結論 (如: "大機構強烈做多中！")
  diagnosisDetail: string; // 詳細人話解釋
  trail: { x: number; y: number; date: string }[]; // 過去 N 天之位移歷史點
}
```
4. **官方資料管線與快取策略**：
   - **TWSE 官方日報端點**：`https://www.twse.com.tw/rwd/zh/fund/T86?response=json&date=YYYYMMDD&selectType=ALLBUT0999`，每日收盤後單次拉取，自動儲存至 IndexedDB `chipsData` 表格，過期時間為次一交易日 15:30。
   - **美股數據**：複用既有 Yahoo Finance Chart API 批次日 K 線獲取，避免新增付費 API。
5. **輕量原生 SVG 渲染與 CSS 動畫**：
   - 拒絕引入龐大第三方圖表庫（0 額外 bundle 負擔）。
   - 採用純 React + 原生 SVG `<circle>`、`<path>` 與 `<text>` 渲染四象限與動態泡泡。
   - 動態移動採用 CSS `transform` 與平滑過渡（`transition: all 0.5s ease-out`），保證 60 FPS 流暢度。

## Testing Decisions

1. **什麼是好測試 (What makes a good test)**：
   - 嚴格遵守「只測試公開行為，不測試內部實作細節」之原則。
   - 測試應在公開介面縫隙處進行斷言，確保在變更內部演算法（如改善平滑公式）時，只要核心輸入輸出邏輯不變，測試應依然保持綠燈。
2. **待測試的模組與縫隙**：
   - **主要縫隙 (Primary Seam)**：`calculateSmartMoneyFlowDynamics`，驗證：
     - 給定台股買賣超與漲跌幅，正確映射至相應的四象限與標籤。
     - 給定美股日 K 量價，正確計算出 CMF 值並歸一化為 Y 軸坐標。
     - 當市場處於「價漲但法人大賣」時，必定落入 `DISTRIBUTION`（割韭菜警戒區）並產出對應警示白話。
   - **輔助縫隙 (Secondary Seams)**：
     - `parseTwseT86Report`：正確解析證交所官方 JSON 回應格式，處理無資料與非交易日異常。
     - `generateMotionTrails`：正確串接歷史時間序列形成連續軌跡座標。
3. **現有程式碼庫中的先例 (Prior Art)**：
   - 參考 `src/engine/technicalIndicatorEngine.test.ts`（技術指標純函數測試）。
   - 參考 `src/engine/historicalNav.test.ts`（時序資料向前補齊與平滑測試）。

## Out of Scope

1. **日內即時逐筆大單串流 (Real-time Tick-by-Tick)**：本功能聚焦於「日 K 與波段級聰明錢移動（1D / 5D / 20D）」，不進行毫秒級逐筆 Tick 串流，避免瀏覽器效能崩潰與付費行情源依賴。
2. **自動代客跟單或下單交易**：觀察儀僅作為決策輔助與教學可視化工具，不具備向券商發送委託下單之能力。
3. **付費第三方籌碼資料庫**：嚴格排除需要額外 API 金鑰或每月收費之商業資料服務。
