- **功能名稱**：持股技術指標警示膠囊 Tooltip 結構化卡片、乖離率 (Bias %) 與多週期共振架構
- **版本**：v7.2.1
- **建立日期**：2026-09-02
- **狀態**：`ACCEPTED` / `IMPLEMENTED`
- **關聯 ADR**：[ADR 0068](../adr/0068-holding-signals-structured-tooltip-bias-confluence.md)

---

## 2. 業務背景與問題定義

在 v7.2.0 上線「持股技術指標警示膠囊與智慧操作建議引擎」後，真實用戶操作反饋以下關鍵問題：
1. **Tooltip 左側截斷缺陷**：
   - 膠囊位於持股表格最左側欄位，預設 `align="center"` 導致 Tooltip 向左突出約 140px，超出螢幕邊緣或被表格父層的容器遮擋截斷。
2. **純文字描述缺乏券商專業度**：
   - 單一純文字字串在視覺上缺乏結構，專業投資人無法一眼洞察量化得分、多空分項與風控指引。
3. **缺少均線乖離率 (Bias %) 標籤**：
   - 單純標記「月線之上」無法判斷股價是否已過度超買過熱（可能正乖離過大面臨修正風險）或負乖離過大（超跌反彈契機）。
4. **缺少多週期共振判定**：
   - 短線均線（5MA）與長線均線（60MA/季線）方向不一致時（例如空頭走勢中的短線強彈），需要明確定義「長空短多 (反彈減碼)」與「長多短空 (拉回止跌)」。

---

## 3. 解決方案與核心架構設計

### 3.1 Tooltip 靠左對齊防截斷 (`align="left"`)
- 在 `HoldingSignalCapsules.tsx` 中將所有定調徽章與各維度警示膠囊的 `<Tooltip>` 屬性統一指定為 `align="left"` 與 `position="top"`。
- Tooltip 起始錨點固定於膠囊本體左緣（`left: 0`），寬度向右展開，完全避免向左突出螢幕。

### 3.2 結構化專業資訊卡片 (`Structured Directive Tooltip`)
將定調徽章的 Tooltip 升級為三層結構：
1. **頂部 Header**：
   - 呈現四字定調高亮標籤（含 Sparkles 圖示）
   - 呈現量化評分徽章（例如 `量化評分: +3` 或 `-3`）
2. **中部 Content**：
   - 客觀紀律性操作指南內文（例如「股價突破短期均線糾結並放量上攻...」）。
3. **底部 Footer**：
   - 標註底層量化規則來源與風控紀律備註。

### 3.3 均線乖離率 (Bias %) 量化引擎
- **20MA 月線乖離率**：$\text{Bias}_{20} = \frac{\text{Price} - \text{MA}_{20}}{\text{MA}_{20}} \times 100\%$
- **60MA 季線乖離率**：$\text{Bias}_{60} = \frac{\text{Price} - \text{MA}_{60}}{\text{MA}_{60}} \times 100\%$
- **膠囊觸發規則**：
  - $\text{Bias}_{20} \ge +8.0\%$：觸發 `月線正乖離 (+X.X%)`（調性：`WARNING`，權重：`-1`，提示慎防短線過熱拉回）。
  - $\text{Bias}_{20} \le -6.0\%$：觸發 `月線負乖離 (X.X%)`（調性：`WARNING`，權重：`+1`，提示短線超跌反彈契機）。

### 3.4 多週期共振結構 (Multi-Timeframe Confluence)
- **長空短多 (反彈)**：$5\text{MA} > 20\text{MA}$ 且 $\text{Price} < 60\text{MA}$（調性：`WARNING`，權重：`0`）。
- **長多短空 (拉回)**：$5\text{MA} < 20\text{MA}$ 且 $\text{Price} \ge 60\text{MA}$（調性：`NEUTRAL`，權重：`+1`）。
