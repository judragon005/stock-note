# PRD 0098: 肌肉書僮三色實戰決策矩陣與多因子真動態 AI 晨報規格書

## 1. 背景與核心痛點

1. **痛點 1（肌肉書僮缺乏明確操作動作）**：
   - 使用者進入「肌肉書僮·動能雷達」後，只看到生硬的統計術語（「箱頂突破」、「底穿上」、「布林極致壓縮」），無法第一時間獲得清晰的操盤動詞指引（**哪一支要買、哪一支不能碰、哪一支要賣**），亦缺乏進場防守價與停損點。
2. **痛點 2（AI 晨報作戰方針淪為空泛廣告看板）**：
   - 戰情室頂部的「AI 晨報作戰方針」目前使用泛用型靜態區間，輸出「定期定額、安心專注本業」等與個人帳戶無關的心靈雞湯。
   - 缺乏對使用者**在庫持股突破/破線事件、待收股息進度、重大催化劑天數、目標配置偏離度**之動態結合，喪失實戰參考價值。

---

## 2. 規格細節與實作架構

### 2.1 肌肉書僮三色實戰決策矩陣 (Traffic-Light Action Matrix)
在 `src/engine/muscleBookerEngine.ts` 新增操作判定模型：
- **`ActionType = 'BUY' | 'AVOID' | 'SELL' | 'HOLD'`**：
  1. **`BUY` (🟢 建議買進)**：
     - 條件：① 箱頂帶量突破 (`BREAKOUT_UP`) 且 20MA 向上；或 ② 底穿上破底翻反轉 (`isBottomPenetrationRebound`)。
     - 輸出：
       - `actionBadge`: `🟢 建議買進`
       - `entryPrice`: 當前收盤價
       - `stopLossPrice`: 箱頂價或破底翻下影線低點
       - `targetPrice`: 依箱體等幅對稱映射（箱頂 + 箱體寬度）
       - `riskRewardRatio`: 預期風益比（例如 `1 : 3.2`）
  2. **`AVOID` (⛔ 觀望不碰)**：
     - 條件：① 布林極致壓縮中 (`isBollingerSqueeze`，帶寬 < 8% 未出方向)；或 ② 20MA 扣抵高檔下彎反壓 (`ma20Slope === 'DOWN'`)。
     - 輸出：
       - `actionBadge`: `⛔ 嚴禁碰觸`
       - `actionReason`: `變盤前夕等待表態，禁止預測押注` 或 `均線下彎蓋頭反壓，切忌接刀`
  3. **`SELL` (🔴 建議賣出/停損)**：
     - 條件：① 跌破箱底防守線 (`BREAKOUT_DOWN`)；或 ② 假突破長黑跌回箱內。
     - 輸出：
       - `actionBadge`: `🔴 建議賣出`
       - `actionReason`: `跌破箱底防守線，嚴格無條件停損保本金`
  4. **`HOLD` (🔵 區間續抱/觀察)**：其餘箱內正常震盪者。

- **工作區 UI 交互 (MuscleBookerWorkspace)**：
  - 增設快速決策標籤過濾：`🔥 全部標的` | `🟢 建議買進 (X)` | `⛔ 觀望不碰 (Y)` | `🔴 建議賣出 (Z)`。
  - 卡片顯著呈現「操作動作標籤 + 停損防守點 + 風益比」。

### 2.2 帳戶多因子真動態 AI 晨報引擎 (Account Event-Driven AI Advisor)
在 `src/engine/macroAdvisorEngine.ts` 擴展 `generateAiMorningBrief`，由多因子事件流驅動：
1. **持倉動態事件 (Holding Radar Events)**：
   - 掃描在倉持股，檢測出有突破買點者（如台積電）、跌破箱底停損者（如中信金）。
2. **現金與待收股息事件 (Cash & Receivables Events)**：
   - 注入待收股息資訊（未來 14 天內即將發放之現金股息金額與標的）。
3. **宏觀催化劑事件 (Macro Catalysts Events)**：
   - 注入 7 天內重磅經濟事件（如美國 CPI、FOMC）。
4. **配置偏離事件 (Allocation Drift Events)**：
   - 找出偏離目標配置超過警戒門檻的個股或板塊。
5. **晨報指令動態生成**：
   - 標題 (Headline)：動態指出今日核心矛盾（例：`【動能分歧・防守為先】`、`【突破訊號浮現・逢低加碼】`）。
   - 今日客觀紀律執行清單（3 條具體指令）：
     - 指令 1：**具體持股進出指示**（點名股票代號與停損點位）。
     - 指令 2：**宏觀催化劑防禦與資金調度**（依據倒數天數指示加碼或觀望）。
     - 指令 3：**股息與配置再平衡指引**（點名待收股息再投資或超配標的停利）。

## 3. 測試驗收準則 (Acceptance Criteria)

1. **AC-1**: 肌肉書僮引擎能對任一標的準確評定 `BUY` / `AVOID` / `SELL` / `HOLD`，並計算停損點與風益比。
2. **AC-2**: 肌肉書僮頁面提供「🟢 建議買進 / ⛔ 觀望不碰 / 🔴 建議賣出」過濾標籤，卡片清晰展示動作與點位。
3. **AC-3**: AI 晨報作戰方針根據個人真實在庫股票狀態動態生成，能具體點名持股代號與價位，徹底擺脫廣告看板。
4. **AC-4**: 全專案單元測試 100% 綠燈，TypeScript 0 錯誤。
