## 1. Problem Statement (問題陳述)

在 V1.2 中，系統建立了基準日時序回溯判定與基礎公司行動（除權息、減資退款、分割）架構。然而在實務投資體驗中仍面臨三大痛點：
1. **資料源覆蓋度不足**：先前依賴的 Yahoo Finance 國際版 Chart API 並不收錄台灣證交所 (TWSE) 的「現金減資退還股款」與部分上櫃 (TPEx) 資訊；且依賴的靜態離線備援庫標的有限（如缺乏 9927 泰銘），導致使用者掃描時顯示「0 事件」而無法自動補登。
2. **市場類別不夠全面**：投資人的持股組合涵蓋台股上市 (TWSE)、上櫃 (TPEx)、台股 ETF、債券型 ETF（如 00679B, 00751B）以及美股全市場（NYSE, NASDAQ, AMEX, 美股 ETF），需要全市場純線上即時對接。
3. **缺乏特殊公司行動支援**：企業併購換股 (Merger)、特別股到期收回 (Redemption)、企業分拆 (Spin-off)、可轉債 (CB) 換股、公開收購私有化 (Tender Offer) 等複雜事件在資本市場屢見不鮮，現有系統缺乏對應的事件型別與會計成本轉移/拆分模型。

---

## 2. Solution (解決方案)

全面升級為**「全市場 100% 純線上即時掃描 + 特殊公司行動全覆蓋會計引擎」**：
1. **全市場純線上即時資料源 (100% Live Online)**：
   - **台股全市場**：串接台灣證交所 (TWSE) 官方 OpenAPI（`TWT48U_ALL` 減資預告表、`TWT49U_ALL` 除權除息預告表）與櫃買中心 (TPEx) 上櫃/債券資料源，支援上市、上櫃、各類股票與 ETF。
   - **美股全市場**：直連 Yahoo Finance API（支援 NYSE/NASDAQ/AMEX 股票與 ETF 之 Dividends & Splits），搭配多重 CORS 代理池自動輪詢與指數退避重試機制。
   - **全面廢除靜態離線假資料庫**，確保掃描結果 100% 為真實公開市場數據。
2. **智能持有時間窗口劃定 (Dynamic Time Horizon)**：
   - 自動依持股的「最早買進日」至「今日」動態拉取歷史事件，並嚴格過濾非持股期間之事件。
3. **五大特殊公司行動會計引擎全量擴充**：
   - **換股合併 (`STOCK_MERGER`)**：原標的股數歸零，新標的按比例增股，投入成本基準轉移至新標的。
   - **特別股贖回 (`PREFERRED_REDEMPTION`)**：公司以約定價收回，退還現金，計算已實現損益並結清持股。
   - **企業分拆 (`SPIN_OFF`)**：母公司按比例拆分原始成本予新分拆子公司，新子公司按配發比例新增持股。
   - **可轉債 (CB) 換股 (`CB_CONVERSION`)**：將債券總投入成本與張數依轉換價格轉化為新普通股股數。
   - **公開收購 / 私有化 (`TENDER_OFFER`)**：依收購價全額結算賣出並結算已實現損益。
4. **雙模錄入與即時試算介面**：
   - 智慧掃描彈窗支援全市場事件一鍵預覽與批次入帳。
   - 交易彈窗 (`TradeModal`) 提供 12 種交易/公司行動模式之專屬動態表單與基準日持股即時試算。

## 3. User Stories (使用者故事)

1. **US-36 (台股全市場減資與除權息線上掃描)**：作為台股投資人（持有上市、上櫃、ETF 如 9927 泰銘、00679B 等），我點擊智慧掃描，系統能自動向 TWSE/TPEx 與即時金融 API 拉取持有期間內的現金減資與除權息，自動計算應退款金額與配息。
2. **US-37 (美股全市場線上即時掃描)**：作為美股投資人（持有美股標的與 ETF），我點擊智慧掃描，系統能自 Yahoo Finance 即時拉取除息與股票分割事件。
3. **US-38 (智慧掃描一鍵補登與庫存即時連動)**：作為投資人，當我勾選補登 9927 泰銘的 2025 現金減資時，持股庫存自動由 10,000 股縮減為 7,172 股，本金扣減 $28,280 元，表格自動呈現「原買入 10,000 股」與「已扣減資退款」。
4. **US-39 (連線容錯與指數退避自動重試)**：作為使用者，當網路暫時受限或 API 被限流時，系統於介面明確標示「⚠️ 連線異常」，並自動以指數退避演算法排程重試或提供手動重試按鈕。
5. **US-40 (換股合併會計處理)**：作為投資人，當我記錄 A 公司被 B 公司換股合併時，系統將 A 公司持股歸零，並將原始本金按換股比率轉移至 B 公司新增之持股。
6. **US-41 (特別股贖回會計結算)**：作為特別股投資人，當特別股到期被公司以發行價收回時，系統退還現金、持股歸零並結算歷史已實現損益。
7. **US-42 (企業分拆成本拆分)**：作為投資人，當母公司分拆新子公司時，母公司成本依分攤比率調降，新子公司以分攤後之成本與獲配股數入帳。
8. **US-43 (可轉債換股普通股)**：作為債券/可轉債投資人，我輸入債券成本與轉換價，系統自動換算新發行之普通股股數與成本。
9. **US-44 (公開收購私有化下市)**：作為被收購公司股東，我輸入收購價格，系統自動全數結清該標的並結算最終損益。
10. **US-45 (交易彈窗 12 種動態表單與試算)**：作為使用者，我在新增/編輯交易時切換至任意常規或特殊公司行動，表單動態呈現專屬欄位（如換股比率、轉換價、收購價、分攤比例），並自動依基準日持股即時試算。
11. **US-46 (CSV 匯出匯入擴充相容)**：作為使用者，我匯出與匯入 CSV 時，完整相容所有 12 種交易類別與新增欄位。

## 4. Implementation Decisions (實作架構決策)

1. **擴充統一事件流型別 (`src/types/stock.ts`)**:
   - `TradeType` 擴充為 12 種型別：
     - 常規：`'BUY' | 'SELL' | 'DIVIDEND' | 'STOCK_DIVIDEND' | 'STOCK_SPLIT' | 'CAPITAL_REDUCTION' | 'CAPITAL_INCREASE'`
     - 特殊：`'STOCK_MERGER' | 'PREFERRED_REDEMPTION' | 'SPIN_OFF' | 'CB_CONVERSION' | 'TENDER_OFFER'`
   - `TradeRecord` 擴充選擇性欄位：
     - `targetSymbol?: string` (換股或分拆之目標標的代碼)
     - `allocationRatio?: number` (分拆成本分攤比例)
     - `conversionPrice?: number` (CB 轉換價)
     - `cashAmount?: number` / `ratio?: number` / `exDate?: string`

2. **全市場多源純線上掃描架構 (`src/engine/corporateActionScanner.ts`)**:
   - 串接 TWSE OpenAPI 減資表 (`TWT48U_ALL`) 與除權息表 (`TWT49U_ALL`)。
   - 支援上市代碼 (`.TW`)、上櫃代碼 (`.TWO`)、各類台美股 ETF 與一般股票。
   - 建立多重 CORS Proxy 輪詢機制（`corsproxy.io`, `api.allorigins.win`, `codetabs`）確保跨域請求高可用性。
   - 廢除靜態假資料庫，回傳真實資料與連線狀態。

3. **計算與會計引擎擴充 (`src/engine/calculator.ts`)**:
   - 擴充純函式 `applyTradeToShares` 支援所有 12 種型別之股數計算。
   - 擴充 `calculateHoldingsAndSummary` 支援跨標的成本轉移（合併）、成本比例拆分（分拆）、債券轉股票（CB 換股）與贖回收購結算。

4. **UI 組件全面升級**:
   - `CorporateActionScannerModal.tsx`：呈現全市場線上掃描結果、各標的連線狀態與自動重試按鈕。
   - `TradeModal.tsx`：支援 12 種型別分類切換器與專屬動態欄位。
   - `HoldingsTable.tsx` & `TradeHistoryTable.tsx`：支援特殊事件徽章、換股關聯標記與股權異動時間軸。
