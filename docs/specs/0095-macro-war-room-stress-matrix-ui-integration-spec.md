# 需求規格說明書 (PRD) - 0095: 宏觀戰情室與黑天鵝壓力測試矩陣前端 UI 視覺化全面整合

## 1. 概述 (Overview)

### 1.1 背景與問題說明 (Context & Problem Statement)
專案已順利實作完成 5 大高階量化風控底層引擎（API 速率限制器、肌肉書僮歷史指標庫、雙重動能輪動評分、黑天鵝壓力矩陣與斷頭逃生模擬器、宏觀指標與雙軌制 AI 作戰方針引擎）。然而，目前前端視圖（View Layer）尚未掛載這些引擎，導致使用者在瀏覽器中無法看見實施成效與進行實戰操作。

### 1.2 系統目標 (Goals & Non-Goals)
- **Goals**：
  1. **新建「🏛️ 總體戰情室 (War Room)」工作區組件 (`WarRoomWorkspace.tsx`)**：
     - **頂部**：【🤖 AI 智慧每日作戰方針】四字定調卡片（如 `【防禦蓄勢・分批低接】`）、宏觀診斷、防護盾評語與今日行動要點。
     - **第一層**：市場四柱即時脈搏（利率美債、恐慌情緒 VIX、避險商品黃金/原油、全球流動性美元指數/匯率）。
     - **第二層**：個人投資組合宏觀防護盾（現金購買力水位、質押借貸維持率安全等級、資產配置偏離度）。
     - **第三層**：雙重動能跨資產趨勢輪動排行榜（支援三大預設資產池切換、避風港狀態指示與 12-1M 分數）。
     - **第四層**：關鍵財經催化劑倒數日曆（FOMC、美國 CPI、非農與央行會議倒數）。
  2. **在導覽列 (`WorkspaceTabs.tsx`) 註冊 `warroom` 頁籤**，支援一鍵切換與未讀/亮點狀態。
  3. **全面升級 `MarginStressModal.tsx`**：
     - 將舊版單純滑桿升級為「黑天鵝 6 維情境動態壓力矩陣」切換卡（常態 -5%/-10%、重挫 -20%、黑天鵝 -30%、純除息跳水、複合黑天鵝）。
     - 呈現每檔質押標的之「斷頭臨界價格逆推清單」與最大耐受跌幅。
     - 呈現「一鍵逃生雙軌救生圈」（方案 A 償還本金 / 方案 B 補繳現金擔保品 / 方案 C 加質現有持股）。
  4. **增強持倉訊號膠囊 (`HoldingSignalCapsules.tsx`)**：
     - 展示肌肉書僮箱子戰術突破/跌破/箱內盤整標籤與均線扣抵提示。
- **Non-Goals**：
  - 本次更新專注於前端視覺化呈現與操作互動，不破壞底層引擎現有已通過之測試與向後相容性。

## 2. 介面與組件規格 (UI Components Specification)

### 2.1 導覽列擴充 (`src/components/WorkspaceTabs.tsx`)
- 新增標籤 Key：`warroom`
- 標籤名稱：`總體戰情室`
- 圖示：`Compass` 或 `Flame`
- 徽章：`AI 晨報` (高亮色彩)

### 2.2 宏觀戰情室工作區 (`src/components/WarRoomWorkspace.tsx`)
- 採用專案 Modern Glassmorphism 設計風格，深色暗色模式自適應。
- 支援手動微調宏觀參數（如 VIX、10Y 利率、恐慌貪婪指數）進行即時互動推演。
- 輪動排行榜支援資產池切換（全球核心 ETF、台股高息與市值、美股美債對沖）。

### 2.3 質押黑天鵝逃生彈窗升級 (`src/components/MarginStressModal.tsx`)
- 頂部保留維持率儀表盤與安全水滴條。
- 中部新增「6 維情境矩陣快捷切換卡」，點選任一情境即時切換壓力數值。
- 下部新增「斷頭臨界價逆推表格」與「救生圈逃生方案卡片」。

## 3. 驗收標準 (Acceptance Criteria)

1. 點擊導覽列「🏛️ 總體戰情室」可順暢切換至戰情室畫面，渲染 AI 每日作戰方針、四柱脈搏、個人防護盾與雙重動能輪動榜。
2. 點擊「質押維持率」開啟壓力測試彈窗時，能看見完整的 6 維情境切換、每檔個股斷頭臨界價與逃生三方案。
3. 持倉列表訊號膠囊能正常顯示短線動能與肌肉書僮箱子狀態。
4. 全專案 100% 通過單元測試，TypeScript 編譯零錯誤，Vite build 正常。
