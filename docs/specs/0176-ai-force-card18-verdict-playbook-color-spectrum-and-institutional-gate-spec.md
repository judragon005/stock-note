# Spec 0176: Card 18 主力追蹤總評判操盤指引升級、5 態作戰光譜圖例、三軌色彩認知對齊與機構級風控門檻

## 1. 概述 (Overview)

本規格針對主力戰情室第 7 層的核心壓軸面板 **Card 18「主力追蹤總評判 (MLP-AI)」** (`MainForceVerdictCard`) 進行深度功能升級與版面重構。

在現行架構中，Card 18 獨佔第 7 層右欄滿高（~480px），但卡片中央留有超過 180px 的深色留白荒漠；同時色彩判定存在斷層，導致「低接吸籌」被錯誤渲染為天藍色且標示為「防禦觀望」，文字解析 Regex 亦未能匹配現行量化數列格式。

本規格透過「方案 A（微型光譜圖例條）+ 方案 B（量化研判彈窗指南）」互補架構，全面整合**券商研究部、交易所監理、機構法人與終端投資人**四方視角，將 Card 18 由單純的大字標籤卡進化為具備實戰錨點、週期引導、風控閥值與清晰色彩認知的旗艦級作戰總指揮面板。

## 2. 使用者痛點與四方角色盲點分析 (Problem Statement & 4-Perspective Analysis)

### 2.1 現狀核心缺陷
1. **版面留白荒漠**：卡片僅靠 `justifyContent: space-between` 撐開，中間高達 150~200px 缺乏實質決策內容，嚴重浪費空間。
2. **色彩語意認知混淆與 Bug**：
   - 「低接吸籌」未命中「進貨/買」，掉入 Fallback 天藍色 `#38bdf8`。
   - 右側小燈號文字因條件缺失，顯示「防禦觀望」，與主動低檔吸籌意圖矛盾。
3. **數據膠囊失聯**：`parseVerdictMetrics` 正則表達式寫死於舊格式，無法抓取當前引擎輸出的「收盤價、VWAP 乖離率、主力成本」，膠囊完全未渲染。

| 市場角色 | 核心關注重點 | 現狀盲點與漏洞 | 本規格對應補強措施 |
| :--- | :--- | :--- | :--- |
| **券商營業員 / 投顧 (Brokerage)** | 具體點位、勝率、操作週期 | 只給四字指令，無進場區間、無停損點、無適用週期，交易員無法向客戶交代。 | 提供「建議分批承接區間」、「絕對停損點」、「目標反彈價」與「適配操作週期標籤」。 |

## 3. 架構設計與功能規範 (Detailed Specifications)

### 3.1 5 態主力作戰光譜圖例條 (方案 A: Micro Spectrum Bar)

在核心看板（「主力核心語意」）正下方嵌入一條高度 26px 的橫向微型光譜導航條，呈現主力運作之 5 大週期階段：

```
[超跌反彈] ➔ [低接吸籌] ➔ [鎖碼推升] ➔ [高檔調節] ➔ [區間震盪]
 🟣 搶反彈     🔵 逢低佈局    🔴 順勢加碼    🟡 分批停利    ⚪ 空手觀望
 (半透明)      ★ 高亮發光     (半透明)       (半透明)       (半透明)
```

- **規格細節**：
  - 容器採用 `display: flex; gap: 4px; padding: 4px 6px; background: rgba(15, 23, 42, 0.5); borderRadius: 8px;`。
  - 當前個股命中之語意狀態（如「低接吸籌」）：
    - 背景呈現該色彩 18% 透明度之膠囊底色。
    - 邊框具備 `1px solid ${color}` 與柔和 Box-Shadow 光暈。
    - 文字高亮顯示並帶有 `★` 或圓點標記。
  - 其餘 4 個未命中狀態：
    - 維持低對比半透明（`opacity: 0.45`），文字以灰色 `#64748b` 呈現。
  - **點擊或懸停微交互**：懸停未激活標籤時顯示該階段之簡要觸發門檻 Tooltip。

### 3.2 空白區域重塑：語意解析與實戰操盤指引 (Market Context & Action Playbook)

於中央空白區域建構雙層結構化 Bento 資訊區塊：

#### A. 語意深度解析 (Market Context Panel)
- **容器樣式**：深藍半透明背景 `rgba(30, 41, 59, 0.45)`，左側具備 3px 品牌光條（對齊當前語意主色），內距 `8px 12px`。
- **內容展示**：
  - 標題：`▌ 語意微觀解析 (Market Context)`。
  - 內文：基於現有 `currentPrice`、`mainForceCost (VWAP)`、乖離率與籌碼動態，生成客觀的量價因果解讀。
  - *範例（低接吸籌）*：「現價 (367.5 元) 回落至主力成本線 (-4.3%)，短線跌幅已深；大戶賣壓逐步衰竭，機構資金於關鍵支撐帶低掛買盤吸納浮額，籌碼進行沉澱。」

#### B. 實戰操盤指引 (Actionable Playbook Panel)
- **容器樣式**：`background: rgba(15, 23, 42, 0.6); border: 1px solid rgba(255, 255, 255, 0.08); borderRadius: 8px; padding: 10px 12px;`。
- **內容結構（四合一矩陣）**：
  1. **操作週期 (Horizon)**：顯示適配週期標籤膠囊（如 `3~5 日短線波段` / `波段續抱` / `忌追高當沖`）。
  2. **建倉/應對策 (Execution Directive)**：給出具體建倉步調（如「分批金字塔掛單，切忌市價追擊」）。
  3. **關鍵錨點 (Price Anchors)**：
     - **防守停損價 (Stop-Loss Pivot)**：計算近 20 日低點或主力成本下緣（如 `355.0 元 (-3.4%)`）。
     - **目標滿足價 (Target Resistance)**：回測 20 日 VWAP 成本位（如 `384.2 元 (+4.5%)`）。
     - **預估風報比 (R/R Ratio)**：動態計算顯示（如 `2.4 : 1`）。
  4. **風控失效條件 (Invalidation Gate)**：
     - 明確標示「若盤中放量摜破 355.0 元或外資單日大賣超，吸籌邏輯宣告失效」。

### 3.3 三軌色彩認知體系與燈號邏輯校正 (Color Cognitive Realignment)

重構 `getVerbBadgeColor` 與右側狀態燈號判定，杜絕斷層：

| 核心語意 (Verb) | 認知軌道 | 主題色 (Hex) | 背景 / 邊框 | 右側燈號文字 | 心理認知定位 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **鎖碼推升** / **強勢續抱** | 軌道一：多頭攻擊 | `#ef4444` (台股紅) | 紅色系玻璃 | `● 偏多集結` | 順勢多方攻擊、量增價揚 |
| **低接吸籌** | 軌道二：吸籌蓄勢 | `#38bdf8` (科技藍) | 藍色系玻璃 | `● 偏多承接` *(修正！原為觀望)* | 逢低防守型買盤、分批佈局 |
| **超跌反彈** | 軌道二：超跌轉折 | `#c084fc` (紫羅蘭) | 紫色系玻璃 | `● 跌深反抽` | 負乖離過大、短線投機快打 |
| **調節減碼** / **高檔出貨** | 軌道三：風險警戒 | `#f59e0b` (琥珀黃) | 琥珀色系玻璃 | `● 區間警戒` | 高檔派發、分批獲利入袋 |
| **區間觀望** / **洗盤整理** | 軌道三：盤整中性 | `#94a3b8` (板岩灰) | 灰白系玻璃 | `● 空手觀望` | 均線糾纏、等待表態 |

### 3.4 量化研判彈窗指南升級 (方案 B: Modal Deep-Dive)

點擊頂部右側 `[量化研判]` 按鈕所觸發之彈窗，進行二級深度投研升級：

- **容器寬度**：由 `280px` 擴充至 `360px`。
- **內容清單**：
  1. **5 態主力作戰門檻對照表**：列出各語意觸發的量化邏輯（如：VWAP 偏離區間、5 日法人買賣超閾值、量價條件）。
  2. **流動性與防作線警示狀態**：若 5 日成交均量 < 300 張，亮起黃色警示「⚠️ 流動性偏低，量化指標權重降低」。
  3. **合規宣告 (Regulatory Disclaimer)**：註記「本研判由類神經量化模型生成，僅供輔助分析，非投資買賣保證」。

### 3.5 關鍵指標膠囊正則修復 (Regex & Capsule Repair)

重構 `parseVerdictMetrics`，支援現行引擎產出字串：
- 支援提取：
  1. `最新收盤價\s*([\d,]+(?:\.\d+)?)\s*元` ➔ 標籤「最新收盤價」。
  2. `20\s*日\s*VWAP\s*主力成本\s*\(([\d,]+(?:\.\d+)?)\s*元\)` ➔ 標籤「20日VWAP」。
  3. `乖離\s*([+-]?\d+(?:\.\d+)?%)` ➔ 標籤「成本乖離率」。
  4. 相容舊版 `法人近\s*5\s*日合計` 與 `RSI` 格式。

## 5. 防禦性評估與非目標 (Defensive Assessment & Non-Goals)

- **非目標 (Non-Goals)**：
  - 本規格不變動後端 SQLite Lakehouse 之數據管道或日 K 計算邏輯。
  - 本規格不改變 Layer 7 外層 Bento-Grid 容器的網格比例（Card 18 依然維持獨佔滿高）。
- **向後相容**：若外部傳入之 `data` 為空或舊版文字，卡片應優雅降級（Fallback）呈現預設數據，絕不產生白畫面崩潰。
