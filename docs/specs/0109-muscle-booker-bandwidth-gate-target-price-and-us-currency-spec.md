# PRD 0109: 肌肉書僮動能雷達「布林帶寬審查硬門檻 (Bandwidth <= 8%)、目標價一致性與美股 US$ 標示」規格書

## 1. 概述 (Overview)

本規格針對肌肉書僮動能雷達中「買進決策過度寬鬆、缺少帶寬審查」、「上下資訊不一致（上方看板缺少目標價且風益比文字格式錯誤）」以及「美股缺少 US 幣別前綴標示」進行系統性重構，徹底還原肌肉書僮短線波段戰術之核心交易紀律。

---

## 2. 問題診斷與痛點 (Problem Statement)

1. **買進決策缺乏帶寬壓縮審查**：
   - 目前在 `evaluateMuscleBookerAction` 中，只要 `BREAKOUT_UP`（破箱頂）且 `ma20Slope === 'UP'`，風益比 $\ge 2.0$，就草率給出 `BUY` 決策。
   - 即使帶寬高達 20%~40%（未經歷極致壓縮蓄勢、主力早已拉開差價甚至高檔背離），也被系統誤推為「建議買進」先鋒。
   - 肌肉書僮短線戰術核心為：**「布林極致壓縮（帶寬 $\le 8\%$）凝聚勢能 ➔ 隨後帶量站上箱頂，20MA 翻揚助漲 ➔ 方向確立！第一買點進場」**。若未經壓縮而隨意突破，風險極高。
2. **上方作戰看板與下方表格資訊脫節**：
   - 下方表格展開清晰標註 `目標價: $397.61`，上方「今日買進先鋒」卡片卻漏掉目標價，造成上下資訊不一致。
   - 上方卡片風益比文字拼裝錯誤，輸出 `🔥 風益比: 1:1:6.0R`。
3. **美股貨幣符號未標示 US**：
   - 美股價格直接顯示 `$`，未標示 `US$`，無法一眼與台股區隔。

---

## 3. 功能需求與規格細節 (Functional Specifications)

### 3.1 買進決策硬門檻強化 (Strict BUY Gate)
- 在 `evaluateMuscleBookerAction` 中，`BUY`（建議買進）的先決條件必須同時滿足：
  1. **帶寬審查 (Bandwidth Squeeze Gate)**：布林帶寬必須 $\le 8.0\%$（`bbands.bandwidth <= 8.0` 或 `bbands.isSqueeze === true`）。
     - 若帶寬 $> 8.0\%$，即使突破箱頂且 20MA 向上，亦必須安全降級為 `HOLD`（區間觀望 / 帶寬未收斂），操盤建議標註：「帶寬未極致收斂 (X%)，非壓縮爆發起點，切忌追高」。
  2. **方向確立 (Direction Confirmation)**：`boxStatus === 'BREAKOUT_UP'` 且 `deduction.ma20Slope === 'UP'`。
  3. **風益比保護 (Risk-Reward Gate)**：$R:R \ge 2.0$。

### 3.2 今日買進先鋒卡片資訊補齊與格式修復
- 卡片明確展示三大核心量化指標：
  - **防守價**：`防守: {currency} {stopLossPrice}`
  - **目標價**：`目標: {currency} {targetPrice}`
  - **風益比**：`🔥 風益比: {riskRewardRatio}R`（消除多餘的 `1:`）
- 白話操盤建議與進場理由保持一致。

### 3.3 美股貨幣別統一標示 `US$`
- 建立 `formatCurrencyPrice(price: number, market: 'TW' | 'US')` 輔助函數：
  - 當 `market === 'US'` 時：統一顯示 `US$ {price.toFixed(2)}`（如 `US$ 368.16`）。
  - 當 `market === 'TW'` 時：統一顯示 `NT$ {price.toLocaleString()}` 或 `$ {price.toLocaleString()}`（如 `$1,010`）。
- 全面覆蓋作戰看板、三色導航儀與表格。

---

## 4. 驗收標準 (Acceptance Criteria)

1. **帶寬審查單元測試**：
   - 帶寬 $> 8.0\%$ 且突破箱頂之標的，判定結果絕對不可為 `BUY`，必須為 `HOLD`。
   - 帶寬 $\le 8.0\%$ 且突破箱頂、20MA 翻揚、風益比 $\ge 2.0$ 之標的，方可判定為 `BUY`。
2. **目標價與格式**：
   - 上方買進卡片 100% 呈現目標價，風益比無重複 `1:` 字符。
3. **美股貨幣符號**：
   - 美股模式下現價、防守價與目標價皆帶有 `US$`。
4. **全量測試與構建**：
   - 57 個測試套件 100% 綠燈，`npm run build` 0 型別錯誤。
