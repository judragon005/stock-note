# Spec 0211: 主力戰情室 Layer 7 作戰決策雙欄對稱重組與 Card 18 終極作戰指南 100% 滿版橫幅升級規格書

## 1. 概述 (Overview)

本規格針對 **AI 主力戰情室（AiForceDashboard）Layer 7 作戰決策區** 進行結構性重組與實戰視覺重構。

目前 Layer 7 採用 3 欄並列排版（欄 1: 15+09、欄 2: 11+16+17、欄 3: 18）。在實際交易看盤情境下存在以下痛點：
1. **Card 18 空間擠壓**：Card 18（主力追蹤總評判 / MLP-AI 作戰命令與操盤指南）身為全戰情室最高層級的總裁級操盤指示（包含主力核心動詞、5 態光譜、微觀語意、Playbook 防守/目標價/損益比、AI 結論），被局限在三分之一欄寬度中，垂直高度長且文字密度高，缺乏戰略收尾的從容感。
2. **Card 11 資訊展示受限**：Card 11（健康度綜合評估表）包含 5 項健康維度圓環，在窄欄環境下百分比與文字間距吃緊。
3. **資訊流順序斷裂**：微觀籌碼動態（15、09）與微觀籌碼力道（16、17、11）並排時，使用者的視線在垂直三欄之間跳躍，未能形成「**微觀籌碼驗證 ➔ 結構健康定錨 ➔ 終極操盤兵棋推演**」的完整交易心理收斂鏈條。

本規格將 **Card 18 升級為如同頂部 Card 01（KLine 全盤態勢圖）的 100% 滿版獨立大視野（Layer 8: 終極作戰指令旗艦卡）**，並將前置的 **15、09、11、16、17 重構為優雅的雙欄對稱平衡矩陣（Layer 7: 籌碼收斂與體質定調）**。

實戰法人與專業交易者的決策路徑遵循「**微觀異動 ➔ 結構強度 ➔ 執行兵棋**」三部曲：

```
┌─────────────────────────────────┐      ┌─────────────────────────────────┐
│ Card 15: 籌碼異動摘要 (外投自)   │  ──▶ │ Card 11: 五維健康度綜合評估     │
│ (資金真金白銀進出方向)           │      │ (基本/技術/籌碼/波動/法人綜合)  │
├─────────────────────────────────┤      ├─────────────────────────────────┤
│ Card 09: 隔日沖風險分析         │      │ Card 16: 買賣力分布 (法人vs散戶)│

                                   │
                                   ▼
┌──────────────────────────────────────────────────────────────────────────┐

│ • 底區：AI 總結與 250 日量能研判全幅徽章                                │
└──────────────────────────────────────────────────────────────────────────┘
```

## 3. 架構變更與詳細佈局規格 (Layout Specifications)

### 3.1 Layer 7: 雙欄對稱矩陣 (Bento Dual-Column Matrix)

- **容器設定**：
  ```tsx
  <div
    data-layer="7-chips-health-matrix"
    style={{
      display: 'grid',
      gridTemplateColumns: 'repeat(auto-fit, minmax(420px, 1fr))',
      gap: '12px',
      alignItems: 'stretch',
    }}
  >
  ```
- **左欄（微觀籌碼動向與短線風險防護）**：
  - `Card 15 籌碼異動摘要 (ChipsSummaryCard)`：呈現外資、投信、自營商買賣超張數與 20 日土洋對作結論。
  - `Card 09 隔日沖風險分析 (DayTradeRiskCard)`：呈現主力賣出異常、換手率、沖銷比、回檔風險等 5 項雷達指標。
  - 兩卡垂直平分高度（`flex: 1`），外層具備 `display: flex; flexDirection: column; gap: 8px`。
- **右欄（結構健康度與多空籌碼對抗）**：
  - `Card 11 健康度綜合評估表 (HealthSummaryCard)`：享有半版寬度（~480px+），5 個百分比進度圓環舒展展示，底部標籤文字間隔寬鬆，徹底杜絕疊字。
  - **下方雙子區**：
    - `Card 16 買賣力分布圖 (ForceDistributionCard)`
    - `Card 17 多空強度分布 (BullBearStrengthCard)`
    - 在右欄內部可垂直排列或在寬螢幕下以 `display: grid; gridTemplateColumns: 1fr 1fr` 緊湊呈現，與左側 Card 09 高度完美拉齊。

### 3.2 Layer 8: Card 18 終極作戰指南 100% 滿版展開 (Executive Command Deck)

- **容器設定**：
  ```tsx
  <div
    data-layer="8-main-force-verdict-deck"
    style={{
      width: '100%',
      minWidth: 0,
    }}
  >
    <MainForceVerdictCard data={report.mainForceVerdict} />
  </div>
  ```
- **Card 18 內部滿版響應式結構優化 (Responsive Grid Inside Card 18)**：
  - **頂部狀態列**：維持標題「18 主力追蹤總評判 (MLP-AI)」、右側量化研判指南按鈕。
  - **主核心動詞與光譜層**：
    - `主力核心語意`（22px~24px 發光字體）與燈號狀態。
    - `5 態主力作戰光譜`（超跌反彈、低接吸籌、鎖碼推升、高檔調節、區間震盪）由原本緊湊小膠囊舒展為全寬大光譜導覽條，滑鼠懸浮反饋更清晰。
  - **中央戰術核心網格（桌機雙欄/三欄自適應展開）**：
    - 寬螢幕時（`min-width: 768px`），將 **語意微觀解析 (Market Context)** 與 **實戰操盤指引 (Playbook)** 由上下堆疊改為 **左右雙欄橫展**：
      - **左欄（Market Context）**：微觀環境背景、大戶散戶資金對峙狀態、量價結構解讀。
      - **右欄（Action Playbook）**：包含操作指令、波段週期徽章、關鍵價位三欄網格（防守停損價、目標價、損益比）、以及重要警示「失效門檻紅框」。
  - **底部總結列**：
    - 4 顆指標膠囊（最新收盤價、20日 VWAP、成本乖離率、信號等級）全寬平鋪。
    - AI 結論段落完整展示，字距與行高自然延展，不再發生縱向過度拉伸。
