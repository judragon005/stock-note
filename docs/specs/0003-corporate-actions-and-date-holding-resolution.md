# 產品需求規格說明書 (PRD): V1.2 公司行動（除權息、減資、增資、分割）依日期判定持股與分項加總

- **編號**: 0003
- **對應 Issue**: [#17](https://github.com/judragon003/-/issues/17)
- **狀態**: Approved
- **日期**: 2026-08-20

---

## Problem Statement (問題陳述)

投資人在長期持有台股與美股的過程中，標的常會經歷「現金股息 (除息)」、「股票股利 (除權)」、「現金減資 / 虧損減資」、「現金增資 / 認股」以及「股票分割 / 反分割」等公司行動 (Corporate Actions)。
目前的股票紀錄系統僅能手動記錄買進、賣出與簡單的現金股息，缺乏：
1. 依歷史交易日期精確推算「除權息/減資基準日持股數量」的時序回溯機制。
2. 股票股利（配股）、股票分割、現金減資退款與現金增資的正式事件型別與會計成本調整邏輯。
3. 連線官方與免費金融資料源（TWSE / Yahoo Finance）自動掃描持股歷史事件並一鍵補登的能力。
4. 針對累計股息、減資退還本金、累計配股等項目的獨立分項加總與真實成本殖利率 (YoC) 分析。

---

## Solution (解決方案)

透過擴充統一事件流 (`TradeType`) 與歷史時序計算引擎，建立具備自動化掃描能力的「公司行動全生命週期管理系統」：
1. **完整事件流模型**：支援 `BUY`, `SELL`, `DIVIDEND` (現金股利), `STOCK_DIVIDEND` (配股/除權), `STOCK_SPLIT` (分割/合併/反分割), `CAPITAL_REDUCTION` (現金減資/虧損減資), `CAPITAL_INCREASE` (現金增資)。
2. **時序回溯與基準日持股判定**：計算引擎支援在任意歷史事件基準日精確推算當日持有股數，並依公司行動動態調整持股總數、投入本金成本基準 (Cost Basis) 與平均單位成本。
3. **智慧掃描與自動補登**：一鍵向免費金融資料源比對持股區間內發生的公司行動事件，自動以基準日持股換算配息金額、配股數與退款金額，支援一鍵批次補登。
4. **全方位指標加總與報表**：在總覽卡片與持股明細中，清晰分項加總「累計領取股息」、「累計減資退還現金」、「累計配股股數」，並計算真實調整後成本與 YoC。

## User Stories (使用者故事)

1. **US-22 (歷史基準日持股回溯)**：作為投資人，我希望系統能依據交易日期精確推算出特定基準日當時我所持有的有效股數，以便正確計算當次應領股息、配股或減資退款。
2. **US-23 (股票股利 / 除權配股)**：作為台股投資人，我希望記錄除權配股，系統自動增加持有股數，總投入本金不變，並將平均每股買入成本稀釋調降。
3. **US-24 (股票分割 / 反分割)**：作為美股/台股投資人，我希望記錄股票分割（如 1 拆 10 或反分割 10 併 1），系統依比例調整股數，總成本不變。
4. **US-25 (現金減資退還股款)**：作為投資人，我希望記錄現金減資，系統依減資比例扣減股數，並將退還之現金扣減總投入本金（資本返還），重新分攤剩餘股數成本。
5. **US-26 (虧損減資彌補)**：作為投資人，我希望記錄虧損減資，系統扣減持有股數，總投入成本不變，單位持股成本上升。
6. **US-27 (現金增資 / 認股)**：作為投資人，我希望記錄現金增資認購，系統增加持有股數，並將認購總金額（股數 × 認購價 + 費用）計入總投入本金。
7. **US-28 (一鍵智慧掃描官方事件)**：作為使用者，我希望點擊「智慧掃描」，系統自動向免費官方/金融資料源（TWSE / Yahoo Finance）抓取我持有區間內的所有除權息與減資事件。
8. **US-29 (批次預覽與一鍵自動補登)**：作為使用者，我希望能檢視掃描出的待入帳事件清單與自動計算之配息/配股金額，並可一鍵批次補登至交易歷史。
9. **US-30 (總覽現金流與資本返還分項加總)**：作為使用者，我希望在資產總覽卡片上看見獨立的「累計股息」與「累計減資退款」，清楚區分盈餘分配與本金退回。
10. **US-31 (持股明細股權異動標記)**：作為使用者，我希望在持股明細表中看見「原始買入股數」、「累計配股 (+股數)」與「減資縮股 (-股數)」，並能展開時間軸查看歷次事件。
11. **US-32 (真實投入本金與 YoC 修正)**：作為長線存股投資人，我希望成本殖利率 (YoC) 能以扣除減資退款後的「真實投入本金基準」計算，真實反映現金流效率。
12. **US-33 (交易彈窗動態欄位與試算)**：作為使用者，我在新增或編輯交易時切換至不同公司行動，表單能動態切換專屬欄位（如退還金額、配股率、分割比），並自動帶出基準日持股試算。
13. **US-34 (CSV 匯出匯入相容)**：作為使用者，我希望 CSV 匯出匯入能無損支援所有新增的公司行動事件與欄位。
14. **US-35 (跨域連線容錯與手動重試)**：作為使用者，當網路連線或外部資料源暫時無法訪問時，系統能提供友善提示與手動重試機制。

## Implementation Decisions (實作架構決策)

1. **擴充統一事件流資料模型 (`src/types/stock.ts`)**:
   - `TradeType` 擴充為：`'BUY' | 'SELL' | 'DIVIDEND' | 'STOCK_DIVIDEND' | 'STOCK_SPLIT' | 'CAPITAL_REDUCTION' | 'CAPITAL_INCREASE'`。
   - `TradeRecord` 擴充可選欄位：`ratio?: number` (比例), `cashAmount?: number` (減資退款/配息現金), `exDate?: string` (除權息/基準日)。
   - `HoldingPosition` 擴充加總欄位：`totalCapitalReturned: number` (累計減資退款), `totalStockDividendsShares: number` (累計配股), `adjustedCostBasis: number` (扣除退款後本金)。

2. **時序回溯與計算核心 (`src/engine/calculator.ts`)**:
   - 提供 `getHoldingsAsOfDate(trades: TradeRecord[], targetDate: string, symbol: string): number`。
   - 核心會計計算邏輯：
     - `STOCK_DIVIDEND`: 股數增加 `+shares`，成本不變。
     - `STOCK_SPLIT`: 股數乘以 `ratio`，成本不變。
     - `CAPITAL_REDUCTION`: 股數減少 `reducedShares`，退還現金扣減本金 `totalCostBasis = Math.max(0, totalCostBasis - cashAmount)`，累計 `totalCapitalReturned += cashAmount`。
     - `CAPITAL_INCREASE`: 股數增加 `+shares`，成本增加 `(shares * price) + fee + tax`。
     - `DIVIDEND`: 累計 `totalDividends += netDividend`。

3. **免費金融資料掃描模組 (`src/engine/corporateActionScanner.ts`)**:
   - 整合免費 Yahoo Finance API（支援台美股歷史 Dividends & Splits）與 TWSE OpenData。
   - 依持有區間 `[firstBuyDate, lastDate]` 掃描事件，並比對已有交易避免重複。

4. **組件升級與全新互動介面**:
   - 新增 `CorporateActionScannerModal.tsx`（掃描進度、事件預覽、批次入帳）。
   - 升級 `TradeModal.tsx`（動態表單、基準日持股自動換算）。
   - 升級 `SummaryCards.tsx`（分項呈現股息與減資退款）。
   - 升級 `HoldingsTable.tsx`（股權異動標註與時間軸展開）。
   - 升級 `Header.tsx`（新增「✨ 智慧掃描」按鈕）。

1. **核心測試縫隙 (Public Seam)**:
   - `src/engine/calculator.test.ts`：以純函式方式進行黑盒時序測試，覆蓋：
     - 基準日持股回溯（在不同買進賣出時序點推算持股）。
     - 除權配股後平均成本稀釋測試。
     - 股票分割 (美股 1 拆 10) 股數與成本測試。
     - 現金減資退款（扣減成本與累計退款金額）與虧損減資測試。
     - 現金增資認購成本累加測試。
     - 混合交錯時序（買進 ➔ 除息 ➔ 減資 ➔ 配股 ➔ 賣出）綜合算力驗證。
   - `src/engine/corporateActionScanner.test.ts`：測試查重邏輯與依基準日持股換算配發數之正確性。
2. **驗證門檻**:
