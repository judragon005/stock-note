# PRD #0103: 台股上櫃 (.TWO) 與上市 (.TW) 雙軌備援重試、美股特殊代碼相容與市場推斷規格書

## 1. 執行摘要 (Executive Summary)

本規格書針對使用者回饋在肌肉書僮動能雷達中輸入「6204 艾華」出現「查無標的歷史行情」之重大缺陷，剖析底層 Yahoo Finance API 協議與台美雙市場代碼規範，建構全方位高韌性代碼解析與回補管線：

1. **台股上市 (.TW) 與上櫃 (.TWO) 雙軌自動探測與備援重試**：
   - Yahoo Finance API 中，台股上市代碼為 `.TW`（如 `2330.TW`），上櫃代碼為 `.TWO`（如 `6204.TWO`、`8299.TWO`）。原回補引擎盲目補 `.TW`，遭遇 404 報錯時未重試 `.TWO`，導致上櫃標的全數失敗。
   - 升級為候選清單雙軌探測架構：依據字典先驗屬性優先決定次序，遇 404 或無日 K 時自動無縫重試對偶後綴，100% 覆蓋全台上櫃股票。
2. **美股特殊代碼格式容錯與候選備援 (US Symbol Resilience)**：
   - 支援美股點號與連字號互轉（如 `BRK.B` $\leftrightarrow$ `BRK-B`、`BF.B` $\leftrightarrow$ `BF-B`）。
   - 支援 5 碼代碼智能探測（如 `BRKB` 自動備援探測 `BRK-B`）。
   - 支援去除 `.US`、`NASDAQ:`、`NYSE:` 等常見輸入後綴與前綴。
3. **市場智能推斷引擎升級 (`inferMarketFromSymbol`)**：
   - 解決僅用純數字正則導致台股主動型 ETF（如 `00403A`、`00981A`）被誤判為美股的漏洞。
   - 解決使用者輸入 `6204.TWO` 或 `2330.TW` 時因包含英文後綴被誤判為美股的缺陷。
4. **官方字典歷史殘存清理**：
   - 校正 `stockDictionary.ts` 中殘留的 `6204O` 為 `6204`（艾華），標記 `source: 'TPEX'`，達成代碼與名稱 100% 雙向對齊。

## 2. 功能規格與驗收條件 (Features & Acceptance Criteria)

### 功能 1：台股上市 (.TW) 與上櫃 (.TWO) 雙軌自動探測回補

- **業務邏輯**：
  - 在 `backfillSymbolOhlcvAndIndicators` 與 `fetchQuote` 中：
  - 輸入代碼清洗去除 `.TW` / `.TWO` 後，若為台股（`market === 'TW'`）：
    - 檢查字典先驗屬性：若 `source === 'TPEX'` 或 `category` 包含上櫃，候選清單為 `[`${cleanSymbol}.TWO`, `${cleanSymbol}.TW`]`。
    - 若非上櫃或未知，候選清單為 `[`${cleanSymbol}.TW`, `${cleanSymbol}.TWO`]`。
    - 依序發起 Yahoo Finance 請求，若遭遇 404 或回傳日 K 數列為空，自動嘗試下一個候選代碼。
- **AC-1.1**：輸入 `6204` 執行雷達診斷，系統應能自動嘗試 `6204.TWO`，成功取得艾華歷史日 K 與最新市價，不再出現「查無標的」錯誤。
- **AC-1.2**：輸入 `2330` 執行雷達診斷，首選 `2330.TW` 正常取得日 K，不發起多餘的 `.TWO` 請求。
- **AC-1.3**：快取與 IndexedDB 存儲鍵維持純數字 `cleanSymbol`（如 `6204`），後續查詢直接命中本地快取。

### 功能 2：美股特殊代碼容錯與備援 (US Symbol Resilience)

- **業務邏輯**：
  - 輸入代碼若判定為美股（`market === 'US'`）：
    - 清洗常見後綴（如 `.US`）與空白。
    - 若代碼包含 `.`（如 `BRK.B`），首選轉為 Yahoo 規範之 `BRK-B`；若首選失敗，備援重試原代碼 `BRK.B`。
    - 若代碼為常見 5 碼連寫（如 `BRKB`），若首選 404，備援重試 `BRK-B`。
- **AC-2.1**：輸入 `BRK.B` 或 `BRK-B` 執行診斷，均能正確取得波克夏公司歷史日 K 與肌肉書僮雷達訊號。
- **AC-2.2**：輸入 `AAPL.US`，自動清洗為 `AAPL` 並正常連線拉取。

### 功能 3：市場智能推斷引擎全面升級 (`inferMarketFromSymbol`)

- **業務邏輯**：
  - 提供獨立匯出純函數 `inferMarketFromSymbol(raw: string): MarketType`：
    - 若以 `.TW` 或 `.TWO` 結尾 $\to$ 強制 `TW`。
    - 若以 `.US` 結尾 $\to$ 強制 `US`。
    - 若符合台股代碼特徵（純數字 4~6 碼，或數字+英文字母如 `00403A`、`00981A`） $\to$ `TW`。
    - 若在官方台股字典中存在該代碼 $\to$ `TW`。
    - 其餘英文字母（1~5 碼） $\to$ `US`。
- **AC-3.1**：輸入 `6204.TWO` 正確判定為 `TW`，不被誤判為 `US`。
- **AC-3.2**：輸入 `00403A` 正確判定為 `TW`，不被誤判為 `US`。
- **AC-3.3**：輸入 `NVDA` 或 `BRK.B` 正確判定為 `US`。

### 功能 4：官方字典校正

- **業務邏輯**：
  - 將 `stockDictionary.ts` 中 `6204O` 更正為 `6204`，確保 `resolveOfficialSecurityName('6204')` 直接解析為「艾華」。
- **AC-4.1**：`resolveOfficialSecurityName('6204')` 回傳「艾華」。
