## 1. 環境準備與快速啟動

### 1.1 前置需求檢核
請確認本地開發環境已安裝以下工具：
- **Node.js**: `v18.0.0` 以上版本（建議 `v20+` LTS）
- **npm**: `v9.0.0` 以上版本
- **瀏覽器**: Chrome, Edge, Safari 或 Firefox 現代瀏覽器

```bash
# 檢查 Node.js 與 npm 版本
node -v
npm -v
```

### 1.2 安裝依賴套件
在專案根目錄（`d:\APP\股票紀錄`）執行：
```bash
npm install
```

### 1.3 啟動本地開發伺服器
```bash
npm run dev
```
啟動成功後，終端機將顯示本地服務網址（預設為 `http://localhost:5173/`）。使用瀏覽器開啟該網址即可進入系統。

> [!TIP]
> 若欲模擬正式環境打包並預覽，可執行：
> ```bash
> npm run build
> npm run preview
> ```

## 2. 標準驗證劇本 (Step-by-Step Runbook)

### 劇本一：雙市場基礎買賣與移動加權平均成本

#### 操作步驟
1. 點擊頂部右上角 **「+ 記一筆交易」** 按鈕開啟錄入彈窗。
2. **新增第一筆台股買進**：
   - 市場：`台股 (TWD)`
   - 代碼：`2330`（名稱會自動帶入或手動填寫「台積電」）
   - 動作：`買進 (BUY)`
   - 股數：`1000` 股
   - 價格：`900` 元
   - 手續費折數：`5折`（系統自動計算手續費 `900 * 1000 * 0.001425 * 0.5 = 641` 元）
   - 點擊「儲存交易」。
3. **新增第二筆加碼買進**：
   - 股數：`1000` 股，價格：`1000` 元，手續費：`5折`（手續費 713 元）。
   - 點擊「儲存交易」。
4. **驗證持倉總覽 (Holdings Table)**：
   - 持股總數：應為 `2,000` 股。
   - 平均成本：應為 `(900,641 + 1,000,713) / 2000 = 950.68` 元/股。
   - 總投入成本：`1,901,354` 元。
5. **部分賣出獲利了結**：
   - 點擊持倉列表中 2330 旁的 **「平倉/賣出」** 按鈕。
   - 股數輸入 `1000` 股，價格輸入 `1100` 元，點擊「儲存交易」。
   - **驗證已實現損益**：頂部「已實現損益」卡片應正確呈現獲利 `(1100 * 1000 - 交易稅 - 賣出手續費) - (950.68 * 1000)`。

### 劇本二：一般公司行動（除權息、增資、現金減資）

#### 1. 現金股利 (CASH_DIVIDEND)
- 點擊「+ 記一筆交易」➔ 類型選擇 `現金股利`。
- 代碼輸入 `2330`，除息交易日選擇今天，每股配息金額輸入 `4.0` 元。
- **預期結果**：持股 1,000 股自動試算入帳 `4,000` 元股利，頂部累積股利收入增加 `4,000` 元，持股股數與平均成本維持不變。

#### 2. 股票股利 (STOCK_DIVIDEND)
- 類型選擇 `股票股利`。
- 每股配發股數輸入 `0.1` 股（即每千股配 100 股）。
- **預期結果**：持股數由 1,000 股增加至 `1,100` 股，總持股成本不變，平均每股成本被稀釋下降。

#### 3. 現金減資 (CASH_REDUCTION)
- 類型選擇 `現金減資`。
- 減資退還比例輸入 `20%`（每股退還 2 元）。
- **預期結果**：持股數減少 20%（剩餘 880 股），同時收到現金退還款，每股平均成本依減資會計準則重算。

### 劇本三：5 大特殊公司行動會計處理

| 交易類型 | 測試操作重點 | 驗證標準 |
| :--- | :--- | :--- |
| **換股合併 (`STOCK_MERGER`)** | 選擇標的 A 與目標標的 B，輸入換股比例（如 1:1.5） | 標的 A 持股歸零；標的 B 增加換算股數，並完全承接標的 A 原始投入成本。 |
| **特別股贖回 (`PREFERRED_REDEMPTION`)** | 選擇特別股代碼，輸入贖回總價金 | 原特別股庫存歸零，價金與投入成本之差額結算為已實現損益。 |
| **企業分拆 (`SPIN_OFF`)** | 輸入母公司、子公司代碼、獲配股數與成本分拆比例（如 30%） | 母公司持股數不變但成本扣除 30%；子公司以該 30% 成本與獲配股數建立全新庫存。 |
| **可轉債換股 (`CB_CONVERSION`)** | 選擇 CB 代碼，輸入轉換後普通股代碼與股數 | 原始債券全額除役，債券投入本金轉為新普通股的持股成本基準。 |
| **公開收購 (`TENDER_OFFER`)** | 選擇被收購標的，輸入收購價格與股數 | 標的依收購價全額結算平倉，扣除證交稅與處理費後認列損益。 |

### 劇本四：全市場即時公司行動線上掃描

1. 點擊頂部功能列的 **「📡 智慧掃描公司行動」** 按鈕。
2. 彈窗將自動獲取當前持倉清單，並依各標的「最早買進日」自動設定掃描區間。
3. 點擊 **「開始線上即時掃描」**。
4. **驗證代理池與資料解析**：
   - 系統依序調用 TWSE 官方開放資料（`TWT48U_ALL` 減資、`TWT49U_ALL` 除權息預告表）。
   - 掃描結果列表將列出基準日介於買進日後的所有事件，並提供「自動試算預計影響」。
5. 勾選欲補登之事件，點擊 **「一鍵補登至交易歷程」**。
6. 檢查持倉表與交易紀錄，確認已自動寫入並更新持股損益。

1. **資產配置樹狀圖檢驗**：
   - 當同時持有台股與美股多檔標的時，中間區塊會呈現純原生 SVG Squarified Treemap。

   - **台灣模式**：獲利呈現艷紅色，虧損呈現翡翠綠。
   - **國際模式**：獲利呈現翠綠色，虧損呈現玫瑰紅。
   - 驗證頂部卡片、持倉列表、樹狀圖之所有顏色皆同步瞬間響應。

## 4. 常見問題與排錯指南 (Troubleshooting)

### Q1: 啟動時提示 `Port 5173 is in use`（連接埠已被佔用）
- **原因**：先前運行的 Vite 伺服器尚未關閉，或有其他應用程式佔用 5173 連接埠。
- **解法**：
  1. Vite 會自動嘗試切換至下一個可用埠號（如 `http://localhost:5174/`），可直接開啟該網址。
  2. 或在終端機關閉佔用的行程（Windows PowerShell）：
     ```powershell
     Get-Process -Id (Get-NetTCPConnection -LocalPort 5173).OwningProcess | Stop-Process
     ```

### Q2: 智慧掃描公司行動時提示「連線逾時」或「CORS 限制」
- **原因**：部分公用 CORS 代理伺服器（如 corsproxy.io）可能暫時性壅塞或遭受速率限制。
- **解法**：
  - 系統內建 3 組代理池（`corsproxy.io`、`allorigins.win`、`codetabs`）自動輪替重試機制。
  - 請稍候 5 秒後再次點擊「開始線上即時掃描」，系統會自動切換至備用代理線路。

### Q3: 匯出 CSV 檔案在 Excel 開啟時呈現亂碼
- **原因**：微軟 Excel 預設未啟用 UTF-8 辨識。
- **解法**：
  - 本系統匯出 CSV 時已強制寫入 `\uFEFF` (UTF-8 BOM)，在現代 Excel 點擊開啟即可自動識別繁體中文。
  - 若使用舊版 Excel，可透過「資料」➔「從文字/CSV 匯入」並指定「65001: Unicode (UTF-8)」編碼。

### Q4: 如何重置所有本機測試資料？
- **解法**：
  - 開啟瀏覽器開發者工具 (F12) ➔ 切換至 `Application` (應用程式) 頁籤 ➔ `Local Storage` ➔ 找到 `http://localhost:5173` ➔ 點擊清除全部，重新整理網頁即可恢復為乾淨預設狀態。
