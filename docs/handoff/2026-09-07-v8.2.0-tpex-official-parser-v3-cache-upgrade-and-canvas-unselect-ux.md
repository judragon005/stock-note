# 2026-09-07 交接手冊：v8.2.0 TPEx 官方三大法人 24 欄解析器升級、V3 快取換代與畫布點擊取消選取

## 1. 本次迭代成果與核心變更 (Summary)

本次迭代徹底修復並驗證了聰明錢流動視覺化（Smart Money Flow）中的兩大核心缺陷：
1. **上櫃股票（TPEx）三大法人張數顯示為 0 之重大修復**：
   - 修正 TPEx 官方日報資料提取路徑：改自 `rawData.tables?.[0]?.data` 提取，終結取值恆為 `undefined` 之缺陷。
   - 修正 TPEx 24 欄位索引對應：精確解析外資及陸資合計 (8..10)、投信 (11..13)、自營商合計 (20..22) 與三大法人合計 (23)，並除以 1,000 四捨五入換算為張數。
   - 實測以 8299 群聯為例，2026/09/04 日報精確獲取外資 +122 張、投信 -22 張、自營商 +57 張、三大法人合計 +157 張，杜絕虛假 0 張文案。
   - 升級快取鍵名前綴為 `TWSE_TPEX_CHIPS_V3_`，自動隔離並淘汰過去未含上櫃資料的 IndexedDB 污染快取。
2. **畫布點擊取消選取與 Tooltip 雙重關閉體驗**：
   - 於主 SVG 畫布區域及其 `<svg>` 綁定 `setSelectedBubble(null)`，點擊畫布任何空白處即可即時清空選取，卡片順暢退場。
   - 於標的泡泡節點 `<g>` 加上 `e.stopPropagation()`，杜絕點擊泡泡時誤觸畫布清空事件。
   - `calculateTooltipPlacement` 支援 `isPinned` 參數，卡片固定時設置 `pointerEvents: 'auto'`，卡片內部點擊 `e.stopPropagation()` 避免誤觸關閉。
   - 卡片固定時於右上角顯著提供「✕」關閉按鈕，提供直覺且優雅的雙重取消選取路徑。
