# 2026-09-11 V8.36.0 聰明錢盤中前日基底防空值與金融級法定還款沖償引擎交付手冊

## 一、版本核心目標 (Release Goal)
本版本完整實作 **Spec #0117**（對應架構決策 **ADR #0117**），成功解決金融實務與使用者回饋的兩大核心痛點：

1. **聰明錢動態星圖盤中結算前防空值 (Smart Money Last-Known-Good Base)**：
   - **痛點**：台股三大法人買賣超於每日 15:30 後才正式發布，導致 15:30 前籌碼動態星圖外資/投信/自營商均顯示為 0 張，氣泡在中軸一字排開，造成使用者誤解與視覺困擾。
   - **解法**：在 `institutionalReportFetcher.ts` 引入 `fetchTwseInstitutionalReportDetailed` 與 `institutionalHistoryCache`，盤中（15:30 前或當日尚未結算時）自動遞補抓取前一有效交易日之全量籌碼作為 baseline；前端 UI（`ChipsWorkspace.tsx`）新增「基準：YYYY-MM-DD（前日結算）」提示標章，徹底阻斷盤中空值與盲區。

2. **金融級質押借貸法定還款沖償引擎 (Statutory Debt Repayment Engine)**：
   - **痛點**：舊版質押借貸部分還款存在「利息少算一日（還款次日計息基準日偏移）」以及「集保規費重複計收 60 元」的重大會計漏洞。
   - **解法**：在 `cashLedgerEngine.ts` 建立符合民法與券商實務的 `applyDebtRepayment` 核心純函式引擎，嚴格落實「**規費 ➔ 應計利息 ➔ 本金**」法定沖償順序。部分還款時將已計利息完全結清歸零並更新計息基準日（`startDate` 遷移至還款日），規費精準沖償（預設 0 元，若有設定則先沖償），餘額全數抵充本金。

3. **美股融資借貸借鏡與對齊 (US Margin Alignment)**：
   - 全面盤查美股融資機制，確認美股融資（Margin）無台股集保撥券規費（$60），利息隨月結算或即時沖銷，`applyDebtRepayment` 通用設計已原生相容美股跨幣別零規費沖償。
