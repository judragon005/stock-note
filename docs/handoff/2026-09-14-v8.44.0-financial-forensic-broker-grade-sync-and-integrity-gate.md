# 2026-09-14 V8.44.0 穿透式財報券商級常態同步、審計季度錨定與完整性門禁系統交接手冊

## 1. 迭代核心目標 (Goal)
解決使用者實盤檢視【2327 國巨】穿透式財報戰情室時反饋的兩大嚴重問題：
1. 圖 1：柱狀圖柱頂金額標籤出現 `499,910 億` 等荒誕天文數字。
2. 圖 2：「為何有一些數值是空的？」——毛利 38.1%、淨利 0.0%、負債比 `-`、CFO 0 億、杜邦 ROE 0.0%，柱狀圖全為 0 百萬。
3. 同步體驗最佳化：落實券商常態標準——「如果更新資料需要時間，請延遲顯示，等資料同步了才正式顯示」。

---

## 2. 根因剖析 (Root Causes)
1. **單位誤判放大**：`formatCurrencyMillions` 將元 (TWD) 誤當作百萬元再次縮放，導致金額暴增萬倍。
2. **本地舊殘缺快取污染**：使用者本地 IndexedDB 存有歷史殘留之單表快取，缺少 CFO 與總資產，系統未檢驗快取完整性直接採信。
3. **空殼未申報季污染**：API 預載自結營收，造成空殼季度（無淨利、資產負債與現金流）排在首位，導致系統評估基準與四大卡片抓取到空殼季。
4. **過渡期缺少骨架屏**：資料同步期間缺少結構固定的深色骨架屏，導致未完成數據短暫閃爍或跳動。

---

## 3. 架構改進與交付物 (Deliverables)

### 3.1 金額自適應換算器 (`FinancialTrendsLayer.tsx`)
- 實作 `formatFinancialAmount(val: number): string`：
  - 嚴格以「元 (TWD)」為基底。
  - $\ge 1$ 億元 $\to$ `X.X 億`
  - 100 萬～1 億元 $\to$ `X.X 百萬`
  - $< 100$ 萬元 $\to$ 千分位整數
  - 徹底消滅 `499,910 億` 天文數字。

### 3.2 快取完整性檢驗與自癒管線 (`financialReportService.ts` & `taiwanFinancialPipeline.ts`)
- 實作 `isFinancialRecordsCacheValid(records)`：若所有季度之 CFO 為 0 且總資產為 0，判定為舊版殘缺快取，自動觸發背景全量重撈覆蓋寫入，無需手動清空資料庫。
- 全面覆蓋三大報表官方科目別名映射（資產總計、資產總額、負債總計、營業活動現金流入等）。

### 3.3 正式審計季度過濾哨兵 (`financialScoringEngine.ts` & `FinancialHeroLayer.tsx`)
- 實作 `isQuarterRecordComplete(record)`：過濾尚未申報完整季報（無淨利與資產負債）的自結空殼季度（如 26Q2）。
- 0 秒戰報、四大體質卡片、杜邦分析嚴格錨定於「最新完整申報季」。
- 頂部明確標記【審計基準季：YYYY-QX】，卡片金額指標統一採用自適應格式化，徹底消滅 `0.0%`、`負債比 -`、`CFO 0 億` 等假陽性空白。

### 3.4 券商級深色毛玻璃骨架屏與平滑淡入門禁 (`FinancialSkeletonLayer.tsx` & `FinancialForensicModal.tsx`)
- 新增 `FinancialSkeletonLayer.tsx`：提供 Hero 決策層、四大指標卡、三率走勢圖與深度審查之固定佔位骨架屏（Zero-CLS）。
- 資料聚合驗證完備後，以 0.2 秒平滑淡入（Fade-In）點亮呈現，嚴禁半殘過渡畫面提前渲染。
