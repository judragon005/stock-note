## 🎯 本次迭代核心目標與成果

解決「在途資金交割時序排程 (Settlement Timeline)」在項目較多（如 4 筆未來排程）時寬度被多欄 CSS Grid 擠壓成直式窄條、文字直立斷裂無法閱讀的問題。透過全面重構為**單行橫向條列 (1 Row 1 Item)** 清單，並導入多維度視覺標籤與分組小計，達成極致的財務看板觀看體驗。

---

## 🛠️ 具體變更與架構落地

1. **單行條列式項目元件重構 (`src/components/PendingSettlementCard.tsx`)**：
   - 捨棄卡片式窄幅排版，改採水平展開的 Flex Row 條列式設計。
   - **左側時序區**：展示交割日期（日曆圖標）+ 倒數膠囊（`今日到期`、`明日到期`、`N 天後`、`逾期 N 天`）+ 類別徽章（`股票買進`、`股票賣出`、`現金股息` 等）。
   - **中間資訊區**：券商帳戶（加粗）+ 詳細交易備註（支援 Tooltip 與文字省略）。
   - **右側操作區**：等寬金額（正綠負紅）+ 一鍵核銷按鈕。
   - 匯出測試縫隙 `getCategoryBadge` 與 `getCountdownBadge`。

2. **時序排程看板容器與分組小計 (`src/components/CashLedgerWorkspace.tsx`)**：
   - 內部容器由多欄網格改為垂直單行清單（`flex-direction: column; gap: 6px;`）。
   - 五大分組（🔴 逾期 / ⚡ 今日 / 📅 明日 / 🗓️ 本週 / 🔮 未來）標題右側動態折算展示各組預估淨現金流（如 `小計: +NT$ 966,814`）。
   - 組內嚴格遵循交割日由近至遠升冪排列。

3. **單元測試與 TDD 閉環 (`src/components/PendingSettlementCard.test.ts`)**：
   - 建立 12 項針對類別標籤配色、倒數天數膠囊及物件完備性的單元測試。
   - 全專案 33 個測試檔案、373 個測試案例 100% 綠燈通過。
