## 迭代成果概述 (Summary of Changes)

1. **按需緊湊歷史日 K 提取與單例記憶體快取**：
   - 擴充 [`src/engine/marketCacheLoader.ts`](../../src/engine/marketCacheLoader.ts)，新增 `loadSymbolCompactHistory` 與 `getLatestSummaryQuote`。
   - 按需從 `public/market-cache/tw_market_ohlcv_compact.json` (17.5 MB) 解析指定台股標的並轉換為標準 `DailyCandle`。
   - 採用模組級單例 Promise 快取，避免同一 Session 內重複觸發大型 JSON 之網路拉取與反序列化消耗；失敗時自動釋放快取支援後續自癒。
2. **歷史日 K 與當日收盤無縫合流與防限流降級**：
   - 於 [`vite.config.ts`](../../vite.config.ts) 的 `/api/yahoo` 加入桌面 Chrome `User-Agent` 與 `Referer` 標頭，降低被 ATS 邊緣節點阻擋之機率。
   - 於 [`src/engine/historicalOhlcvBackfill.ts`](../../src/engine/historicalOhlcvBackfill.ts) 升級降級管線：當外部 Yahoo API 遭遇 429 限流或斷網且 IndexedDB 歷史不足（< 5 根）時，自動調用本地 compact 歷史日 K 與每日 16:00 盤後更新之 `tw_market_summary.json` 當日收盤價，透過 `mergeDailyCandles` 去重升冪合併，重新計算指標並持久化沉澱至 IndexedDB，提供 100% 不破圖、不空白之本機高可用底座。
3. **無效標的代碼智慧診斷與指引**：
   - 於 [`src/components/aiForceDashboard/AiForceDashboardView.tsx`](../../src/components/aiForceDashboard/AiForceDashboardView.tsx) 中增加代碼有效性核對：當使用者輸入查無資料且無官方對應名稱之代碼（如筆誤之 `004EA`）時，系統明確標註「⚠️ 查無此台股標的代碼，請確認代碼是否輸入正確（如 00403A、2330）」，消除使用者對系統故障之猜忌。
4. **端到端驗證**：
   - 新增 [`src/components/aiForceDashboard/AiForceRealDataE2E.test.ts`](../../src/components/aiForceDashboard/AiForceRealDataE2E.test.ts)，驗證查詢 `00403A` 時主 K 線（60 根）、18 張 Bento 卡片與「任務五：原始資料表」完全正常渲染。
