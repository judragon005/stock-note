## 2. 交付成果清單

### 2.1 新增/修改的核心檔案
1. `src/types/signal.ts`：定義技術訊號、指標與操作建議之標準模型。
2. `src/types/stock.ts`：在 `HoldingPosition` 中擴充 `signals` 與 `actionDirective`。
3. `src/engine/technicalIndicatorEngine.ts`：實作 MA(5/20/60/120/240)、KD(9,3,3)、MACD(12,26,9)、成交量均量比、5日/20日高低點極值之純前端量化運算。
4. `src/engine/holdingAdvisorEngine.ts`：實作確定性專家操作建議矩陣，產出四字定調與紀律操作指引。
5. `src/engine/historicalPriceFetcher.ts`：新增 `parseYahooHistoricalCandlesResponse` 支援完整日 K 棒解析。
6. `src/components/common/HoldingSignalCapsules.tsx`：打造多維色彩膠囊（翡翠綠、亮紅、琥珀金、沉穩藍紫）與懸浮 Tooltip 互動元件。
7. `src/components/HoldingsTable.tsx`：整合膠囊列至標的名稱下方，並於展開詳情中呈現「🤖 智慧量化技術診斷與操作方針」卡片。
