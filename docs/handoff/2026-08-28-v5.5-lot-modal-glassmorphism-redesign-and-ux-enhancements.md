## 1. 核心交付與功能實作 (Deliverables)

1. **徹底解決樣式崩潰**：
   - 移除無效之 Tailwind CSS 類別，全面升級為專案原生 Glassmorphism 深色毛玻璃與 CSS 變數體系。
   - 支援紅漲綠跌主題色彩自適應。

2. **頂部 4 格結構化資產指標看板**：
   - 在庫總股數、總成本基準、參考現價、未實現損益（含正負色塊與報酬率膠囊）。

3. **批次明細表格 (Lots Table) 體驗全面升級**：
   - 點擊表頭動態排序（買進日期、股數、單價、單股成本、未實現損益、稅務持有天數 🔼/🔽）。
   - 數值靠右對齊並套用 `JetBrains Mono` 等寬字型，徹底根除文字黏連（如 `2024-04-24150`）。
   - 長短期稅務持有期彩色徽章：💎 長期 (≥365天) 綠色標籤 / ⚡ 短期 藍色標籤。
   - 年份快速過濾晶片（全部 / 2026 / 2024 ...）。

4. **💡 節稅沖銷對照 (Tax Comparison) 智慧儀表板**：
   - 橫向網格展示 4 種會計法（FIFO / LIFO / HIFO / 移動平均）的已實現/未實現利得比較。
   - 自動高亮 `👑 最佳節稅` 推薦徽章，並計算相比 FIFO 之節稅/遞延利得差額。
