# 2026-10-15 v8.95.0 戰情室 Prompt 標的時態隔離、庫存自動錨定與時態籌碼細化 (Grounding, Stale State & Portfolio Isolation)

## 1. 迭代目標與背景
本版本為解決華邦電（2344）在一鍵複製戰情 Prompt 貼入外部 ChatGPT-4o 測試時，暴露出的多項深水區邏輯缺陷：
- 標的切換時 `...prev` 導致 0050 的 165 元價格與籌碼殘留（Stale State Ghosting）。
- 提示詞未自動錨定使用者持倉庫存，將現價硬編碼為買入成本，導致外部 AI 誤發剛進場應停損割肉的荒謬指令。
- 三大法人單日買賣超誤填至 20 日累計欄位，被大語言模型識破時態矛盾。
- 均線固定為現價，缺少計量單位，且景氣循環股未提供週期高峰殺估值質詢。

---

## 2. 核心變更與架構落地

### A. 標的切換原子重置阻斷幽靈狀態 (State Sanitization)
- **`AiForceDashboardView.tsx`**：在 `loadDataForSymbol` 切換標的時，移除 `setReport(prev => ({ ...prev, symbol }))`，改以 `createDefaultAiForceReport(targetSymbol, ...)` 進行原子重置，徹底阻斷舊標的價格、均線與籌碼幽靈殘留。
- **`WarRoomPromptCard.tsx`**：接入 `isLoading` 與 `isDataPending` 狀態，資料同步中禁用按鈕並顯示「⏳ 數據同步校準中...」；複製失敗時自動展開抽屜並提供手動選取指引。

### B. 方案 1：全自動庫存比對與雙態分流 (Auto-Portfolio Grounding & Dual Pivots)
- **`aiForcePromptAdapter.ts`**：自動比對全域持倉 `holdings`，支援跨帳戶多筆持倉計算加權平均成本 (`avgCost`) 與保本價 (`breakevenPrice`)：
  - **庫存持有 (`IN_POSITION`)**：帶入真實成本與保本價。脫敏模式下預設隱匿金額，輸出未實現報酬率 `%` 與部位佔比 `%`；`<pre_calculated_pivots mode="HOLDING_DEFENSE">` 指示持倉防禦與保本移動停利。
  - **空手觀望 (`ZERO_POSITION`)**：部位佔比宣告為 0%，`<pre_calculated_pivots mode="HYPOTHETICAL_ENTRY">`，從買方視角評估潛在建倉位階與風報比，嚴禁發出停損命令。

### C. 籌碼時態細化、單位明載與湖倉真實均線
- **時態物理拆分**：分離最新單日三大法人買賣超 (`totalNetShares1D`) 與日 K 累積之近 20 日法人數據 (`totalNetShares20D`)。
- **計量單位標註**：所有數量標籤注入 `unit="張"` 或 `unit="股"`，成交金額標註 `unit="億元"`。
- **日 K 均線真實驗算**：MA20/MA60 自日線歷史數據真實驗算，動態判定多頭/空頭/糾結排列與 20 日均量比。
- **景氣循環股紅隊質詢**：整合 `industryGate.ts` 自動標記記憶體（華邦電）等週期股，在黑帽思考帽中強制啟動「週期高峰殺估值陷阱」質詢。

### D. Code Review 型別衛生與 XML 空行過濾收斂
- `ChipsSummaryData` 正規化宣告別名，徹底消除 `aiForcePromptAdapter.ts` 內所有的 `(chipsSummary as any)` 轉型。
- XML 模板生成改用陣列 `.filter(Boolean).join('\n')`，消除條件未成立所產生的多餘空行，優化 Token 預算。
