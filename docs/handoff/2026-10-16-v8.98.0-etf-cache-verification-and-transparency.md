## 2. 核心變更清單 (Core Changes)

1. **單次掃描 SQL Prepared Statement 升級 (`scripts/market-sync/backfill-tw-history-web.cjs`)**：
   - 擴充 `stockStmt`，利用 SQLite 條件聚合單次掃描取得總數、普通股數（含創新板）與 ETF 數：
     ```sql
     SELECT 
       count(*) AS totalCount,
       count(CASE WHEN symbol GLOB '[1-9][0-9][0-9][0-9]' THEN 1 END) AS stockCount,
       count(CASE WHEN symbol GLOB '00*' THEN 1 END) AS etfCount
     FROM daily_candles 
     WHERE date = ? AND (symbol GLOB '[1-9][0-9][0-9][0-9]' OR symbol GLOB '00*');
     ```
   - 乾淨排除 6 碼權證（03~08 開頭、7 開頭）。
2. **快取健康雙指標門檻向前相容 (`scripts/market-sync/backfill-tw-history-web.cjs`)**：
   - 維持以 `stockCount >= 1800 && chipCount >= 2000` 為安全放行標準，回補早年台股歷史時不誤判失效。
   - 回傳物件完整暴露 `quotesCount: totalCount`, `stockCount`, `etfCount` 與 `chipsCount`。
3. **終端機日誌透視化 (`scripts/market-sync/backfill-tw-history-web.cjs`)**：
   - 快取略過輸出格式升級為：
     `✔ 快取命中已在庫 ⚡ 略過 (有效標的: 2327 檔 [股票: 1979, ETF: 348], 籌碼: 2271 筆)`。
4. **單元測試強化 (`scripts/market-sync/backfill-tw-history-web.test.cjs`)**：
   - 新增測試 6：驗證單次掃描精確區分普通股、ETF 並排除權證。
   - 新增測試 7：驗證快取命中回傳結構正確暴露 `stockCount` 與 `etfCount`。
