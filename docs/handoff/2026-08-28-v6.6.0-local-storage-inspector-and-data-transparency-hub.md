## 🎯 迭代目標與完成摘要

本版本完整解決了「使用者無法掌握瀏覽器本地存放了哪些資料、容量佔用與儲存健康度」的黑箱問題，提供 100% Client-Side Local-First 離線隱私信任與分級資料管理中心：

1. **底層資料庫檢測與指標採集 (`src/utils/db.ts`)**：
   - 實作 `getLocalStorageInspectionStats()` 異步採集全庫 10 個 ObjectStore 的筆數、涵蓋標的數、資料點總數、交易日期區間與 API 配置狀態。
   - 整合 Web API `navigator.storage.estimate()` 動態取得已使用空間（Bytes/MB）、配額（Quota）與佔用百分比（%），具備無痕模式安全降級。
2. **階梯式細粒度快取安全清除函式 (`src/utils/db.ts`)**：
   - `clearHistoricalPricesCache()`：安全清除歷史股價快取。
   - `clearHistoricalFxCache()`：安全清除外匯匯率快取。
   - `clearPriceMetadataCache()`：安全清除即時行情中繼快取。
   - `clearCorporateActionsCache()`：安全清除除權息/減資事件庫快取。
   - **核心資產護盾 (Core Asset Shield)**：快取抹除與核心資產資料表 (`trades`, `brokerAccounts`, `cashTransactions`, `loanRecords`) 完全實體隔離，絕不誤刪帳本。
3. **設定工作區看板全方位升級 (`src/components/SettingsWorkspace.tsx`)**：
   - 頂部展示「🔒 100% 本地離線存儲保證」翡翠綠隱私資安徽章。
   - 呈現瀏覽器磁碟空間配額進度條與健康指示燈。
   - 三大維度本地數據卡片群（【核心個人資產】、【行情與市場快取】、【系統快照與配置】）。
   - 支援四組細粒度「清空快取」按鈕，並提供即時 Toast 反饋與統計刷新。
   - 整合時光機快照管理（手動建立、鎖定保護、一鍵還原與二次確認）。
