## 1. 迭代目標與完成摘要 (Executive Summary)

本迭代針對使用者對於 V8.47.0 盤後定時同步功能的反饋進行深度重構與痛點解答：
1. **頂部 Header 視覺一致性重構**：
   - 移除 Tailwind 類別與白邊突兀感，改採原生黑金深色半透明毛玻璃 (`rgba(19, 29, 49, 0.7)`)。
   - 文字精簡為膠囊格式 (`🇹🇼 16:00 · 🇺🇸 08:00`)，並將該元件由左側按鈕列移至右側狀態晶片組（與「台股盤中」狀態並列），左側操作按鈕完全恢復對稱呼吸感。
2. **設定中心 Windows 背景排程管理面板 (`MarketScheduleHubSection`)**：
   - 全透明展示台股（16:00）與美股（08:00）水線狀態。
   - 針對使用者「如何移除排程」之痛點，提供一鍵複製 CMD / PowerShell 卸載指令：
     `schtasks /delete /tn "StockTracker_TW_Sync" /f & schtasks /delete /tn "StockTracker_US_Sync" /f`
     以及雙擊批次檔選單 `[2]` 移除指引。
   - 提供安裝路徑複製與專案搬遷路徑重綁定說明，嚴格恪守瀏覽器沙盒安全邊界與 KISS 原則。
3. **代碼審查 Auto-Fix**：
   - 修正彈窗標題列 CSS `justifyContent: 'space-between'` 置雙端對齊。
   - 補齊複製按鈕計時器 `useRef` 與 `useEffect` unmount 清理防禦及無障礙標籤。
