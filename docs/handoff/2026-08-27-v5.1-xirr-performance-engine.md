## 1. 本次迭代成果總結

1. **核心數學求解器 (`src/engine/xirrCalculator.ts`)**：
   - 0 外部依賴，純原生實作 Newton-Raphson 快速數值解法（50 次迭代，容差 $10^{-7}$）。
   - 內建 Bisection Method（二分逼近法，區間 $[-0.9999, 10.0]$）降級防禦，100% 杜絕數值震盪或崩潰。
   - 實作 30 天智能平滑防護（$< 30$ 天以絕對累積報酬呈現並標記非年化，消除短線極端次方外推失真）。
2. **三層級現金流聚合器**：
   - **整戶總體 XIRR (`calculatePortfolioXirr`)**：彙整歷史外部入金/出金與期末淨資產 (NAV)，精確過濾股票內部扣款以防重複計入。
   - **個股含息 XIRR (`calculateSecurityXirr`)**：逐筆追蹤買進成本（含手續費與稅）、賣出收回淨額、歷年現金股利、減資退款與期末在倉市值。
   - **特定週期 XIRR (`calculateTimeRangeXirr`)**：支援 1M/3M/6M/1Y/YTD/ALL 時間區間折現。
3. **全維度 UI 整合與深色玻璃擬態診斷彈窗 (`src/components/XirrDetailModal.tsx`)**：
   - `SummaryCards.tsx` 卡片 2 顯示整戶 XIRR 與 `[透視金流]` 入口。
   - `PortfolioGrowthChart.tsx` 週期指標展示區間 XIRR 與透視按鈕。
   - `HoldingsTable.tsx` 展開時間軸與股息損益欄展示各標的含息 XIRR 與透視按鈕。
   - `XirrDetailModal` 展示 4 格 KPI 卡片、折現公式說明條與時序現金流明細表（含折現年數與現值 PV）。
4. **測試與品質**：
   - 全專案 13 個測試檔案、**186 項單元測試 100% 綠燈通過**，`npm run build` 成功（TypeScript 0 錯誤）。
