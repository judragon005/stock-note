## 1. 本次迭代概述
- **關聯規格**：Spec #0179 (`docs/specs/0179-tdcc-card-stale-state-repair-and-dynamic-signals-multi-perspective-refactor-spec.md`) / ADR #0179 (`docs/adr/0179-tdcc-card-stale-state-repair-and-dynamic-signals-multi-perspective.md`)

- **合併 PR**：GitHub PR [#231](https://github.com/judragon005/stock-note/pull/231) 與 [#233](https://github.com/judragon005/stock-note/pull/233)
- **核心目標**：
  1. **Card 19 (TDCC 集保千張大戶趨勢) 換股凍結殘留徹底根治**：
     - React 節點顯式綁定 `key={symbol}`，換股時強制銷毀重繪，杜絕 DOM 重用。
     - 非同步查詢啟動時即刻洗淨 `report.tdccDistribution` 為 loading 待命空狀態。
     - 美股市場與空資料標的呈現高質感毛玻璃 Honest Empty State，標註「美股無集保機制 (採 13F 機構申報)」。
  2. **Card 12 (AI 主力動態信號判斷) 廢除硬編碼純紅燈**：
     - 建立多因子量化評分純函式（$0.35\text{籌碼} + 0.30\text{趨勢} + 0.20\text{動能} - 0.15\text{風險}$，截斷 0~100 分，支援自訂權重）。
     - 連動三色動態呼吸光暈燈號（綠燈 $\ge 60$、黃燈 $40\sim 59$、紅燈 $< 40$）。
  3. **多空矛盾智能仲裁演算法 (`arbitrateSignals`)**：
     - 精準識別四大實戰金融型態：「洗盤破底翻 (Bear Trap)」、「誘多高檔出貨 (Bull Trap)」、「共振主升段 (Harmonic Surge)」、「共振破位主跌段 (Harmonic Collapse)」，並提供白話操作指引與關鍵防守價。
  4. **四重視角數據整合 (Bento 結構呈現)**：
     - 交易所：處置股票（5分盤撮合）、列注意股票、當沖過熱投機警戒標籤。
     - 券商：融資餘額與破線風控（標註「融資浮額沉重 / 斷頭防守警戒」）。
     - 法人：20 日 VWAP 成本標準差偏離（如 `-2.1σ 超跌`）。
     - 個人：關鍵防守價（MA20）與轉強壓力價（MA5）。
  5. **架構技術債收錄 (技術債 0049)**：
     - 依據 Code Review 建議將 Card 12 專業層與決策層子元件模組化解耦重構登記至 `docs/debts/0049-dynamic-signals-card-subcomponent-decomposition.md`。

## 3. 開發注意事項與架構守門

1. **Card 19 TDCC 生命週期防護**：
   - 任何涉及 `AiForceDashboardView` 的卡片重構，務必保留 `key={symbol}` 綁定，避免 React 節點復用導致舊數據殘留。
2. **零假資料與美股空狀態 (Zero-Mock Policy)**：
   - 美股市場標的一律標註「美股無集保機制 (採 13F 機構申報)」，嚴禁產生偽造之集保折線。
3. **Card 12 動態燈號防硬編碼**：
   - 燈號必須完全由 `calculateCompositeQuantScore` 與 `mapScoreToVerdictLight` 決定，嚴禁將紅色/綠色靜態色碼寫死於 UI 呈現層。
