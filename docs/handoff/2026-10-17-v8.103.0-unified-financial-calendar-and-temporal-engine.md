## 🛠️ 2. 核心架構與交付模組 (Delivered Architecture)

| 模組 | 檔案路徑 | 職責與關鍵演算法 |
| :--- | :--- | :--- |
| **SSOT 日曆字典** | [`src/data/market-holidays.json`](file:///d:/APP/股票紀錄/src/data/market-holidays.json) | 跨前後端共用之單一真理來源。收錄台美法定節日、修法假期與不可抗力天災停市日；獨立定義 `EARLY_CLOSE` 黑色星期五半日市。 |
| **後端時序運算引擎** | [`scripts/market-sync/trading-calendar-engine.cjs`](file:///d:/APP/股票紀錄/scripts/market-sync/trading-calendar-engine.cjs) | 接入 SSOT。提供 `isTradingDay`、`getHolidayReason`、`getSettlementDate`、`getHoldingInterestDays`、`DEFAULT_MARGIN_ANNUAL_INTEREST_RATE` (6.45%)、`calculateMarginInterest`、`isDerivativesExpiryDay`、`getLatestTdccPublishDate`、`getRevenueDeadlineDate`。 |
| **前端時序日曆橋接** | [`src/engine/holidayCalendar.ts`](file:///d:/APP/股票紀錄/src/engine/holidayCalendar.ts) | 保持 100% 向後相容既有介面與常數 Set（相容 `cashLedgerEngine`），底層全量平滑遷移至 SSOT JSON 字典。 |
| **即時營業狀態引擎** | [`src/engine/marketStatusEngine.ts`](file:///d:/APP/股票紀錄/src/engine/marketStatusEngine.ts) | 利用原生 `Intl.DateTimeFormat` 自動感知夏令/冬令時區，精準計算台美兩地即時營業狀態（盤前試撮、盤中、盤後作業、全日休市、半日市）。 |
| **同步排程零 I/O 守衛** | [`scripts/market-sync/sync-tw-market.cjs`](file:///d:/APP/股票紀錄/scripts/market-sync/sync-tw-market.cjs)<br>[`scripts/market-sync/sync-us-market.cjs`](file:///d:/APP/股票紀錄/scripts/market-sync/sync-us-market.cjs) | 盤後排程執行前進行營業日與美東休市守衛攔截。遇休市日輸出繁體中文日誌秒級退出，零磁碟與網路負擔。 |
| **歷史回補防污染** | [`scripts/market-sync/backfill-tw-history-web.cjs`](file:///d:/APP/股票紀錄/scripts/market-sync/backfill-tw-history-web.cjs) | 250 天歷史回溯候選日事前排除休市日；手動傳入休市日時優雅標記為休市略過，絕不推入 `failedDates`，消除重試死循環。 |
| **前端即時看板 UI** | [`src/components/MarketScheduleHubSection.tsx`](file:///d:/APP/股票紀錄/src/components/MarketScheduleHubSection.tsx) | 排程卡片 header 即時渲染營業狀態徽章與中文休市原因標籤；支援 Page Visibility API 感知分頁休眠暫停與前景即時校準。 |
