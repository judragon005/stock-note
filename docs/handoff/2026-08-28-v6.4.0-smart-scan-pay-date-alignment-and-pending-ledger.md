# 專案交接手冊 (Handoff) - V6.4.0 智慧掃描公司行動除息日與發放日雙欄位注入與現金在途隔離

日期: 2026-08-28

## 1. 本次迭代核心成果 (Key Achievements)

1. **持股數判定驗證與基準恆定**：
   - 深入分析驗證智慧掃描配息邏輯，確認以「除息日前一日（$Ex\text{-}Date - 1\text{ day}$）」收盤在籍庫存計算，絕不受除息日後的買賣干擾。
2. **掃描模型與雙日期完整注入**：
   - 在 `ScannedCorporateAction` 與 `RawCorporateEvent` 中新增 `payDate?: string` 欄位。
   - 掃描引擎結合官方行事曆（2330、2886、00878、00923、9927）與交割週期自動推算發放日（台股 +28 日、美股 +21 日）。
3. **自動補登資料結構健全**：
   - `CorporateActionScannerModal` 套用補登時，將 `exDate`（除息日）與 `payDate`（發放日）同步寫入 `TradeRecord`，並在交易備註清晰標記。
4. **現金帳本在途隔離與自動交割流轉**：
   - `cashLedgerEngine` 依 `trade.payDate` 進行交割狀態劃分（未到期為 `PENDING` 在途款項，發放日當天轉為 `SETTLED` 可用現金）。
   - `syncTradesWithCashTransactions` 支援可選 `asOfDate`，強化時間回溯測試。
5. **品質與測試驗收**：
   - 31 個測試檔案、**352 項單元測試 100% 綠燈通過**。
   - `npm run build` 打包與 TypeScript 檢查 **0 錯誤**。
