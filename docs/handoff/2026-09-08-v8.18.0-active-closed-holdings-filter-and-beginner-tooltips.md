# 交付手冊：V8.18.0 在倉持股精確分流與小白動能百科 (Active/Closed Holdings Separation & Beginner Tooltips)

## 1. 交付背景與核心目標
本迭代旨在解決使用者在實戰操作中回饋的三大痛點：
1. **AI 晨報在倉真實性**：解決已平倉出清的 0 股標的（如 00746B、1717 等）誤出現在晨報「破線停損」清單之 Bug。
2. **動能雷達資產池明確化**：將混入歷史平倉共 60 檔的「持倉」拆解為獨立的「在倉持股」與「歷史平倉」，直觀掌握當前風險曝險。
3. **股市小白認知降維**：為操盤導航儀中的關鍵術語（風益比、箱頂防守、破底翻、布林壓縮、跌破箱底、均線扣抵）提供通俗生動的 Tooltip 懸浮百科。

## 2. 架構變更與關鍵實作
- **在倉標的過濾海關**：
  - `src/components/WarRoomWorkspace.tsx`：將晨報 `holdingSignals` 抽取邏輯約束為 `holdings.filter(h => h.shares > 0)`，確保晨報只對目前持有部位發出警報。
- **肌肉書僮資產池雙軌分流**：
  - `src/components/MuscleBookerWorkspace.tsx`：定義 `activeHoldings` 與 `closedHoldings`，按鈕動態呈現 `在倉持股 (${activeHoldings.length})` 與 `歷史平倉 (${closedHoldings.length})`。
- **動能百科字典與 Tooltip 整合**：
  - 定義 `BEGINNER_TOOLTIPS`，並於三色戰術矩陣、四大象限卡片與均線扣抵望遠鏡表頭中無縫掛載 `<Tooltip>` 元件，文字套用 `underline dotted` 與 `cursor: help`。

## 3. 測試與驗證結果
- **測試框架**：Vitest `v3.2.7`
- **測試結果**：57 個測試檔案、624 個單元測試 100% 通過。
- **打包檢驗**：`npm run build` TypeScript 0 錯誤，Vite 建置成功。
