# 交接手冊：V8.9.0 台股加權指數 Benchmark 全歷史日線與全市場股票字典補全

## 1. 任務背景與問題根因

### 1.1 使用者需求
- 使用者提供本機路徑 `D:\APP\諮詢\私人\股市\台股加權指數_歷史數據` 下由 Python 抓取的全歷史金融數據庫。
- 要求進行深度調研，評估對專案資料庫補全之價值，並在不破壞既有架構與遵守專案規範的前提下，執行第一階段數據補全。

### 1.2 現存三大缺陷
1. **大盤基準資料稀疏且缺乏加權指數 (TAIEX)**：
   - 專案原先的大盤基準僅有 `0050` 與 `SPY`，且 `0050` 僅有 48 個半月抽樣點，缺乏真實每日日線；且無台股代表性最強的「加權指數 (^TWII)」。
2. **股票名稱字典覆蓋率不足**：
   - 原 `src/data/stockDictionary.ts` 僅約 700 餘行，新發行的主動型 ETF（如 00400A、00401A、00403A 等）或上櫃中小型標的在離線環境下無法解析中文名稱。
3. **外部高品質歷史數據庫未被充分利用**：
   - 使用者本機維護至 2026-09-07 的加權指數 7,153 筆日線與 2,340+ 檔標的未標準化整合進專案。
