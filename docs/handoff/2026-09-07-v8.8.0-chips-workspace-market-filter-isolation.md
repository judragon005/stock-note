# 交接手冊：V8.8.0 籌碼動態星圖市場篩選隔離與 Header 狀態雙向同步

## 1. 任務背景與問題根因

### 1.1 使用者回饋
- 在頂部 Header 選擇「US 美股」後，切換至「全市場法人焦點 Top 30」時，畫面上既有 NVDA, AAPL, MSFT, META, TSLA 等美股，又同時出現 0050, 2344, 2409, 00918, 00919 等台股。
- 要求檢視並一次檢查「美股」、「台股」、「全部」的篩選邏輯與 Bug。

### 1.2 三大根本原因 (Root Cause Analysis)
1. **根本原因 1 (Props 脫鉤)**：
   - `App.tsx` 渲染 `<ChipsWorkspace>` 時未傳遞頂部 Header 的 `currentMarket`，導致 `ChipsWorkspace` 內部的市場狀態停留在初始預設的 `'ALL'`。
2. **根本原因 2 (UI 條件隱藏)**：
   - `ChipsWorkspace.tsx` 原先寫了 `{viewMode === 'PORTFOLIO' && (`，導致在「全市場法人焦點 Top 30」模式下，市場切換按鈕整組隱藏，使用者無法在工作區內切換美股/台股。
3. **根本原因 3 (ALL 模式的混雜定義)**：
   - 在 `marketFilter === 'ALL'` 時，系統預設回傳 20 檔台股 + 10 檔美股巨頭；因此當使用者在 Header 點了美股，結果畫面上因狀態脫鉤持續以 `'ALL'` 模式渲染，造成台美股混雜。

---

## 2. 核心架構變更與實作

### 2.1 抽離純函數 `filterMarketFocusList`
在 [src/components/ChipsWorkspace.tsx](file:///d:/APP/股票紀錄/src/components/ChipsWorkspace.tsx) 抽離純函數，嚴格隔離輸出市場：
- **`US` 模式**：100% 純美股 Top 25 標的清單（`US_MARKET_FOCUS_LIST`），絕不注入任何台股。
- **`TW` 模式**：100% 純台股 Top 30 標的清單（三大法人日報合計排序），絕不注入任何美股。
- **`ALL` 模式**：台股焦點 Top 20 結合美股巨頭 Top 10，均衡呈現。

### 2.2 雙向狀態連動
- `ChipsWorkspaceProps` 擴充 `market?: 'ALL' | MarketType; onMarketChange?: (market: 'ALL' | MarketType) => void;`。
- `ChipsWorkspace` 監聽外部 `market` 傳入，內部點擊切換時透過 `handleSetMarketFilter` 同時呼叫 `onMarketChange`。
- `App.tsx` 於 `<ChipsWorkspace>` 綁定 `market={currentMarket}` 與 `onMarketChange={setCurrentMarket}`。

### 2.3 解鎖市場按鈕常駐顯示
- 移除 `{viewMode === 'PORTFOLIO' && (`，不論在持倉模式或全市場焦點模式，市場切換按鈕（全部 / 台股 / 美股）皆常駐可見。

- **單元測試**：在 [src/components/ChipsWorkspace.test.ts](file:///d:/APP/股票紀錄/src/components/ChipsWorkspace.test.ts) 新增 3 項測試：
