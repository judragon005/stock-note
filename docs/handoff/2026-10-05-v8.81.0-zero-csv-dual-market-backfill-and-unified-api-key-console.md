## 1. 迭代目標與成果總覽 (Executive Summary)

本迭代針對真實投資人在主力戰情室與系統設定中的兩大痛點進行深度根治：
1. **照片一缺陷：00411A / 00679B 代碼誤判與長天期指標空白修復**：
   - 強化 `inferMarketType` 支援後綴字母之台股代碼（`/^[0-9]{4,6}[A-Z]?$/`），`00411A`、`00679B` 正確識別為台股 `TW`，鎖定計價幣別為 `TWD`、成交量單位為 `張`。
   - `daily_candles` 新增 `transactions` 欄位並冪等遷移。
   - 技術債 0043 結案：歷史櫃買帶 `O` 尾綴標的無損標準化歸併，日 K 查詢提供雙向別名探測。
   - 主力戰情室 18 張卡片全面連動真實資料庫，針對短天期新標的實施 Smart Adaptive Depth 降級，長天期指標以 Honest Empty State 標註「新上市數據累積中」，徹底杜絕崩潰與虛構數據。
2. **照片二缺陷：設定頁面重複金鑰介面消除與統一暗黑毛玻璃控制台**：
   - 移除舊版原生白底 input 與舊版金鑰池獨立區塊。
   - 導入全新的 `UnifiedApiKeyManager`（Provider-Centric 統一卡片式、Web Crypto 256-bit 保護、單鍵測活與 30s 冷卻防連點、全域 Proxy 配置）。
3. **台美雙軌零 CSV 背景歷史回補全流程**：
   - 實作日期驅動官方 TWSE/TPEx 全市場日 K 回補腳本 (`backfill-tw-history-web.cjs`)，零 CSV 依賴。
   - 實作台美雙軌背景全回補總控腳本 (`backfill-full-market-history.cjs`) 與 Vite 中介層 `POST /api/market/backfill-all`、`GET /api/market/backfill-status`。
   - 於設定排程中心新增「台美雙軌零 CSV 背景全歷史回補」控制面板，支援按鈕背景啟動、電腦不關機持續執行、SQLite 斷點續傳與即時動態進度條。

## 4. 驗收與操作指引 (Verification & Manual Testing)

1. **驗證 00411A / 00679B 市場識別**：
   - 開啟主力戰情室，搜尋輸入 `00411A`。
   - 確認頂部標示「🇹🇼 台股」，計價幣別為 `NT$`，量能為「張」。
   - 若資料庫為新上市天數（如 37 筆），短天期 MA5/10/20 正常輸出，MA60/250 顯示「新上市數據累積中 (37/60D)」。
2. **驗證金鑰控制台**：
   - 進入「設定 ➔ 外部金融 API 整合控制台」。
   - 確認無原生白底 input，整合成高雅暗黑毛玻璃卡片。
   - 可依 FinMind, FMP, Finnhub 等分頁切換管理金鑰與單鍵測活。
3. **驗證背景歷史全回補**：
   - 進入「設定 ➔ 全市場每日盤後自動化與 Windows 排程管理」。
   - 點擊「啟動背景全回補」。
   - 確認按鈕即時轉為「⚡ 背景回補運行中...」，進度條每 3 秒自動更新進度，可安全關閉或重新整理網頁，後台守護進程自動透過 `sync_checkpoints` 推進。
