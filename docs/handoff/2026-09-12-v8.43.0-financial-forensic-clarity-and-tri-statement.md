# 2026-09-12 V8.43.0 穿透式財報深度分析儀三大報表原子聚合與操盤手決策系統交接手冊

## 變更摘要 (Release Summary)

本次迭代（V8.43.0 / Spec #0125 / Issue #47 / PR #48）針對使用者在檢視穿透式財報戰情室時反饋之「視覺上看不出分析意義、現金流為 0 假陽性、結論語意矛盾、缺乏刻度數值與具體指引」等痛點，實施全面重構與補強：

1. **台股三大財務報表原子聚合管線 (`taiwanFinancialPipeline.ts`)**：
   - 並行請求 FinMind 損益表 (`TaiwanStockFinancialStatements`)、資產負債表 (`TaiwanStockBalanceSheet`) 與現金流量表 (`TaiwanStockCashFlowsStatement`)。
   - 依據結算日跨表原子歸併至標準 16 項財務科目，補齊台股營業活動現金流 (CFO)、資本支出 (Capex)、總資產、總負債與權益總計，徹底根除台股 CFO 假陽性為 0 的系統漏洞。
2. **資深操盤手風格結構化方針與決策引擎 (`financialScoringEngine.ts`)**：
   - 徹底移除盲目「獲利與營運現金流處於健康區間」之矛盾兜底文字。
   - 引入四級操盤定調（`【強勢造血·長線續抱】`、`【體質穩健·逢回布局】`、`【體質承壓·防守觀望】`、`【重大風險·嚴格戒備】`）、核心矛盾洞察（如紙上富貴/失血風險）與具體操盤方針，確保戰報結論與指示燈號 100% 邏輯一致。
3. **三率折線圖動態 Y 軸刻度與最新三率數值膠囊 (`FinancialTrendsLayer.tsx`)**：
   - SVG 左側動態計算百分比 min/max 刻度與水平格線，消弭盲猜走勢缺陷。
   - 頂部圖例清晰展示最新一季毛利率、營益率、淨利率百分比數字膠囊。
4. **淨利 vs CFO 雙向階梯柱與金額標籤 (`FinancialTrendsLayer.tsx`)**：
   - 支援雙向正負柱狀排版（負 CFO 明確向下延伸並呈醒目紅柱），柱身直接標註每季金額標籤（百萬/億），背離時顯著呈現「⚠️紙上富貴」警示標籤。
5. **四大體質維度卡片數據化 (`FinancialHeroLayer.tsx`)**：
   - 獲利能力（毛利率、ROE、淨利率）、安全性（負債比、速動比、淨現金）、營運效率（DSO、DIO/豁免）、現金流（最新季 CFO、FCF 金額）均內嵌最新數據，決策依據一目了然。
6. **領域文件與治理同步**：
   - 新增 ADR `docs/adr/0125-financial-forensic-clarity-tri-statement-and-action-directive.md`。
   - 同步更新 `CONTEXT.md` 與 `README.md`。
   - 全量 88 個測試檔案、870 個單元測試 100% 綠燈通過，TypeScript 0 報錯。
