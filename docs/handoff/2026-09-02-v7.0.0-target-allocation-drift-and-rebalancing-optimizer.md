## 📌 本次迭代核心成果 (Key Achievements)

1. **目標資產配置模型與持久化 (Target Allocation Engine)**：
   - 建立 `src/types/allocation.ts` 與 `src/utils/allocationStorage.ts`。
   - 支援「市場維度 (TW/US/Cash)」與「個股維度 (Symbol-level)」策略設定與切換。
   - 內建目標比例合計 100% 之即時校驗防呆機制。
2. **偏離度量化與再平衡演算法 (Rebalancing Engine)**：
   - 建立 `src/engine/rebalancingEngine.ts`。
   - 偏離度分析：即時計算佔比與差距，提供 `🟢 正常平衡`、`🟡 輕度偏離`、`🔴 顯著失衡` 評級。
   - 定期注水加碼 (Cash-in Only)：優先依缺口比例補足低配標的，只買不賣，零額外摩擦成本與稅負。
   - 全量買賣再平衡 (Full Rebalance)：超配賣出、低配加碼，買賣總額平衡。
   - 下單規格轉換：台股自動拆解「整張數 (1,000股) + 零股」，美股支援碎股小數點計算，並同步輸出原幣別與折合台幣建議金額。
3. **UI 視覺化與互動整合**：
   - 建立 `src/components/RebalancingView.tsx`，並整合至 `src/components/AllocationChart.tsx` 頂部「⚖️ 目標配置與再平衡」Tab。
   - 包含策略動態編輯器、雙色水平長條對比圖、注水加碼輸入框（含一鍵帶入可用現金）與建議下單明細表。
