## 2. 核心成果清單

1. **頂部 Header 自封閉秒級跳動市場時鐘 (`RealtimeMarketClock`)**：
   - 解決過去 Header 時鐘在市價未更新時呈現靜態死鐘之問題。
   - 提取獨立葉子節點元件 `RealtimeMarketClock.tsx`，內部自封閉 `setInterval(..., 1000)` 計時器與局部 `useState`。
   - 實現秒級平滑跳動且**對父層 `<Header>` 及整個 App 造成 0 額外重繪 (Zero Re-render Spillover)**。
   - 支援顯示台北時間（`Asia/Taipei`），自適應開休市即時標籤狀態。

2. **跨平台 ICU 午夜格式跨環境相容加固 (`formatTaipeiClock`)**：
   - 發現並修復 Linux/Ubuntu CI 環境下 `Intl.DateTimeFormat` 在午夜可能輸出 `24:00:00` 之 ICU 規範邊界異常。
   - 導出共用格式化函數 `formatTaipeiClock`，建立模組級單例 `TAIPEI_CLOCK_FORMATTER` 消除重繪 GC 開銷。
   - 內建 `startsWith('24:')` 轉 `00:` 防禦正規化邏輯，在 Windows、macOS 與 Linux CI 環境下 100% 穩定輸出 `00:00:00`。

3. **即時時鐘與市價更新時間解耦 (`Price Sync Decoupling`)**：
   - 頂部導覽列狀態文字清楚解耦為：「秒級即時市場時鐘（走動中）」與「市價更新 {HH:mm:ss}（靜態快照時戳）」。
   - 消除使用者對「時鐘是否停止」的困惑與認知衝突。

4. **官方除息入帳日對照庫精確登錄 (`Official Dividend Payment Date Database`)**：
   - 依使用者銀行存摺實際入帳日期，於 `OFFICIAL_TW_PAY_DATE_MAP` 登錄泰銘 (9927)：
     `'9927:2025-11-13': '2025-12-01'`。
   - 確保泰銘 2025 年配息精準歸屬於 2025 年 12 月（非先前推估之 12/11）。

5. **股利稅務與二代健保解析防禦加固 (`resolveEffectiveDividendTaxAndNet`)**：
   - 強化 `taxComplianceEngine.ts`：當交易紀錄具備顯式 `tax` / `fee` 時，優先保留顯式記錄。
   - 杜絕系統自動補登時以毛額填入 `cashAmount` 導致淨額被誤判為毛額、進而產生重複扣抵二代健保之時序失真問題。

6. **永豐金大戶投股利全量入帳勾稽與透明提示**：
   - 確立以「含泰銘（2025-12-01 到帳）」為全量準則。
   - 更新 `DividendLogView.tsx` 首張 KPI 卡片 Tooltip 提示，完整說明永豐金大戶投 600,745 元（未含泰銘）與全量 625,508 元（含泰銘）之對帳勾稽關係。
