## 1. 本次迭代核心成果 (Deliverables)

1. **多來源免費 API Key 池與自適應輪替調度器**：
   - 核心引擎：[`src/engine/smartKeyRotator.ts`](file:///d:/APP/股票紀錄/src/engine/smartKeyRotator.ts)
   - 支援 Round-Robin 負載均衡、429 指數退避（5s ~ 60s）、401/403 永久拉黑、跨日自動重置配額。
   - 支援本地加密持久化存儲 [`src/engine/apiKeyStorage.ts`](file:///d:/APP/股票紀錄/src/engine/apiKeyStorage.ts)。
   - 連線探針具備 30 秒冷卻防連點保護與 UI 倒數計時 [`src/engine/apiKeyHealthProbe.ts`](file:///d:/APP/股票紀錄/src/engine/apiKeyHealthProbe.ts)。
   - 設置頁面嵌入金鑰池管理面板 [`src/components/ApiKeyPoolManager.tsx`](file:///d:/APP/股票紀錄/src/components/ApiKeyPoolManager.tsx)。

2. **SEC EDGAR 官方美股財報管線 (100% 免費權威)**：
   - 合規傳輸層 [`src/engine/secEdgarTransport.ts`](file:///d:/APP/股票紀錄/src/engine/secEdgarTransport.ts)：嚴格遵守 SEC 10 req/s 限制與合規 User-Agent。
   - 財報解析器 [`src/engine/secEdgarParser.ts`](file:///d:/APP/股票紀錄/src/engine/secEdgarParser.ts)：全面覆蓋 US-GAAP 與 IFRS-full (ADR) 之 16 大標準財務科目與多樣化營收認列標籤。
   - 美股財報服務 [`src/engine/usFinancialPipeline.ts`](file:///d:/APP/股票紀錄/src/engine/usFinancialPipeline.ts)：SEC 官方直連第一優先，FMP 免費 Key 池自動降級備援。

3. **台股官方除權除息預告與平盤參考價推算**：
   - 資料庫表：`corporate_action_calendar`。
   - 採集腳本：[`scripts/market-sync/ingest-tw-corporate-actions.cjs`](file:///d:/APP/股票紀錄/scripts/market-sync/ingest-tw-corporate-actions.cjs)（對接 TWSE TWT48U / TPEX OpenAPI）。
   - 純函式推算引擎 [`src/engine/receivableDividendEngine.ts`](file:///d:/APP/股票紀錄/src/engine/receivableDividendEngine.ts)：前瞻推算未來股利現金流（`projectFutureDividends`）與官方開盤參考價（`computeExDividendReferencePrice`）。

4. **董監事質押法證雷達防雷**：
   - 資料庫表：`tw_insider_pledge_records`。
   - 採集腳本：[`scripts/market-sync/ingest-tw-pledge.cjs`](file:///d:/APP/股票紀錄/scripts/market-sync/ingest-tw-pledge.cjs)（對接 MOPS 董監事質押統計）。
   - 法證分析引擎 [`src/engine/forensicRadarEngine.ts`](file:///d:/APP/股票紀錄/src/engine/forensicRadarEngine.ts)：董監質押率 > 50% 觸發紅燈並扣除 30 分。

5. **FRED 總經指標與動態真實無風險利率**：
   - 資料庫表：`macro_sentiment_daily`。
   - 採集腳本：[`scripts/market-sync/ingest-macro-sentiment.cjs`](file:///d:/APP/股票紀錄/scripts/market-sync/ingest-macro-sentiment.cjs)（10 年期美債殖利率 DGS10 與恐慌指數）。
   - 量化引擎 [`src/engine/quantMetrics.ts`](file:///d:/APP/股票紀錄/src/engine/quantMetrics.ts)：動態注入無風險利率計算真實夏普比率。
