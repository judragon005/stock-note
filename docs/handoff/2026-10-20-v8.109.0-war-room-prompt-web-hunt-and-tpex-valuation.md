  2. **TWSE / TPEx 每日官方 PE / PB / 殖利率沉澱與 SQLite 快取**：建立 `tw_valuation_daily` 表，盤後整包寫入 SQLite 並整合進 `tw_market_summary.json`，支援冪等寫入與快速命中。
  3. **戰情室前端單季財報貫通與籌碼均量比率**：非阻塞調用 `loadOrFetchFinancialReport`，提取最新單季 EPS、毛利率與營業利益率；計算外資與投信佔 20 日均量比（`foreignRatio20D`、`trustRatio20D`）；盤中量 `<= 0` 時自動附註前一交易日收盤量。
  4. **智策提示詞中樞受控聯網獵犬協議 (<web_retrieval_instructions>)**：限定僅在包含【待同步】或 N/A 欄位時聯網；限定官方白名單來源（MOPS、TWSE、TPEx、Yahoo 股市、權威財經日報）；資訊發布日必須為 2026 年自證；禁止覆蓋本地價量均線與主力 VWAP SSOT；強制隔離機構推估與官方實績。
  5. **輸出格式契約升級與 Token 門禁**：強制第一行唯一方向燈號（🟢/🟡/🔴）；Markdown 3 欄式點位作戰表（進場/目標/停損/失效）；下檔 2 大致命暴雷點質詢；精煉文本確保 Master Prompt 嚴格維持在 < 4,500 tokens 門禁之內。
  6. **官方估值零值防禦與單季財報提取優雅降級**：擴充 `cleanValuationNumber` 支援 `allowZero: false`，將本益比/淨值比 `<= 0`（含 `'0.00'`、`'--'`、負數）轉化為 `null`，殖利率合法保留 `0.00`；強化型別守門與除以零保護，以專案統一之 `logger.warn` 記錄非致命異常。
