## 1. 迭代完成目標與核心成就 (Achievements)

1. **台美雙軌本地官方股票名稱字典庫**：
   * 內建全量台股官方上市、上櫃、興櫃、主動/被動/高股息/債券 ETF（如 `2330` ➔ `台積電`、`0050` ➔ `元大台灣50`、`6547` ➔ `高端疫苗`、`00679B` ➔ `元大美債20年`）。
   * 內建美股全量 **599 檔**標的（完整收錄 S&P 500 全部成分股、Nasdaq 100 指數成分股及主流 ETF 繁體中文簡稱，如 `NVDA` ➔ `輝達`、`AAPL` ➔ `蘋果`、`MSFT` ➔ `微軟`、`VOO` ➔ `Vanguard標普500 ETF`、`VT` ➔ `Vanguard全世界股票ETF`）。
2. **TPEx CORS 代理與衍生權證智慧過濾網 (`isValidTaiwanSecurity`)**：
   * 支援 `/api/tpex` 代理路由，打通證券櫃檯買賣中心 OpenAPI 清單抓取。
   * 實作正則過濾邏輯，自動剔除近萬檔短天期 6 碼認購售權證/牛熊證與可轉換公司債，確保台股收錄聚焦在真正的股票、特別股與 ETF（穩定於 2,500 ~ 2,800 檔）。
3. **雙向智慧搜尋與表單即時自動補齊 (`TradeModal.tsx`)**：
   * 標的代碼輸入框支援輸入「代碼 (Ticker)」或「中文關鍵字」即時模糊檢索全量字典。
   * 輸入精確代碼時自動補齊標的名稱，若手動修改名稱則以手動為準並自動持久化記錄至自訂字典。
   * 點擊建議項目時自動同步帶入代碼、名稱並切換所屬市場（TW / US）與相應折讓手續費。
4. **全域一致官方繁中名稱解析 (`resolveOfficialSecurityName`)**：
   * 升級全域解析引擎，庫存列表、歷史紀錄、資產樹狀圖 (Treemap)、報表及未來的 CSV 匯入管線皆能自動呈現統一官方繁體中文名稱。
5. **官方 OpenAPI 一鍵同步與設定頁面板 (`SettingsWorkspace.tsx`)**：
   * 串接臺灣證券交易所 (TWSE) 與櫃買中心 (TPEx) OpenAPI 清單。
   * 於設定頁提供專屬管理面板，具備收錄檔數即時統計、一鍵同步與重設快取功能。
