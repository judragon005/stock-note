## 🎯 迭代背景與成果總結

### 1. 痛點解決
- 徹底根除在切換「慣用紅綠漲跌（台股模式：紅漲綠跌 / 國際模式：綠漲紅跌）」時，因近期開發元件（如 `PortfolioGrowthChart.tsx`、`XirrDetailModal.tsx`）內部寫死 Hex 色碼而導致的損益色彩錯亂與倒置問題。
- 修正 Header 工具列切換按鈕文字對稱性，補齊國際模式漏字（改為「`🟢 綠漲 🔴 紅跌`」）。

### 2. 核心功能交付
1. **全域 CSS 變數體系對齊 (`src/index.css`)**：
   - 確立 `var(--gain-color)` 與 `var(--loss-color)` 為唯一事實來源，受根節點 `data-color-theme` 自動控制。
2. **NAV 圖表概覽卡片重構 (`src/components/PortfolioGrowthChart.tsx`)**：
   - 「當日漲跌額 / 報酬率」、「全期累計總損益」、「累積報酬率 %」、「XIRR」、「Alpha 超額回報」全面動態連動。
   - 「當前淨資產 (NAV)」與「最高淨值 (ATH)」總額維持中性主題亮色，層次分明。
3. **明細視窗與統計卡片對齊 (`src/components/XirrDetailModal.tsx`, `SummaryCards.tsx`)**：
   - XIRR 累積報酬率、平倉卡片與已實現損益卡片之 Award 圖示與背景色全數完成連動替換。
4. **無損回歸與品質把關**：
   - 24 個測試檔案、296 項單元測試 100% 綠燈通過。
   - `npm run build` TypeScript 0 錯誤。
