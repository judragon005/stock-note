## 🎯 迭代背景與解決之痛點

1. **設質登記費 0 值被誤判為 53/54 且規費重複翻倍**：
   使用者在永豐金質押借貸中僅登記了撥券費（NT$ 53 / NT$ 54），設質登記費為 0。然而舊版相容性欄位 `pledgeFee: 53`（合計）被錯誤回填至 `paidPledgeRegistryFee`，且帳本規費流水無法正則拆解時被整筆灌入設質費，導致已付設質費與撥券費皆為 53/54，規費總額重複翻倍（變成 106 / 108）。
2. **結清還款日缺乏手動校準途徑**：
   缺乏還款流水時系統預設為今日（2026-09-03），使用者無法手動調整至實際清償日。

## 🚀 本次交付核心改進

1. **三大規費明細單一事實來源 (SSOT) 與 0 值防禦**：
   - 重構 `calculateLoanSettledSummary`：只要借貸本體存在明確的三大規費設定（`transferFee`、`pledgeRegistryFee` 或 `handlingFee`），嚴格以各項目明細為準。
   - 設質費登錄為 0 即強制為 0，嚴禁使用舊 `pledgeFee` 回退覆蓋。
   - 撥券費為 53/54，設質費為 0，開辦費為 0，總規費精確等於 53/54，不再翻倍！
2. **`LoanModal` 支援結清還款日 (closedDate) 手動維護**：
   - 當編輯未還本金為 0（已結清借貸）時，動態呈現「**✅ 結清還款日 / 終止日 (已結清借貸)**」日期選擇器。
   - 允許投資人隨時自主調整真實還款日，系統即時連動重新計算實際歷時天數與利息成本。
