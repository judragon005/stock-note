# 2026-09-12 V8.42.1 穿透式財報深度戰情室浮動彈窗樣式修復與點擊激活交接手冊

## 變更摘要 (Release Summary)

本次迭代（V8.42.1 / Spec #0124 / Issue #45）全面修復了使用者回報之「持股時間軸點擊 📊 財報穿透 按鈕無任何反應」的根本病灶：
- **徹底清除無效 Tailwind CSS classes**：將 `FinancialForensicModal` 及其 3 個子圖層全面改寫為原生 Vanilla CSS + Inline Styles + CSS Variables。
- **彈窗全螢幕置中與高層級遮罩**：設定 `position: fixed; inset: 0; zIndex: 9999; backdropFilter: blur(8px)`，點擊立即浮起，支援 ESC 與外部點擊關閉。
- **三層圖層原生美學渲染**：
  - Layer 1 (0 秒戰報與四大維度體質指示燈)
  - Layer 2 (近 8 季三率折線 SVG、稅後淨利 vs CFO 柱狀階梯圖、杜邦 ROE 三因子矩陣)
  - Layer 3 (「市場沒說什麼」逆向鑑識排雷卡片、會計師查核意見與四大事務所標章、一鍵複製 Markdown 戰報)
- **零破壞與品質保證**：
  - 88 個測試套件、867 個測試 100% 通過。
  - `npm run build` TypeScript 0 報錯，生產打包成功。
