## 📌 一、本次迭代交付重點 (Delivered Features)

1. **正幾何資本來源模型 (Capital Employed Positive Geometry)**：
   - 樹狀圖 (Squarified Treemap) 維持以全資產 $\text{TotalAssets} = \sum \text{StockValue} + \max(0, \text{CashBalance})$ 為分母，當存在未結清借款（$\text{validDebt} > 0$）時，以正數面積動態注入 `id: 'DEBT_TWD'` 節點。
   - 區塊面積精確反映負債佔總資產之財務槓桿佔比，零借款時 100% 自動隱藏。

2. **專屬琥珀金警示視覺語意 (Amber Warning Visual Semantics)**：
   - 借款節點採用專屬高對比琥珀金底色（`hsla(38, 92%, 50%, 0.85)` / `#f59e0b`）與深琥珀外框（`#d97706`），完全獨立於紅綠漲跌主題，消除與持股損益或現金的視覺混淆。
   - 節點標籤展示 `🏦 借貸負債`、總負債金額與年化成本標註（例如 `-2.35% 年息` 或 `負債項`）。

3. **多層次借貸合約透視 Tooltip (Hierarchical Contract Inspection)**：
   - 滑鼠懸浮於借款區塊時，彈出結構化毛玻璃卡片，完整羅列各筆借款合約名稱、借款類別（質押/融資/信貸）、本金與年化利率。

4. **權重清單與頂部 LTV 膠囊同步連動 (Bars & LTV Capsule Integration)**：
   - 切換至「權重清單 (Bars)」視圖時，同步納入借款長條項；頂部市場配置條維持純資產百分比，並於比例 HUD 動態呈現 `🏦 負債比 LTV: XX.X%` 膠囊。

5. **全量單元測試與生產構建驗收**：
   - 遵循 TDD 紅-綠-重構循環，全專案 45 個測試檔案、483 項單元測試 100% 綠燈通過。
   - `npm run build` 0 TypeScript 錯誤，完成 Vite Bundle 生產版本封裝。
