## 1. 核心需求與交付亮點

### 1.1 肌肉書僮動能雷達：三色實戰操盤動作矩陣 (Traffic-Light Action Matrix)
- **痛點解決**：以往動能雷達僅有指標象限分群，缺乏直觀明確的操作指導；散戶面對大量代號往往不知所措。
- **實戰動詞四分流**：
  - `🟢 建議買進 (BUY)`：三日箱頂有效站穩且 20MA 向上翻揚，或底穿假跌破破底翻；自動計算箱頂防守價、等幅目標價與風益比 (R:R)。
  - `⛔ 觀望不碰 (AVOID)`：布林極致壓縮（帶寬 `<8%`）等待出方向變盤，或 20MA 下彎蓋頭反壓反彈無力；警告切勿接刀。
  - `🔴 建議賣出 (SELL)`：跌破三日箱底防守線，破線立即停損保全本金；嚴禁凹單。
  - `⚪ 區間觀望 (HOLD)`：箱內常態震盪整理。
- **UI 交互**：
  - 頂部導航新增實戰動作篩選標籤（`🔥 全部標的` / `🟢 建議買進` / `⛔ 觀望不碰` / `🔴 建議賣出`）與即時數量計數器。
  - 卡片與表格均提供明確徽章、防守點位、風益比，並支援點擊展開「實戰小抄（Action Reason）」。

### 1.2 宏觀總體戰情室：多因子真實帳戶事件驅動 AI 晨報引擎
- **痛點解決**：告別假大空的廣告看板與靜態泛用雞湯，讓每天早晨的作戰方針真正具備個人專屬參考價值。
- **多因子動態決策**：
  - 整合個人在倉持股之達瓦斯突破/破線事件 (`holdingSignals`)。
  - 整合關鍵財經事件倒數 3 天內預警 (`urgentCatalysts`)，如 CPI、FOMC。
  - 整合即將到期入帳之現金股息現金流 (`upcomingDividends`)。
- **方針與指令動態化**：
  - 持股破線立即點名代號、名稱與停損點，標題動態升級為 `【破線警戒・汰弱留強】`。
  - 持股站穩箱頂點名代號與加碼防守點，標題動態升級為 `【強者恆強・突破進攻】`。
  - 提示重大事件倒數防範波動，預告股息入帳規劃再平衡活水。
  - UI 標色分明：紅色警戒停損、綠色動能突破、青色催化劑倒數、金色股息活水。
