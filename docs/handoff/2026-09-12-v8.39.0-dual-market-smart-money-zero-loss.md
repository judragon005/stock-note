# 交付手冊：V8.39.0 台美雙市場全量籌碼零遺漏、雙軌原子合流與真實 20D CMF 入庫防禦

## 1. 交付背景與核心訴求 (Background & Objectives)
- **問題回溯**：
  - 9/12 啟動系統時，發現「聰明錢籌碼動能」資料停留在 9/9，9/10 與 9/11 資料空白。
  - 使用者指示：籌碼動能是判斷是否購買股票以及避開地雷股的核心技術，不能有任何模糊或不確定空間，台股與美股市場的所有籌碼資料必須保證 100% 完整捕捉並存入 IndexedDB。
- **根因發現**：
  - `vite.config.ts` 中的 Proxy 路由，較短的 `'/api/twse'` 排在較長的 `'/api/twse-www'` 前面，導致請求被前綴遮蔽 (Prefix Shadowing)，上市大盤三大法人日報請求被改寫為 `-www/...` 打向 OpenAPI 伺服器，100% 報 404 (nginx)。
  - 系統僅能取得 TPEx 上櫃約 894 檔，多維完整性哨兵判定日報未齊全拒絕寫入快取，但因缺乏原子合流與快取洗滌，系統無限期退回 9/9 快取。
  - 美股籌碼過去採 `Array.from({ length: 20 })` 進行虛擬常態分佈模擬日 K 計算 CMF，非真實成交數據。

---

## 2. 解決方案與關鍵變更 (Key Changes)

### 2.1 Vite Proxy 路由前綴優先權修正 (`vite.config.ts`)
- 將 `'/api/twse-www'` 明確宣告於 `'/api/twse'` 之前。
- 測試驗證：上市三大法人日報請求立即回傳 200 OK，順利取得上市 1,330 檔股票。

### 2.2 上市櫃雙龍頭互補哨兵與雙軌原子合流 (`smartMoneyFetcher.ts`)
- **雙龍頭哨兵**：`isInstitutionalReportComplete` 升級為同時檢核上市台積電 (`2330`) 與上櫃群聯 (`8299`)、全市場總檔數門檻（$\ge 1,800$ 檔）與前 50 大活躍法人買賣超非零。
- **原子合流 (All-or-Nothing)**：在 `fetchCombinedTwseAndTpex` 中實施全有或全無原子合併，任一市場失敗一律視為未發布完畢，嚴禁殘缺寫入。
- **指數退避重試**：實作 `fetchWithRetry`（最大 3 次重試，404 即時快速失敗）。
- **歷史快取自癒洗滌 (Cache Wash)**：讀取本地歷史快取時全面套用雙哨兵檢驗，自動標記殘缺快取無效並增量重拉覆蓋。

### 2.3 美股真實 3 個月日 K 入庫與真實 20D CMF 計算 (`smartMoneyFetcher.ts` & `ChipsWorkspace.tsx`)
- 對接 Yahoo Finance 官方 Chart API 獲取真實 3 個月日 K（OHLCV）。
- 將美股日 K 持久化至 IndexedDB `ohlcvStore`。
- 徹底拔除美股持倉與市場焦點中的所有虛擬模擬代碼，全面改由真實日 K 計算真實 20D CMF 與滾動時序 flow。

### 2.4 雙市場健康指標 HUD 與一鍵全量重新同步 (`ChipsWorkspace.tsx`)
- 頂部工具列提供台股與美股獨立狀態徽章（TWSE+TPEx 總檔數、更新日期、美股真實 CMF 狀態）。
- 新增「🔄 雙市場全量重新同步」按鈕，支援使用者手動觸發強制洗滌快取與全量回補。
