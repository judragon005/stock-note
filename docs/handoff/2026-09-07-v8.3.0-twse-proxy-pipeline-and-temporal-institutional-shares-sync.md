# 2026-09-07 交接手冊：v8.3.0 證交所 TWSE 本地代理管線接入與時序影格三大法人張數動態跳動

## 1. 本次迭代成果與核心變更 (Summary)

本次迭代徹底修復並驗證了聰明錢流動視覺化（Smart Money Flow）中上市股票數據與時序播放器的兩大關鍵缺陷：
1. **上市股票（TWSE）三大法人數據為 0 之重大修復**：
   - 根因：證交所日報官方網址為 `www.twse.com.tw`，而既有 Vite proxy 僅代理了 `openapi.twse.com.tw`，導致前端瀏覽器請求 T86 日報時直接被 CORS 政策攔截。
   - 修復：在 `vite.config.ts` 增設 `/api/twse-www` 反向代理，並在 `src/engine/priceFetcher.ts` 接入 `targetUrl.startsWith('https://www.twse.com.tw')` 路由替換。上市股票 100% 透過 Vite 代理穩定取得，徹底終結上市股票外資、投信、自營商顯示為 0 的問題。
2. **三大法人張數時序影格全管線動態跳動**：
   - 根因：`trail` 節點型別缺少各日法人張數欄位，且 `SmartMoneyBubbleChart.tsx` 之 Tooltip 底部的 `formatInstitutionalDetailText` 死鎖在 `activeBubble` 根物件數值，使播放時法人張數永遠固定在最後一天。
   - 修復：
     - 在 `src/types/stock.ts` 擴充 `trail` 與 `historicalDailyFlows` 支援 `foreignNetShares`、`trustNetShares`、`dealerNetShares`、`cmf`。
     - 在 `src/components/ChipsWorkspace.tsx` 生成 5 日歷史時序時，動態注入各交易日對應的法人張數。
     - 在 `src/engine/smartMoneyEngine.ts` 升級 `getTemporalBubbleFrameData` 動態回傳影格法人張數與 CMF，並傳入當日實質淨流向金額以重新評估診斷。
     - 在 `src/components/SmartMoneyBubbleChart.tsx` 中將 `formatInstitutionalDetailText` 改為接收當前影格數據 `activeFrameData`，隨時間軸前進（T-4 ➔ T-3 ➔ T-2 ➔ T-1 ➔ T）即時跳動更新。
