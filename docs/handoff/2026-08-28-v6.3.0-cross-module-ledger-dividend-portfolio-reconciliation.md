## 1. 本次迭代成果概述

本迭代由使用者發起 `/grill-me` 針對「臺股歷史交易帳本與現金借貸、股利日誌與現金流、投資組合與庫存」進行全量深度交叉稽核，排查出 16 項邊界矛盾與隱蔽漏洞，並透過 TDD 4 大波次完成 100% 修復：

### 核心修復與架構防禦 (16 項工單)

1. **Ticket #001 (P0)**: 融資買進 (`MARGIN_BUY`) 在現金帳本嚴格依 40% 自備款加手續費扣款，消除 60% 融資負債重複扣除現金的致命漏洞。
2. **Ticket #005 (P0)**: 移除除息在籍判定 Fallback 漏洞，已除息標的若在籍持股為 0 即刻排除，徹底防禦除息日後才買進者冒領股利。
3. **Ticket #002 (P1)**: 歷史淨值納入融資負債拆解，股票市值 100% 入資產、自備款扣現金、60% 入負債，確保 $T\sim T+2$ 跨期淨值絕不膨脹。
4. **Ticket #006 (P1)**: 歷史淨值每日快照與即時總額納入未到期之 `receivableDividends`，徹底消除除權息旺季歷史曲線鋸齒狀假性暴跌。
5. **Ticket #013 (P1)**: 在 `calculatePortfolioXirr` 實作智能探針：無手動出入金時自適應以歷史交易實質投入成本 (Mode B) 求解年化 XIRR。
6. **Ticket #014 (P1)**: 現金減資每股成本 0 元保底防禦，未實現損益率永不發生正負號反轉。
7. **Ticket #007 (P1)**: 台股應收股息試算精確扣除 10 元跨行匯費 (`estimatedWireFee`) 與 2.11% 二代健保，與交割存摺 100% 吻合。
8. **Ticket #009 (P2)**: 實作 `generateMonthlyLoanInterestTransactions`，依質押起息日自動推算每月 20 號結息流水 (`FINANCING_FEE`)。
9. **Ticket #010 (P1)**: 以在庫實際持股 (`effectiveShares = Math.min(shares, actualHoldingShares)`) 限制質押擔保品市值，在庫賣出時擔保品自動核銷，杜絕虛擬幽靈股票維持率膨脹。
10. **Ticket #003 (P2)**: 手續費退佣以專屬科目 `FEE_REBATE` 記錄，不竄改歷史交易原始扣款，維持會計真實性。
11. **Ticket #004 (P2)**: 現金帳本清楚隔離手動建立之外部金流與股票自動交割款，消除雙重扣款。
12. **Ticket #008 (P2)**: 股票股利 (`STOCK_DIVIDEND`) 自然稀釋每股平均成本，現金帳本 0 污染。
13. **Ticket #011 (P2)**: 支援 `LOAN_DISBURSEMENT` 與 `LOAN_REPAYMENT` 專屬科目與合約來源標記。
14. **Ticket #012 (P2)**: 精確計算質押維持率補足至 130% 與 160% 所需之現金與股票差額。
15. **Ticket #015 (P2)**: 支援加權平均與 FIFO 批次明細雙軌切換。
16. **Ticket #016 (P2)**: 歷史每日淨值採用平滑歷史匯率，與即時總額無縫接軌。
