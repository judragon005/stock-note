## 1. 迭代背景與核心改善

使用者在實際操作頁面時提出兩大關鍵指示：
1. **Header 頂部按鈕精簡**：移除頂部的 `[ 💸 摩擦成本 ]` 與 `[ ⚙️ 券商設定 ]` 重複按鈕，統一由底下的活頁標籤進入。
2. **工作台更名為「設定」並擴充 API Key**：將第三個活頁籤更名為「⚙️ 設定」，內建券商帳戶、摩擦深度分析，並新增外部金融資料 API 金鑰管理區塊（FinMind / FMP / Alpha Vantage / 自訂 Proxy）。

---

## 2. 核心架構與交付成果

### 2.1 Header 頂部按鈕瘦身 (`src/components/Header.tsx`)
- 徹底移除頂部 Header 上的「摩擦成本」與「券商設定」按鈕與相關 props，頂部工具列回歸極簡純粹。

### 2.2 活頁標籤更名 (`src/components/WorkspaceTabs.tsx`)
- 第三個活頁標籤更名為 `⚙️ 設定`，`WorkspaceTabKey` 支援 `settings`，並平滑相容舊版 LocalStorage 儲存之 `friction`。

### 2.3 全新 ⚙️ 設定工作台 (`src/components/SettingsWorkspace.tsx`)
- **模組 A: 🏛️ 券商帳戶與費率管理**：帳戶 CRUD、折讓率（2.8折等）、最低手續費、美股模式設定、一鍵範本庫。
- **模組 B: 💸 交易摩擦成本深度分析**：4 大發光看板、佔比進度條、摩擦分佈與優化建議。
- **模組 C: 🔑 外部金融資料 API 金鑰管理**：
  - FinMind Token（台股高階即時/除權息）
  - FMP API Key（美股行情與公司行動）
  - Alpha Vantage Key（外匯大盤數據）
  - 自訂 Proxy URL
  - 支援密碼遮罩 `👁️` 與獨立 LocalStorage 隔離保存 (`STOCK_TRACKER_API_KEYS_V1`)。
