## 2. 核心變更清單 (Core Changes)

1. **傳輸層升級至原生 `fetch` 與 `AbortSignal.timeout(20000)` (`scripts/market-sync/backfill-tw-history-web.cjs` & `sync-tw-market.cjs`)**：
   - 捨棄舊有 `http.get` / `https.get` 容易導致串流掛起之實作。
   - 統一採用 Node.js 18+ 原生 `fetch` 搭配 `AbortSignal.timeout(20000)`，覆蓋連線建立、Header 與資料串流讀取階段，徹底根絕 Socket 靜默掛起問題。
2. **單日守護層熔斷看門狗 (`scripts/market-sync/backfill-tw-history-web.cjs`)**：
   - 在 `runTwDateDrivenBackfill` 主迴圈中為單日 `fetchAndIngestTwDailyData` 加上 `Promise.race` 看門狗（上限 45 秒）。
   - 單日若遇網路異常或超時，自動推入 `failedDates` 並安全推進至下一交易日，保證排程絕不死鎖。
3. **後端任務取消與狀態強制重設 API (`scripts/market-sync/backfill-full-market-history.cjs` & `vite-market-middleware.cjs`)**：
   - 實作 `cancelBackfillTask()` 與 `resetBackfillGlobalStatus()`，透過 `AbortController` 發送信號中止進行中非同步排程。
   - Vite 中介層註冊 `POST /api/market/backfill-cancel` 與 `POST /api/market/backfill-reset` 端點。
4. **前端排程中心可觀測性加固 (`src/components/MarketScheduleHubSection.tsx`)**：
   - 面板新增「停止任務」與「重設狀態鎖」按鈕，使用者無需開啟終端機即可完全自主排除異常與釋放狀態鎖。
5. **技術債歸檔與跟蹤 (`docs/debts/0052-default-fetch-json-compound-abort-signal.md`)**：
   - 登記技術債 0052，記錄未來採用 `AbortSignal.any()` 進行取消信號與超時信號雙重複合的架構演進建議。
