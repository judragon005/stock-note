# 開發交接手冊：智策精煉投資決策多維提示詞引擎與六頂思考帽工作區生成器 (v8.91.0)

## 1. 本次迭代概述
- **關聯規格**：Spec #0153 (`docs/specs/0153-smart-strategic-prompt-engine-and-workspace-generator-spec.md`) / ADR #0153 (`docs/adr/0153-smart-strategic-prompt-engine.md`)
- **關聯 Issue**：GitHub Issue [#135](https://github.com/judragon005/stock-note/issues/135) (已自動關閉)
- **合併 PR**：GitHub PR [#225](https://github.com/judragon005/stock-note/pull/225)
- **核心目標**：
  1. **個股與 ETF 雙軌特徵語意壓榨 (`strategicPromptDigest.ts`)**：
     - 個股軌道：行情量價、均線糾結度、三大法人籌碼、董監質押警戒線（>20% 自動標註風控）、月營收成長。
     - ETF 軌道：自動識別核心市值、高股息、主題型、債券型四大分類；自動提取穿透十大持股、折溢價率、內扣費用率與收益平準金政策。
  2. **六頂思考帽多維投資決策框架 (`strategicPromptEngine.ts`)**：
     - 白帽 (客觀事實)、紅帽 (市場情緒)、黑帽 (魔鬼代言/下檔風險批判)、黃帽 (樂觀成長催化劑)、綠帽 (創新戰術/對沖)、藍帽 (操盤指引總結)。
     - 支援全量 Master Prompt 與單頂思考帽專屬 Prompt 一鍵生成。
  3. **雙層嚴格 Token 預算防護守門**：
     - 單頂思考帽專屬 Prompt 控制於 700 ~ 1,000 tokens（嚴格低於 1,200 tokens 上限）。
     - 全量 Master Prompt 控制於 2,500 ~ 3,800 tokens（嚴格低於 4,500 tokens 上限）。
  4. **零信任數據海關與部位隱私脫敏**：
     - 遵循 Zero-Mock Policy，無假資料，缺失指標以 `N/A` 標註。
     - 預設脫敏個人持股金額與股數，僅保留市場事實與未實現損益狀態（`PROFIT`/`LOSS`/`BREAKEVEN`）。
  5. **工作區 UI 面板無縫整合 (`StrategicPromptPanel.tsx`)**：
     - 嵌入 [StockAnalysisWorkspace](file:///d:/APP/股票紀錄/src/components/analysis/StockAnalysisWorkspace.tsx)，具備六頂思考帽色彩膠囊、即時 Token 儀表板、部位隱私脫敏開關、一鍵複製與結構化 XML 展開預覽。

## 3. 開發注意事項與架構守門

1. **Token 預算限制**：
   - 單頂思考帽 Prompt 嚴禁 dump 全量原始歷史與長財報，必須使用 `buildSingleHatCompactFactSheet`，以維持在 1,200 tokens 內。
2. **零信任海關**：
   - 嚴禁造假數據或使用 Mock 資料，缺失指標必須保持 `undefined` 並輸出 `N/A`。
3. **隱私脫敏**：
   - 預設必須開啟 `desensitized: true`，杜絕個人財務真實部位外洩至外部大模型。
