## 1. 本次迭代核心目標與解決痛點

依據使用者在實盤截圖中回報之 5 大問題與深度要求（全面檢查個股分析各子分類、修復數值異常與未串接黑屏）：
1. **頂部導航重複**：一級選單同時出現「個股分析」與「股票健診」，重疊且未收斂。
2. **健診二級分流失效**：「四大健診總覽」與「21項量化指標」切換無差異。
3. **財報負債與每股淨值歸零**：台泥 1101 等個股因 FinMind API 科目名稱別名差異，每股淨值 (BVPS) 與負債/權益全部顯示為 0。
4. **歷年股利誤讀個人記帳**：財報之「股利政策」誤讀使用者本地個人 `trades` 記帳，而非公開市場上市公司真實歷年每股配息。
5. **總資產長條圖齊平**：缺乏動態 Baseline 浮動底線，4500 億至 6200 億之總資產柱狀圖在絕對零點下呈現等高假象。
6. **23 個二級指標未串接黑屏**：營業費用率拆解、業外佔比、ROE/ROA 走勢、河流圖、借款結構等指標未實作 JSX 分支，點選呈現黑屏空白。

## 2. 交付成果與架構落地

### 2.1 頂部一級導航收斂與相容重定向
- **[src/components/WorkspaceTabs.tsx](file:///d:/APP/股票紀錄/src/components/WorkspaceTabs.tsx)**：移除頂部 `health` 頁籤，將股票健診全面收編至個股分析工作區。
- **[src/App.tsx](file:///d:/APP/股票紀錄/src/App.tsx)**：加入相容重定向：當 `activeTab === 'health'` 自動無痛映射至 `StockAnalysisWorkspace`。

### 2.2 股票健診 21 項量化指標平鋪全覽
- **[src/components/analysis/StockAnalysisWorkspace.tsx](file:///d:/APP/股票紀錄/src/components/analysis/StockAnalysisWorkspace.tsx)**：
  - 【四大健診總覽】：維持 4 大卡片流與點擊彈窗。
  - 【21項量化指標】：全量平鋪展開 21 項量化指標檢驗表，直接展示四大維度通過率、各指標門檻、實測值、綠勾/紅叉與特許豁免（如金融股豁免存貨週轉），免開彈窗一覽無遺。

### 2.3 FinMind 真實科目對齊與會計自癒平衡
- **[src/engine/taiwanFinancialPipeline.ts](file:///d:/APP/股票紀錄/src/engine/taiwanFinancialPipeline.ts)**：
  - 補齊真實科目別名：`Liabilities`、`Equity` / `EquityAttributableToOwnersOfParent`、`ShorttermBorrowings`、`LongtermBorrowings`。
  - 導入會計恆等式自癒平衡（$Assets = Liabilities + Equity$）。
- **[src/engine/financialReportService.ts](file:///d:/APP/股票紀錄/src/engine/financialReportService.ts)**：
  - 在 `isFinancialRecordsCacheValid` 判定殘缺舊快取（有資產但權益負債歸零）失效並自動遠端重撈自癒，徹底修復台泥每股淨值為 0 的歷史問題。

### 2.4 公開市場上市公司歷年股利專屬服務
- **[src/engine/dividendService.ts](file:///d:/APP/股票紀錄/src/engine/dividendService.ts)**：
  - 獨立串接 FinMind `TaiwanStockDividend` 獲取真實歷年每股現金股利與股票股利，支援民國年容錯校準。
  - 內建 24 小時 TTL 與 `MAX_CACHE_ENTRIES = 100` 容量守衛（FIFO 淘汰），杜絕記憶體洩漏。
  - 個股分析加載時直接注入 `companyDividends`，徹底拔除讀取個人帳本 trades 之偏差。

### 2.5 圖表高度動態 Baseline 浮動底線
- **[src/components/analysis/AnalysisMetricView.tsx](file:///d:/APP/股票紀錄/src/components/analysis/AnalysisMetricView.tsx)**：
  - 長條圖導入自適應浮動底線演算法（$\text{baseMin} = \min \times 0.85$）。
  - 將 4500 億至 6200 億之總資產等數據起伏以 15%~100% 比例立體放大，使資產擴張階梯起伏清晰可辨。

### 2.6 個股分析 45 項二級指標 100% 完整視覺化
- 補齊費用率拆解、業外佔比、ROE/ROA 走勢、週轉能力、利息保障倍數、四大年增率 YoY 柱狀圖、PE/PB 河流圖通道、借款結構與重大事件日曆，徹底消滅未串接黑屏。
