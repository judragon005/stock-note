## 1. 核心變更總結 (Executive Summary)

針對使用者回饋在 QNAP NAS 部署環境中，外部金融 API 控制台測試有效金鑰出現 `Failed to fetch` 與 `403 Forbidden` 的問題，本版本完成以下關鍵修復：

1. **CSP 安全白名單對齊**：在 `index.html` 與 `src/engine/cspSecurity.ts` 補齊 `finnhub.io`、`api.stlouisfed.org`、`api.polygon.io`、`api.coingecko.com`、`data.sec.gov`，消除瀏覽器沙盒的強制連線阻斷。
2. **FMP 探針相容端點升級**：將探針測試端點遷移至新版相容的 `/stable/quote`，避開舊版 `/api/v3/profile` 端點之 403 方案權限限制。
3. **探針代理感知與 NAS 通用反向代理**：`probeApiKey` 支援 `proxyUrl` 轉發；在 NAS `prod-server.cjs` 建立通用 `/api/proxy` 反向代理（內建 SSRF 白名單防禦與自動注入 CORS 標頭），一舉解決 FRED 官方無 CORS 標頭的跨域難題。
4. **架構演進防禦**：將跨裝置金鑰同步與全端伺服器代理收錄至 Debt 0046。
