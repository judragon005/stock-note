# 2026-09-11 V8.37.0 質押借貸自訂還款日期、歷史補登動態試算與編輯付息日交付手冊

## 一、版本核心目標 (Release Goal)
本版本完整實作 **Spec #0118**（對應架構決策 **ADR #0118**），徹底解決使用者在實際金融場景中「昨日還款、今日補登」的時間軸對帳落差與利息多算痛點：

1. **還款彈窗自訂「還款扣款生效日」控制項 (`CashLedgerWorkspace.tsx`)**：
   - **痛點**：舊版還款彈窗強制綁定為系統「今日」，當使用者於昨日（9/10）在券商 APP 還款、今日（9/11）才補登時，系統自動計算 2 天利息（$448），導致利息多計 1 天（$224），侵蝕了實質沖償本金金額。
   - **解法**：新增「📅 還款扣款生效日」輸入控制項，預設今日，支援自由選取昨日或歷史任一有效日期，並具備借款起日防呆下限（`min = loan.startDate`）。
2. **響應式動態即時試算 (Reactive Preview)**：
   - 當使用者在彈窗中將還款日期切換至昨日（`2026-09-10`）時，畫面即時重新試算計息天數（1 天）、應計利息（NT$ 224）、本金沖償（NT$ 1,011,836）與預估剩餘本金（NT$ 1,000,164），所見即所得，100% 吻合券商還款扣款憑單。
3. **全域生效日精確入帳與流水對齊**：
   - 還款確認後，自動產生之 3 筆現金帳本交易分錄（`WIRE_FEE`, `FINANCING_FEE`, `LOAN_REPAYMENT`）與借貸合約付息起點 `lastInterestPaymentDate` 均嚴格記為自訂生效日（`2026-09-10`），杜絕會計日期偏移。次日（9/11）開啟卡片時精確計息 1 天（NT$ 111），應還款總金額精確為 **NT$ 1,000,275**，完全吻合券商 APP 截圖。
4. **LoanModal 支援手動維護「前次繳息基準日」(`LoanModal.tsx`)**：
   - 新增選填欄位「前次繳息/還款基準日 (`lastInterestPaymentDate`)」，提供使用者手動校正或建立歷史借貸合約付息起點之通道，並徹底修復了編輯保存時遺漏付息日屬性的缺陷。
5. **Code Review Auto-Fix 全面收斂 (PR #30)**：
   - 全額結清切換自訂日期時自動連動更新輸入金額框，並加入手動鍵盤輸入日期邊界防呆與資料結構極簡化。
