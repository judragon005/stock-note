## 1. 核心實施項目 (Key Deliverables)

### 1.1 象限顏色動態連動使用者習慣燈號 (`ColorThemeMode`)
- 解決前版寫死紅底綠底、在國際慣例（綠漲紅跌）下多空認知錯亂的痛點。
- 抽出純函數 `getQuadrantWatermarkColors(colorTheme)` 與 `getChipsQuadrantCardStyles(colorTheme)`：
  - **台灣模式 (`taiwan`, 🔴 紅漲 🟢 綠跌)**：
    - 主力抬轎區：紅色系 (`rgba(248, 113, 113, 0.55)` / `#f87171` / `rgba(239, 68, 68, 0.12)`)
    - 割韭菜警戒區：綠色系 (`rgba(52, 211, 153, 0.55)` / `#34d399` / `rgba(16, 185, 129, 0.12)`)
  - **國際模式 (`international`, 🟢 綠漲 🔴 紅跌)**：
    - 主力抬轎區：綠色系 (`rgba(52, 211, 153, 0.55)` / `#34d399` / `rgba(16, 185, 129, 0.12)`)
    - 割韭菜警戒區：紅色系 (`rgba(248, 113, 113, 0.55)` / `#f87171` / `rgba(239, 68, 68, 0.12)`)
  - 逢低撿便宜區維持金黃色，冷凍提款區維持冷灰藍色。

### 1.2 籌碼資料本地化儲存背景增量補足 (`Local Incremental Chips Hydration`)
- 實踐使用者「用時間換空間，慢慢補足」的核心訴求：
  - 首屏渲染優先使用本地 IndexedDB `settings` 表的最新快取，保證毫秒級秒開。
  - 首屏完成後，非同步低優先級背景發起 `fetchRecentTwseReports(5)`：
    - 若本地快取已包含該日上市櫃日報，直接命中不重複抓取。
    - 若未快取，發送請求抓取並非同步存入 IndexedDB。
  - 抽取純函數 `buildHoldingHistoricalFlows`：
    - 在時序回放各影格中，優先查詢該日之歷史日報。若存在真實數據，直接對齊該日真實的外資、投信、自營商買賣超張數與分數；未補齊前平滑降級為係數模擬。
  - 頂部資訊列增設狀態徽章（`⏳ 歷史補足中` / `💾 歷史籌碼 (N 天)`），使用者可即時掌握本地沉澱進度。
