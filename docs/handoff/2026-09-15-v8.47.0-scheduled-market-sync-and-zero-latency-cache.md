## 1. 本次迭代核心目標與解決痛點

1. **收盤後資料更新痛點**：
   - 過去籌碼、日 K 線與技術指標在使用者打開網頁時發送大量非同步 API 請求，標的多時耗時轉圈且易觸發數據源 HTTP 429 封鎖。
2. **純前端 SPA 沙盒邊界突破**：
   - 瀏覽器在分頁關閉狀態下無法主動喚醒或在背景執行定時任務。本次透過 Node.js 批次腳本結合 Windows 工作排程器 (Task Scheduler)，實現電腦開機時每日 16:00 (台股) 與 08:00 (美股) 自動於背景靜默更新。
3. **打開網頁毫秒級「瞬間秒讀 (Zero Latency)」**：
   - 盤後所有三大法人籌碼、收盤行情與技術指標（MA/RSI/MACD/Darvas 箱體）預先計算並持久化於本地快取庫，打開網頁時記憶體級熱載入，達成 0 網路延遲瞬間秒讀，隨後非同步沉澱至 IndexedDB。
4. **全市場標的零遺漏保證 (Zero Data Loss)**：
   - 整合休市日曆過濾機制；交易日實施實收覆蓋率比對與 Dead-Letter Queue 3 次重試，輸出 `sync_audit_report.json`。

## 2. 交付成果與架構落地

### 2.1 台股全市場批次獲取引擎 (`scripts/market-sync/sync-tw-market.cjs`)
- **第一性原理整包下載**：單次請求直接獲取 TWSE 與 TPEx 官方全市場（2,200+ 檔）三大法人籌碼 (T86) 與每日收盤行情 (MI_INDEX)，杜絕逐檔打 API 造成的 429 限制。
- **本地 CPU 增量計算指標**：於本機記憶體中追加今日收盤價並滾動計算 MA (5/10/20/60)、RSI14、MACD 與 Darvas 箱體指標，產出快取至 `public/market-cache/tw_market_summary.json`。

### 2.2 美股雙層隊列與自適應限流引擎 (`scripts/market-sync/sync-us-market.cjs`)
- **雙層優先隊列 (Tiered Queue)**：
  - Tier 1（持股、自選追蹤名單、S&P 500、NASDAQ 100 指數成份股）以受控併發（Concurrency = 3，間隔 200ms）優先秒級補齊。
  - Tier 2 搭配帶抖動的指數退避重試（Exponential Backoff with Jitter）防禦 429 限流。

### 2.3 前端零延遲快取秒讀載入器 (`src/engine/marketCacheLoader.ts`)
- 開機時透過 `loadMarketCacheSummary` 熱加載本地盤後快取總表，注入持股現價與指標；
- 隨後在閒置時調用 `syncMarketCacheToIndexedDB` 批量沉澱至 IndexedDB，保障離線可用性。

### 2.4 防漏水稽核與休市過濾模組 (`scripts/market-sync/audit-verifier.cjs`)
- 自動判斷週末與台美法定國定假日，休市日標註 `MARKET_CLOSED`；
- 比對實收 vs 預期清單，失敗標的進入 Dead-Letter Retry 重試 3 次，產出透明稽核報告 `sync_audit_report.json`。

### 2.5 Windows 工作排程一鍵安裝工具 (`scripts/market-sync/`)
- [`scripts/market-sync/setup-windows-task.bat`](file:///d:/APP/股票紀錄/scripts/market-sync/setup-windows-task.bat)：
  - 以系統管理員身分執行即可在 Windows 工作排程器中一鍵註冊每日 16:00 (台股) 與 08:00 (美股) 自動任務；
  - 支援一鍵移除、手動測試與路徑重綁定。
- [`scripts/market-sync/run-sync-silent.vbs`](file:///d:/APP/股票紀錄/scripts/market-sync/run-sync-silent.vbs)：
  - 透過 VBS 隱藏終端機視窗，實現完全無感的背景靜默運行。

### 2.6 同步狀態指示徽章 (`src/components/MarketSyncStatusBadge.tsx`)
- 整合於頂部導航控制列，即時展示今日台美股盤後同步時間與檔數；
- 點擊開啟毛玻璃彈窗查看完整審計報告與手動測試提示。
