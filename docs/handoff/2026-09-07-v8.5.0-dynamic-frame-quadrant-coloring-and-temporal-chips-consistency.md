# 2026-09-07 v8.5.0 動態影格象限色彩同步、象限邊界守門員與時序籌碼一致性交接報告

## 1. 任務概要 (Task Overview)
本版本徹底解決使用者在籌碼動態星圖中發現之「第三象限氣泡呈現黃色」之嚴重視覺與邏輯 Bug：
1. **動態影格象限色彩 100% 綁定 (`Dynamic Frame Quadrant Coloring`)**：
   - 徹底修復泡泡位移至第三象限卻仍顯示黃色吸籌光暈之痛點：`SmartMoneyBubbleChart.tsx` 中 `placedBubbles` 依當前影格坐標動態計算 `dynQuadrant`，且 `getBubbleFillColor` 與 `getBubbleStrokeColor` 支援 `overrideQuadrant` 參數傳入當日真實象限。
   - 只要標的物理坐標處於第三象限（$x < 0, y < 0$），外觀 100% 呈現冷灰藍色 (`rgba(100, 116, 139, 0.4)` / `#94a3b8`)，**絕對不出現任何黃色**。
2. **象限邊界零軸守門員 (`Strict Quadrant Boundary Guard`)**：
   - 修正 `smartMoneyEngine.ts` 象限判定漏洞：將 `x < 0 && y >= 0` 收斂為嚴格大於零 `x < 0 && y > 0`。
   - 零籌碼動作標的（$y \le 0$）嚴格歸入 `LIQUIDATION`（冷凍提款區，灰色），徹底消滅零動作被誤判為逢低吸籌黃色的病根。
3. **時序流向缺損平滑 Fallback (`Temporal Neutral Fallback`)**：
   - 修正 `ChipsWorkspace.tsx` 中 `baseFlow`：當外部籌碼資料缺損時，設為 `0` 而非 `(todaysPnLPercent)/5`，避免在無法人數據時將下跌股票偽造為大舉倒貨負向位移。
