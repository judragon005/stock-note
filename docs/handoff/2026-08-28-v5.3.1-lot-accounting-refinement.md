## 2. 核心架構與實作檔案

1. **`src/engine/lotEngine.ts`**：
   - `MOVING_AVERAGE` 導入「加權平均持有天數 (Weighted Average Holding Days)」，修正歷史賣出歸因與 $\ge 365$ 天長短期持有判定。
   - 比例分攤導入「最後一筆剩餘差額扣除法 (Residual Balance Deduction)」，徹底解決浮點數累積偏差與碎股殘存。
   - `calculateTaxComparison` 支援傳入 `currentPrices`，精準計算未實現損益與 `remainingCostBasis`。
2. **`src/types/lot.ts`**：
   - `TaxComparisonResult` 型別擴充 `remainingCostBasis`。
3. **`src/components/LotsBreakdownModal.tsx`**：
   - 導入 `useMemo` 快取 `symbolTrades`, `lotResult`, `openLots`, `disposals`, `taxComparison`，避免分頁切換時 5 次 O(n) 重複計算。
   - 支援鍵盤 `Escape` 鍵監聽與外層遮罩點擊關閉。
4. **`src/components/common/Tooltip.tsx`**：
   - 重構為純粹 Vanilla CSS 樣式，優化動畫與懸停顯示。
   - 補齊 `useId()` 動態綁定 `id` 與 `aria-describedby`，支援鍵盤焦點 `tabIndex={0}` (`onFocus`/`onBlur`)。
5. **`src/App.tsx`**：
   - 修正型別宣告，靜態引入 `AccountingMethod`。
6. **測試套件 (`src/engine/lotEngine.test.ts` & `src/engine/taxOptimizer.test.ts`)**：
   - 補齊跨多 Lot 賣出、手續費與證交稅分攤、移動平均加權天數、TaxOptimizer 節稅掃描等測試。
