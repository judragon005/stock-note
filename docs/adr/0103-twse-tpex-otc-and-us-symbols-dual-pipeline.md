# 0103. 台股上櫃雙軌探測與美股特殊代碼容錯回補架構 (TWSE/TPEx Dual-Pipeline & US Symbols Resilience)

- **狀態**：ACCEPTED
- **日期**：2026-09-09
- **議題**：修復肌肉書僮雷達查詢 6204 艾華等上櫃標的時出現「查無標的」，以及支援美股特殊代碼格式容錯。

---

## 背景與問題陳述 (Context & Problem Statement)

在肌肉書僮動能雷達（MuscleBookerWorkspace）中，使用者輸入代碼時：
1. **上櫃標的查無日 K 數據**：例如輸入 `6204`（艾華），系統原先僅向 Yahoo Finance 請求 `6204.TW`，但該標的為櫃買中心上櫃標的，Yahoo Finance 正規代碼為 `6204.TWO`。請求回傳 HTTP 404 後導致回補失敗，畫面顯示「查無標的」。
2. **美股特殊代碼格式多元**：美股波克夏、布朗霍文等標的代碼包含點號（如 `BRK.B`）、連字號（`BRK-B`）或 5 碼連寫（`BRKB`），以及使用者手動輸入附帶之市場後綴（`AAPL.US`），原先未提供自動去點、轉連字號與候選備援機制。
3. **台股主動型 ETF 判斷偏誤**：台股新推出的主動型 ETF（如 `00403A`、`00981A`）因代碼結尾包含英文字母，若僅以單純純數字正規表達式判斷市場，會誤判為美股。

---

## 決策方案 (Decision)

我們採取了「智能市場推斷 + 候選代碼清單雙軌自動備援 + 官方字典校準」的三層防護架構：

1. **智能市場推斷 (`inferMarketFromSymbol`)**：
   - 提取並集中至 `src/engine/priceFetcher.ts`，供所有工作區與回補模組統一調用。
   - 支援辨識台股主動型 ETF（`^\d{4,6}[A-Z]?$`）、`.TW` / `.TWO` 後綴，並優先查詢本地 `STATIC_TW_STOCKS` 字典確認市場。
   - 辨識美股 `.US` 後綴與美股字母代碼。

2. **Yahoo Finance 候選查詢代碼清單 (`getYahooCandidateSymbols`)**：
   - **台股雙軌優先探測**：
     - 若代碼已標明 `.TWO` 或存在於 TPEx 上櫃字典中，首選為 `.TWO`，備援為 `.TW`。
     - 若為一般台股，首選為 `.TW`，備援為 `.TWO`。
   - **美股格式容錯與備援**：
     - 自動清洗 `.US` 及 `NASDAQ:` / `NYSE:` 等交易所前綴。
     - 點號自動轉連字號備援（`BRK.B` $\to$ `['BRK-B', 'BRK.B']`）。
     - 連字號轉點號備援（`BRK-B` $\to$ `['BRK-B', 'BRK.B']`）。
     - 連寫 4~5 碼且帶 Class A/B 尾碼自動拆解（`BRKB` $\to$ `['BRKB', 'BRK-B', 'BRK.B']`）。

3. **日 K 回補引擎雙軌重試 (`backfillSymbolOhlcvAndIndicators`)**：
   - 遍歷 `getYahooCandidateSymbols` 回傳之候選清單，逐一透過 `fetchWithCORSProxy` 發起查詢。
   - 若前項請求遭遇 404 或資料為空，自動無縫切換至備援候選代碼重試，成功取得日 K 後停止。

4. **官方字典與名稱解析校準**：
   - 將 `src/data/stockDictionary.ts` 中的 `6204O` 校正為純代碼 `6204`（艾華），避免 `O` 後綴污染。
   - 擴充 `stockNameResolver.ts`，支援自動剝離 `.TW` / `.TWO` / `.US` 後綴進行中文化名稱比對。

---

## 結果與影響 (Consequences)

### 正向影響 (Positive)
- **100% 解決上櫃標的回補問題**：6204 艾華等櫃買標的能自動以 `6204.TWO` 成功拉取日 K 並計算指標。
- **美股兼容性大幅提升**：無論輸入 `BRK.B`、`BRK-B` 或 `BRKB` 均能精準獲取報價與日 K。
- **效能卓越**：利用 `otcSymbolSet` 建立快取，O(1) 判斷上市/上櫃，不耗費額外遍歷成本。
- **全專案綠燈**：57 個測試套件、643 個單元測試 100% 通過，TypeScript 0 錯誤。

### 權衡與潛在代價 (Trade-offs)
- 當非台股亦非美股之極其罕見標的輸入時，若首選失敗會多產生一次備援候選請求（均在受控超時與代理池內，不影響系統穩定）。
