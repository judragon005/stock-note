# ADR-0002: V1.1 資產樹狀圖、主題系統與費率計算架構

## 狀態 (Status)

Accepted (已核准) — 2026-08-19

## 背景與脈絡 (Context)

V1.0 完成核心記帳引擎後，V1.1 需要加入三項新能力：
1. **資產分佈視覺化**：使用者希望直觀看到各持倉市值佔比與損益狀況。
2. **漲跌色彩偏好**：台灣市場習慣「紅漲綠跌」，國際市場習慣「綠漲紅跌」，需要可切換的主題系統。
3. **智慧交易錄入**：台股手續費涉及券商折數與最低收費，需要系統協助試算，減少人為計算錯誤。

## 決策 (Decision)

### 1. Treemap：純 TypeScript + SVG，零外部圖表套件

**選擇**：自行實作 Squarified Treemap 演算法（`src/utils/treemap.ts`），以原生 SVG 渲染（`src/components/TreemapChart.tsx`）。

**理由**：
- 外部圖表套件（D3.js, ECharts）Bundle 體積龐大（> 500 kB），與 KISS 原則相悖。
- SVG viewBox 自適應確保任何螢幕尺寸下佈局正確，無需響應式 breakpoint。
- Squarified 演算法保持矩形長寬比趨近 1.0，視覺可讀性最佳。

**色彩策略**：`getNodeColor(pnlPercent)` 以 HSLa 映射，`0.35 ~ 0.90` 透明度範圍對應 `0 ~ ±40%` 損益率，色相依 ColorThemeMode 決定。

---

### 2. 色彩主題系統：CSS 變數 + data-attribute 切換

**選擇**：在 `<html>` 根元素設定 `data-color-theme="taiwan" | "international"`，`index.css` 透過 attribute selector 覆蓋 `--profit-color` / `--loss-color` CSS 變數。

**理由**：
- CSS 原生解決方案，無需 JavaScript 計算，瀏覽器自動處理 cascade。
- 新增市場主題只需增加一組 attribute selector，不需修改任何 React 元件。
- `localStorage` 持久化一行即可，開機自動恢復上次偏好。

---

### 3. 費率計算：純函式 + 完整 deps useEffect 解決 Stale Closure

**選擇**：費用試算邏輯拆分為純函式 `recalcFees(p, s, mkt, type, discount, customDisc, minFeeOn, sym)`，透過 `useEffect` 並在 deps 陣列中列出所有參數觸發，不依賴閉包捕捉狀態。

**理由**：
- React 的 ESLint `exhaustive-deps` 規則強制要求，避免 stale closure 導致 ETF（0.1%）與股票（0.3%）稅率混用的財務計算錯誤。
- 純函式設計使費率邏輯可獨立單元測試（`calculateTaiwanFee`、`calculateTaiwanTax` 各有 TDD 案例）。

## 後續影響 (Consequences)

- `TreemapChart.tsx` 與 `treemap.ts` 為零外部依賴模組，可獨立抽取複用。
- 新增市場類型（如港股）時，在 `ColorThemeMode` 加入新 variant，並在 `index.css` 新增對應 CSS 變數即可，無需修改計算邏輯。
- 費率計算函式設計為純函式，未來擴充美股 SEC 規費或其他稅種只需新增函式，不影響現有邏輯。
