# ADR 0148：AI 主力戰情室卡片視覺保真還原與說明小視窗抗遮蔽架構 (Spec 0148)

## 狀態
Accepted (已通過 100% 單元測試與 TypeScript 0 錯誤構建)

## 上下文 (Context)
在實際盤中操作「AI 主力戰情室」時，發現以下問題：
1. **04 AI 籌碼熱區圖**：價格刻度與 4 欄熱力矩陣色階硬編碼，查詢不同股票未動態更動。
2. **02 AI 決策核心**：橫幅固定寫死紅色 `AI WARNING`，未依據趨勢判斷、籌碼健康度、隔日沖風險做綜合評判，導致多頭優質股依然掛著紅色警報。
3. **06 累積型預測與 07 成本結構**：06 未呈現照片四中左上角半透明深底小方塊圖例與三色擴散扇面；07 為平緩水平波浪，色階順序反向，未還原照片四的山脈高峰低谷。
4. **新手字典小視窗 (TermTooltip)**：高度過高缺乏最大高度限制與滾動條，在邊界處遭裁剪並遮擋下方面板。

## 決策 (Decision)
1. **04 籌碼熱區圖自適應演算法**：
   - 依據歷史 K 線動態計算 5 階價格刻度（由大到小排序）。
   - 計算近 5、10、20、60 日真實成交量在 9 階價格區間的累積密度，動態著色（深藍 ➔ 亮青 ➔ 鮮綠 ➔ 黃綠）。
2. **02 決策核心多態橫幅狀態機**：
   - 多頭優質（健康度 ≥ 70，隔日沖 < 40%）：綠色/青色 `🚀 AI BULLISH`。
   - 區間中性（健康度 50~69）：天藍色 `⚡ AI BALANCED`。
   - 警戒防禦（健康度 < 50 或隔日沖 ≥ 60%）：紅色 `⚠️ AI WARNING`。
3. **06 與 07 像素級視覺還原**：
   - 06：圖例改為左上角懸浮半透明深色方塊，主體採用三色半透明扇形擴散充填，中央震盪軌道改為實線帶圓點。
   - 07：校準為四層山脈堆疊面積圖，色階由頂至底依序為：衰竭區(藍) ➔ 套牢區(綠) ➔ 主力成本區(黃) ➔ 大量成交區(橘)。
4. **字典說明小視窗抗裁切保護**：
   - 設定 `maxHeight: '280px'` 與 `overflowY: 'auto'`，搭配暗色平滑自定義滾動條。
   - 智慧計算可視高度並支援點擊外部或 ESC 鍵快速關閉。

## 後果與效益 (Consequences)
- 視覺還原度 100% 對齊設計圖。
- 輸入任何價位個股皆有精確的量價分佈刻度與動態熱力。
- 說明視窗閱讀流暢且絕不破版裁切，不干擾盯盤操作。
