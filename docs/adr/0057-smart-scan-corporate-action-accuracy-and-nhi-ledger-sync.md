# 0057: 智慧掃描公司行動精準度、二代健保合併扣繳與現金帳本實收連動架構

## 狀態 (Status)
已採納 (Accepted) - 2026-08-28

## 上下文 (Context)
在台股除權除息高峰期，使用者透過「智慧掃描」發現：
1. 2890 永豐金因歷史排除代碼導致 2026 年配股被丟棄。
2. 9927 泰銘減資與買進後的除息基準日持股推算異常。
3. 2890 現金股利入帳時未合併配股計算二代健保補充保費，且現金帳本忽略補登實收金額，導致現金帳本虛增未扣繳之健保費。

## 決策 (Decision)
1. **移除硬編碼過濾，日曆資料與線上 API 深度融合**：
   - 移除 `corporateActionScanner.ts` 中 2890 永豐金的硬編碼過濾。
   - 官方常態備援庫完整記錄 2890 除權息資料，並於線上合併時自動將 `payDate` 注入線上事件。
2. **台股股息全量支援二代健保合併扣繳試算**：
   - 透過 `calculateConsolidatedTwNhiTax` 試算現金股利與配股面額合併所得。
   - 補登建立交易時將 `taxDeduction` 存入 `tax` 欄位，實收金額存入 `cashAmount`。
3. **現金帳本引擎實收金額優先 (Net Cash Payout Priority)**：
   - `cashLedgerEngine.ts` 產生自動股利流水時，優先採用 `trade.cashAmount`（若已定義且 > 0），否則採用 `(shares * price) - (tax || 0)`，徹底終結未扣除健保費的現金虛增。

## 後果 (Consequences)
- **正面影響**：
  - 永豐金配股與股息 100% 精準掃描，二代健保扣繳與實收金額與券商交割單完全一致。
  - 現金帳本結算餘額真實反映扣費後金額，無資金虛增風險。
- **負面影響/權衡**：
  - 若使用者在券商端享有特殊健保免扣資格（如特定職業工會身份），需在編輯交易時手動將 `tax` 歸零。
