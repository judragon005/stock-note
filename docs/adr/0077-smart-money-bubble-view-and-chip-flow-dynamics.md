# ADR-0077: 籌碼與聰明錢動態觀察儀（零基礎小白友善版、量價動能四象限泡泡圖與時序播放軌跡系統）

## 狀態 (Status)
**已接受 (Accepted)** - 2026-09-07

## 背景與問題陳述 (Context & Problem Statement)
投資人在進行股票投資管理時，傳統工具存在顯著盲區：
1. 缺乏外部機構主力（外資、投信、大單）資金動態的透視能力，難以察覺持股是處於「主力吸籌推升」還是「高檔出貨接刀」階段。
2. 既有籌碼工具門檻過高，充斥冰冷專有名詞（投外本比、買賣家數差、CMF 等），零基礎新手難以在幾秒鐘內理解多空意涵。
3. 靜態數據缺乏時序維度，無法直觀看到資金是「連續流入」還是「一日誘多」。
4. 台美市場資料結構不同（台股每日公開三大法人明細，美股僅有季度 13F 與日內量價時序），缺乏跨市場標準化對齊模型。

## 決策 (Decision)

1. **零基礎小白友善之大白話四象限模型**：
   - 橫軸（X 軸）：價格漲跌幅動能 ($-100 \sim +100$)。
   - 縱軸（Y 軸）：大機構聰明錢進出強度 ($-100 \sim +100$)。
   - 四象限生活化定調：
     - **🔥 主力抬轎飆股區 (右上)**：大機構砸錢買進、股價同步強推。
     - **🛡️ 逢低撿便宜區 (左上)**：股價震盪回檔但大機構逆勢悄悄大買吃貨。
     - **⚠️ 割韭菜警戒區 (右下)**：股價看似在漲但大機構趁高倒貨出逃。
     - **❄️ 冷凍提款區 (左下)**：股價大跌且大機構也在大賣逃跑。
2. **跨市場一手官方資料管線**：
   - **台股 (TW)**：直連台灣證券交易所 (TWSE) 官方開放日報 `fund/T86`，單次拉取全市場三大法人進出，並配合 IndexedDB 快取。
   - **美股 (US)**：採用 Chaikin Money Flow (CMF 佳慶資金流向 20 日指標)，利用官方轉發的日 K 線高低收與成交量計算資金吸籌與派發強度。
   - **標準化歸一**：雙市場統一換算至 $[-1.0, +1.0]$ 之 `flowScore`。
3. **輕量原生 SVG 渲染與時序播放器 (Timeline Motion Player)**：
   - 0 額外龐大圖表庫依賴，純 React + SVG 渲染四象限、自適應半徑泡泡與半透明彗星尾巴 (Motion Trails)。
   - 底部提供播放/暫停/重播/速度切換與日期滑桿，流暢回放過去 5~20 天歷史軌跡。
4. **人類大白話結論先行懸浮 Tooltip**：
   - 滑鼠懸浮泡泡時，第一眼呈現親切診斷結論（如「🟢 主力強烈做多中！」），隨後展示生活化詳細解說與具體張數數據。
5. **獨立工作台分頁 (`chips`)**：
   - 於 `WorkspaceTabs` 新增「籌碼與動態星圖」分頁，支援【我的在庫持倉】與【全市場法人焦點 Top 30】雙模式切換。

## 後果 (Consequences)

### 正面影響 (Positive Impact)
- 零基礎初學者無須具備籌碼基礎，花 3 秒即可看懂持股當前主力動向。
- 0 付費 API 依賴、0 外部龐大圖表庫，維持極速載入與 IndexedDB 離線秒開。
- 徹底消除台美股跨市場籌碼視覺化割裂。

### 限制與權衡 (Trade-offs & Mitigations)
- 美股 CMF 為量價演算法代理指標，與台股直接公布之三大法人名冊在微觀顆粒度上存在統計性質差異，介面中已提供貼心白話提示說明兩者成因。
