# ADR-0080: 二維空間正交排斥散度、時序影格圖卡即時同步與機構共振決策系統

## 狀態 (Status)
**已接受 (Accepted)** - 2026-09-07

## 背景與問題陳述 (Context & Problem Statement)
1. **照片 1 烤肉串痛點（水平一字排開與大球吞小球）**：
   - 歷史軌跡與流向分數被夾止在 ±75，導致大量個股的 Y 坐標完全相同 (Δy ≈ 0)。排斥演算法僅在 X 軸互相推擠，無法垂直錯開，全部泡泡串成一條水平線。
   - 大半徑泡泡覆蓋小半徑泡泡，滑鼠移至交疊區時微小標的完全無法被拾取或 Hover，造成嚴重資訊遺漏。
2. **照片 2 圖卡數值鎖死**：
   - Tooltip 浮窗數值寫死讀取最終最新一天的靜態數據，當時間軸由第 0 天播至第 4 天時，圖卡上的漲跌幅與法人數據完全不跳動，使用者無法理解當日動態判定原因。
3. **專業券商與經理人機構共振模型缺漏**：
   - 當外資賣 5,000 張、投信買 5,000 張時，代數相加為 0，原邏輯誤判為「三大法人進出平衡 (0 張)」，忽視了盤面「土洋對作 ⚡」的激烈籌碼換手對決。

## 決策 (Decision)

1. **2D 正交空間排斥微擾動與半徑收斂 (2D Orthogonal Dispersion & Radius Convergence)**：
   - 在 resolveBubbleCollisions 放鬆迭代中，當兩球重疊且垂直距離極小 (|Δy| < 6) 時，主動注入正交垂直分量 dy = orthoSign * max(6, minDist * 0.45)，使原本水平重疊的泡泡產生垂直分向力，展開為二維錯落蜂巢狀。
   - 泡泡半徑由原本的 14px ~ 46px 收斂至 16px ~ 36px，降低極端視覺落差。
2. **DOM 頂層繪製小球優先排序 (Small-Bubble Top-Layer Ordering)**：
   - 渲染順序按半徑由大到小降序排列（大球先畫於底層，小球後畫於頂層），確保小球永遠位於頂部，滑鼠事件優先拾取小球，徹底杜絕小球被覆蓋吞噬。
   - 被 Hover 或選中的泡泡排在絕對最末尾，以聚光燈脈衝光暈置頂。
3. **圖卡影格即時同步與生活化診斷重算 (Temporal Frame Data Extractor)**：
   - 實作純函數 getTemporalBubbleFrameData(bubble, dateIndex, dateStr)，依據時間軸當前播放影格動態抽取當日日期、漲跌幅、流向評分，即時重算四象限與生活化診斷結論。
   - Tooltip 頂部新增播放日標籤（如 📅 2026-09-03）與當日表現，數據隨播放進度實時跳動。
4. **專業機構共振態識別模型 (Institutional Synergy Detector)**：
   - 實作 detectInstitutionalSynergy(foreignNet, trustNet)，識別：
     - DUAL_BUY (🚀 土洋合買抬轎)：內外資多頭強烈共振。
     - TUG_OF_WAR (⚡ 土洋對作激戰)：外資買投信賣（或外資賣投信買），盤面激烈換手，杜絕被代數加總抹平。
     - DUAL_SELL (💣 土洋同步調節)：雙向大舉提款。
   - 在 Tooltip 浮窗中醒目展示機構共振態徽章，診斷文字詳細說明換手對決格局。

## 後果 (Consequences)

### 正面影響 (Positive Impact)
- 徹底消滅水平烤肉串現象，泡泡於四象限自然蜂巢狀錯落分佈。
- 小球 100% 可被滑鼠精準拾取，零遮蔽、零吞噬。
- 播放時序時圖卡數值隨進度動態跳動，讓投資人清晰理解主力歷史推演。
- 杜絕土洋對作被誤判為平衡，精準提示法人激烈換手風險。
