# ADR 0181: 智策提示詞外聯職責遷移至主力戰情室與防幻覺定錨架構

## 狀態 (Status)

`ACCEPTED` (2026-10-15)

## 背景 (Context)

原本「智策多維提示詞引擎 (`StrategicPromptPanel`)」置於「個股深度分析 (`StockAnalysisWorkspace.tsx`)」的頂部。這導致兩個架構矛盾：
1. **職責搶佔 (Responsibility Usurpation)**：個股深度分析的核心定位是深度財報三表、杜邦分析與估值模型。頂部巨大的提示詞面板產生反客為主的視覺雜訊。
2. **決策動線斷裂 (Workflow Fragmentation)**：使用者複製 AI 戰情提示詞貼至外部線上 LLM（如 ChatGPT、Claude）的高頻時機，是看完「主力戰情室」的即時量價、籌碼與訊號之後。
3. **外部 AI 幻覺威脅**：外部 LLM 缺乏時態概念（將昨日結算誤當盤中現況）、算術脆弱、且具備迎合使用者的討好偏見 (Sycophancy)。

## 決策 (Decision)

1. **職責分離 (SoC)**：
   - 從 `StockAnalysisWorkspace.tsx` 徹底移除 `StrategicPromptPanel`，讓個股分析純粹化。
   - 將提示詞外聯職責遷移至 `AiForceDashboardView.tsx`（主力戰情室）最底層，作為全域決策的終局輸出。
2. **KISS 原則與防過度工程化**：
   - 拒絕多模型方言切換器、龐大歷史快照 DB、多層巢狀時間尺度切換器。
   - 採用單一精煉的高濃度 Markdown + XML 語意結構。
3. **字串級防護三護欄**：
   - **時態分割宣告**：明確宣告盤中即時 vs 昨日結算 vs 週末集保時態。
   - **前端精確算術代勞**：所有停損價、風報比由前端算好填入，嚴禁 AI 算術。
   - **客觀反討好紅隊指令**：強制揭露下檔暴雷風險，打破 AI 迎合偏見。
4. **台美雙軌自動隔離**：
   - 美股標的自動剔除台股特有之三大法人與資券欄位。
5. **佈局避讓**：
   - 放置於底部吸附式 `TaskViewsSwitcher` 上方，預留 `marginBottom: 16px`，全任務視圖通用。

## 後果 (Consequences)

### 正面效益 (Positive)
* 個股深度分析介面專注度顯著提升，完全回歸法務與財報本質。
* 主力戰情室形成完整的「數據觀測 ➔ 指標解讀 ➔ 外部 AI 深度推演」閉環。
* 外部 AI 不再產生算術與時態錯亂幻覺。
* 代碼量少、侵入性極低，維護成本微乎其微。

### 潛在限制 (Negative / Trade-offs)
* 戰情室底部長度輕微增加（透過緊湊卡片與可折疊抽屜設計予以緩解）。
