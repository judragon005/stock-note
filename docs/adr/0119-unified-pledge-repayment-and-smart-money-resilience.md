# ADR 0119: 質押借貸還款繳息按鈕整併、籌碼日報多維哨兵優雅降級與聰明錢動能雷達優化

## 狀態
已通過 (Accepted) - 2026-09-11

## 上下文 (Context)
在 V8.36.0 (法定沖償順序) 與 V8.37.0 (自訂還款日期與歷史補登) 合併後，使用者回報了兩大關鍵操作與視覺痛點：
1. **質押借貸操作分散**：卡片底部的「💰 繳息」與「💳 還本」二元分立按鈕，在實務上造成使用者認知障礙。底層早已實作《民法》第 323 條法定沖償順序（規費 ➔ 利息 ➔ 本金），操作入口應予單一化。
2. **籌碼日報假同步 Bug**：15:30 證交所 API 資料未齊全（全市場僅 894 檔或三大法人全為 0 張）時，舊哨兵因僅檢查台積電 (2330) 是否存在而誤判為「今日已同步完成」，導致強茂 (2481) 等大量個股氣泡在 0 軸平躺，誤導使用者。
3. **歷史籌碼膠囊認知混淆**：頂部 `💾 歷史籌碼 (5)` 為無操作反饋的靜態技術徽章，未能提供使用者所需的「中短期資金動能視角（哪幾檔可以買、哪幾檔要閃）」。

## 決策 (Decision)
1. **質押借貸入口整併**：
   - 將卡片底部「💰 繳息」與「💳 還本」合併為單一主要按鈕 `[💳 還款 / 繳息]`（保留 `[⚡ 一鍵結清]`）。
   - 還款彈窗頂部提供快捷鍵 `[帶入本期利息]` 與 `[帶入本息總額]`，統一走 `applyDebtRepayment` 依民法順序沖償。
2. **多維完整性哨兵與優雅降級**：
   - 實作 `isInstitutionalReportComplete`：要求全市場檔數門檻（正常 1800+ 檔，若 $< 1200$ 檔判定為未發布完畢）與前 50 大活躍法人買賣超非零驗證。
   - 當日日報不合格時，不污染快取，自動優雅回退 T-1 完整日報，狀態列以黃燈誠實提示 `🟡 盤後結算中：暫呈 T-1 完整日報`。
3. **動能時間窗與決策看板**：
   - 移除頂部靜態膠囊，升級為 `[1日 (當日)]` / `[3日 (短波段)]` / `[5日 (週籌碼)]` 膠囊切換鈕。
   - 實作 `chipsAggregator.ts` 加總歷史日報，星圖 Y 軸自動對齊多日累計買賣超，過濾隔日沖噪音。
   - 新增【🧭 聰明錢動態決策快報】折疊看板，輸出「🟢 法人聯手搶買榜 (可以買)」與「🔴 主力大舉提款榜 (一定要閃)」。

## 後果與效益 (Consequences)
- **正面效益**：
  - 借貸還款心智模型極簡化，操作入口統一，消除技術債與重複邏輯。
  - 徹底杜絕盤後殘缺日報導致的假同步與全 0 張平躺氣泡。
  - 散戶使用者進站 3 秒內即可獲取法人波段認養與主力出逃避險信號。
- **維護約束**：
  - 新增日報資料源時必須持續相容 `isInstitutionalReportComplete` 多維哨兵規範。
