# ADR 0122: 全能技術指標大腦升級、市場狀態機與三層實戰階梯矩陣架構

## 狀態 (Status)
已接受 (Accepted)

## 脈絡 (Context)
在 Spec 0121 引入了 15 大全技術指標矩陣與多空共振評分儀後，實戰檢驗中暴露出致命盲點：
1. 在窄幅無趨勢橫盤市場中，均線可能因微幅波動暫時排列為多頭，但 ADX 趨勢強度極低（例如 ADX = 5.94 < 20）且 -DI 大於 +DI（空方動能實際上大於多方）。系統因缺乏市場狀態機與矛盾懲罰，依舊評出 95 分「強烈看多」，誤導交易者追高被套。
2. 缺乏布林極致壓縮（Bandwidth < 8%）的變盤預警，錯失波動率爆發前的先驗佈局。
3. 關鍵阻力（Pivot R1、Darvas 箱頂、布林上軌、Fibonacci）分散呈現，缺乏相近價位（< 1.5%）的「阻力共振聚集帶 (Resistance Cluster)」演算法。
4. 交易者面臨海量指標容易認知過載，亟需「0秒定性 ➔ 3秒作戰 ➔ 深度佐證」的三層漸進式架構。

## 決策 (Decision)
1. **引入市場狀態機 (Market Regime State Machine)**：
   - 純函式 `evaluateMarketRegime`，定義 `VOLATILITY_SQUEEZE`、`CHOPPY_RANGE`、`TRENDING_BULL`、`TRENDING_BEAR` 四大狀態。
2. **無趨勢鈍化與多空矛盾懲罰 (Contradiction Penalty)**：
   - 當 `ADX < 20` 時，趨勢維度得分乘上 0.4 折扣。
   - 當均線多排但 `-DI > +DI` 時，扣除 20 分矛盾分數，且總分**強制封頂於 58 分 (NEUTRAL)**，徹底阻斷無趨勢橫盤的高分幻覺。
3. **關鍵價位密集聚集演算法 (Key Level Proximity Clustering)**：
   - 收集 Pivot、Fibonacci、布林軌道、Darvas 箱頂/箱底價位，將相距 ≤ 1.5% 的價位聚合成第一/次級壓力帶與防守帶。
4. **真實波幅 ATR(14) 吊燈動態移動防守 (Chandelier Exit)**：
   - 計算 Wilder ATR(14)，動態吊燈防守點 = 22日最高價 - 2.5 × ATR(14)。
5. **背離偵測與價格行為假突破誘多偵測 (Divergence & Bull Trap)**：
   - 搜尋近 20 根 K 線波峰波谷，偵測價格創新高但 RSI/MACD 走低的頂背離；在壓力帶偵測長上影線墓碑倒錘線之假突破 (Bull Trap)。
6. **三層漸進式決策 UI (Progressive Disclosure)**：
   - 第 1 層 (0秒決策)：頂部 Hero 卡片（校正後評分、市場狀態徽章、操盤大白話一句話）。
   - 第 2 層 (3秒作戰地圖)：4-Box 實戰交易階梯矩陣（第一減碼區、續強加碼位、短線動態防守線、結構底線）。
   - 第 3 層 (深度佐證區)：三大 Tab（風險雷達與形態、15大指標全景、Markdown 研報）。

## 後果 (Consequences)
- **正面效益**：
  - 徹底根除無趨勢盤整時誤判給出 95 分的高危盲點，大幅提升量化系統的可信度。
  - 將零散的點位自動聚合成具備操作性的第一壓力帶，輔以 ATR 動態防守線，提供具體清晰的點位階梯。
  - 三層漸進式介面極大幅度降低認知負擔，兼顧極簡易讀與專業深度。
- **維護代價**：
  - 指標運算量略有增加，但皆為不可變純數學函式，單次計算耗時小於 2ms，效能無虞。
