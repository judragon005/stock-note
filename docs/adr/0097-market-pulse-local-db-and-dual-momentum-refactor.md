# ADR 0097: 市場四柱在地持久化、雙動能百分比與採樣修復、肌肉書僮市場連動

- **狀態**：Accepted
- **日期**：2026-09-08
- **決策者**：Antigravity Agent & User

## 背景與問題 (Context)
1. 肌肉書僮動能雷達未與全域市場狀態 `currentMarket` 連動，美股模式下混雜台股資料。
2. 雙重動能排行榜在 UI 渲染時發生百分比雙重乘算（`* 100`），且採樣步長在少量日期點下退化，導致所有週期數據全數相同。
3. 雙重動能資產池僅包含指數型 ETF，缺乏投資人實戰所需的權值個股龍頭池，且缺乏調倉週期防躁動指引。
4. 宏觀戰情室的「市場四柱即時脈搏」目前全數為靜態 Mock 快照，使用者需要能在地化持久保存與導出分析之架構。

## 決策內容 (Decisions)
1. **肌肉書僮工作區市場聯動**：
   - 透過 Props 傳遞 `currentMarket`，對齊在倉持股篩選。
   - 動態派發標的清單：台股模式下提供台股焦點與台股權值 Top 50；美股模式下提供美股焦點與美股巨頭 Top 50。
2. **雙動能數學與渲染修復**：
   - 移除 UI 渲染的二次 `* 100`，格式化保持 1 位小數並帶百分比。
   - 優化取樣算法：當歷史資料天數小於標準週期（63/126/252 日）時，採用比例插值取樣，精準反映 3M/6M/12M 漲跌幅差異。
3. **擴增個股龍頭動能池與月結調倉窗口**：
   - 保留經典 ETF 資產池，追加「台股權值巨頭輪動池」與「美股巨頭科技輪動池」。
   - UI 增設每月調倉日倒數與在倉持股核對建議。
4. **市場四柱在地持有化資料庫 (Local Persistence DB)**：
   - 打造 `macroPulseStorage` 模組，優先使用本地快取/儲存。
   - 支援離線直接讀取過往歷史脈搏紀錄，支援 CSV 導出供深度量化回測。

## 影響評估 (Consequences)
- **正面效益**：
  - 修正所有顯示與採樣錯誤，數學計算回歸 100% 準確。
  - 使用者體驗高度一致，台美股完全切分。
  - 宏觀數據沉澱於本地，具備長期分析價值與離線可用性。
- **邊界防護**：
  - 本地儲存具備結構升級防護與降級保護（Graceful fallback），杜絕舊資料格式衝突。
