# ADR 0068: 持股技術指標警示膠囊 Tooltip 結構化卡片、乖離率 (Bias %) 與多週期共振架構

## 狀態
`ACCEPTED` (已實作並通過全量 TDD 驗證)

## 決策背景 (Context)
在持股清單技術指標膠囊上線後，使用者反饋 Tooltip 懸浮提示在表格左緣出現截斷問題，且希望以專業券商與基金經理人視角增加「均線乖離率 (Bias %)」與「多週期長短共振結構」的深度評估能力。

## 決策內容 (Decisions)
1. **Tooltip 靠左對齊防溢出 (`align="left"`)**：
   - 將 Tooltip 錨點固定於目標膠囊左側，內容向右展開，徹底消除表格左側被視窗或外層容器裁剪的痛點。
2. **結構化資訊卡片 (Structured Information Card)**：
   - 頂部包含四字定調高亮標籤與量化得分進度徽章。
   - 中部展示客觀紀律操作指引。
   - 底部標示量化規則來源與風控紀律備註。
3. **均線乖離率與多週期共振 (Bias% & Confluence Engine)**：
   - 純前端即時計算 20MA 與 60MA 乖離率，標記短線過熱或超跌反彈。
   - 辨識「長空短多 (反彈減碼)」與「長多短空 (拉回止跌)」，輔助經理人進行部位控管。

## 影響評估 (Consequences)
- **正面效益**：
  - 徹底解決 UI 截斷問題，提升閱讀體驗。
  - 增加量化交易員必備之乖離率與多週期共振指標，操作依據更全面。
  - 100% 保持純前端離線計算，零額外 API 與效能負擔。
- **維護注意事項**：
  - 未來新增技術指標時，應於 `technicalIndicatorEngine.ts` 統一定義並擴充對應單元測試。
