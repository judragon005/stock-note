# ADR-0018: 歷史帳本稅費智慧拆分修復與雙幣別摩擦計算架構

- **狀態**：ACCEPTED
- **日期**：2026-08-24
- **負責人**：Antigravity Agent
- **關聯 PRD**：[SPEC-0018: 歷史帳本稅費智慧拆分修復、雙幣別換算與除權息摩擦成本引擎](../specs/0018-tax-fee-auto-repair-and-currency-engine.md)

---

## 背景與問題 (Context)

從用戶 587 筆真實交易與看板發現四項摩擦數據異常：
1. 外部 Ghostfolio/CSV 匯入時因缺少 tax 欄位，將賣出 0.3% 證交稅併入 fee，導致累計證交稅為 0、賣出手續費暴增至 15.9 萬，且折讓判斷全數失效。
2. 美股手續費 USD 直接當 TWD 加總，未乘上即時匯率。
3. 除權息二代健保 (2.11%) 與美股 30% 股息預扣稅未納入摩擦體系。

---

## 決策 (Decision)

1. **實作無損稅費拆分純函式**：依成交額推導真實證交稅並自 fee 扣減，交割淨額與損益 100% 不變。
2. **多幣別匯率整合**：`calculateFrictionCostSummary` 引入 `usdRate` 參數，美股所有費用與稅額統一換算為 TWD 折算。
3. **除權息摩擦引擎**：納入台股單筆 $\ge 2$ 萬 2.11% 二代健保與美股 30% 股息預扣稅。
4. **帳本 UI 智慧修復橫幅**：自動識別異常並提供一鍵安全修復按鈕。

---

## 影響與後續 (Consequences)

- 587 筆歷史帳本將恢復真實的「已繳證交稅」與真實「已省下券商折讓」（預計從 NT$ 5,361 大幅上升至數萬甚至十幾萬元）。
- 雙幣別與除權息摩擦衝擊度達到 100% 財務真實度。
