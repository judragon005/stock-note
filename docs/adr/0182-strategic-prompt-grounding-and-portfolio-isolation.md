# ADR 0182: 戰情室 Prompt 標的時態隔離、庫存自動錨定與時態籌碼細化 (Grounding, Stale State & Portfolio Isolation)

## 狀態 (Status)
**ACCEPTED (已通過並實裝)**

## 背景與問題陳述 (Context & Problem Statement)
使用者在 AI 主力戰情室針對個股（如華邦電 2344）執行「一鍵複製戰情 Prompt」貼入外部大語言模型（如 ChatGPT / Claude）進行外聯對策分析時，發現多項關鍵異常：
1. **標的切換價格幽靈殘留 (Stale State Ghosting)**：切換標的時，因狀態合併模式使得 0050 的預設價格（如 165 元）被誤拷貝到新標的上，導致大模型強烈質疑資料真實性。
2. **持股成本硬編碼現價**：原架構在未傳入成本時預設現價為買入成本，使大模型誤以為剛買進而頻繁發出「剛進場應立即停損砍倉」等不合理指令。
3. **單日誤標 20 日籌碼**：三大法人日買賣超被填入 20 日累計欄位，遭到大模型識破並扣分。
4. **均線寫死與週期股失焦**：MA20/MA60 未從真實日 K 計算；記憶體等景氣循環股未提供週期高峰警示，缺乏紅隊質詢深度。

## 決策 (Decision)
1. **標的切換狀態原子重置**：
   - 在 `AiForceDashboardView.tsx` 中，切換標的時嚴格使用 `createDefaultAiForceReport(targetSymbol, ...)` 重新初始化，杜絕舊標的價格污染。
2. **方案 1：全自動庫存比對與雙態分流架構**：
   - 跨所有交易帳戶精準計算目標標的之加權平均成本 (`avgCost`) 與保本價 (`breakevenPrice`)。
   - **庫存持有 (`IN_POSITION`)**：輸出真實成本與保本價（脫敏模式下隱匿金額，輸出未實現報酬率 `%` 與部位佔比 `%`），`<pre_calculated_pivots mode="HOLDING_DEFENSE">` 指示持倉防禦。
   - **空手觀望 (`ZERO_POSITION`)**：明確輸出 `0%` 部位佔比，`<pre_calculated_pivots mode="HYPOTHETICAL_ENTRY">` 強制禁止發布任何割肉停損指令，僅評估潛在風報比與買點。
3. **時態籌碼與數據物理細化**：
   - 拆分 `totalNetShares1D` 與基於歷史法人資料真實驗算的 `totalNetShares20D`。
   - 明確標記籌碼與成交量單位（台股：張，美股：股）。
4. **景氣循環股與 ETF 動態感知**：
   - 識別記憶體、晶圓代工、航運等週期股標籤，在 Prompt 中強制黑帽針對「循環高峰殺估值陷阱」進行紅隊質詢。

## 後果 (Consequences)
- **正面效益**：
  - 外聯大模型不再質疑價格與時態矛盾，回答精準度大幅躍升。
  - 空手與持倉情境涇渭分明，徹底杜絕未持股卻被建議停損的荒謬邏輯。
  - 隱私脫敏守則 100% 遵守，絕不外洩用戶帳戶總資產與具體金額。
- **技術保障**：
  - 專案全量測試 218 檔案、1,614 測試通過率 100%。
  - TypeScript 生產包編譯 0 錯誤。
