# ADR #0051: 跨模組歷史帳本、現金借貸、股利日誌與投資組合全域一致性勾稽架構

## 狀態 (Status)
已採納 (Accepted)

## 上下文 (Context)
在進行四大模組（交易帳本、現金借貸、股利日誌、庫存/XIRR/NAV）交叉驗證時，發現了 16 項邊界矛盾與跨期計算斷層。最嚴重的問題包括：
1. 融資買進 (`MARGIN_BUY`) 被自動連動扣除 100% 總價款而非 40% 自備款，導致現金嚴重超額扣款。
2. 除息日在籍股數計算在無持有紀錄時誤 fallback 取當前庫存，導致除息後買進者被誤判享有該次股利。
3. 歷史淨值 (NAV) 在交易交割 $T\sim T+2$ 期間與除息 $Ex\sim Pay$ 期間缺乏在途款與應收股利對齊，導致淨值曲線產生跳空斷層。
4. 全組合 XIRR 在未手動記錄 `DEPOSIT` 的情境下，外部金流為空導致求解失效。

## 決策 (Decisions)
1. **融資買進資金拆解 (Margin Buy Accounting)**：
   - 交易紀錄標記為 `MARGIN_BUY` 時，現金帳本扣除金額為：$-(\text{Shares} \times \text{Price} \times 0.4 + \text{Fee})$。
   - 券商融資 60% 作為借貸負債納入整體槓桿與利息模型。
2. **除息在籍嚴格判定 (Strict Holding on Ex-Date)**：
   - 移除 `sharesHeld <= 0` 時的當前庫存 fallback，若除息日前一日持股為 0，則排除該次除息。
3. **全週期連續總淨值 (Continuous NAV)**：
   - 公式定義：$$\text{NAV} = \text{在席股票市值} + \text{已交割現金} + \text{在途應收} + \text{待入帳應收股利} - \text{在途應付} - \text{借貸質押負債}$$
4. **XIRR 自適應雙模式探針 (Adaptive XIRR Solver)**：
   - 若存在顯式 `DEPOSIT`/`WITHDRAWAL`，採用 Mode A 銀行加權模型；
   - 若僅有股票交易紀錄，自動切換為 Mode B 歷史實質投入成本模型。
5. **10 元匯費與減資成本 0 元保底**：
   - 臺股現金股息納入可選 10 元跨行匯費；
   - 現金減資每股成本設定最低 0 元保底防禦。

## 後果與效益 (Consequences)
- **正面效益**：四大模組數據 100% 守恆，消除淨值鋸齒狀懸崖與 XIRR 失效，融資與除權息計算完全對齊券商與法規真實口徑。
- **維護性**：以統一數學公式貫穿各引擎，降低未來新增功能時產生非預期副作用的風險。
