# ADR 0121: 全市場個股全技術指標透視分析與多空共振量化評估架構

## 狀態
已通過 (Accepted) - 2026-09-12

## 上下文 (Context)
在個人股票交易實務中，使用者提出全面提升技術分析深度的核心需求：
1. **指標碎片化與覆蓋斷層**：既有系統雖具備移動平均線、KD、MACD 與肌肉書僮箱子戰術，但缺少成熟交易體系必備之 Wilder RSI、DMI/ADX (趨勢強度)、CCI (順勢指標)、Williams %R (威廉指標)、OBV (能量潮累積)、以及 Fibonacci 黃金分割位與 Pivot 樞紐點。
2. **多指標矛盾與「分析癱瘓」**：當各維度指標多空方向不一時，投資人容易陷入猶豫不知所措，缺乏客觀量化的多空共振綜合計分機制。
3. **缺乏全市場隨選透視面板**：無法對任意自選代碼（台股/美股）進行一站式的即時全景技術體檢與研報輸出。

## 決策 (Decision)

1. **五大維度全技術指標純函式核心 (`src/engine/omniIndicatorEngine.ts`)**：
   - 實作 100% 純輸入輸出、無副作用之量化運算函式：
     - **趨勢矩陣**：MA (5/20/60/120/240)、多頭/空頭/糾結排列、MACD (12, 26, 9) 柱狀體與交叉、DMI / ADX (14)。
     - **動能矩陣**：Wilder 平滑法 RSI (6, 14, 24)、KD (9, 3, 3)、CCI (20)、Williams %R (14)。
     - **波動矩陣**：布林通道 (20, 2)、帶寬壓縮 Squeeze 警示 (帶寬 $\le 8\%$)、ATR (14) 移動防守價、MA20/60 乖離率。
     - **量能矩陣**：5日/20日均量比、爆量攻擊/量縮窒息判定、OBV 能量潮累積與趨勢斜率。
     - **關鍵位階**：Darvas Box (三日法則箱頂/箱底)、Fibonacci 黃金分割位 (0.236/0.382/0.5/0.618/0.786)、樞紐點 Pivot Points (P, R1, R2, S1, S2)。
   - 各演算法皆具備嚴密的除零邊界防禦與極端平盤數據防呆。

2. **多空共振量化評分儀 (`calculateTechnicalConfluence`)**：
   - 將 15 種指標依照趨勢 (35%)、動能 (25%)、型態 (20%)、量能 (20%) 進行權重試算，收斂為 0~100 分之單一評分。
   - 劃分五階多空位階：`STRONG_BULL` ($\ge 80$), `MODERATE_BULL` ($60 \sim 79$), `NEUTRAL` ($41 \sim 59$), `MODERATE_BEAR` ($21 \sim 40$), `STRONG_BEAR` ($\le 20$)。
   - 動態輸出核心共振特徵、明確操作紀律導引與風險警示標籤。

3. **隨選日 K 線回補與研報管線 (`src/engine/omniReportPipeline.ts`)**：
   - 串接 IndexedDB `historicalOhlcv` 快取與 Yahoo Finance 回補調度器，支援全市場任意代碼（台股/美股）隨選取得日 K 線並組裝報告。
   - 具備 6 小時新鮮度快取，未滿時零外部網路請求；實作 `generateOmniReportMarkdown` 產出排版嚴謹的 Markdown 研報，供外部大模型提示詞消費。

4. **個股全景透視面板 UI (`src/components/OmniTechnicalInspectorModal.tsx`)**：
   - 毛玻璃風格彈窗，支援代碼搜尋、台美股切換、在庫持股快速選取。
   - 頂部呈現多空共振計分儀與操作建議，核心區以 5 大卡片展示指標細節，完全同步全域漲跌顏色主題。
   - 支援「📋 一鍵複製 Markdown 研報」功能。

5. **在庫持倉與動能雷達無縫串接**：
   - 在 `HoldingsTable.tsx` 持倉展開按鈕列整合「📊 全指標透視」。
   - 在 `MuscleBookerWorkspace.tsx` 動能雷達卡片中整合「📊 全指標透視」，達成一鍵直達。

## 後果與效益 (Consequences)
- **正面效益**：
  - 補齊了系統在傳統技術分析與動能擺盪指標上的所有缺口，達成全市場、全指標覆蓋。
  - 多空共振評分儀成功化解多指標矛盾痛點，提供清晰的交易紀律導引。
  - 單元測試覆蓋率 100%（新增 19 個測試，全專案 73 個測試套件、786 個測試全數綠燈）。
- **維護約束**：
  - 所有的指標計算函式必須保持為純函式，嚴禁引入非同步或可變狀態。
