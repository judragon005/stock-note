# ADR-0014: 活頁本工作台架構與券商手續費整併收斂

- **狀態**：ACCEPTED
- **日期**：2026-08-24
- **關聯 PRD**：[SPEC-0014: 活頁本工作台 (Tabbed Workspace) 與券商手續費整併規格書](../specs/0014-tabbed-workspace-and-broker-fee-consolidation.md)

---

## 1. 背景與脈絡 (Context)

在 V3.0 多券商帳戶與摩擦成本分析儀上線後，使用者在實際操作中發現介面長度過長、彈窗操作割裂，且 Header 上的全域賣出手續費折讓選單與新版「券商帳戶體系」功能重複。

---

## 2. 決策考量與方案對比 (Decision Drivers & Alternatives)

### 方案 A：維持單一垂直長頁面 + 彈窗，僅移除 Header 手續費選單
- **優點**：改動最小。
- **缺點**：頁面極度冗長，使用者在查看持倉、檢查歷史帳本、管理券商與分析摩擦成本時需不斷上下滾動或頻繁開關彈窗，體驗割裂。

### 方案 B (採用)：活頁本工作台 (Tabbed Workspace) + 賣出手續費徹底整併入券商帳戶
- **優點**：
  1. **職責單一 (SSOT)**：徹底廢棄全域賣出手續費折讓選單，所有折讓率、低消由所屬券商帳戶統籌管理。
  2. **視圖解耦與聚焦**：劃分三大專屬活頁（📊 投資組合、📜 歷史帳本、⚡ 券商與摩擦中心），各視圖專注特定任務，大幅降低認知負擔。
  3. **內嵌工作台體驗**：券商管理與摩擦成本分析轉為獨立活頁內嵌渲染，免去彈窗開關的打斷感。
- **缺點**：需重構 `App.tsx` 的佈局組織，但元件本身具備高重用性，風險低。

---

## 3. 決策內容 (Decision)

1. **移除全域手續費折讓選單**：
   - 廢棄 `brokerFeeDiscount` 全域狀態與 Header 選單。
   - `calculateHoldingsAndSummary` 中持有部位之預估賣出手續費一律由該持股所屬券商帳戶（或預設帳戶）的 `discountRate`、`minFee` 試算。
2. **導入活頁本導覽列 (Tabbed Workspace Hub)**：
   - 定義 3 大頁籤：`portfolio` (投資組合)、`ledger` (交易帳本)、`friction` (券商與摩擦中心)。
   - 支援 LocalStorage 狀態記憶與現代玻璃擬態 UI 切換動畫。
3. **交易筆數透明化展示**：
   - `TradeHistoryTable` 表頭提供 `(顯示 M 筆 / 全量共 N 筆)` 指示與一鍵重置篩選功能。

---

## 4. 後續影響與相容性 (Consequences & Compatibility)

- **正向影響**：
  - 介面層次分明、現代感與專業度顯著提升。
  - 手續費計算邏輯單一化，杜絕選單與帳戶間的衝突。
  - 歷史交易篩選狀態直觀透明，杜絕「資料是否不見」的疑慮。
- **相容性**：
  - 既有 LocalStorage 的交易資料與券商帳戶 100% 相容，無破壞性變更。
