# ADR-0005: 全市場即時與延遲多源報價引擎、交易時段智慧輪詢與自訂價格鎖定防禦架構

- **狀態 (Status)**: Approved
- **日期 (Date)**: 2026-08-21
- **決策者 (Deciders)**: Core Engineering Team
- **關聯規格 (PRD)**: [PRD 0005: V1.4 全市場即時與延遲報價系統與自訂價格鎖定](../../docs/specs/0005-realtime-and-delayed-market-quotes-system.md)
- **關聯 Issues**: #46, #47, #48, #49, #50

## 1. 背景與脈絡 (Context)

在先前版本中，系統持股之參考市價完全依賴使用者手動逐一輸入或建倉之成交價。當投資組合標的數量增加時，手動維護極為繁瑣，且無法即時反映盤中波動。
此外，使用者提出關鍵限制與需求：
1. **零後端與免費/官方優先**：必須在純前端環境下執行，優先使用免費公開來源或官方端點，無須額外架設後端伺服器或購買付費 API Key。
2. **多市場涵蓋**：需同時支援台股（上市 `.TW`、上櫃 `.TWO`、ETF）與美股（NYSE / NASDAQ / AMEX）。
3. **自訂價格保護與斷線容錯**：使用者手動輸入的壓力測試價格不可被定時輪詢覆蓋；遭遇 API 限制或網路斷線時系統不可崩潰，必須平滑降級。

## 2. 決策事項 (Decisions)

### 決策一：純前端多源免費報價引擎與多代理池 (`src/engine/priceFetcher.ts`)
- **主資料來源 (Primary)**：採用 Yahoo Finance Chart API (v8/v7)，透過前端多節點 CORS 代理池（`corsproxy.io`、`api.allorigins.win`、`codetabs`）發送請求，獲取最新成交價、前一日收盤價 (`previousClose`)、當日漲跌額與百分比。
- **官方備援 (Fallback)**：針對台股市場，若 Yahoo Finance API 請求超時或異常，自動降級調用台灣證交所 (TWSE) 官方每日收盤價開放資料 (`STOCK_DAY_ALL`)。
- **超時與熔斷機制**：單一代理請求設定 4000ms 超時限制與指數退避輪替，保證單一節點失效不影響整體拉取。

### 決策二：交易時段判定與智慧定時輪詢 Hook (`src/hooks/usePriceAutoRefresh.ts`)
- **交易時段精準計算**：
  - 台股時段：台北時間週一至週五 09:00 ~ 13:30（自動排除週末與休市日）。
  - 美股時段：美東時間週一至週五 09:30 ~ 16:00（夏令台北時間 21:30 ~ 04:00）。
- **輪詢策略**：
  - **進站自動抓取**：元件載入時發起首次全持股同步。
  - **開盤定時輪詢**：處於開盤時段時，以 60 秒為間隔背景自動刷新未鎖定持股。
  - **休市節省資源**：非開盤時段暫停定時器，節省使用者頻寬與公共代理額度。

### 決策三：自訂價格手動鎖定保護 (🔒) 與持久化快取降級 (⚠️) (`src/utils/storage.ts`)
- **鎖定保護機制 (Manual Lock Shield)**：使用者於持股表格手動修改特定標的現價時，系統強制將該標的標記為「自訂鎖定 (🔒)」。自動輪詢排程器主動過濾鎖定標的，杜絕覆蓋使用者的自訂試算價格；使用者亦可隨時一鍵解鎖以恢復全自動跟隨。
- **本地持久化快取 (localStorage)**：每次成功獲取報價時，將資料寫入 `STOCK_TRACKER_PRICE_METADATA_V1`；當網路離線或全代理節點不可用時，平滑退回本地最後有效報價並標記為 `CACHED` (⚠️)。

### 決策四：UI 狀態透明化與單元格子元件解耦 (`src/components/HoldingsTable.tsx` & `Header.tsx`)
- **四色狀態徽章**：🟢 盤中即時/延遲、🟡 昨日收盤價、🔒 自訂鎖定、⚠️ 離線快取。
- **漲跌色塊**：並列呈現當日漲跌金額與百分比，色彩與全域主題感知（台股紅漲綠跌 / 國際綠漲紅跌）。
- **架構解耦**：將價格單元格抽離為獨立子元件 `<PriceDisplayView />`，消除 JSX 中的立即執行函式 (IIFE)，提升可維護性。
- **統一日誌工具 (`src/utils/logger.ts`)**：統一封裝前端 error/warn 日誌，取代散落的 console 調用。

## 3. 影響與評估 (Consequences)

### 正面效益 (Positive)
- **極致使用者體驗**：開啟網頁即全自動同步最新市價，開盤時段無須手動重整頁面即可獲得即時損益動態。
- **零營運成本**：完全無需自建伺服器與付費行情 API，100% 依賴公開開源生態。
- **極高強健性**：多代理輪替 + TWSE 官方備援 + localStorage 離線快取，達成三重防禦。
- **尊重使用者決策**：自訂鎖定機制保證了投資人進行壓力測試與情境模擬的自由度。

### 潛在限制與應對 (Trade-offs & Mitigation)
- **公共 CORS 代理頻寬限制**：透過「休市停止輪詢」、「已鎖定標的跳過」、「批次並行」與 60 秒間隔，嚴格控制請求頻率，避免觸發公共節點限流。
- **延遲報價說明**：免費 Yahoo Finance API 之美股與部分台股可能具備 15 分鐘延遲，系統透過狀態徽章（🟢 DELAYED / PREVIOUS_CLOSE）與最後更新時間戳充分向使用者揭露。
