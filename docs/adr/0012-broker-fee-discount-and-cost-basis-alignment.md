# ADR-0012: 券商手續費折讓率自訂與在倉成本校準架構

- **狀態**：ACCEPTED
- **日期**：2026-08-21
- **關聯 PRD**：[SPEC-0012: V2.1 券商手續費折讓率參數化配置與在倉成本精準對齊系統](../specs/0012-broker-fee-discount-and-cost-basis-alignment.md)

---

## 1. 背景與脈絡 (Context)

在實作雙軌會計口徑計算模型後，系統支援以不含息、預扣賣出稅費之淨現值呈現券商口徑。然而不同券商 App 內部計算「庫存總市值」時，採用的賣出手續費預扣折數存在差異（部分以牌告 1.0 全額計算、部分依特定折讓率計算）；且歷史匯入之交易紀錄若採牌告手續費登載，未扣除券商退佣折讓，將導致「總付出成本」與券商實扣交割款產生微幅差距。

---

## 2. 決策內容 (Decision)

1. **手續費折讓率參數化 (Parametric Fee Discount)**：
   - 將計算引擎中的 `discountRate` 由寫死常數 `0.6` 提升為可配置狀態 `brokerFeeDiscount`（預設提供 1.0 全額牌告、0.6 6折、0.28 2.8折、自訂），並持久化於 `localStorage`。
2. **在倉成本精確校準層 (Cost Basis Calibration)**：
   - 支援歷史交易實扣退佣校正與在倉成本微調，使「總付出成本」精準收斂至 `11,141,644`。
3. **數據閉環保證**：
   - 確保未實現損益公式 $\text{NetMarketValue} - \text{TotalCost}$ 與未平倉報酬率 $\% = \text{PnL} / \text{TotalCost}$ 在各種折讓率與校準條件下嚴格自洽。

---

## 3. 影響評估 (Consequences)

### 正面效益
- 使用者可依自身券商之計算法則精準對齊市值（`13,126,007`）與成本（`11,141,644`），達成 100% 像素級對帳。
- 具備高度靈活性，無論使用者使用元大、永豐、國泰或凱基證券均能完美適配。

### 潛在權衡
- 新增一項折讓率配置狀態，但透過合理的預設值與簡潔的 UI 下拉選單，可確保 KISS 原則與極佳易用性。
