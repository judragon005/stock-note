# ADR-0015: 公司行動雙軌資料源、受控限速與本地代理防禦架構

- **狀態**：ACCEPTED
- **日期**：2026-08-24
- **關聯 PRD**：[SPEC-0015: 公司行動雙軌資料管線、受控限速與本地代理防護規格書](../specs/0015-corporate-action-dual-pipeline-and-rate-limiting.md)

---

## 1. 背景與脈絡 (Context)

在處理大批量歷史交易紀錄（如 386 筆）時，掃描器向外部金融端點查詢歷史除權息與公司行動時，遭遇瀏覽器 CORS 跨域政策攔截與免費代理池不穩定問題。同時，大批量請求若缺乏節流與快取機制，極易觸發遠端 API 的頻率限制 (HTTP 429)。

---

## 2. 決策內容 (Decision)

1. **雙軌資料源管線**：
   - 🇹🇼 台股：台灣證券交易所 (TWSE) 官方 OpenAPI (`TWT48U_ALL`) 優先，Yahoo Finance 作為備援與分割資料補充。
   - 🇺🇸 美股：以 Yahoo Finance 為主要來源。
2. **傳輸層 Vite 本地代理 (Dev Proxy)**：
   - 在 `vite.config.ts` 建立 `/api/twse` 與 `/api/yahoo` 代理轉發，徹底擺脫瀏覽器 CORS 限制。
   - 保留外部 CORS 代理池作為純靜態託管時的平滑降級備援。
3. **外部呼叫防護與節流機制**：
   - **並行度控制**：Concurrency = 2。
   - **請求節流延遲**：每次查詢後加入 150ms 抖動延遲，防禦 429 封鎖。
   - **24 小時實體快取**：導入 `STOCK_TRACKER_CA_CACHE_V1` LocalStorage 快取，已查標的 0 重複請求。
   - **超時熔斷**：單次請求 4 秒超時保護。

---

## 3. 效益與影響 (Consequences)

- **正面效益**：
  - 徹底解決瀏覽器掃描除權息時「結果全部為空或漏失」的問題。
  - 大幅降低外部 API 負載，杜絕 IP 封鎖與 429 錯誤。
  - 掃描體驗由 30 秒卡頓縮短為 2~3 秒秒級響應。
- **相容性**：
  - 完全向後相容，測試套件保持 100% 覆蓋。
