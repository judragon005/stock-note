# ADR-0001: 核心技術架構與雙幣別會計計算模型

## 狀態 (Status)
Accepted (已核准)

## 背景與脈絡 (Context)
本專案旨在為個人投資者提供美股與台股之交易紀錄管理與進階投資組合分析。台股與美股在計價幣別（TWD vs USD）、交易單位（台股整股/零股 vs 美股小數點股數）與稅費結構（台股證交稅/手續費 vs 美股規費）上存在差異。此外，系統需支援離線可用、資料零洩漏、極致流暢的資料視覺化與可擴展性。

## 決策 (Decision)
1. **技術架構**：採用 **React 18 + TypeScript + Vite + Vanilla CSS** 構建純前端單頁應用程式 (SPA)。
2. **數據持久化**：採用瀏覽器本機儲存 (LocalStorage / IndexedDB)，支援 JSON / CSV 完整雙向備份匯入與匯出，確保使用者財務數據 100% 本機私密保存。
3. **多幣別記帳機制**：
   - 交易紀錄層：以 **原始幣別 (Native Currency - TWD/USD)** 精確記帳，手續費與稅費分別獨立核算，杜絕匯率波動污染單筆交易報酬。
   - 投資組合總覽層：提供即時/自訂匯率折算功能，支援統一以 TWD 或 USD 匯總整體資產淨值與報酬。
4. **成本與損益計算模型**：預設採用 **移動加權平均法 (Moving Weighted Average Cost)** 計算單位持股成本與已實現損益，並在資料結構中預留 Lot 批次標識以支援未來擴充 FIFO 模式。

## 後續影響 (Consequences)
- 無需外部伺服器即可直接本機執行或部署至靜態網頁託管服務（如 GitHub Pages）。
- 資料結構具備高精度與清晰邊界，利於後續擴充技術指標、股息日曆、再平衡模擬與圖表分析儀。
