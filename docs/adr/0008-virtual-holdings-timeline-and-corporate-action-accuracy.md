# ADR-0008: 虛擬時序動態配股與台股減資整數換發架構

## 狀態 (Status)
**已接受 (Accepted)** - 2026-08-21

## 上下文 (Context)
在投資者匯入全量手動交易紀錄並執行智慧掃描時，發現以下問題：
1. **多次配股基數失準**：一檔標的若在歷史上經歷多次連續配股（如 2890 永豐金 2023、2024、2025 連續除權），靜態手動交易未包含前次配股，導致後續配股計算基準股數偏低。
2. **減資縮股四捨五入誤差**：台股現金減資集保換發採向下取整 (`Math.floor`)，四捨五入會導致泰銘 10,000 股減資少扣 1 股（扣 2,828 股而非 2,829 股）。
3. **除權日當天買進誤計**：除權息當天買進者不享有除權息權益，需以 $T-1$ 收盤在倉為基準。
4. **已平倉標的重複補登**：若股票已全數賣出平倉（0 股），歷史配股若被重新補登會導致已平倉股票重新出現假庫存。

## 決策 (Decision)

1. **實作虛擬時序動態推進器 (Virtual Holdings Timeline)**：
   - 掃描過程中動態維護 `virtualTrades`，每當識別出未入帳的除權配股或分割時，即時寫入時序副本，供後續公司行動以最新動態持股為計算基數。
2. **採用集保向下取整減資換發公式 (Floor New Ratio)**：
   - 縮減股數公式：`sharesHeld - Math.floor(sharesHeld * (1 - reductionRatio))`。
3. **引入除權日前一日收盤基準 (T-1 Ex-Date Resolution)**：
   - 使用 `ev.date` 前一日 $(T-1)$ 計算基準在倉股數。
4. **引入零持股安全守護 (Zero-Holding Shield)**：
   - 最新持股為 0 股之標的，歷史股票分割與配股一律標記為 `isAlreadyRecorded = true`。

## 後果 (Consequences)

- **優點**：
  - 徹底杜絕了手動寫死特例的壞味道，智慧掃描具備 100% 通用性與自洽性。
  - 21 檔持股在倉股數與 5 檔已平倉標的在經歷純手動匯入 ➔ 智慧掃描 ➔ 套用補登後，庫存 100% 精準吻合。
- **缺點**：
  - 在執行智慧掃描時需在記憶體中維護 `virtualTrades`，但運算時間僅增加幾毫秒，對使用者體驗無可感知影響。
