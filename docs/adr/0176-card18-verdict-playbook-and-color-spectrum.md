# ADR 0176: Card 18 主力追蹤總評判操盤指引升級、5 態作戰光譜與機構級風控門檻

## 狀態
已採納 (Accepted) - 2026-10-12

## 背景與痛點
在主力戰情室第 7 層中，壓軸面板 Card 18「主力追蹤總評判 (MLP-AI)」獨佔右欄滿高 (~480px)。先前面臨以下結構性缺陷：
1. **版面留白荒漠**：中央區域僅以 `justifyContent: space-between` 撐開，存在高達 150~200px 的無效深色留白。
2. **色彩與語意認知斷層**：「低接吸籌」未命中「進貨/買」關鍵字掉入 Fallback，且右側燈號標示為「防禦觀望」，與主動低接蓄勢意圖相矛盾。
3. **數據膠囊失聯**：正則表達式未支援現行引擎產出的收盤價、20日 VWAP 主力成本與乖離率格式。
4. **四方視角缺漏**：缺乏券商營業員需要的具體點位與週期、監理合規流動性守門員 (<300張防作線)、機構失效條件 (Invalidation Gate) 與散戶 5 態週期直觀光譜。

## 決策核心架構

### 1. 方案 A：5 態主力作戰微型光譜圖例條 (Micro Spectrum Bar)
- 於核心看板正下方嵌入高度 26px 之微型橫向導航條，呈現 5 大週期階段：`[超跌反彈] ➔ [低接吸籌] ➔ [鎖碼推升] ➔ [高檔調節] ➔ [區間震盪]`。
- 當前語意命中階段呈現 18% 透明度膠囊底色、發光邊框與高亮文字；其餘 4 態維持 `opacity: 0.45` 半透明，並具備定義 Tooltip。

### 2. 中央留白荒漠重塑：雙層 Bento 操盤結構
- **語意微觀解析 (Market Context)**：深藍半透明背景搭配品牌主色光條，生成量價因果解讀。
- **實戰操盤指引 (Action Playbook)**：整合四合一矩陣：
  1. 適配操作週期 (Horizon) 膠囊
  2. 建倉/應對策 (Execution Directive)
  3. 關鍵錨點三欄網格 (防守停損、目標滿足、預估風報比)
  4. 風控失效條件 (Invalidation Gate)

### 3. 三軌色彩認知體系對齊
- 軌道一（多頭攻擊）：`#ef4444`「● 偏多集結」（鎖碼推升 / 強勢續抱）
- 軌道二（吸籌蓄勢 / 超跌轉折）：`#38bdf8`「● 偏多承接」（低接吸籌）、`#c084fc`「● 跌深反抽」（超跌反彈）
- 軌道三（風險警戒 / 盤整中性）：`#f59e0b`「● 區間警戒」（調節減碼 / 高檔出貨）、`#94a3b8`「● 空手觀望」（區間震盪）

### 4. 方案 B：量化研判深度指南彈窗 (360px Deep-Dive)
- 包含 5 態門檻對照表 (QUANT_VERDICT_THRESHOLDS)。
- 植入流動性守門員門檻 (日成交均量 < 300 張防作線警示)。
- 標註合規免責宣告。

### 5. 滿高容器與正則提取防禦
- 最外層容器加入 `overflowY: 'auto'` 防止極端比例破版。
- `parseVerdictMetrics` 支援提取最新收盤價、20日VWAP、成本乖離率，並向下相容舊版法人與 RSI 格式。
