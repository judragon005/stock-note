# ADR 0232: 近日持倉除息行事曆雷達與跨期現金流前瞻排程架構決策

- **狀態**：Accepted
- **日期**：2026-11-16
- **關聯規格**：[0232-ex-dividend-radar-and-calendar-horizon-spec.md](../specs/0232-ex-dividend-radar-and-calendar-horizon-spec.md)
- **關聯議題**：#565, #566, #567, #568, #569, #570, #571, #572

## 背景與問題 (Context)

使用者在檢視股利日誌與被動現金流時，缺乏針對當前持倉股票近期（未來 60~90 天內）確切除息日程的即時前瞻雷達。同時，除息日（Ex-Date）與入帳日（Pay-Date）之間存在 20~35 天資金凍結期，且單筆達 20,000 元之二代健保補充保費（2.11%）缺乏事前預警，容易引發流動性誤判與非預期稅負扣折。

## 決策 (Decision)

1. **雙軌動態時序視窗 (Confirmed 60d vs. Projected 90d)**：
   - 預設提供近 60 天官方公告確定視窗 (`scheduleType: 'CONFIRMED'`)，並支援展開至 90 天歷史週期統計推估視窗 (`scheduleType: 'PROJECTED'`)，透明區分法定義務與週期性預測。
2. **除息與入帳雙時序解耦**：
   - 每個雷達事件明確展示 `exDate`（除息日）與 `payDate`（預計入帳日），並計算 `daysUntilEx`（倒數 T-X 天）與 `daysFromExToPay`（在途凍結天數），杜絕將除息日誤認為現金可用日的錯誤預期。
3. **稅務防禦與二代健保穿透預警**：
   - 台股單筆現金股利 $\ge 20,000$ 新台幣時，自動標記二代健保警示徽章，並計算 2.11% 扣繳保費與免扣繳建議臨界股數；美股標的即時換算匯率並扣除 30% 預扣稅。
4. **全域多帳戶與跨市場隔離**：
   - 雷達事件完全遵循全域 `selectedAccountId` 與 `market` 篩選狀態，單一券商模式下獨立計算該券商之持倉規模與稅負門檻。
5. **獨立 ExDividendRadarCard 元件與頂層 E2E 整合**：
   - 抽離為高內聚之卡片元件，掛載於現金流月度長條圖上方，並以 `DividendLogView.test.ts` 真實 DOM 測試作為最高整合縫隙。

## 影響與後果 (Consequences)

- 補齊「第一幕：近日除息雷達 (Pre-Ex)」，使股利工作台形成「前瞻除息 $\to$ 年度展望 $\to$ 歷史對帳」之完整三幕劇閉環。
- 透過 7 個垂直切片票券（#566 ~ #572）逐一以 TDD 紅-綠-重構交付，維持 100% 測試綠燈與 0 型別錯誤。
