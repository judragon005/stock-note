# ADR 0071: 頂部導航列漲跌色彩切換按鈕文字對稱化與智慧 Tooltip 語意升級 (Color Theme Toggle Label & Tooltip UX)

## 狀態 (Status)
已接受 (Accepted) - 2026-09-02

## 背景與問題脈絡 (Context)
頂部工具列提供「慣用紅綠漲跌」色彩切換按鈕（台股習慣 `taiwan`：紅漲綠跌；國際習慣 `international`：綠漲紅跌）。
原先按鈕渲染邏輯使用 `{colorTheme === 'taiwan' ? '🔴 綠跌' : '🟢 紅跌'}`，造成嚴重視覺與認知矛盾：
1. 在國際模式下按鈕顯示為 `[調色盤] 🟢 紅跌`，使用者誤解為「綠點代表紅跌」。
2. 在台股模式下按鈕顯示為 `[調色盤] 🔴 綠跌`，缺乏「漲」的標籤，語意殘缺。
3. 提示 Tooltip 為靜態字串，無法告知使用者當前生效中的模式及點擊後將切換至何種模式。

## 決策內容 (Decision)
1. **模式標籤對稱化**：
   - 抽出純邏輯輔助函式 `getColorThemeLabel(colorTheme)`：
     - `taiwan` ➔ `🔴 紅漲 🟢 綠跌`
     - `international` ➔ `🟢 綠漲 🔴 紅跌`
2. **動態雙行智慧 Tooltip**：
   - 抽出 `getColorThemeTooltip(colorTheme)`：
     - 懸浮時明確呈現目前模式與點擊切換目標：
       - 台股模式：`目前模式：台股習慣 (紅漲綠跌)\n點擊切換為：國際/美股習慣 (綠漲紅跌)`
       - 國際模式：`目前模式：國際/美股習慣 (綠漲紅跌)\n點擊切換為：台股習慣 (紅漲綠跌)`
3. **單元測試守護**：
   - 建立 `src/components/Header.test.ts`，驗證標籤渲染與動態 Tooltip 內容規範。

## 影響與後果 (Consequences)
- **正面效益**：
  - 徹底消除「綠球配紅跌」的視覺歧義，提高使用者操作信心與直覺性。
  - 遵循 KISS 原則與單一職責，輔助邏輯抽離為純函式易於單元測試。
- **負面影響 / 限制**：
  - 無，對現有資料流、LocalStorage 與 CSS 變數體系零破壞。
