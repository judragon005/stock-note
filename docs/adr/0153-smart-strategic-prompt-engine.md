## 背景與說明
在專案 V8.64 推進至 V8.65 期間，建立了 Issue #135 規劃本功能。因團隊優先推進 V8.65 歷史日 K 緊湊快取注入 (Spec 0154)，使 0153 處於保留待實作狀態。本 ADR 記錄其設計原則與架構邊界，待 Issue #135 開工時執行實作。

## 決策核心架構
1. **SSOT 注入模式**：提示詞引擎不得重複計算數據，必須直接自量化引擎與 SQLite 本地湖倉提取指標。
2. **零隱私洩漏原則**：所有組裝之提示詞均在客戶端本地端動態生成，不經由任何未加密中繼伺服器外洩個人持倉隱私。
