# ADR-0053: 本機公司行動資料庫 (IndexedDB)、多源交叉增量同步管線與減資除息時序校準

## 狀態 (Status)

已採納 (Accepted) — 2026-08-28

## 背景 (Context)

在計算股票除權除息股數與入帳金流時，系統面臨以下問題：
1. **減資歷史事件遺漏**：外部單一資料源（如 Yahoo Finance）未回傳歷史現金減資時，系統以減資前舊股數計算未來股利，導致金額嚴重高估（例如泰銘 9927 曾被誤算為 64,145 元而非實質持股 10,000 股的 48,945 元）。
2. **除息日與發放日錯置**：官方日曆常態庫將 9927 的預估發放日誤填為 2026-10-01 當天，破壞了現金帳本的在途交割隔離機制（實際發放常態應為 2026-10-29）。
3. **缺乏本機持久化公司行動資料庫**：每次全量重掃易遭 Rate Limit 阻擋或 CORS 失敗，缺乏增量儲存與「以時間換空間」歷史深度回填機制。

## 決策 (Decision)

1. **本機持久化公司行動資料庫 (`StockTrackerDB.corporate_actions`)**：
   - 於 IndexedDB 新增專屬 Store，以 `${symbol}-${type}-${date}` 為主鍵，支援本機離線讀取與差異化增量 Upsert。
2. **三層多源交叉驗證管線 (Three-Tier Pipeline)**：
   - **Tier 1 (內建官方基準庫 SSOT)**：內建 9927 減資、2330、2886、00878、00923 等重大行動，100% 離線可用。
   - **Tier 2 (官方開放資料端點 - 免 Key)**：串接 TWSE `TWT48U_ALL`（除權息預告）、`TWTAVU`（減資恢復買賣）與 TPEx 官方端點。
   - **Tier 3 (深度歷史回填 - 選填免費 Key)**：在設定頁支援填入 **FinMind Token**（免費申請，每日 600 次額度），以 200ms 受控節流背景回填台股過去 10 年歷史減資與配息；美股支援選填 FMP / Finnhub Key 或 Yahoo 備援。
3. **泰銘 (9927) 專項校準**：
   - 納入 2025-09-15 現金減資（28.28%），在籍股數鎖定為 **10,000 股**。
   - 2026-10-01 除息事件：未稅毛額 **50,000 元**，扣除 2.11% 二代健保（1,055 元）後實質入帳 **48,945 元**，預估發放日修正為 **2026-10-29**。
   - 現金帳本自動連動流水同步校正為 `+NT$ 48,945`，於 2026-10-29 到達前保持 `PENDING` 在途狀態。

## 後果與影響 (Consequences)

- **正面效益**：
  - 本地離線存取極速，增量同步大幅節省網路頻寬與 API 配額。
  - 歷史減資縮減股數與配權配息完全按時序前置扣減，消除配息金額虛胖高估。
  - 除息日與發放日徹底分離，現金帳本精準反映在途交割。
- **維護責任**：
  - 官方基準日曆庫需定期維護大型權值股最新公告。
