# ADR 0098: 肌肉書僮三色實戰決策矩陣與多因子真動態 AI 晨報

- **狀態**：Accepted
- **日期**：2026-09-08
- **決策者**：Antigravity Agent & User

## 背景與問題 (Context)
1. 肌肉書僮頁面目前僅呈現統計分類（「箱頂突破」、「底穿上」、「布林極致壓縮」），使用者無法第一眼辨識「哪一支買、哪一支不碰、哪一支賣」與具體防守價位。
2. 戰情室「AI 晨報作戰方針」目前使用泛用雞湯範本，缺乏個人在倉即時事件、待收股息與催化劑的有機結合，淪為空洞的廣告看板。

## 決策內容 (Decisions)
1. **肌肉書僮操作決策三色化**：
   - 封裝 `evaluateMuscleBookerAction`，將技術指標聚合為投資人最直觀的動作：`BUY`（買進）、`AVOID`（觀望不碰）、`SELL`（賣出停損）、`HOLD`（續抱）。
   - 計算關鍵停損線（箱頂或箱底）與預估風益比 (R:R)。
   - 工作區提供快速戰術過濾標籤與直覺卡片標籤。
2. **多因子動態帳戶事件驅動晨報 (Event-Driven Morning Brief)**：
   - 注入使用者持倉突破/破線事件、待收股息日程、重大催化劑與配置偏離。
   - 每日晨報直接具體點名個人股票代號與停損點位，產出具備實操價值的作戰清單。

## 影響評估 (Consequences)
- **正面效益**：
  - 投資人進入動能儀頁面 1 秒內即可獲知確切交易動作與防守點，降低決策心智負擔。
  - 戰情室 AI 晨報具備真正的個人化動態情報價值，每日隨持倉與市場實況演進。
- **架構防護**：
  - 保持 100% 離線確定性計算，零外部 API 費用與延遲，零幻覺。
