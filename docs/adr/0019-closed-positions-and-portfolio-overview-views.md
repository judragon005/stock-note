# ADR-0019: 投資組合三態檢視（持倉中/已平倉/全部總覽）與已平倉績效評估架構

- **狀態**：`ACCEPTED`
- **日期**：2026-08-24
- **負責人**：Antigravity Agent
- **關聯 PRD**：[SPEC-0019: 投資組合庫存三態檢視與勝率戰績儀表板](../specs/0019-closed-positions-and-portfolio-overview-views.md)

---

## 1. 背景與決策動機 (Context)

股票投資人需要同時掌握「現有持倉之即時風險曝險」與「已平倉標的之歷史實現戰績」。先前的介面僅過濾顯示 `shares > 0` 的持股，使已平倉標的變成黑洞，無法檢視出場損益與領取股利，亦無法得知投資組合的全生命週期勝率。

## 2. 決策內容 (Decision)

1. **三態檢視架構**：
   - 於 `HoldingsTable` 工具列導入 `positionFilter: 'ACTIVE' | 'CLOSED' | 'ALL'` 狀態。
   - `ACTIVE`：$shares > 0$
   - `CLOSED`：$shares = 0$ 且具備歷史交易紀錄
   - `ALL`：全標的展示，並附帶 `🟢 持倉中` 與 `⚪ 已清倉` 狀態徽章。
2. **動態摘要卡片聯動 (Dynamic Summary)**：
   - 當處於 `CLOSED` 模式時，卡片自動切換為顯示「已實現總損益」、「已領股利」與「勝率 / 賺賠比儀表板」。
   - 當處於 `ALL` 模式時，卡片顯示全週期總報酬（未實現 + 已實現 + 股利）。
3. **已清倉快速建倉 (Re-entry Action)**：
   - 在已平倉標的列提供「再次買入」按鈕，快速帶入預填資料開啟下單彈窗。

## 3. 結果與影響 (Consequences)

- **優點**：
  - 提供完整閉環的投資戰績追蹤，強化複盤與決策分析能力。
  - 完全基於現有計算引擎產出之資料結構，無額外運算開銷。
- **維護注意事項**：
  - 排序邏輯需兼顧台股優先與已實現損益排序。
