# 0105. 肌肉書僮風益比硬門檻 (R:R >= 2.0)、帶寬方向確立與無效代碼防護架構 (Muscle Booker Risk-Reward & Bandwidth Direction Gate)

- **狀態**：ACCEPTED
- **日期**：2026-09-09
- **議題**：杜絕向上空間極度狹隘（如 1599 宏佳騰 0.1R）之雞肋標的誤判為買進，建立風益比 $\ge 2.0$ 硬門檻、帶寬方向確立審查、以及無效股票代碼（如 3175）防護機制。

---

## 背景與問題陳述 (Context & Problem Statement)

在肌肉書僮動能選股系統中，發現以下三項亟需改善之交易紀律與數據邊界漏洞：
1. **風益比不足依然給出買進訊號（如 1599 宏佳騰）**：
   - 1599 現價 $23.15，箱型頂部壓力為 $23.25，向上利潤空間僅剩 $0.1 元。
   - 停損防守箱底 $22.30，下檔承擔風險高達 $0.85 元。
   - 風益比計算僅得 $0.1 / 0.85 \approx 0.12R$（承受 1 元風險僅賺 0.12 元）。
   - 原代碼僅檢查是否符合破底翻型態，未將風益比設為買進先決條件，導致散戶進場承擔巨大虧損風險卻幾乎無肉可吃。
2. **帶寬極度收斂（壓縮）時方向未明，提早猜測押注**：
   - 布林帶寬極致壓縮（$\le 8\%$）時，股價多空拉鋸，若 20MA 下彎蓋頭反壓，隨時可能向下破線崩跌。此時盲目判定買進違反短線紀律。
3. **無效股票代碼被誤存（如 3175）**：
   - 自訂觀察池未對使用者輸入做存在性查驗，造成不存在之幽靈代碼被持久化於 LocalStorage，引發查無資料或異常錯誤。

---

## 決策方案 (Decision)

我們遵循「交易風控第一、非確定方向不進場」第一性原理，實施以下核心防護：

1. **風益比 $\ge 2.0$ 硬門檻 (Risk-Reward Hard Gate)**：
   - 在 `MuscleBookerActionDecision` 擴充 `riskRewardRatioValue?: number` 數值欄位。
   - **突破箱頂**：計算突破潛在等幅空間與防守箱頂之風益比，若 $< 2.0$ 則自動降級為 `HOLD`（觀望待變），明確提示「突破空間不足或風益比僅 1:XR < 2.0R，切忌追高」。
   - **破底翻**：計算向上至箱頂之利潤與向下防守箱底之風險，若 $R:R < 2.0$ 則強制降級為 `HOLD`，主理由提示「向上空間狹窄（至箱頂利潤不足），風益比僅 1:XR < 2.0R，切忌追高」。
   - 僅在 $R:R \ge 2.0$ 且方向確立時，才給出 `BUY` 決策。
2. **帶寬壓縮與方向確定性審查 (Bandwidth & Direction Gate)**：
   - 當布林帶寬 $\le 8\%$ 時，標記為極致壓縮狀態，前置判定為 `AVOID`（方向未明，嚴禁猜測押注）。
   - 當 20MA 明顯下彎蓋頭反壓時，前置判定為 `AVOID`（均線蓋頭，反壓沉重），絕不在空頭趨勢中冒進。
3. **導航儀優先呈現高風益比標的 (Risk-Reward Priority Sorting)**：
   - 導航儀的「建議買進」卡片池，全面依 `riskRewardRatioValue` 降序排序，將 5.3R ➔ 3.2R ➔ 2.1R 等高報酬風險比標的優先置頂。
   - 卡片上對 $R:R \ge 2.0$ 標記金色火焰高光 `🔥 風益比: 1:XR`。
4. **無效代碼防護與歷史幽靈代碼清理 (Invalid Symbol Protection)**：
   - 加入自訂觀察名單時，嚴格檢核輸入代碼是否存在於本地字典或透過遠端 API 探測行情，查無標的則阻擋並彈出警告。
   - 元件初始化時，自動從 LocalStorage 清理已殘留之無效幽靈代碼（如 `3175`）。

---

## 結果與影響 (Consequences)

### 正向影響 (Positive)
- **保護交易資金**：徹底阻斷 1599 宏佳騰等 0.1R 雞肋買點，只有具備 1:2 以上賺賠比且方向確定之標的才獲推薦。
- **提升使用者勝率與盈虧比**：導航儀自動置頂最高風益比標的，直覺引導投資人挑選向上空間最大之標的。
- **名單健全性**：自訂觀察名單 100% 杜絕幽靈股票代碼。
- **測試與構建全綠**：57 個測試套件、646 個單元測試 100% 通過，TypeScript 0 型別錯誤。
