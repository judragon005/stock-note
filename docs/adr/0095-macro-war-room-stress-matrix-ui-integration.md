# ADR 0095: 宏觀戰情室工作區、質押黑天鵝逃生矩陣與肌肉書僮持倉膠囊 UI 落地整合 (Macro War Room, Margin Stress Matrix & Muscle Booker UI Integration)

## 狀態
已接受 (Accepted)

## 脈絡 (Context)
在 Phase 1 至 Phase 5 迭代中，系統成功實作了 5 大底層量化風控與宏觀分析引擎（包含全域 API 熔斷配額守護、本地歷史指標回填與肌肉書僮箱子突破、雙重動能與跨資產輪動、黑天鵝質押情境矩陣與斷頭求解器、市場宏觀流動性與四柱脈搏診斷）。
然而，純運算引擎完成後，前端視圖層（View Layer）尚未提供專屬的工作區與互動視圖，使得投資者在日常使用時無法直觀感知 5 大引擎的運作與診斷成果。

具體瓶頸包括：
1. 主畫面導航列缺乏專屬的「宏觀戰情室」工作區，宏觀流動性診斷、資產防護盾、雙重動能輪動與財經事件日曆無法一站式監控。
2. 質押維持率彈窗仍停留在單一跌幅測試階段，缺乏黑天鵝 6 維情境矩陣快捷切換、各檔斷頭價求解清單與三軌逃生指南。
3. 投資組合持倉訊號尚未視覺化展示肌肉書僮「突破箱頂、跌破箱底、底穿上反轉、月線扣低翻揚、布林極致壓縮」等即時技術型態膠囊。

## 決策 (Decision)
我們在前端視圖層進行全量整合與視覺化渲染：

1. **宏觀戰情室工作區 (`WarRoomWorkspace.tsx`)**：
   - 在 `WorkspaceTabs.tsx` 新增 `warroom`（「🏛️ 宏觀戰情室」）頁籤，附帶「AI 作戰方針」標籤徽章。
   - 頂部 AI 晨報 Banner：提供宏觀環境診斷、投資組合宏觀防護盾健康度（現金購買力比率、質押維持率、偏離度）、行動要點與一鍵複製 LLM Prompt Payload。
   - 市場四柱脈搏矩陣：殖利率倒掛、VIX 恐慌指標、金油比與通膨、全球流動性（美元指數/M2）。
   - 雙重動能跨資產輪動排行榜：支援股債輪動池、全球防禦池與核心衛星池，標註 12-1M 加權動能分與避風港指示。
   - 關鍵財經事件倒數日曆：清晰列出重要經濟數據與央行會議之倒數天數與市場預期影響。

2. **升級質押黑天鵝逃生彈窗 (`MarginStressModal.tsx`)**：
   - 整合 `evaluateMarginStressMatrix` 引擎。
   - 加入黑天鵝 6 維情境卡片快捷切換（常態 -5%/-10%、空頭 -20%、黑天鵝 -30%、除息跳水、複合黑天鵝）。
   - 加入個股 130% 斷頭臨界價格逆推求解表 (Liquidation Price Solver)，清楚標記個股斷頭價格與免疫狀態。
   - 視覺化一鍵逃生三軌救生圈指南（方案 A 還本金、方案 B 補現金保證金、方案 C 質押現股）。

3. **肌肉書僮持倉訊號膠囊 (`technicalIndicatorEngine.ts`)**：
   - 擴充 `extractHoldingSignals`，整合 `BoxTheoryEngine` 與月線扣抵值分析。
   - 於持倉膠囊即時渲染「🔥 箱頂突破」、「⚠️ 跌破箱底」、「🚀 底穿上反轉」、「📈 月線扣低翻揚」、「📉 月線扣高下彎」、「⚡ 布林極致壓縮」等狀態標籤。

## 後果 (Consequences)
- **優點**：
  - 5 大技術債底層量化引擎 100% 於前端視覺化落地，使用者可於界面直觀操作與切換。
  - 質押融資者具備極度清晰的斷頭求解器與逃生指南，避險效率大幅提升。
  - 完全保持無侵入性設計，各模組維持鬆耦合架構，現有測試 100% 綠燈相容。
- **注意事項**：
  - 宏觀戰情室目前優先支援本地投資組合快照與內建情境模擬，外部總經即時 API 連線受 RateLimiter 配額保護。
