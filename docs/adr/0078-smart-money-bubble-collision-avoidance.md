# ADR-0078: 籌碼泡泡圖自適應相對冪次縮放、2D 圓形防碰撞排斥算法與聚光燈佈局系統

## 狀態 (Status)
**已接受 (Accepted)** - 2026-09-07

## 背景與問題陳述 (Context & Problem Statement)
在 v7.7.0 導入籌碼泡泡圖後，使用者檢視「全市場法人焦點 Top 30」標的時，發現嚴重的介面視覺問題：
1. **上下天花板/地板邊界貼壁截斷**：原演算法以靜態 2,500 張作為滿分上限，全市場活躍標的買賣超動輒數萬張，導致所有買超標的均被鎖死在 $Y = +100$，所有賣超標的均被鎖死在 $Y = -100$，在上下邊框排成一條水平死線。
2. **多泡泡嚴重重疊與文字穿透**：相鄰標的缺乏二維圓形幾何排斥機制，圓形相互重疊，代碼與漲跌幅數字交叉覆蓋，完全無法辨識。
3. **缺少畫布呼吸緩衝區**：最外側邊緣泡泡文字切出視窗外。

## 決策 (Decision)

1. **自適應相對冪次縮放演算法 (Adaptive Power-Law Scaling)**：
   - 廢除寫死除數，自動取當前資料集最大買賣超 $|\text{flow}|_{\max}$ 與最大漲跌幅 $|\Delta P|_{\max}$ 為基準動態歸一。
   - 採用 $0.65$ 次方平滑曲線，將坐標限制於 $[-75, +75]$ 區間內。
   - 永遠為上下左右保留至少 25% 的呼吸安全區，徹底消除天花板與地板貼壁現象。
2. **2D 圓形防碰撞排斥純函數演算法 (`resolveBubbleCollisions`)**：
   - 0 外部物理引擎套件，純原生數學迭代（8 輪 Relax Iteration）。
   - 檢測兩圓距離 $\text{dist} < r_1 + r_2 + 4\text{px}$，沿連心線方向平滑推開。
   - **象限守恆守門員 (Quadrant Invariant Guard)**：推開時加入中軸安全邊界約束（$X=0$ 與 $Y=0$），確保原本屬於「🔥 主力抬轎」等象限的標的絕不跨越中軸，保持多空分類 100% 精準。
3. **SVG DOM 頂層繪製排序與滑鼠聚光燈高亮 (Spotlight Mode)**：
   - 當滑鼠 Hover 或選中任一泡泡時，將該泡泡排至 SVG DOM 最末尾，確保其在最頂層渲染，文字與光暈零遮蔽。
   - 啟動聚光燈模式：其餘泡泡透明度平滑降至 `0.25`，目標泡泡維持 `1.0` 脈衝發光，快速聚焦。
4. **全市場模式動能散度增強**：
   - 依據法人籌碼強弱程度與在庫持倉連動，使 30 檔股票自然呈現於四個維度，不再扎堆。

## 後果 (Consequences)

### 正面影響 (Positive Impact)
- 徹底解決 30 檔標的疊合貼壁問題，文字與圓形清晰易讀。
- 0 外部重量級物理函式庫依賴，運算效能極高，60fps 流暢渲染。
- 象限守恆確保生活化多空意涵完全不被幾何推擠破壞。
