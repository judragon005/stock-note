# 0085. 動態影格象限色彩同步、象限邊界守門員與時序籌碼一致性架構決策 (ADR)

## 狀態 (Status)
提議 (Proposed) / 實作中 (In Progress)

## 上下文 (Context)
在籌碼星圖中，使用者發現位處第三象限（左下角「❄️ 冷凍提款區」）的標的竟然被渲染成第二象限的黃色。深度檢視發現泡泡顏色未依當前影格動態計算象限，且判定條件將零籌碼誤判為逢低吸籌。

## 決策 (Decision)
1. **動態影格象限色彩映射**：泡泡渲染時的 `fillColor` 與 `strokeColor`，不再依賴靜態初始的 `b.quadrant`，而是依據當前選定影格的坐標動態計算當前真實象限 `frameQuadrant`。
2. **象限邊界零軸守門員**：嚴格收斂象限分界：$y > 0$ 且 $x < 0$ 才是 `ACCUMULATION`；$y \le 0$ 且 $x < 0$ 嚴格歸為 `LIQUIDATION`。
3. **時序軌跡增量平滑化**：確保持倉股票法人數據缺失時不產生偽造倒貨負向位移。

## 後果 (Consequences)
- 徹底根除第三象限泡泡出現黃色之視覺與邏輯矛盾。
- 畫布四象限、外觀色彩、浮窗徽章與頂部統計卡四位一體，保持 100% 一致。
