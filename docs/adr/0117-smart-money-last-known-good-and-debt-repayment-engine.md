# ADR 0117: 籌碼動態星圖盤中有效日報回溯機制與質押借貸「費用➔利息➔本金」法定沖償引擎

## 狀態
已通過 (Accepted) - 2026-09-11

## 脈絡與背景 (Context)
在先前版本中，系統在盤中籌碼分析與股票質押借貸記帳上存在兩項嚴重的業務與金融會計缺陷：
1. **籌碼動態星圖盤中空值與 0 張現象**：
   - 臺灣證券交易所 (TWSE) 與櫃檯買賣中心 (TPEx) 的三大法人買賣超日報，通常於每日 15:00~16:30 始陸續公布。使用者在營業盤中（09:00~13:30）或下午 3 點前開啟星圖時，當日盤後資料尚未產出。
   - 舊版代碼採用中性靜默 Fallback 將數據全數歸零，導致所有持倉（如國巨 2327、台積電 2330 等）之外資、投信、自營商全數顯示 0 張，泡泡全部平躺在 Y=0 中軸一字排開，嚴重誤導使用者；且 UI 無任何狀態指示器，時間軸使用抽象的 `T-4, T-3` 虛擬代號。
2. **質押借貸「部分還本」篡改繳息起點、利息蒸發與規費重複計費**：
   - 舊版在使用者執行「還本」（償還部分本金）時，代碼強制將 `lastInterestPaymentDate` 覆寫為當日（如 9/10），導致借款起日（9/9）至還款日之間由原借款本金（約 201 萬）所產生的利息（NT$ 224）憑空蒸發、漏算，次日僅計算還款後剩餘本金（99.9 萬）的 1 天利息。
   - 系統違反臺灣《民法》第 323 條與金融實務之法定清償順序（**費用 ➔ 利息 ➔ 本金**），粗暴將還款金額 100% 沖抵本金。
   - 券商扣款收取的 60 元解質撥券費未標記結清，致使卡片持續重複加總 60 元規費。美股保證金融資借貸亦存在相同利息被抹除與規費誤算問題。

## 決策細節 (Decision Details)

### 1. 籌碼日報 Last Known Good 回溯哨兵與狀態透明化
- **15:30 時間閥值與盤中前一日自動鎖定**：
  - `getLatestTradingDateString` 調整為以台北時間 15:30 作為當日與前一日分界點。在 15:30 前或未公布盤後資料時，自動將目標鎖定為 T-1 前一交易日已結算日報。
- **Last Known Good 歷史快取自動回溯**：
  - `fetchTwseInstitutionalReportDetailed` 在線上請求失敗時，遞迴向歷史回溯檢索 IndexedDB 中最新一份有效日報（以包含 2330 台積電為有效哨兵），回傳結構化物件 `InstitutionalReportResult`（包含 `reportDate`, `isLiveToday`, `data`, `totalSymbols`），確保「畫面永遠有真實法人數據」，絕不回傳空字典。
- **狀態徽章與真實交易日時間軸**：
  - 星圖頂部新增狀態徽章：`🕒 盤中模式：顯示 MM/DD 盤後 (共 N 檔)` 或 `🟢 已同步：MM/DD 盤後`。
  - 時間軸滑桿全面真實交易日化（如 `09/04 ➔ 09/05 ➔ 09/08 ➔ 09/09 ➔ 09/10`），且查無資料標的友善標註「無此日盤後法人進出數據」。

### 2. 金融級「費用➔利息➔本金」法定沖償引擎 (`applyDebtRepayment`)
- **三段式法定沖償純函數**：
  - 第一順位：$\text{feesPaid} = \min(\text{repaymentAmount}, \text{pledgeFees})$（美股 USD 預設 0 規費）。
  - 第二順位：$\text{interestPaid} = \min(\text{remaining}, \text{accruedInterest})$。
  - 第三順位：$\text{principalPaid} = \min(\text{remaining}, \text{principal})$。
- **繳息日起算點保護**：
  - 僅當利息完全結清時（$\text{interestPaid} \ge \text{accruedInterest}$），繳息日起算點才推進至當日；純還本金或利息未清時，嚴禁篡改 `lastInterestPaymentDate`，徹底杜絕利息蒸發。
- **規費扣抵歸零與防二次重複計費**：
  - 沖銷規費後合約中對應規費扣減歸零，卡片上之結清總金額絕不再度重複加上該筆規費。
- **還款彈窗智慧拆分試算**：
  - 輸入還款金額時，介面實時展示「規費、利息、本金拆分與預估剩餘本金」，並自動產生 1~3 筆乾淨的現金帳本流水。
- **卡片展示履歷摘要**：
  - 標註 `前次繳息/還款: YYYY-MM-DD`，清楚交代計息天數由來；美股卡片隱藏設質三大規費。

## 影響評估 (Consequences)
- **正面效益**：
  - 徹底解決白天盤中開啟星圖泡泡全部平躺在 Y=0 中線與全 0 張的嚴重體驗痛點。
  - 質押借貸會計計算完全符合金融法規與銀行扣款慣例，還款拆分與記帳流水精確到每一塊錢，利息天數與剩餘本金 100% 正確。
- **折衷與邊界 (Trade-offs & Boundaries)**：
  - 盤中模式明確告知使用者資料為 T-1 盤後，建立正確的金融預期，消除疑惑。
