# ADR 0129: 個股深度分析工作區與關鍵量化估值體系架構 (Stock Analysis Workspace & Key Metrics Engine)

## 狀態 (Status)
已接受 (Accepted) - 2026-09-14

## 背景與問題陳述 (Context & Problem Statement)
原先系統中雖然具備「財務透視」與「股票健診」功能，但兩者分立且缺乏像專業財報分析平台（如財報狗）般有系統、多層次的一站式深度分析體驗。使用者在評估單一個股時，需要反覆在不同分頁與彈窗切換，無法連續瀏覽 20 季的財務報表走勢、獲利能力拆解（杜邦三因子、三率走勢、週轉天數）、償債安全性指標（流速動比、利息保障倍數、CFO/淨利比）與關鍵量化估值模型（Piotroski F-Score 9 分卡、FCF Yield、彼得林區 PEG、DCF 折現與 DDM 折現）。

## 決策內容 (Decision)
1. **一級工作區導航整合**:
   - 於頂部一級分頁註冊 `📊 個股分析 (analysis)`，並將原有的「股票健診」以內部子分頁形式無縫收編。
   - 標的快捷膠囊列 (Stock Pills): 自動融合使用者即時持倉、自訂追蹤清單與台美龍頭股，支援一鍵點選即時切換。
   - ETF 智慧防呆遮罩: 針對 0050、0056、VOO、QQQ 等指數型基金標的，智慧辨識並提供提示遮罩，引導使用者轉向持股穿透分析，避免呈現無意義的個股財報指標。

2. **雙層二級側邊欄導航 (Two-Tier Hierarchical Topology)**:
   - 一級主題 (8 大類): 最新動態、股票健診、財務報表、獲利能力、安全性分析、成長力分析、價值評估、關鍵指標。
   - 二級細項 (45 個單一微指標): 實現高度清晰、直覺易用的單一微切片檢視。

3. **視覺視圖層 (`AnalysisMetricView.tsx`)**:
   - 採用原生純 CSS Tokens 與高對比度 SVG 走勢圖，杜絕引入外部肥大圖表函式庫。
   - 內建 20 季歷史柱狀圖、長條圖與折線圖，包含杜邦三因子拆解、週轉天數 (DSO/DIO/CCC)、三率趨勢、現金流瀑布等。
   - 提供互動式 DCF 折現模型面板：雙滑桿（折現率 WACC 與永續成長率 g）支援即時拖曳並動態計算每股內在價值與溢折價幅度。

4. **量化估值計算引擎 (`src/engine/keyMetricsEngine.ts`)**:
   - **Piotroski F-Score (9 分卡)**: 嚴格評估獲利能力、槓桿流動性與營運效率，並針對淨利與現金流雙負的虧損邊界建立防禦判斷。
   - **自由現金流報酬率 (FCF Yield)**: 以每股 FCF / 現價計算，並附帶優質與警示評級。
   - **彼得林區合理價與 PEG**: 以 TTM EPS 乘上獲利成長率，判斷市場定價相對於成長動能是否合理。
   - **兩階段 DCF 折現模型**: 結合預測期與終值折現，計算企業價值與股權內在價值。
   - **高登 DDM 股利折現模型**: 針對成熟配息企業估算合理收息價格區間。

## 成果與效益 (Consequences)
- **正面影響**:
  - 全站 92 個單元測試檔、904 項測試 100% 綠燈通過。
  - 生產構建 (`npm run build`) 0 錯誤順利打包。
  - 完全符合無 Tailwind、純原生 CSS Tokens 與現代深色玻璃質感設計規範。
  - 徹底解決個股深度量化分析痛點，提供媲美專業財經終端的直覺操作體驗。
