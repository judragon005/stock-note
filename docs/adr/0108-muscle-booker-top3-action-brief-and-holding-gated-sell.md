# 0108. 肌肉書僮今日核心作戰指令 (Top 3 買進先鋒 vs 在庫持股限定賣出) 與自適應色彩主題架構 (Muscle Booker Top 3 Action Directives & Holding-Gated Sell)

- **狀態**：ACCEPTED
- **日期**：2026-09-09
- **議題**：建立肌肉書僮動能雷達「今日核心作戰指令」雙欄高光看板，篩選確定可買進前 3 檔（風益比 $\ge 2.0$ 降序置頂）與確定需賣出前 3 檔（嚴格限定在庫持股，無持有不顯示），並自適應紅漲綠跌（台股）與綠漲紅跌（國際/美股）動態色彩。

---

## 背景與問題陳述 (Context & Problem Statement)

在肌肉書僮動能雷達中，當前目標池（如 TW50、焦點 30 等）包含數十檔標的。投資人在盤中或盤後複盤時面臨以下挑戰：
1. **買進決策缺乏即時聚光**：雖然清單中有多檔標的呈現 `BUY` 訊號，但投資人需要迅速鎖定「風益比最優、突破型態最強」的前 3 檔主升先鋒，而非大海撈針。
2. **非在籍持股出現賣出訊號造成干擾**：若清單中非持有股票跌破箱底觸發 `SELL`，對投資人而言並無賣出執行的必要，甚至造成持倉恐慌。使用者明確指示：**「賣出的部分，要有持有才建議；若沒有持有，則不用顯示。若兩者都沒有，可以顯示為零或無資料。」**
3. **色彩主題需支援動態切換**：系統具備「紅漲綠跌（台灣）」與「綠漲紅跌（國際/美股）」切換機制，看板不可寫死固定色碼，必須與系統全域色彩變數深度綁定。

---

## 決策方案 (Decision)

1. **今日買進先鋒前 3 檔 (`top3BuyItems`)**：
   - 篩選條件：`actionDecision.action === 'BUY'` 且 `riskRewardRatioValue >= 2.0`。
   - 排序原則：依風益比數值由大到小降序置頂最優標的。
   - 呈現上限：最多呈現前 3 檔。若無符合標的，呈現優雅無資料空狀態。

2. **在庫持股限定賣出建議 (`top3SellItems`)**：
   - 嚴格防護（Holding-Gated）：建立 `activeHoldingsMap`（以大寫代碼為 key），僅當標的屬於在籍持股（`shares > 0`）且技術判定觸發 `SELL`（破線停損）時，方可列入賣出建議清單。
   - 資訊強化：明確標註在庫股數（例如 `🚨 在庫: 1,000 股`）、停損原防守線與破線原因。
   - 安全空狀態：當在籍持股均處於防守線之上無破線時，明確呈現「0 檔 · 🟢 目前在籍持股均在防守線之上，無持股需賣出 (持倉安全)」。

3. **動態主題色彩全面適配 (Color Theme Adaptation)**：
   - 買進卡片與標籤：全面綁定 `var(--gain-color)`、`var(--gain-bg)`、`var(--gain-border)`。
   - 賣出卡片與標籤：全面綁定 `var(--loss-color)`、`var(--loss-bg)`、`var(--loss-border)`。
   - 三色操盤導航儀同步重構為 CSS 變數，並在賣出卡片標記在庫持股狀態。

## 結果與影響 (Consequences)

### 正向影響 (Positive)
- **作戰決策一秒聚光**：投資人進站立刻看到左欄最強 3 檔買進先鋒與右欄需警戒停損的在庫持股。
- **杜絕無謂賣出焦慮**：徹底杜絕未持有標的冒充賣出建議的雜訊，在庫持股未破線時給予安心綠色確認。
- **雙市場色彩自適應**：無論切換台股紅漲綠跌或美股綠漲紅跌，看板與導航儀色彩 100% 同步。
- **防禦性與穩定性確保**：全專案 57 套件、653 個單元測試 100% 通過，TypeScript 0 型別錯誤。
