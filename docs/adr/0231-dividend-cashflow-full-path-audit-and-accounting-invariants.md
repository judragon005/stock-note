# ADR 0231: 股利日誌與被動現金流全路徑帳務不變量與時區/隔離架構決策

- **狀態**：Accepted
- **日期**：2026-11-14
- **關聯規格**：[0231-dividend-cashflow-full-path-audit-and-accounting-invariants-spec.md](../specs/0231-dividend-cashflow-full-path-audit-and-accounting-invariants-spec.md)
- **關聯議題**：#544, #545, #546, #547, #548, #549, #550, #551, #552, #553

## 背景與問題 (Context)

針對「股利日誌與被動現金流全景」頁面進行全路徑稽核時，發現現有實作存在跨帳戶洩漏、美股未乘匯率、除息後清倉漏算、一鍵入帳重複記帳、UTC 與台北時間跨日 ±1 天偏差，以及測試自行複製邏輯導致的假綠燈等系統性缺陷。

## 決策 (Decision)

1. **台北當地時區基準與純日曆運算**：全域股利與現金流模組統一採用 `Asia/Taipei` (`YYYY-MM-DD`) 作為當地日期基準，所有日期加減以純 UTC 日曆整數運算處理，並透過共用 `useTaipeiDateStr` Hook 支援跨午夜與視窗聚焦自動刷新。
2. **複合主鍵隔離**：以 `(market, accountId, symbol, exDate)` 作為應收計算、已入帳比對與持倉對照之複合鍵，嚴格隔離單一券商與全市場視圖。
3. **除息快照與狀態機收斂**：依 $T_{\text{ex}-1}$ 持股快照保留除息後清倉部位的應收股息；一鍵入帳依來源執行「更新原交易」或「帶完整帳戶與稅費新增交易」，消除雙重渲染。
4. **跨幣別與去假值淨化**：所有現金流預測與未來推算強制乘上 `usdToTwdRate` 並套用美股 30% 預扣稅；移除不配息成長股夏季 4% 假殖利率與硬編碼個股假設，並於視圖層統一 `GROSS`/`NET` 與三方加總守恆。

## 影響與後果 (Consequences)

- 所有股利與應收計算將不受宿主系統時區與跨午夜長開影響，且多帳戶與台美股混持時不會產生跨戶覆寫或單位混淆。
- 透過垂直切片（#545 ~ #553）逐批以 TDD 紅-綠測試交付，並以真實 DOM 整合測試取代既有假綠燈測試。
