# ADR 0131: 個股分析成長率基期補齊、極端值視覺防禦、真實河流圖與估值模型審計 (Stock Analysis Growth, River Bands & Valuation Audit)

## 狀態 (Status)
已接受 (Accepted) - 2026-09-14

## 背景與問題陳述 (Context & Problem Statement)
在 Spec 0130 上線後，使用者透過實盤操作截圖提出 5 項關鍵數據與視覺異常，直指量化模型失真：
1. **營收年增率 22Q1~22Q4 顯示 0% 綠柱**：API 起算日缺少 2021 年資料，導致無前期基期時誤輸出 `0%` 且畫出 8% 高度綠色柱體，誤導投資人。
2. **毛利年增率 23Q2 暴衝 +5326.2% 壓平正常走勢**：2022Q2 煤炭暴漲致毛利僅 1.1 億，2023Q2 恢復至 59.8 億，此為真實歷史數據；但缺乏離群值縮放防禦，導致其餘正常季度全被壓成一條直線。
3. **價值評估 7 大子頁面呈現死板藍色方塊**：河流圖使用寫死的 5 個等高 18% 藍色 CSS div，無真實獲利連動、無股價線與落點；股息 3 個頁面全導向同一個靜態 4.17% 框。
4. **自由現金流報酬率 (FCF Yield) 噴出 9135.81% 天文數字**：因寫死 1000 萬股，未反映大型股（台泥實際 75.3 億股）真實規模，每股 FCF 被放大 753 倍。
5. **DCF 現金流折現每股內在價值 28.5 萬元且折價 119 萬趴**：同樣因寫死股數，導致 2 兆元企業折現總值除以 1000 萬股，每股暴增至 285,283 元。

## 決策內容 (Decision)

1. **財務管線起算日擴展與基期缺失平整化**:
   - 將 `taiwanFinancialPipeline.ts` 之 `start_date` 統一擴充至 `2021-01-01`，補齊 2022 年 YoY 基期。
   - 在 `AnalysisMetricView.tsx` 中加入嚴格基期檢查：若缺乏前期基期，輸出 `displayValue: '-'` 且柱高歸零，徹底杜絕虛假 0% 綠柱。

2. **極端值自適應視覺封頂防禦演算法 (Outlier Visual Capping)**:
   - 核實台泥 2023Q2 毛利暴增 `+5326.2%` 為歷史真實數據。
   - 提取非離群值（<300%）上限作為正常比例縮放基準，使常態季度（如 +14.5%, +52.1%）保有真實起伏。
   - 離群極端值柱體高度封頂於 100%，並醒目標註 `⚡+5326.2%` 與歷史低基期效應說明。

3. **真實 SVG 估值河流圖引擎 (`renderValuationRiver`)**:
   - 以真實滾動 4 季 TTM EPS、每股淨值 BVPS、平均股息繪製 4 階多邊形漸層彩色色帶。
   - 疊加即時現價線、最新一季落點脈衝標記與落點區間評級徽章（例如：`落點評估：合理偏高 (18x ~ 22x)`）。
   - 提供歷季各通道價位數據對照矩陣。

4. **全面獨立重構 7 大價值評估子頁面**:
   - `pe_valuation`：TTM EPS、當前 P/E、五檔本益比通道階梯卡片與位階判定。
   - `pe_river`：真實 SVG 本益比河流圖。
   - `pb_valuation`：每股淨值 BVPS、當前 P/B、五檔淨值比通道。
   - `pb_river`：真實 SVG 股價淨值比河流圖。
   - `dividend_yield`：當前現金殖利率卡片與近 5 年股利發放歷程表。
   - `avg_dividend_yield`：近 3 年/5 年平均股息、7%/5%/3.5% 殖利率反推目標價與安全邊際折溢價。
   - `dividend_river`：真實 SVG 平均現金股息河流圖。

5. **全市場動態流通股數推導架構 (`keyMetricsEngine.ts`)**:
   - 優先以資產負債表之股本推導：`capitalStock / 10`。
   - 次級備援取損益表：`netIncome / eps`。
   - 保底常數 10 億股（杜絕非正數崩潰）。
   - FCF Yield 改以近 4 季 TTM FCF 計算，台泥收斂至 5%~15% 合理區間；DCF 每股內在價值收斂至 30~45 元正常區間。

## 成果與效益 (Consequences)
- **正面影響**:
  - 全站 95 個測試檔案、923 項單元測試 100% 綠燈通過（含 9 項嚴格金融審計測試）。
  - `npm run build` TypeScript 0 錯誤、Vite 打包完全成功。
  - 徹底解決 5 大實盤量化估值異常與視覺被壓扁問題，7 大價值評估子頁面具備真實金融模型與精美 SVG 視覺。
