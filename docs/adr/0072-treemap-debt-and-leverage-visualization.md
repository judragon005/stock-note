# ADR 0072: 樹狀圖納入借款與負債槓桿視覺化架構 (Treemap Debt & Leverage Visualization Architecture)

## 狀態
已採納 (Accepted)

## 上下文 (Context)
在 ADR-0066 中，樹狀圖 (Treemap) 與資產配置視圖納入了現金部位（以總資產 $\text{TotalAssets} = \sum \text{StockValue} + \text{Cash}$ 為全局分母）。
然而，對於運用股票質押借款 (Pledge Loan)、信用貸款 (Credit Loan) 或融資買進 (Margin) 的槓桿型投資人而言，目前的樹狀圖僅呈現了「總資產」的一側，未顯現「負債/借款 (Liabilities / Leverage)」的權重與規模。這造成以下認知缺口：
1. **槓桿曝險不可見**：投資人無法在樹狀圖第一眼掌握當前持股中有多少是由借款資金支撐，容易低估市場急跌時的維持率風險；
2. **資本結構割裂**：總資產與負債分散於不同活頁或彈窗（如風險曝險卡片與質押試算彈窗），缺乏在資產配置核心視圖的全局透視。

## 決策 (Decision)

1. **正幾何面積與資本結構模型 (Capital Structure & Positive Geometry)**：
   - 樹狀圖 (Treemap) 本質為正數二維空間分割演算法，無法接受負數面積。
   - 決策將借款視為資本來源 (Capital Employed) 維度，當有效借款總負債 $\text{totalDebtTwd} > 0$ 時，以正數面積注入專屬借款節點（`id: 'DEBT_TWD'`，`symbol: '🏦 借貸負債'`）。
   - 佔比分母維持為 $\text{TotalAssets} = \sum \text{StockValue} + \text{Cash}$，借款區塊之面積比例即代表負債佔總資產比例（即借貸槓桿深度 / 負債比 LTV）。

2. **視覺語意清晰與專屬辨識 (Visual Semantic Separation)**：
   - 借款節點採用專屬**高辨識度琥珀警示色**（`hsla(38, 92%, 50%, 0.85)` / `#f59e0b` 或深琥珀帶），搭配專屬邊框（`#d97706` / `#b45309`）。
   - 數值標籤展示「負債總金額」與「年化借款利率 / 負債標註」，損益或成本欄位以負項或借貸標籤（如 `-2.35% 年息` 或 `負債項`）呈現，與股票損益（紅/綠）及現金（板岩灰藍）清楚分離。

3. **數據聚合與範疇隔離 (Data Scope & Aggregation)**：
   - 借款數據聚合當前市場範圍內所有有效未結清之 `LoanRecord`（本金 + 應計利息 + 相關規費），整合成單一頂級樹狀圖節點。
   - 在 Tooltip 懸浮視窗中，展開顯示各筆借款合約明細（合約名稱、類型、本金、年利率、質押股票）。

4. **權重清單與頂部進度條連動 (Bars & LTV Capsule Integration)**：
   - 「權重清單 (Bars)」視圖同步納入 `🏦 借貸負債` 長條項目，顯示負債總額與相對於總資產之負債比。
   - 頂部三段式進度條維持「台股 / 美股 / 現金」之資產分佈純粹性，並在比例 HUD 區域右側動態追加「`🏦 負債比 LTV: XX.X%`」高對比警示膠囊，維護數學一致性與視覺直觀。

## 後果 (Consequences)
- **正面效益**：
  - 投資人進入投資組合首頁即可一眼通盤掌握「股票分佈 + 現金儲備 + 借款槓桿」，實現真全景資本結構洞察。
  - 保持 Treemap 二維空間分割演算法之數值穩定性與正向幾何無破版。
- **邊界防禦**：
  - 當無借款或負債結清歸零時，借款節點與 LTV 膠囊自動隱藏，對純現貨無槓桿投資人 100% 零視覺負擔。
