# 0062. 全域借款負債納入應計利息與規費及一鍵結清本利和

日期: 2026-09-01

## 狀態 (Status)

已接受 (Accepted)

## 背景 (Context)

在借貸與股票質押會計系統中，存在以下會計計算與操作缺陷：
1. **全域 NAV 看板負債低估**：頂部「借款負債」與曝險引擎僅累加借款未還本金（`loan.principal`），未計入質押借款截至今日產生的「應計利息」（`accruedInterest`）與「設質三大規費」（`pledgeFees`），導致全域淨資產（NAV）高估、槓桿負債比（LTV）失真。
2. **缺乏一鍵結清操作**：借貸卡片僅提供個別「繳交利息」與「本金還款」，當投資人欲全額清償或解質時，無法一鍵全額結清「本利和 + 規費」。
3. **流水記帳缺乏自動拆分**：手動結清容易將本金與利息混在一起記帳，影響利息支出扣抵與會計損益核算。

## 決策 (Decision)

1. **全域負債口徑 SSOT 升級**：
   - `calculateOverallLeverageMetrics` 與 `calculatePortfolioExposure` 統一以 `calculateLoanInterestAndPayoff(loan, asOfDate).totalPayoffAmount` 計算每筆借款即時負債（本金 + 應計利息 + 設質規費）。
   - 全域淨資產 $\text{NAV} = \text{股市總值} + \text{可用現金} - \text{總借款負債}$，精準反映清償後真實淨值。
2. **借貸卡片一鍵結清功能 (One-Click Payoff)**：
   - 卡片新增「⚡ 一鍵結清」按鈕，彈窗清晰呈現本金、計息天數、應計利息、設質規費與總額明細。
3. **現金帳本精準自動拆分記帳 (Split Transactions)**：
   - 結清確認後自動於現金帳本產生 3 筆獨立流水：
     - `LOAN_REPAYMENT` (借貸還本)：扣除本金
     - `FINANCING_FEE` (融資利息)：扣除利息
     - `WIRE_FEE` (電匯/規費)：扣除設質三大規費
   - 同步將借款未還本金歸零，更新結息日為當日。

## 後果 (Consequences)

- **正面影響**：
  - 頂部 NAV、借款負債、LTV 與曝險風險評估 100% 同源且精確反映未繳利息與規費。
  - 提供質押解質與全額還款之一鍵結清體驗。
  - 現金帳本自動拆分流水，保持會計損益與稅務稽核完整性。
  - 全系統 388 項單元測試 100% 綠燈，`npm run build` 0 錯誤。
