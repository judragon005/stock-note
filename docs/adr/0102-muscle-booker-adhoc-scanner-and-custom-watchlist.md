# ADR 0102: 肌肉書僮動能雷達任意代碼即時外部回補診斷與自訂觀察清單架構

## 狀態

已接受 (Accepted)

## 決策背景 (Context)

在原先的肌肉書僮動能雷達架構中，標的清單僅限於系統預設之 4 個池子（焦點 Top 30、台股在倉、歷史平倉、權值 Top 50）。搜尋框僅能對這 4 個池內的標的做純記憶體文字過濾，當投資人渴望分析不在既有持股與核心名單中的冷門股、波段題材股或特定美股時，系統查無任何結果，無法發起外部拉取與技術運算。

同時，若僅提供彈窗單檔診斷，每次查詢後關閉即遺失，使用者缺乏追蹤感；若僅提供自選股清單，又增加每次隨手查詢都必須先新增再刪除的操作成本。

## 決策內容 (Decisions)

採用「二合一整合架構：搜尋即時連線診斷 + 內嵌高光卡片 + 一鍵釘選自訂觀察池」：

1. **任意代碼即搜即算 (Ad-hoc Scan Pipeline)**：
   - 搜尋框支援 Enter 快捷觸發或點擊「連線診斷」按鈕。
   - 自動推斷市場代碼（純數字判定為 `TW`，英文字母判定為 `US`）。
   - 複用 `backfillSymbolOhlcvAndIndicators`，先查 IndexedDB 快取，未命中時非同步向 Yahoo Finance 拉取完整日 K 數列並寫入快取，接著由 `scanMuscleBookerItem` 產出雷達資料。
2. **內嵌置頂高光卡片 (Spotlight Card)**：
   - 在導航儀上方展示診斷標的，呈現三色信號、Darvas 箱頂底線、布林壓縮與停損防守價位。
   - 提供「⭐ 釘選至自訂觀察」與「✕ 關閉」按鈕。
3. **自訂觀察清單池 (Custom Watchlist Pool)**：
   - 在 `src/utils/storage.ts` 提供 LocalStorage 持久化儲存 (`STOCK_TRACKER_MUSCLE_BOOKER_WATCHLIST_V1`)，自動去重並標準化。
   - 在標的池中新增「⭐ 自訂觀察 (N)」按鈕，切換時支援管理面板、快速新增與膠囊標籤一鍵移除。
   - 綜合動能監控總表中，每列均加入「⭐ 觀察」快捷按鈕。

## 影響與驗證 (Consequences & Verification)

- **優點**：兼具零摩擦臨時個股查詢與常態自選股清單追蹤；利用 IndexedDB 24hr 快取避免外部 API 頻繁請求。
- **測試**：新增單元測試涵蓋 storage CRUD 與工作區行為，全專案 57 個測試套件、635 項測試 100% 綠燈，TypeScript 構建 0 錯誤。
