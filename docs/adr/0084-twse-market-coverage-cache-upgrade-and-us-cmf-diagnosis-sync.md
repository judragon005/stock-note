# 0084. TWSE 全市場覆蓋驗證、V4 快取升級、美股 CMF 診斷隔離與時序象限動態連動架構決策 (ADR)

## 狀態 (Status)
提議 (Proposed) / 實作中 (In Progress)

## 上下文 (Context)
在籌碼動態星圖實裝後，使用者反饋了台積電 (2330) 法人為 0、美股 VT 出現三大法人進出 0 張之荒謬幻覺文案，以及時序播放時頂部四象限統計指標卡固定不動的瑕疵。

## 決策 (Decision)
1. **快取防污染守門員**：將 IndexedDB 快取前綴自 `TWSE_TPEX_CHIPS_V3_` 推進至 `TWSE_TPEX_CHIPS_V4_`。讀取快取時若發現缺少 `'2330'` 等關鍵上市代碼，判定為殘缺快取並拒絕使用，直接觸發線上雙軌全量拉取。
2. **美股 CMF 診斷絕對隔離**：`getBeginnerDiagnosis` 傳入 `market` 與 `cmf` 參數，美股標的完全阻斷台股法人文本，全面使用大機構吸籌、派發與觀望的大白話生活化說明。
3. **時序全屬性注入**：在 `ChipsWorkspace` 產出 `historicalDailyFlows` 時，美股依時序權重注入動態 `cmf` 與 `netFlowAmount`。
4. **頂部象限即時動態連動**：依據 `currentDateIndex` 重新評估當前影格各標的所在之象限，即時累加產生四象限檔數統計。

## 後果 (Consequences)
- 徹底消除上市股票 0 張之痛點，確保上市上櫃全數就位。
- 美股與台股徹底解耦，杜絕幻覺文案。
- 時序播放器動態連動更加流暢且數值具備 100% 一致性。
