# 0058: 智慧掃描公司行動真實持股對齊、強制重掃狀態重置與精準配息比對架構

## 狀態 (Status)
已採納 (Accepted) - 2026-08-28

## 上下文 (Context)
在智慧掃描公司行動全盲測驗證中，發現三大核心痛點：
1. **基準日持股數失真**：9927 泰銘在倉 10,000 股，在除息時因虛擬時序引擎將未入帳的 2025 歷史減資（28.28%）預扣，被誤算為 7,972 股。
2. **強制重掃狀態凍結與快取死鎖**：點擊「強制清除快取重掃」時進度條未立即清零，畫面卡在完成狀態，且未跳過本機 IndexedDB 快取。
3. **現金股利模糊比對吃掉待補登項目**：同標的 60 天內只要有其他筆配息即認定已入帳，導致手動刪除單季配息後無法重新掃描出待補登項目。

## 決策 (Decision)
1. **基準日持股嚴格對齊使用者帳本真實交易 (SSOT Trades Alignment)**：
   - 基準日持股數（`sharesHeldOnDate`）嚴格依據使用者帳本歷史交易記錄（`trades`）在 `exDate - 1`（Last Cum-Date）收盤在籍股數計算。
   - 廢除對未入帳歷史減資（`CAPITAL_REDUCTION`）的預扣，僅對實質增加股數之配股（`STOCK_DIVIDEND`）與分割（`STOCK_SPLIT`）動態累加股數。
2. **證券法規除息日買進排除標準**：
   - 嚴格遵守全球證券交易法規：除息日（Ex-Date）當天買進之部位不享有該次配息（持股為 0），杜絕 Double Dip 財務假利潤錯誤。
3. **重掃狀態即時重置與 IndexedDB 快取穿透**：
   - 點擊「強制清除快取重掃」時，立即中斷舊任務並將 `progress` 重設為 0 檔 `scanning`，清空已選取項目。
   - 當 `forceRefresh === true` 時，強制跳過 IndexedDB 快取讀取，向線上端點發起全新連線並覆寫本機快取。
4. **現金股利高精準比對**：
   - 取消 60 天模糊比對，改為比對 `exDate`/`payDate`，或在 45 天內同時驗證每股單價與總金額。刪除特定季配息後，重掃 100% 能識別為待補登。

## 後果 (Consequences)
- **正面影響**：
  - 9927 泰銘 2026-10-01 除息基準日持股精確為 10,000 股（預估入帳 NT$ 48,945），與真實帳本 100% 一致。
  - 強制清除快取重掃體驗極為流暢，即時反映掃描進度與穿透最新資料。
  - 支援投資人任意手動刪除並重新一鍵補登除權息，全量 381 個測試 100% 綠燈。
- **負面影響/權衡**：
  - 若歷史交易中存在多年未補登的連續減資，使用者需先手動確認補登前次減資，方能精確影響更後期的除息在倉股數。
