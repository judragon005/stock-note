## 1. 背景與需求動機 (Context & Motivation)

在個人股票投資與交易實戰中，散戶常見的三大痛點為：
1. **看絕對價格判斷貴賤**：缺乏同業相對估值與產業鏈上下游視角，容易把商業模式不同的公司混為一談。
2. **只看營收表象忽略資產負債與現金流背離**：未能及時察覺「營收成長但應收帳款與存貨暴增」之財報警訊，誤踩地雷股。
3. **無劇本與交易紀律**：進場前無目標價、停損價與觀察指標，行情反轉時淪為被動套牢。

為了建立貫穿「商業定性 ➔ 財務定量 ➔ 同業對照 ➔ 風險避雷 ➔ 估值推演 ➔ 籌碼微觀 ➔ 交易紀律」的決策閉環，規劃引入**全市場通用之「7 步個股深度研究框架」**：

| 步驟 | 模組名稱 | 核心核心提問與決策價值 |
| :---: | :--- | :--- |
| **1️⃣** | **商業模式拆解** | 用 500 字白話說明業務、營收來源、主要客戶及產業鏈上下游位置，釐清能力圈邊界。 |
| **2️⃣** | **財報魔鬼細節** | 檢驗最新財報（營收、毛利、營益、EPS、自由現金流、應收/存貨天數），找出 3 大背離異常點防禦地雷。 |
| **3️⃣** | **同業對照** | 橫向對比 2 檔競爭對手之毛利率、營益率、PE、PB、殖利率 5 指標，破除絕對價格偏誤。 |
| **4️⃣** | **市場沒說的事** | 從供應鏈、客戶集中度、匯率、政策 4 個角度剖析市場主流共識下尚未定價的潛在黑天鵝。 |
| **5️⃣** | **情境推演** | 建立未來一年樂觀、中性、悲觀 3 套劇本，推演對應之營收成長、毛利率、EPS 與合理目標價區間。 |
| **6️⃣** | **籌碼解讀** | 解析近 20 日三大法人買賣超、融資餘額、大戶持股比例，研判主力吃貨、洗盤、出貨或籌碼沉澱階段。 |
| **7️⃣** | **投資筆記** | 產出 200 字極簡交易卡：買進理由、目標價、停損價、預計持有週期、3 個跟蹤觀察指標。 |

## 2. 架構設計與功能藍圖 (Architecture & Blueprint)

### 2.1 全市場適用原則 (Universal Market Coverage)
- **不限於在庫持倉**：使用者可對台股 (TW) 或美股 (US) 之任意合法 Symbol（如 `2330`, `NVDA`, `AAPL`）發起深度投研。
- **持倉與動能聯動**：在庫持倉 (`HoldingsTable`) 與動能雷達 (`MuscleBookerWorkspace`) 的每檔標的動作選單中，提供「🔍 7步深度診斷」快捷入口，一鍵帶入代碼與現有持倉數據。

### 2.2 數據裝配層與既有引擎複用 (Data Assembler & Engine Reuse)
系統將自動抓取與裝配本地已掌握之維度數據，減少手動輸入負擔：
1. **即時行情與估值**：複用 `priceFetcher.ts` 自動拉取當前市價、本益比、殖利率。
2. **主力籌碼數據 (台股)**：複用 `smartMoneyFetcher.ts` 自動注入近 20 日三大法人累積買賣超、融資增減狀況。
3. **關鍵技術防線**：複用 `muscleBookerEngine.ts` 自動帶出近 60 日箱底（關鍵防守支撐）與箱頂（突破進攻防線）。
4. **宏觀環境因子**：複用 `macroAdvisorEngine.ts` 提供美元/台幣匯率與無風險利率基準。

### 2.3 零成本提示詞工廠與決策卡持久化 (Dual-Mode Delivery)
為恪守 KISS 原則與隱私安全，採行雙軌交付架構：
- **模式 A（提示詞工廠 - Prompt Factory）**：
  - 支援「分步微調」與「7 步全量投研報告」兩種 Prompt Payload 輸出。
  - 完美相容 ChatGPT、Claude、Gemini、DeepSeek，提供一鍵無損複製。
- **模式 B（200 字投資筆記本地沉澱 - Memo Storage）**：
  - 提供研報成果回填表單（買進理由、目標價、停損價、持有週期、3 大觀察指標）。
  - 將決策卡持久化至 `localStorage` / `IndexedDB`，並於持倉介面提供觸及停損/目標價之紀律預警。
