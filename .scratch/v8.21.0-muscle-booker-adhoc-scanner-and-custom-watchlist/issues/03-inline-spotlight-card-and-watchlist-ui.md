# Issue 03: 內嵌式置頂診斷高光卡片與自訂觀察清單標的池 UI

## 狀態

- 狀態：`CLOSED`
- 負責人：Agent
- 標籤：`ui`, `ux`, `muscle-booker`

## 需求說明

1. 在三色實戰操盤導航儀正上方實作「⚡ 即時診斷標的」高光卡片：
   - 呈現三色燈號徽章、Darvas 箱頂底線、布林帶寬與進出場防守價位。
   - 右上角提供「⭐ 釘選至自訂觀察」與「✕ 關閉」按鈕。
   - 點擊卡片可切換聚焦標的，連動下方 K 線圖與指標時序。
2. 在標的池切換按鈕新增「⭐ 自訂觀察 (N)」：
   - 支援切換至使用者自選清單。
   - 自選池內標的支援一鍵取消釘選/移除。
   - 提供快速輸入框方便批次新增代碼。

## 實作成果

- 已於三色導航儀上方成功置頂渲染 `adHocItem` Spotlight Card，展示三色燈號、達瓦斯箱頂底、布林壓縮與防守停損價位。
- 提供「⭐ 釘選至自訂觀察 / ★ 已在自訂觀察」與「✕ 關閉」按鈕。
- 標的池切換新增「⭐ 自訂觀察 (N)」按鈕，並於池內提供標的名單管理面板、膠囊標籤與一鍵移除按鈕。
- 在綜合動能監控總表中，每列均加入「⭐ 觀察」快捷按鈕。
