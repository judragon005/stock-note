# 02 — ExportDatabaseModal 視口置中遷移與全站 .modal-backdrop 靜態守門

**Parent:** #605 (Spec 0245)

**What to build:** 將系統全態封包匯出確認對話框由未定義之幽靈遮罩樣式遷移至 `ModalShell`，使使用者於頁面任意捲動位置點擊 JSON 匯出皆於螢幕正中央彈出對話框，且匯出執行期間自動啟用 `closeLocked` 防中斷保護；同步於既有架構適應度靜態守門新增不變量，禁止全前端程式碼再出現未定義之 `modal-backdrop` 類別。

**Blocked by:** 01 — 全域視口傳送彈窗原語 (ModalShell) 與互動護欄

**Status:** ready-for-agent

- [ ] 點擊系統全態 JSON 匯出時，對話框固定置中顯示於當前視口，不再退化下沉至頁面尾端文檔流
- [ ] 匯出對話框呈現標準模糊遮罩與毛玻璃容器，支援點擊遮罩與 `Escape` 關閉；點擊立即匯出執行中鎖定關閉
- [ ] 既有安全脫敏備份與完整遷移備份雙軌切換、實體筆數清單與高風險警語行為維持 100% 不變
- [ ] 架構適應度靜態守門新增不變量驗證全前端原始碼零出現未定義之 `modal-backdrop`，且測試 100% 通過
