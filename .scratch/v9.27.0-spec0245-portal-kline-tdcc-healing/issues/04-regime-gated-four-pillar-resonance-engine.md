# 04 — 市場體制閘控四維量價共鳴判讀引擎與 250D 歷史勝率統計

**Parent:** #605 (Spec 0245)

**What to build:** 建立四維量價動能共鳴純函式大腦，複用既有 ADX／布林市場體制狀態機與頂底背離偵測器，針對「成交量（含張／股單位換算與 OBV）、KDJ（含 J 值與日／週共振）、MACD（零軸位階、柱體連擴連縮與背離）、RSI（6/14 交叉與背離）」產出體制加權後之單項診斷、四維多空共鳴裁決、衝突警示、可執行操作建議與失效防線，並統計近 250 日同類訊號後 10 交易日之歷史勝率與均報酬。

**Blocked by:** 03 — 單趟 O(N) KDJ(含 J) / MACD / RSI(6·14) 序列引擎與盤中零量定錨隔離

**Status:** ready-for-agent

- [ ] 依據市場體制（強多主升 / 空頭主跌 / 震盪盤整 / 布林壓縮）動態標示主導權重指標，盤整盤顯式調降趨勢指標權重、主升段提示高檔鈍化勿輕易逆勢摸頭
- [ ] 完整輸出四維結構化診斷物件：成交量（台股換算為張、美股為股、5D/20D 量比、OBV 與量價型態）、KDJ（含 J 值與日週共振）、MACD（零軸上下、柱體趨勢與頂底背離）、RSI（6/14 與背離）
- [ ] 四維指標出現明顯矛盾（如均線／MACD 偏多但量縮或頂背離）時觸發衝突警戒並產出保守修正建議與明確失效防線
- [ ] 統計近 250 日同類關鍵訊號觸發後 10 日勝率與平均報酬；當樣本數小於 3 次時誠實輸出樣本不足狀態，絕不偽造勝率
- [ ] 盤中零量場景下，量能磚精準採用前收定錨日數值並附帶明確文字標註，不誤觸「窒息量縮」假訊號
