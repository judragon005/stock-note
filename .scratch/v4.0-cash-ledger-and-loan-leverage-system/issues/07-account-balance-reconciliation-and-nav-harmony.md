# 任務 07: 交割戶真實現金餘額一鍵校正與全站 NAV 精準對齊機制

- **狀態**: Completed (已完成)
- **類型**: Feature / UX
- **優先級**: P0

## 任務描述
解決「歷史買進交割款將現金扣成負數並吃掉持股市值」的問題。提供各券商交割戶「✏️ 校正/輸入真實現金」彈窗，使用者輸入當前實際交割銀行餘額後，系統自動回推差額並補登初始入金 (`DEPOSIT`)，使現金餘額歸正且全域 NAV 立即與庫存總市值精準對齊。

## 驗收標準 (Acceptance Criteria)
- [x] 實作 `reconcileAccountBalance` 核心純函式，依目標真實現金與當前系統計算結餘自動推算應補登之入金金額。
- [x] 在 `CashLedgerWorkspace` 的帳戶卡片新增「✏️ 校正/輸入真實現金」快捷按鈕。
- [x] 提供 `ReconcileModal` 彈窗，即時展示當前結餘、輸入框、預估補登入金與起算基準日。
- [x] 確認校正後自動產生 `DEPOSIT` 流水，可用現金餘額立即更新，全域 NAV 立即與持股市值對齊。
- [x] 單元測試覆蓋並通過 100%。
