## What to build
作為使用者介面與端到端操作閉環層，本切片提供：
1. **戰情室緊湊型條列 UI (`WarRoomPromptCard.tsx`)**：
   - 頂部一覽橫幅：展示共識防線點位或分歧度提醒，並具備「全隊一鍵結案」按鈕。
   - 緊湊條列清單：每行約 38px 高度，整合模型小標籤、核心裁決、停損/停利/翻多點位、剩餘天數與單卡獨立結案按鈕（WIN / LOSS / EXPIRED）及刪除按鈕。
   - 貼入覆蓋時具有平滑過渡微高亮動畫，提示更新成功。
2. **貼入回流彈窗與剪貼簿適配**：
   - 「📋 貼入外部 AI 裁決」按鈕支援一鍵讀取剪貼簿或彈窗手動貼上。
   - 若文字中包含單一或多個 AI JSON 代碼區塊，自動執行批次解析並逐一覆蓋/新增入庫。
3. **全員一鍵結案連動**：
   - 點擊「全隊結案」時彈出極簡確認，可將當前標的所有有效模型同時依最新市價結算或標註 EXPIRED，批次記入勝率榜並清空該標的釘選。

## Acceptance criteria
- [ ] 釘選多個 AI 模型時，縱向排版維持緊湊，不影響上方技術指標視圖。
- [ ] 支援單卡獨立結案與全隊一鍵結案，勝率抽屜內能即時反映最新統計結果。
- [ ] 透過剪貼簿或輸入框貼入多模型代碼區塊能一次全部生效。
- [ ] 既有與新增之 React 元件單元測試及 E2E 測試 100% 通過，TypeScript 0 報錯。
