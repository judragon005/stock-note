# 05 — 跨券商庫存對賬審計互動對話框 (Reconciliation Modal UI)

**What to build:**
在持倉管理視圖頂部提供「📑 跨券商對賬審計」按鈕，點擊後彈出現代毛玻璃對話框。使用者可於多行文字框直接貼上券商持倉或點擊匯入檔案，系統即時動態比對並以四色標籤卡片展示結果（綠色吻合、黃色股數差異、藍色系統遺漏、灰色多餘）。針對差異項目，提供一鍵「產生調整單」按鈕；針對同日零股拆合項目，提供一鍵「合併消解」按鈕，並於操作後彈出 Toast 提示更新。

**Blocked by:** 
- 03 — 同日零股分批拆合智能匹配器 (Same-Day Multi-Lot Fuzzy Matcher)
- 04 — 無損審計調整單分錄生成與會計相容機制 (Non-Destructive ADJUSTMENT Trade Entry)

- [ ] 四色對賬狀態卡片清晰展示標的代碼、系統股數、券商實際股數與差異值
