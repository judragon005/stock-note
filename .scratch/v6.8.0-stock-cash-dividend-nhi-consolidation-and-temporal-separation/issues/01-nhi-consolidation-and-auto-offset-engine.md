# 01 — 二代健保配股配息合併試算與代扣引擎 (NHI Consolidation & Auto-Offset Engine)

**What to build:** 
實作二代健保補充保費合併計算核心：當同一次除權除息事件同時分派現金股利與股票股利時，系統自動將「現金股利毛額 + (股票股利獲配股數 × 10 元法定面額)」計入單次給付總額。若總額達 20,000 元門檻，以 2.11% 精算補充保費，並將該補充保費全額自現金股利的應收淨額中代扣，股票股利則以零成本入庫。

**Blocked by:** None — can start immediately.

**Status:** RESOLVED

- [x] 提供合併計算函式，支援傳入每股現金股息、每股股票股利與持有股數，產出給付總額、是否觸發門檻、補充保費金額與實收現金淨額。
- [x] 針對永豐金持有 31,000 股、配息 1.1 元、配股 0.2 元之情境，驗收產出給付總額 40,300 元、二代健保 850 元、實收 33,250 元與 620 股零成本配股。
- [x] 整合至全域稅階預警與摩擦成本統計 (`totalTWDividendTax`) 中。
- [x] 單元測試覆蓋率 100% 且通過測試。
