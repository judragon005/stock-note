# 04 — 智慧掃描關聯除權除息事件配對與雙發放日排程草稿 (Smart Scanner Linked Actions & Dual Pay-Dates Drafts)

**What to build:** 
升級公司行動智慧掃描引擎：當抓取到同標的同一除權除息基準日之配息與配股事件時，自動關聯為同一組合，試算合併給付所得與二代健保補充保費，並產出具備雙發放日期（現金發放日與配股發放日）的排程草稿卡片，支援一鍵預約或排程自動入帳。

**Blocked by:** 01 — 二代健保配股配息合併試算與代扣引擎, 02 — 待入帳配股擴充與持倉未實現損益平滑, 03 — 歷史帳本與現金帳戶之發放日精準入帳連動

**Status:** RESOLVED

- [x] 智慧掃描引擎支援識別與配對同日除權息之 `DIVIDEND` 與 `STOCK_DIVIDEND`。
- [x] 掃描結果彈窗呈現關聯卡片，清晰標示現金預計入帳日、股票預計入庫日與合併健保費試算。
- [x] 現金股利草稿自動代入 $34,100 毛額與 $850 健保代扣，淨額 $33,250；股票股利草稿自動代入 $620 股。
- [x] 支援一鍵套用與批次儲存至 IndexedDB 公司行動庫。
- [x] 單元測試與 UI 流程測試 100% 通過。
