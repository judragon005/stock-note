# 03 — 歷史帳本與現金帳戶之發放日精準入帳連動 (Temporal Separation & Ledger-Cash Sync)

**What to build:** 
實作三階段時間軸分離入帳機制：交易帳本中 `DIVIDEND` 紀錄以 `cashPayDate` 為記錄日並連動現金帳戶入帳；`STOCK_DIVIDEND` 紀錄以 `stockPayDate` 為記錄日並正式增加在庫庫存股數。發放日之前庫存與現金帳戶維持原樣，由待入帳平滑模組接管；發放日當天自動或手動確認轉為實體交易。

**Blocked by:** 01 — 二代健保配股配息合併試算與代扣引擎, 02 — 待入帳配股擴充與持倉未實現損益平滑

**Status:** RESOLVED

- [x] 交易帳本寫入 `DIVIDEND` 時，現金帳戶自動認列 `實收金額 (淨額)` 流入，且可追蹤毛額與健保扣除費。
- [x] 交易帳本寫入 `STOCK_DIVIDEND` 時，在席庫存於 `stockPayDate` 當天起正式增加配股股數（永豐金 31,000 ➔ 31,620 股），零成本平滑稀釋均價。
- [x] 驗證現金帳戶餘額與銀行存摺實收 33,250 元完全一致。
- [x] 單元測試與整合測試 100% 通過。
