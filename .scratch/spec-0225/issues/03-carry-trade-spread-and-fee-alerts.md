# 03 — 質押借貸淨利差 (Carry Spread) 與累計匯費警報模組

**What to build:**
串接 `cashLedgerEngine.ts`，為開槓桿質押存股族計算實質淨利差現金流（實領股息 - 借貸利息支出），並彙總跨行匯費總損耗，對單筆配息 < NT$ 500 遭扣 NT$ 10 匯費的標的發出摩擦損耗警報。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 串接帳本利息支出，提供淨利差現金流純函數計算與展示格式化。
- [ ] 統計年度/歷史跨行匯費總額，並針對小額配息（< 500 元且匯費 >= 10 元）標記警示。
- [ ] 單元測試驗證無借貸利息、利息大於股息（負利差）及匯費摩擦門檻。
