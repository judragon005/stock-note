# 02 — YOC (成本殖利率) 與實質填息/貼息標籤計算模組

**What to build:**
為存股投資人建立長抱心智模型：計算 Yield on Cost (YOC，成本殖利率 = 年度配息 / 持倉成本)，並判定除息標的是否「實質填息」或「貼息中/本金返還」，避免領了股息卻賠了本金的盲點。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 提供純函數計算各標的之 YOC (成本殖利率)，支援單期與全期間換算。
- [ ] 比對目前市價與除息前基準價，輸出 `[實質填息]` 或 `[貼息中]` 狀態標籤。
- [ ] 單元測試驗證零成本、虧損、正常獲利與多幣別邊界情況。
