# 02 — 毛利成長率離群值視覺封頂防禦演算法 (Gross Profit Outlier Visual Capping)

**What to build:**
當企業出現極端季度低基期反轉（例如台泥 2023Q2 毛利爆發 +5326.2%）時，圖表既要保留真實數據的文字呈現與警告標籤，又要避免巨額離群值將其餘正常季度的柱狀圖壓成地平線死線。非極端季度的起伏高度應正常展開（最高柱至少佔圖表高度 50% 以上）。

**Blocked by:** 01 — 成長率基期擴充與缺失基期平整化 (Growth Baseline Expansion & Flattener)

**Status:** ready-for-agent

- [x] 在成長率柱狀圖中實作離群值判定：當極端值超過其他季度最大值之 3 倍且數值大於 100% 時，啟動視覺封頂
- [x] 圖表頂部刻度以非離群季度之最大值為比例基準，確保正常季度柱狀高度顯著起伏
- [x] 極端值柱狀圖視覺高度封頂於 100%，並附加 `⚡` 特殊樣式與 `(低基期暴增)` 說明標註
- [x] 通過審計單元測試，驗證正常季度柱高佔比達標且極端數據不遺失
