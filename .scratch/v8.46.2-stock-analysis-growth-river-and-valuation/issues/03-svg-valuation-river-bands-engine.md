# 03 — 真實 SVG 估值河流圖色帶引擎 (SVG Valuation River Bands Engine)

**What to build:**
將原先僅有寫死 18% 藍色區塊的河流圖，替換為動態真實繪製的向量 SVG 估值河流圖。以歷季本益比 (PE) 或本淨比 (PB) 倍數走勢結合股價，繪製出 4 層漸層多邊形色帶（`<polygon>`）、5 條通道輪廓線、最新現價走勢線以及最新落點脈衝發光點與估值位階評級標籤。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [x] 繪製 4 階半透明漸層色帶與 5 條通道邊界線（低估、合理偏低、合理、合理偏高、高估）
- [x] 繪製股價實體走勢線與最新一季現價脈衝指示圈，並標示即時價位與估值倍數
