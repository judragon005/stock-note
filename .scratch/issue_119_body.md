## 規格與背景說明

依據 [Spec 0119: 質押借貸還款繳息按鈕整併、籌碼日報優雅降級與聰明錢動能優化規格書](docs/specs/0119-pledge-unified-repayment-and-smart-money-resilience-spec.md)，本次迭代落實三大金融實務與視覺化決策優化：

1. **質押借貸還款操作單一化**：
   - 將質押借貸卡片底部的「💰 繳息」與「💳 還本」兩個按鈕合併為單一「💳 還款 / 繳息」按鈕（保留「⚡ 一鍵結清」）。
   - 彈窗提供「帶入本期利息」與「帶入本息總額」快捷按鈕，依民法 323 條法定順序自動折抵費用、利息與本金，並支援自訂還款日期。
2. **籌碼日報多維哨兵校驗與優雅降級 (修復假 0 張 Bug)**：
   - 解決 15:30 盤後證交所 API 數據未齊全（全市場僅 894 檔、或強茂 2481 等個股三大法人全為 0 張）時誤判為「今日已同步完畢」的假陽性 Bug。
   - 引入多維哨兵校驗：全市場檔數門檻（$\ge 1,500$ 檔）與活躍法人交易量檢驗。
   - 未通過驗證時自動優雅回退 T-1 完整日報，頂部狀態燈號以黃燈誠實提示，消除平躺 0 張氣泡。
3. **歷史籌碼膠囊轉型與動能週期切換 (1D / 3D / 5D)**：
   - 移除無反饋的靜態「歷史籌碼 (5)」膠囊，升級為動能時間窗切換鈕。
   - 實作多日法人買賣超累加聚合引擎，過濾隔日沖雜訊。
4. **聰明錢動能決策信號**：
   - 產出「🟢 法人聯手搶買（可以買）」與「🔴 主力大舉提款（一定要閃）」決策榜單與持倉診斷徽章。

## 驗收標準 (Acceptance Criteria)

- [ ] `isInstitutionalReportComplete` 哨兵能正確攔截半殘日報（如 894 檔），並自動降級回退 T-1 完整日報。
- [ ] 質押借貸卡片僅保留「💳 還款 / 繳息」與「⚡ 一鍵結清」按鈕，彈窗快捷帶入利息與本利和計算正確。
- [ ] 籌碼星圖支援 1D / 3D / 5D 動能時間窗切換，法人張數累加計算精確無誤。
- [ ] `npm test` 全量單元測試 100% 綠燈，`npm run build` TypeScript 0 錯誤。
