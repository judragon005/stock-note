     - 看板維持常駐顯示。

     - Alpha 與 Beta 卡片數值顯示「無對應」，副標提示「需設定大盤基準」。
     - Sharpe、自身 MDD 與年化波動度顯示自身實時數據。
   - 有基準時：5 大指標全量聯動對照基準。
