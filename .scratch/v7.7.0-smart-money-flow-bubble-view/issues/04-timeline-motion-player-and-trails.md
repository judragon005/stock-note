# 04 — 歷史時序播放器與彗星位移軌跡 (Timeline Motion Player & Trails)

**What to build:**
建構時間軸播放器與泡泡動態移動軌跡系統：
1. 底部播放控制面板：提供「播放/暫停」按鈕、播放速度開關 (1x/2x) 以及日期進度滑桿。
2. 泡泡位移過渡：運用 CSS `transform` 與平滑動態效果，並渲染過去 5~20 個交易日的半透明淡出彗星尾巴（Motion Trails）。
3. 頂部雙模式切換器：支援【我的在庫持倉 (My Portfolio)】與【全市場法人焦點 Top 30 (Market Movers)】切換。
4. 點選泡泡聚焦聯動：點擊特定泡泡時高亮並突出顯示該標的的完整時序位移路徑。

**Blocked by:** 02 — 官方資料管線與本地快取降級, 03 — 原生 SVG 泡泡圖與小白三秒速讀四象限視圖
