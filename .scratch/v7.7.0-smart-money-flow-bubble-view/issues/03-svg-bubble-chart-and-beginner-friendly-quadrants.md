# 03 — 原生 SVG 泡泡圖與小白三秒速讀四象限視圖 (SVG Bubble Chart & Beginner-Friendly Quadrants)

**What to build:**
建構專為初學者設計的原生輕量 SVG 動態泡泡圖元件：
1. 0 額外龐大圖表庫依賴，使用純 React + SVG 渲染四象限畫布（深色玻璃擬態風格）。
2. 頂部常駐可展開/折疊之「💡 3 秒新手速讀指南」，以大白話圖文解釋泡泡大小、顏色與象限意涵。
3. 泡泡屬性映射：半徑對應持倉市值或成交量；色彩連動全專案「慣用紅綠主題」（外資投信合買亮多頭光暈、雙主力倒貨亮空頭警示）。
4. 懸浮 Tooltip 浮窗：頂部以顯眼粗體第一眼呈現人類直白診斷結論，下方展開買賣超張數與成交金額。
