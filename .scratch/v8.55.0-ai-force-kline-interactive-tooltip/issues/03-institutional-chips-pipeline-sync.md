# 03 — 三大法人歷史進出資料管線與 08 法人計量 / 15 籌碼異動卡片動態連動

**What to build:** 輸入任意台股時，資料管線抓取真實三大法人（外資、投信、自營商）歷史買賣超張數，動態繪製 08 法人行為計量雙軸柱狀圖與近 3 日明細表，並驅動 15 籌碼異動微型走勢圖與法人累積進出張數。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 外資、投信、自營商買賣超柱狀圖依真實歷史繪製（買超紅、賣超綠/藍），雙軸累積折線同步連動。
- [ ] 15 籌碼異動 Sparkline 折線圖繪製真實歷史趨勢，數值與 08 卡片一致。
- [ ] 離線或無法人資料時安全退回模擬中繼資料，不發生介面閃退。
