## 變更摘要 (Change Summary)

依據 [Spec 0119](docs/specs/0119-pledge-unified-repayment-and-smart-money-resilience-spec.md)，本次迭代落實三大金融實務與視覺化決策優化：

1. **質押借貸「還款/繳息」按鈕單一化**：
   - 將卡片底部「💰 繳息」與「💳 還本」整併為單一「💳 還款 / 繳息」按鈕（保留「⚡ 一鍵結清」）。
   - 彈窗新增「帶入本期利息」與「帶入本息總額」一鍵快捷鍵，全數統一經由法定沖償引擎 `applyDebtRepayment` 依民法 323 條（規費 ➔ 利息 ➔ 本金）進行拆分與更新。
2. **多維哨兵與優雅降級 (修復強茂全 0 張假同步 Bug)**：
   - 實作 `isInstitutionalReportComplete`，導入全市場檔數門檻（$\ge 1500$ 檔，若 $< 1200$ 檔判定為未齊全殘缺日報）與前 50 大活躍法人買賣超非零驗證。
   - 當日數據未齊全時自動降級回退 T-1 日報，不污染當日快取，頂部以黃燈誠實提示 `🟡 盤後結算中：暫呈 09/10 完整日報 (共 1,894 檔)`，徹底消除氣泡在 0 軸線平躺假象。
3. **歷史籌碼膠囊升級為「動能時間窗 (1D/3D/5D)」**：
   - 移除無操作反饋的靜態 `💾 歷史籌碼 (5)` 徽章，升級為可點選切換的 `[1日 (當日)]` / `[3日 (短波段)]` / `[5日 (週籌碼)]` 膠囊按鈕列。
   - 實作多日法人買賣超累加計算器 `chipsAggregator.ts`，過濾隔日沖雜訊。
4. **聰明錢動態決策快報折疊看板**：
   - 🟢 **【法人聯手搶買榜（可以買）】**：外資 + 投信雙法人認養前 4 檔標的。
   - 🔴 **【主力大舉提款榜（一定要閃）】**：主力大舉提款前 4 檔出逃標的。
   - 讓使用者 3 秒內一眼掌握聰明錢去向。
