# 01 — 核心三軌色彩認知體系重構、燈號邏輯校正與指標膠囊正則修復

**Parent Issue:** #214

**What to build:**
重構 `getVerbBadgeColor` 與右側狀態燈號判定，解決「低接吸籌」色彩判定斷層與矛盾問題：
1. 將「低接吸籌」色彩映射至科技藍 `#38bdf8`（軌道二：吸籌蓄勢），右側狀態文字由原本錯誤的「防禦觀望」校正為「● 偏多承接」。
2. 對齊三軌認知色彩體系：
   - 軌道一（多頭攻擊）：`#ef4444`（鎖碼推升 / 強勢續抱），燈號「● 偏多集結」。
   - 軌道二（吸籌蓄勢 / 超跌轉折）：`#38bdf8`（低接吸籌 ➔「● 偏多承接」）、`#c084fc`（超跌反彈 ➔「● 跌深反抽」）。
   - 軌道三（風險警戒 / 盤整中性）：`#f59e0b`（調節減碼 / 高檔出貨 ➔「● 區間警戒」）、`#94a3b8`（區間觀望 / 洗盤整理 ➔「● 空手觀望」）。
3. 重構 `parseVerdictMetrics` 正則表達式，完整支援現行量化結論格式：
   - 最新收盤價：`最新收盤價\s*([\d,]+(?:\.\d+)?)\s*元` ➔ 標籤「最新收盤價」。
   - 20日 VWAP：`20\s*日\s*VWAP\s*主力成本\s*\(([\d,]+(?:\.\d+)?)\s*元\)` ➔ 標籤「20日VWAP」。
   - 成本乖離率：`乖離\s*([+-]?\d+(?:\.\d+)?%)` ➔ 標籤「成本乖離率」。
   - 向下相容支援 `法人近 5 日合計` 與 `RSI` 舊版字串。
4. 擴充單元測試驗證色彩與正則解析。
